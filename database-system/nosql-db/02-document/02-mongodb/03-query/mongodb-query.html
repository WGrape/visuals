🔍 MongoDB 查询与聚合

CRUD、过滤与聚合管道

基本查询

查询用查询文档表达条件：{status: "A"}、{age: {$gt: 18}}、{tags: {$in: [...]}}。投影控制返回字段，sort/limit/skip 控制分页。

聚合管道（Aggregation Pipeline）

聚合是『多阶段流水线』：每个阶段（$match、$group、$project、$lookup…）把上一步结果加工后传给下一步，类似 Unix 管道。

💡 $lookup 可实现跨集合『类 JOIN』，但跨分片 $lookup 成本高，能用嵌入式就别用引用。
