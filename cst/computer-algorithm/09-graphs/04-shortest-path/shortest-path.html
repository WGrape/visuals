最短路径

从一张城市的路网里，找到从起点到所有终点「走得最近」的路线。这背后是计算机最常被使用的算法家族之一。

一、问题：什么是「单源最短路」

给定一个带权图（边上有数值，表示距离/时间/成本）和一个起点 s，单源最短路径要求算出 s 到每个节点的最少代价。最短路不一定边数最少，而是权值之和最小。

类比：把图想成地铁线网，边权是站间耗时，最短路径就是「从我家出发，换乘最少时间到达任意目的地」的最优方案。

二、Dijkstra：贪心 + 优先队列

Dijkstra 是处理非负权最短路的经典算法。它维护一个「已确定最短距离」的集合，每一步从「还未确定」的节点里挑当前估计距离最小的那一个，把它确定下来，再用它去「松弛（relax）」邻居——如果「经过我到你」比「你原来的估计」更短，就更新。

为什么要求非负权？因为一旦出现负权，刚被「确定」的节点可能被后面更短的负路径推翻，贪心保证就失效了。
def dijkstra(graph, s):
    dist = {u: inf for u in graph}; dist[s] = 0
    pq = [(0, s)]                       # 优先队列：最小代价优先
    while pq:
        d, u = heappop(pq)
        if d > dist[u]: continue        # 过期条目，跳过
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:    # 松弛
                dist[v] = dist[u] + w
                heappush(pq, (dist[v], v))
    return dist

三、Bellman-Ford 与 Floyd-Warshall

Bellman-Ford

允许负权边，反复对所有边「松弛」V−1 轮。第 V 轮若还能更新，说明存在负权环，此时最短路无定义。

Floyd-Warshall

求全源最短路（任意两点间）。动态规划思想：枚举中转点 k，尝试 dist[i][j] = min(dist[i][j], dist[i][k]+dist[k][j])。复杂度 O(V³)。

选错算法，比不会算法更糟

最短路问题有四种典型形态：无权图用 BFS；非负权单源用 Dijkstra；含负权用 Bellman-Ford；全源小规模用 Floyd。选错不仅变慢，还可能得到错误答案（比如把 Dijkstra 用在含负边的图上）。这一页把边界讲清楚。

Dijkstra 深入与工程要点

① 为什么负权会失效

  • Dijkstra 的核心是「已出队的点距离不再变」——这个性质由非负权保证。
  • 有负边时，一条经过负边的路径可能在「之后」才被发现，已确定的结果会被推翻。
  • Bellman-Ford 用「对所有边松弛 V-1 轮」来保证正确性，代价是慢。
  • 若只是需要「无负环图 + 负权」，可以先用 Bellman-Ford，或考虑 Johnson 重赋权。

② 堆优化的实现细节

  • 优先队列存 (距离, 点)，支持 decrease-key 或采用「懒惰删除」。
  • 懒惰删除：同一节点多次入堆，出堆时若距离已过期就跳过（实现更简单）。
  • visited 标记：第一次出队即最短，之后跳过。
  • 提前终止：只求到某终点的最短距离时，终点出队即可停止。

③ 路径还原

  • 维护 parent 数组：松弛成功时记录前驱。
  • 从终点沿 parent 回溯到起点，再反转。
  • 多条最短路时要明确 tie-breaking 规则，否则结果不稳定。

④ 常见优化与变体

  • 分层图：把「用了几次特殊机会」作为状态维度，解决带约束最短路。
  • 双向 Dijkstra：从起点与终点同时搜索，适合点到点查询。
  • 约束搜索（Contraction Hierarchies、ALT）：真实地图导航的工业方案。
  • 多次查询：考虑 Floyd 预处理或全源缓存，权衡预处理与查询成本。

深入自检

Dijkstra 一定能得到最短路吗？

在所有边权非负的前提下一定可以。它的正确性依赖贪心性质：每次取当前距离最小的未确定节点，由于后续路径只会增加权重，不可能再出现更短的更新，所以该点距离可永久确定。有负权时这个论证不成立。

有负权但没有负环，用什么算法？

Bellman-Ford（或 SPFA）可以正确处理，它对所有边松弛 V-1 轮，能覆盖任何长度的最短路径。若需要全源且图稀疏，可以用 Johnson 算法：先用 Bellman-Ford 重赋权消除负边，再对每个点跑 Dijkstra。

什么是负环，为什么它是「无解」？

负环是总权重为负的环，沿着它绕圈距离会不断减小，可以无限小，因此最短路径没有定义（是 -∞）。实际含义可能是「套利机会」「逻辑矛盾」。Bellman-Ford 在第 V 轮若仍能松弛，就说明存在负环。

BFS 能用于带权图吗？

不能直接用于任意权：BFS 按「边数」分层，而带权图要按「累计权重」排序。但有两种情况可以：一是所有边权相同（等价于无权）；二是用 0-1 BFS（边权只有 0 和 1，用双端队列），或 Dial's algorithm（小整数权重，用桶）。

A* 一定比 Dijkstra 快吗？

不一定，取决于启发函数。若启发函数可采纳（不高估真实距离）且一致性好，A* 能显著减少扩展节点数；若启发函数质量差（接近 0），A* 就退化成 Dijkstra 并多出计算启发的开销。启发函数越强（越接近真实值且不超估），加速越明显。

工程上做地图导航用什么？

真实导航不用裸 Dijkstra/A*，而是预处理 + 查询的两段式：Contraction Hierarchies（收缩层次）、ALT（地标 + 三角不等式）、Hub Labeling 等，能在毫秒级完成大洲级路网查询。核心思想是把计算量前置到离线预处理，用空间换查询时间。
