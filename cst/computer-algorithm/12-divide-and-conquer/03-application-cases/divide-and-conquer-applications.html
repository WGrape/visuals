第 12 章 · 分治

在合并步骤里顺手拿到答案

逆序对用归并时统计、第 k 大用快速选择做到平均线性、最大子数组必须穷尽跨中点情况、快速幂把指数二分。

逆序对计数：归并时顺手统计

逆序对是满足 i < j 且 a[i] > a[j] 的数对。暴力 O(n²)，用归并排序可以在合并时统计：

def count_inversions(a):
    def sort_and_count(arr):
        if len(arr) <= 1: return arr, 0
        m = len(arr) // 2
        L, c1 = sort_and_count(arr[:m])
        R, c2 = sort_and_count(arr[m:])
        i = j = 0; out = []; cross = 0
        while i < len(L) and j < len(R):
            if L[i] <= R[j]:
                out.append(L[i]); i += 1
            else:
                out.append(R[j]); j += 1
                cross += len(L) - i   # L 中剩下的都比 R[j] 大
        return out + L[i:] + R[j:], c1 + c2 + cross
    return sort_and_count(a)[1]
左边 [3,5]，右边 [1,4]。取 1 时左边剩 [3,5] 两个都比 1 大 → 贡献 2 个逆序对 (3,1)、(5,1)。取 4 时左边剩 [5] → 贡献 1 个 (5,4)。

为什么可以这样数？因为左右各自已经有序，一旦 L[i] > R[j]，L 中 i 之后的所有元素都 > R[j]，所以能一次加一整段，而不是逐个比较。

快速选择：平均线性的第 k 大

找第 k 大不必排完整个数组。快排的划分把数组分成「> 基准」和「≤ 基准」两块，只递归进入包含第 k 大的那一块：

def quick_select(a, k):            # k 从 0 开始
    lo, hi = 0, len(a) - 1
    while lo < hi:
        p = partition(a, lo, hi)      # 随机基准 + 三路划分更稳
        if k < p:   hi = p - 1
        elif k > p: lo = p + 1
        else:       return a[k]
    return a[lo]
  • 平均：T(n) = T(n/2) + Θ(n) → Θ(n)（等比数列求和）。
  • 最坏：Θ(n²)，靠随机化基准规避；需要严格保证时用 BFPRT（中位数的中位数）。

最大子数组：跨中点的第三种情况

最大连续子段和分三种情况：完全在左边、完全在右边、跨越中点。前两种递归求解，第三种只需从中点向左扫出最大后缀和、向右扫出最大前缀和，相加即可——线性。

总复杂度仍是 2T(n/2) + Θ(n) = Θ(n log n)。

实际工程里 Kadane 算法是 O(n) 且更简洁，但分治版本是理解「三种情况必须穷尽」的经典范例——很多分治正确性错误就出在漏掉跨分界线的情形。

快速幂：指数上的二分

算 an：若 n 为偶数则 an = (an/2)²，若为奇数则再乘一个 a。递归深度 log n，总复杂度 Θ(log n)。

def fast_pow(a, n, mod=None):
    res, base = 1, a
    while n:
        if n & 1: res = res * base
        base = base * base         # a, a^2, a^4, a^8 ...
        n >>= 1
        if mod: res %= mod; base %= mod
    return res

它本质上是在指数上做二进制分解，因此也叫二进制幂。矩阵快速幂是同一个思路，能把线性递推（如斐波那契）的第 n 项压到 O(log n)。

分治与动态规划的分界

特征分治动态规划
子问题是否重叠不重叠，各自独立大量重叠，需记忆化
递归树形态树（每层规模减半）有向无环图（重复节点）
典型例子归并排序、快速选择、快速幂背包、LCS、区间 DP
复杂度来源树高 × 合并代价状态数 × 转移代价

分治写成递归却出现重复计算（如朴素斐波那契 T(n)=T(n−1)+T(n−2)）时，复杂度是指数级，这时候它已经不是分治问题，而是动态规划问题。
