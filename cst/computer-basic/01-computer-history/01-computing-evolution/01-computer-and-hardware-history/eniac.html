ENIAC：用 18000 只真空管造出的巨兽

1943 – 1946，宾夕法尼亚大学。真空管时代的巅峰，也是它的绝唱。

🏛️ 它是谁？

ENIAC（电子数值积分计算机），由莫奇利和埃克特团队在美国军方资助下建造，最初用于计算炮弹弹道。1946 年正式启用，是世界上第一台通用电子计算机——在此之前，机器要么只能算特定问题，要么根本不用电子元件。

📊 震撼的数字

  • 18000 只真空管 + 70000 只电阻 + 10000 只电容
  • 占地约 170 平方米，重达 30 吨
  • 功耗约 150 千瓦——据说开机时周边街区灯光都会变暗
  • 每秒可做 5000 次加法（比人快 5000 倍，比继电器快上千倍）
ENIAC：真空管计算机的巅峰巨兽

ENIAC 的两大「先天缺陷」

🔢 缺陷一：居然用十进制

ENIAC 用十进制计数（每个数字用 10 只真空管表示 0-9），而不是二进制。原因很朴素：设计团队最初只想做一台「超级计算器」给军方算弹道，没想过逻辑门和通用计算。结果是浪费了真空管——二进制本可以把同样的管子数量变成更大的计算能力。

🔌 缺陷二：没有「存储程序」

ENIAC 的「程序」是插线板 + 旋钮开关：工程师把几千条线插到不同的插座上，拨好开关，机器才会按固定步骤运行。换一个计算任务，就要重新插拔接线、耗时数天。这正好把「图灵机把程序当数据」的思想逼上了台面——下一章的主角因此登场。

💡 一个常被误解的点

ENIAC 不是「第一台计算机」，而是第一台通用电子计算机。图灵机的抽象更早（1936），阿塔纳索夫-贝瑞计算机（ABC，1942）等电子机器也更早但不可编程通用。ENIAC 的独特地位在于：通用 + 电子 + 可编程——它第一次让人们相信，电子计算机可以取代人做海量计算。

# 想亲身感受一次「每秒 5000 次加法」是什么水平，跑一下这个
import time

N = 5_000                    # ENIAC 一秒钟的加法量
t0 = time.perf_counter()
s = 0
for i in range(N):
    s += i
elapsed = time.perf_counter() - t0
print(f'{N} 次加法耗时 {elapsed*1000:.3f} ms')
# 典型结果：不到 1 毫秒 —— 现代机器跑完 ENIAC 一秒的工作量，用不了千分之一秒
# 再换算：现代机器 1 秒 ≈ ENIAC 连续跑数天到数年

# 换个角度：内存容量的差距
eniac_words = 20                       # 20 个累加器
pc_bytes    = 16 * 1024**3             # 16 GB
print(f'内存容量倍数 ≈ {pc_bytes / (eniac_words * 10 / 8) / 1e8:.1f} 亿倍')

ENIAC 最该记住的一点不是参数，而是编程方式：改一道题要重新插线、拨开关，耗时数天。这正是「存储程序」诞生的直接动因 —— 把程序也放进内存，改程序就只是改数据。

第三层 · 关于 ENIAC 的五个常见误解

  • 误解：它是第一台计算机：更早有 ABC、Z3、Colossus 等；ENIAC 是第一台通用电子数字计算机之一，要看限定词。
  • 误解：它用的是二进制：ENIAC 内部用的是十进制环形计数器，这也是它管子数量巨大的原因之一。
  • 误解：它是冯诺依曼结构：ENIAC 不是存储程序机器，EDVAC 才是；冯诺依曼的贡献在后续的报告与结构。
  • 误解：它不可靠所以没用：真空管确实频繁损坏，但它稳定运行了近十年，完成了弹道计算等实际任务。
  • 误解：发明者只有两个人：ENIAC 是团队成果，且为它编程的几位女性程序员长期被忽视，后来才被追认。

记忆锚点：ENIAC = 电子 + 通用 + 可编程（靠插线），缺的是「存储程序」这最后一块，那块由 EDVAC 补上。

第四层 · 它为什么重要

为什么说它开启了电子计算时代？

因为它证明了一件事：用电子速度做通用计算是可行的。在此之前最快的计算设备是机电式的（继电器），速度差了几个数量级。

它和后来的机器差别最大的是哪一点？

编程方式。ENIAC 的程序在硬件连线里，后来的机器程序在内存里。这一步跨越让软件成为一个独立行业。

用今天的眼光看，它有哪些设计被保留下来了？

并行功能单元的思想（ENIAC 有多个可并行工作的面板单元）以另一种形式回到今天的 CPU 与 GPU；而十进制、插线编程、无存储程序这三点都被彻底淘汰。
