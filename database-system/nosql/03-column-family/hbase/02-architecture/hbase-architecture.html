🏗️ HBase 架构

HMaster、RegionServer 与 ZooKeeper

角色

🎯

HMaster

管理元数据、Region 分配与负载均衡，不参与数据读写路径。

🗄️

RegionServer

真正服务数据的节点，管理若干 Region。

🧩

Region

表按 rowkey 区间切分的最小服务单元，类似『分片』。

🐘

ZooKeeper

分布式协调：选主、故障检测、元数据位置。

读写路径

Client 缓存 region 位置；写先写 WAL 再写 MemStore，读先查 MemStore 再读 HFile / BlockCache。Region 过大自动分裂（split）到不同 RegionServer。

💡 HMaster 挂掉只影响元数据操作（建表/均衡），已有读写不受影响；RegionServer 挂掉由 HMaster 重新分配其 Region。
