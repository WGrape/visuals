为什么不用取模

节点数变化时，hash(key) % N 会让大量 key 重新映射→缓存雪崩/数据迁移。分布式环境节点频繁上下线根本承不住。

一致性哈希

节点和 key 都 hash 到环上；key 顺时针找第一个节点。加一个节点只迁移其前驱区间的数据，影响范围极小。

虚拟节点

每个物理节点映射多个虚拟节点，让数据更均匀，避免热点节点。

🎯 面试问答

Q：一致性哈希解决什么？
A：节点扩缩容时最小化数据迁移范围。
Q：虚拟节点作用？
A：让数据更均匀，避免热点节点。
Q：Redis Cluster 用什么分片？
A：16384 个哈希槽(slot)，思想类似一致性哈希。
