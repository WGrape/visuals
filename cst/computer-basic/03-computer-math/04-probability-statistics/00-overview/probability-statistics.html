概率与统计：在不确定中做决策

概率描述「世界如何随机」，统计描述「从数据反推世界」。机器学习、A/B 实验、风控与排队论都建立在这套语言上。

核心速览

概率

给定模型，算事件发生的可能性：P(A)

统计

给定数据，反推模型参数或检验假设

随机变量

把随机结果映射成数字，便于计算期望与方差

推断

用样本估计总体：点估计、区间估计、假设检验

一句话分清概率与统计

三条公理与由此推出的一切

柯尔莫哥洛夫的三条公理是整个概率论的地基：

① 非负性

0 ≤ P(A) ≤ 1

② 规范性

P(Ω) = 1，必然事件概率为 1

③ 可列可加性

互斥事件 A₁, A₂, … 满足 P(∪Aᵢ) = ΣP(Aᵢ)

推论

P(∅)=0、P(Aᶜ)=1−P(A)、P(A∪B)=P(A)+P(B)−P(A∩B)

从这三条能推出全部常用公式——条件概率、全概率公式、贝叶斯定理、独立性。这种「极少公理 → 庞大体系」的结构，也正是概率论在计算机科学里如此好用的原因。

五个必须熟练的核心公式

公式表达用途
条件概率P(A|B) = P(A∩B) / P(B)已知 B 发生后 A 的概率
乘法公式P(A∩B) = P(A|B)·P(B)链式法则的基础
全概率公式P(A) = Σ P(A|Bᵢ)P(Bᵢ)分情况加权求和
贝叶斯定理P(B|A) = P(A|B)P(B) / P(A)由结果反推原因
独立性P(A∩B) = P(A)P(B)一个发生不影响另一个
最常见的思维错误是混淆 P(A|B) 与 P(B|A)。经典例子：疾病检测准确率 99%，你检测为阳性，患病概率是多少？答案是远低于 99%——还要看基础患病率（先验）。这就是贝叶斯定理要解决的问题。

随机变量、期望与方差

随机变量 X 把随机试验的结果映射成实数，于是可以用代数工具处理随机性。它的两个最重要数字特征：

期望 E[X] = Σ x·P(X=x)（离散）　或　∫ x·f(x)dx（连续）
方差 Var(X) = E[(X − E[X])²] = E[X²] − (E[X])²
性质表达式注意
期望的线性E[aX + bY] = aE[X] + bE[Y]无条件成立，不要求独立
方差的平移Var(X + c) = Var(X)平移不改变离散程度
方差的缩放Var(aX) = a²Var(X)注意是 a 的平方
独立时方差可加Var(X + Y) = Var(X) + Var(Y)必须独立，否则要加 2Cov(X,Y)
Jensen 不等式f(E[X]) ≤ E[f(X)]（f 凸）解释「为什么波动会拖累长期收益」
「期望的线性性不需要独立」是概率论里最强大也最常用的性质：哪怕变量之间高度相关，E[X+Y] = E[X]+E[Y] 依然成立。这让很多看似复杂的问题（如随机算法的期望运行时间、哈希冲突的期望次数）能被一行算式解决。

三大定律：大数定律与中心极限定理

大数定律（LLN）

样本均值 X̄ₙ 依概率收敛到真实期望 μ。掷硬币次数越多，正面频率越接近 0.5。这是蒙特卡洛方法的理论保证。

中心极限定理（CLT）

无论总体分布是什么，只要方差有限，√n(X̄ₙ − μ) 依分布收敛到 N(0, σ²)。即样本均值的分布近似正态。

马尔可夫 / 切比雪夫不等式

P(X ≥ a) ≤ E[X]/a；P(|X−μ| ≥ kσ) ≤ 1/k²。不依赖分布形状的粗上界，用于快速 bound。

切尔诺夫界

对独立随机变量的和给出指数级衰减的尾概率，比切比雪夫紧得多，是随机算法分析的主力工具。

统计推断：从样本到结论

任务做法产出
点估计用样本统计量估计参数（如 X̄ 估 μ）一个数值
区间估计构造置信区间 [L, U]「μ 落在区间内」的置信度
假设检验设 H₀，算 p 值，与 α 比较拒绝 / 不拒绝 H₀
最大似然 MLE选使观测数据概率最大的 θ参数估计的通用框架
贝叶斯估计先验 × 似然 → 后验参数的完整分布
置信区间的正确读法：「用同样方法重复抽样 100 次，约有 95 次构造出的区间会覆盖真值 μ」——不是「μ 有 95% 的概率落在这个区间里」（后者是贝叶斯可信区间的说法，因为频率学派认为 μ 是固定常数、不是随机变量）。

计算机科学里的典型应用

领域用到的概率统计
随机化算法期望运行时间、切尔诺夫界、蒙特卡洛 / 拉斯维加斯
哈希与布隆过滤器碰撞概率、误判率 FPR = (1 − e^(−kn/m))ᵏ
负载均衡泊松到达、排队论、长尾延迟（P99）
机器学习损失函数即期望风险、MLE/MAP、正则化即先验
A/B 实验假设检验、置信区间、功效分析、多重比较校正
系统可靠性故障率建模、MTBF、串联/并联可用性计算
推荐与搜索点击率估计、贝叶斯平滑、汤普森采样
一个高频实战点：延迟要看分位数（P99/P999）而不是平均值。平均延迟会被大量快请求「平均掉」，而用户感知的是最慢的那 1%。这就是为什么 SLO 通常写成「P99 < 200ms」。

🎯 常见问法与答题要点

Q：概率和统计的区别是什么？

A：方向相反：概率是「已知模型 → 推算数据」（已知硬币公平，算 10 次里 7 次正面的概率）；统计是「已知数据 → 反推模型」（看到 10 次里 7 次正面，判断硬币是否公平）。概率论是统计学的数学基础，统计学是概率论的反问题。机器学习本质上就是统计推断的工程化。

Q：为什么 P(A|B) 和 P(B|A) 不能混为一谈？

A：因为它们 Conditioning 的方向不同，数值可以差几个数量级。经典例子：某病患病率 0.1%，检测灵敏度与特异性都是 99%。P(阳性|患病) = 99%（很高），但 P(患病|阳性) 只有约 9%——因为 1000 人里只有 1 个病人，却有约 10 个假阳性。忽略基础概率（先验）是医学筛查、风控、A/B 实验中最常见的错误。

Q：期望的线性性为什么不需要独立？

A：因为期望本质是积分（或求和），而积分天然是线性的：E[X+Y] = Σ(ω)(X+Y)p(ω) = ΣX p + ΣY p = E[X]+E[Y]，推导过程中从未用到独立性假设。独立只在方差可加（Var(X+Y)=Var(X)+Var(Y)）和乘法期望 E[XY]=E[X]E[Y] 时才需要。这条性质让「随机算法的期望代价」能被拆解成各部分的期望之和，非常好用。

Q：大数定律和中心极限定理分别说了什么？

A：大数定律：样本均值 X̄ₙ 随 n 增大收敛到真实期望 μ（掷硬币次数越多，频率越接近 0.5）——保证「多采样就准」。中心极限定理：不仅收敛，还告诉你误差的分布形状近似正态 N(μ, σ²/n)——保证「能给出置信区间、能做假设检验」。前者给「准不准」，后者给「误差多大、怎么量化」。

Q：置信区间 95% 到底是什么意思？

A：频率学派的正确含义：如果用同样的方法重复抽样并构造区间 100 次，大约有 95 个区间会覆盖真实参数。注意不是「真值有 95% 概率落在这个区间内」——因为频率学派把 μ 视为固定常数，随机的是区间本身。后一种说法属于贝叶斯可信区间（credible interval），它把参数当随机变量，可以直接谈概率。

Q：p 值是什么？常见误读有哪些？

A：p 值 = 在原假设 H₀ 为真的前提下，观察到当前结果或更极端结果的概率。p 小说明数据与原假设不太相容，于是拒绝 H₀。常见误读：① p 值不是「H₀ 为真的概率」；② p > 0.05 不等于「证明 H₀ 成立」，只是「证据不足」；③ p 值会随样本量增大而变小，大样本下微小差异也能显著，所以必须同时看效应量；④ 多次检验会 inflated 假阳性，需要 Bonferroni 或 FDR 校正。

Q：为什么系统监控要看 P99 而不是平均延迟？

A：因为平均值会被大量快速请求稀释，掩盖长尾问题。假设 99% 请求 10ms、1% 请求 2000ms，平均只有 30ms，看起来很健康，但每 100 个用户就有 1 个遭遇 2 秒卡顿。而一次用户会话往往包含几十个请求，遇到长尾的概率被放大——P99 差意味着「几乎所有重度用户都会觉得卡」。所以 SLO 普遍写成 P99 / P999 分位数。
