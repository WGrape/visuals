网络层 · 跨层设备地图

数据包经过哪些网络设备？

从交换机、路由器到防火墙、负载均衡器：它们不是都在“转发包”。沿一段真实路径，看看谁只碰比特，谁按 MAC / IP 选出口，谁改地址，谁甚至结束旧连接、发起新请求。

02 / DEVICE ATLAS

九类设备：职责、依据、实际动作

设备名字对应的是主要功能，不一定对应一台独立盒子：家用路由器常同时做交换、Wi-Fi、NAT、防火墙；云上的“网关”和“负载均衡”也可能是软件服务。

中继器 / 集线器 L1 · 比特

把收到的物理信号恢复、送到其他端口；集线器会把比特广播到其他端口，现代以太网中已很少使用。

看什么：电/光信号，不查 MAC 或 IP。
改什么：信号形态；不做目标选择，不有意识地修改 IP 包。

调制解调器 / 光猫 ONT 接入介质

在以太网与接入线路的信号或链路协议之间转换，让家庭或企业网络接入运营商；不同产品的终结位置取决于部署。

看什么：接入链路的帧与信号。
改什么：介质和链路封装；若开启路由模式，还可能兼做 NAT、防火墙。

无线 AP L2 · 无线接入

让终端通过 Wi-Fi 关联入网，典型桥接模式下在 802.11 无线帧与有线以太网帧之间转接。

看什么：无线帧、终端关联与链路状态。
改什么：链路层封装；桥接模式一般不修改 IP 源/目的。家用无线路由器还包含路由功能。

网桥 / 二层交换机 L2 · 帧

从源 MAC 学习端口位置，按目的 MAC 与 VLAN 决定出口；已知单播定向转发，未知单播/广播在所属 VLAN 内泛洪。

看什么：MAC 表、VLAN。
改什么：可能添加/去掉 VLAN 标签并重算帧校验；普通二层转发不改 IP 地址或 TTL。

路由器 / 三层交换机 L3 · IP 包

按目标 IP 查路由表（最长前缀匹配），选下一跳与出口，把 IP 包装入下一段链路的新帧。

看什么：目的 IP、路由表 / 邻居表。
改什么：每个三层转发跳 TTL 减 1、换链路头；IPv4 头校验和随之更新，通常不改 IP 两端地址。TTL 到期则丢弃并通常回 ICMP。

NAT 网关 L3/4 · 地址映射

在内外网之间维护映射。常见出站 NAPT 将私有源 IP 与端口换成公网 IP 与端口，并在回包时反向还原。

看什么：地址、端口和映射状态。
改什么：IP / 端口及相关校验和；它通常与路由器集成，NAT 本身不等于“找路”。

防火墙 L3/4 · 策略

按规则及连接状态放行、拒绝或丢弃流量；某些下一代防火墙还能深入检查应用数据（能否查看加密内容取决于是否解密）。

看什么：协议、地址、端口、会话状态，可选 L7。
改什么：主要是是否允许通过；透明模式不必改 IP，路由模式则会逐跳重封装。

负载均衡器 L4 或 L7 · 选后端

把一个服务入口（VIP）的请求分配给健康后端。L4 按连接、四/五元组转发；L7 可依据 HTTP 主机名、路径等选择后端。

看什么：连接字段或解密后应用请求。
改什么：可能 DNAT / SNAT、封装转发，或终止连接后重新发起；实现方式并不唯一。

反向代理 / API 网关 L7 · 请求

面向客户端接受连接，按域名或路径转到应用，常负责 TLS 终止、鉴权、限流或缓存；再向后端建立独立连接。

看什么：可读取的 HTTP 请求及策略（TLS 终止后）。
改什么：可改请求头/内容，生成新请求；原 TCP/IP 包不会原封不动穿过代理。

04 / CHECK YOUR MODEL

三个容易混淆的问题

交换机和路由器都在“转发”，到底差在哪？

普通二层交换机按目的 MAC 在同一 VLAN 找出口；路由器按目的 IP 在不同网络间选下一跳，TTL 递减并重新封装链路帧。三层交换机也能做路由，所以关键是当前执行的功能，不是机箱名称。

从电脑到网站，源 IP 和目的 IP 一直都不变吗？

普通路由转发通常保持两端 IP 不变；遇到 NAT、DNAT 或代理则可能改变。MAC 只在本跳有效，路由器转发时会更换链路层源/目的。L7 代理更进一步：原连接在代理处终止，后面是新连接。

防火墙、负载均衡、反向代理会同时出现吗？

可能，但不是必需，也可能合并部署。防火墙决定能否通过，负载均衡决定交给哪个后端，反向代理处理应用层请求；一台设备可以同时承担多种职责。
