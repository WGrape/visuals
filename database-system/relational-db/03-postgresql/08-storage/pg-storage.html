存储结构：堆表、页与 TOAST

relfilenode、8KB 页、元组布局，以及大字段的 TOAST 行外存储。

堆表与文件页与元组TOAST表膨胀

① 堆表与 relfilenode

每张表是一个 堆（Heap） 文件，由 relfilenode 命名，超 1GB 自动分段（relfilenode.1 …）。索引是独立文件。表本身是无序堆，顺序由写入决定。

② 页（Page）与元组

数据文件按 8KB 页（默认 block_size）组织，每页含若干元组（行）。元组头部存 xmin/xmax/ctid 等 MVCC 与定位信息。行通过 ctid（块号+偏移）定位。

③ TOAST：大字段行外存储

单行不能超过一页（约 8KB，留头）。超阈值（约 2KB）的宽列（text/jsonb/bytea）会被 TOAST 压缩并切分存到附属的 toast 表，主表只留指针。查询不访问该列时不读 toast，省 IO。

SELECT relname FROM pg_class WHERE reltoastrelid != 0;  -- 查看有 TOAST 的表

④ 表膨胀（bloat）

MVCC 的死元组、频繁 UPDATE 会产生 表膨胀：文件里大量行版本已不可见但未被回收。需 VACUUM 回收，并用 pgstattuple 评估膨胀率。
