第四层 · 它和 TiDB / CockroachDB 的差别

三者架构上最大的不同是什么？

TiDB 是计算存储分离（TiKV 存、TiDB 算）；CockroachDB 是对等节点 + Range 分片；OceanBase 是分区 + 多副本 + LSM-Tree，且原生支持租户级资源隔离。

LSM-Tree 带来的取舍是什么？

写性能好、压缩率高，代价是读放大与写放大（后台合并持续消耗 IO）。所以它更适合写多读少、批量写入的场景，极端点查场景不如 B+ 树稳定。

什么时候该选 OceanBase？

需要多业务共用一套集群、强一致、且要控制成本时（租户隔离是关键能力）；如果团队更看重生态与易用性，TiDB 往往上手更快。
