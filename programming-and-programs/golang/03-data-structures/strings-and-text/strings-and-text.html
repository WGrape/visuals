不可变与代价

每次拼接都分配新内存

因为不可变，用 + 在循环里拼接字符串会产生大量临时对象。高频场景要用 strings.Builder 或 bytes.Buffer。

s := "a"
s = s + "b" + "c"   // 每次都新分配

// 循环里这样写会很慢
for _, w := range words {
    s += w  // 反复分配拷贝
}
strings 包高频函数

覆盖日常文本操作

strings 提供大小写、前后缀、包含、分割、替换、裁剪等；strconv 负责字符串与基本类型的互相转换。

strings.HasPrefix(s, "go")
strings.Contains(s, "lang")
strings.Split("a,b,c", ",")     // [a b c]
strings.Join(parts, "-")
strings.ReplaceAll(s, "old", "new")
strings.TrimSpace(s)

strconv.Itoa(42)              // int->string
strconv.Atoi("42")            // string->int (带 err)
高效拼接：Builder

复用缓冲区，避免反复分配

strings.Builder 内部维护一个 []byte，WriteString 追加不分配新内存，最后 String() 一次性产出。

var b strings.Builder
for _, w := range words {
    b.WriteString(w)
}
s := b.String()   // 一次成型，性能远好于 +
与 []byte 的转换

转换会拷贝

string 与 []byte 互转默认是拷贝（保证不变性）。极热路径可用 unsafe 避免，但绝大多数业务不需要。

bs := []byte(s)      // 拷贝出新字节切片
s2 := string(bs)    // 再拷贝回字符串

// 仅读取可用 unsafe 省拷贝（谨慎）
