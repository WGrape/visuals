策略时机优点缺点
惰性删除访问时零额外开销冷 key 永不清
定时扫描周期任务兜底清理有扫描开销
时间轮按过期槽精准高效实现复杂

时间轮简介

把过期时间映射到环形槽，指针转动到对应槽时批量清理，避免全量扫描，适合大量短时 TTL 场景。

🎯 面试问答

Q：惰性删除的问题？
A：冷 key 不被访问就永远占内存，需定时扫描兜底。
Q：时间轮比定时扫描好在哪？
A：按槽批量清理，避免每次全量遍历。
