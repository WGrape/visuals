无主架构

Cassandra 没有 Master，所有节点对等，客户端可连任意节点。某个节点挂了，其余照常服务，天然适合多数据中心部署。

数据分布

用一致性哈希把数据 key 映射到环上，副本按顺时针落在后续 N 个节点，扩缩容只迁移少量数据。

一致性级别

级别含义
ONE写/读 1 个副本即返回
QUORUM过半副本确认
ALL全部副本确认

读写一致性级别可独立配置，在性能与强一致之间权衡。

🎯 面试问答

Q：Cassandra 怎么保证不丢？
A：写操作按一致性级别复制到多个副本并落 SSTable，配合 Hinted Handoff 处理临时离线节点。
Q：什么时候选 Cassandra 而不是 HBase？
A：需要多活多数据中心、写吞吐极高、接受最终一致时，Cassandra 更合适。
