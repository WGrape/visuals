概率基础：条件概率、独立性与贝叶斯

从三条公理出发，用文氏图与概率树建立直觉，再掌握条件概率、全概率公式与贝叶斯定理这三件核心工具。

核心速览

条件概率

P(A|B) = P(A∩B)/P(B)：把样本空间缩小到 B 里

独立性

P(A∩B) = P(A)P(B)：知道 B 不改变对 A 的判断

全概率

把复杂事件拆成若干互斥情形再加权求和

贝叶斯

由「结果」反推「原因」，先验 + 似然 → 后验

样本空间、事件与文氏图

样本空间 Ω 是所有可能结果的集合，事件是 Ω 的子集，概率是给事件分配 0~1 数字的测度。文氏图是最直观的辅助工具：

条件概率：把世界缩小到已知信息里

P(A|B) 的直觉是：既然 B 已经发生，就把 Ω 缩小成 B，再看 A 在其中占多大比例。

P(A|B) = P(A ∩ B) / P(B)，要求 P(B) > 0
分母从 Ω 变成了 B P(B|A) 的分母则是 A —— 两者不同！
一个帮助记忆的例子：班上 100 人，60 人会 Python（P=0.6），其中 42 人也会 Go。P(Go|Python) = 42/60 = 0.7；反过来若全班 50 人会 Go，则 P(Python|Go) = 42/50 = 0.84。分子相同，分母不同，结果就不同。

乘法公式与概率树

由条件概率定义立刻得到 P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)，推广到多个事件就是链式法则：

P(A₁∩A₂∩…∩Aₙ) = P(A₁)·P(A₂|A₁)·P(A₃|A₁A₂)…

概率树是处理「分阶段随机试验」的利器：每条路径的概率 = 沿途分支概率相乘；某个结果的概率 = 到达它的所有路径概率相加。

# 例子：三局两胜，单局胜率 0.6，求最终获胜概率
# 路径：WW（两连胜）| WLW | LWW
p = 0.6
win = p*p + p*(1-p)*p + (1-p)*p*p      # 0.36 + 0.144 + 0.144
print(win)                              # 0.648

# 链式法则：不放回抽两张牌都是 A 的概率
print((4/52) * (3/51))                  # ≈ 0.00452

全概率公式：分情况加权求和

若 B₁, B₂, …, Bₙ 构成 Ω 的一个划分（两两互斥且并集为 Ω），则：

P(A) = Σᵢ P(A|Bᵢ)·P(Bᵢ)

用处：当 P(A) 不好直接算，但在每种「情况 Bᵢ」下都好算时，就分情况算再加权。

# 例子：三台机器生产同一零件
# 机器1：产量 50%，次品率 2%
# 机器2：产量 30%，次品率 3%
# 机器3：产量 20%，次品率 5%
p_defect = 0.5*0.02 + 0.3*0.03 + 0.2*0.05
print(p_defect)          # 0.029，即 2.9%

# 贝叶斯反推：抽到一个次品，它来自机器 3 的概率？
print(0.2*0.05 / p_defect)   # ≈ 0.345（远高于 20% 的产量占比）
几何直觉：全概率公式就是把 A 切成若干互不重叠的碎片（A∩Bᵢ）再求和；贝叶斯定理则是知道总和后，反过来看某一块占多大比例。所以两者常成对出现。

贝叶斯定理：从结果反推原因

P(B|A) = P(A|B)·P(B) / P(A)　=　P(A|B)·P(B) / Σᵢ P(A|Bᵢ)P(Bᵢ)

四个名词要记住：P(B) 是先验（在看到证据前的信念）、P(A|B) 是似然（该原因下出现此证据的可能性）、P(A) 是证据的总概率（归一化因子）、P(B|A) 是后验（看到证据后修正的信念）。

# 经典：疾病检测
# 患病率（先验）0.1%，灵敏度 P(+|病) = 99%，特异性 P(−|健康) = 99%
prior = 0.001
p_pos_given_dis = 0.99
p_pos_given_ok  = 0.01
p_pos = p_pos_given_dis*prior + p_pos_given_ok*(1 - prior)   # 全概率
posterior = p_pos_given_dis*prior / p_pos
print(p_pos)        # ≈ 0.01098
print(posterior)    # ≈ 0.0902 → 阳性后真正患病只有约 9%！

# 再做一次检测（用第一次的后验作为新先验）
prior2 = posterior
p_pos2 = p_pos_given_dis*prior2 + p_pos_given_ok*(1 - prior2)
print(p_pos_given_dis*prior2 / p_pos2)   # ≈ 0.907 → 二次阳性后升至 90%
这个例子是贝叶斯思维最好的教材：单次阳性不足以确诊，因为假阳性的绝对数量远超真患者（1000 人中 1 个病人 vs 约 10 个假阳性）。复检之所以有效，正是把第一次的后验当作第二次的先验——信息在累积。

独立性：什么时候可以放心相乘

定义：A、B 独立 ⟺ P(A∩B) = P(A)·P(B)，等价地 P(A|B) = P(A)（知道 B 不改变对 A 的判断）。

概念定义易混点
两两独立任意两事件满足 P(AB)=P(A)P(B)不蕴含相互独立
相互独立任意子集都满足乘积式更强，必须显式要求
条件独立P(A∩B|C) = P(A|C)P(B|C)独立 ≠ 条件独立（辛普森悖论）
互斥 vs 独立互斥是 A∩B = ∅互斥 ≠ 独立；若 P(A),P(B)>0，互斥反而必不独立
互斥与独立是两回事，甚至是相反的：互斥意味着「一个发生另一个必不发生」，是最强的信息关联（知道 A 发生就知道 B 一定不发生），因此绝不独立。独立的本质是「信息不传递」。这是初学者最常见的混淆点。

计数：古典概型的算力来源

当所有基本事件等可能时，P(A) = |A| / |Ω|，于是问题转化为计数：

模型数量例子
n 个不同元素全排列n!5 本书排序 = 120
从 n 取 k 排列（有序）n!/(n−k)!冠军亚军
从 n 取 k 组合（无序）C(n,k) = n!/(k!(n−k)!)抽 5 张牌
可重复组合C(n+k−1, k)隔板法
多重集排列n!/(n₁!n₂!…)MISSISSIPPI
# 生日悖论：23 人中至少两人生日相同的概率就超过 50%
def birthday(n, d=365):
    p = 1.0
    for i in range(n):
        p *= (d - i) / d            # 全不相同的概率
    return 1 - p

print(birthday(23))   # ≈ 0.507
print(birthday(50))   # ≈ 0.970
print(birthday(70))   # ≈ 0.99916
生日悖论是哈希碰撞分析的基础：在 m 个桶里放 n 个 key，碰撞概率 ≈ 1 − e^(−n²/(2m))。所以当 n ≈ √m 时碰撞就已经很常见——这就是「生日攻击」能在 2^(k/2) 次尝试内找到 k 位哈希碰撞的原因。

🎯 常见问法与答题要点

Q：条件概率 P(A|B) 到底在算什么？

A：把样本空间从 Ω 收缩到 B，再看 A 在 B 中占多大比例。公式 P(A|B) = P(A∩B)/P(B) 中，分母从 1 变成 P(B)，正是这一「收缩」的体现。直觉例子：100 人中 60 人会 Python，其中 42 人也会 Go，则 P(Go|Python) = 42/60 = 0.7——分母是「会 Python 的人」而不是「全班」。

Q：为什么 P(A|B) 与 P(B|A) 会差这么多？

A：因为分母不同：P(A|B) 的分母是 P(B)，P(B|A) 的分母是 P(A)。当 P(A) 与 P(B) 相差悬殊时（如罕见病检测中「患病」远比「检测阳性」罕见），两者可以差几十倍。贝叶斯定理正是连接两者的桥：P(B|A) = P(A|B)P(B)/P(A)。

Q：互斥和独立有什么区别？

A：完全相反。互斥：A∩B = ∅，一个发生另一个必不发生——这是最强的关联（知道 A 就完全确定 B 不发生）。独立：P(A∩B) = P(A)P(B)，知道 B 对判断 A 毫无帮助——零关联。所以若 P(A) > 0 且 P(B) > 0，互斥必然不独立。这是最常见的概念混淆点。

Q：全概率公式什么时候用？

A：当直接求 P(A) 困难，但在若干互斥「情形」Bᵢ 下求 P(A|Bᵢ) 都容易时使用：P(A) = Σ P(A|Bᵢ)P(Bᵢ)。典型场景：多台机器生产同一产品求总次品率、多个来源混合求总体分布、分阶段试验求最终结果。使用前提是 Bᵢ 构成样本空间的一个划分（互斥且穷尽）。

Q：贝叶斯定理的「先验、似然、后验」是什么意思？

A：先验 P(B)：看到数据前对假设的信念（如疾病的患病率）；似然 P(A|B)：若假设成立，观察到该数据的可能性（如检测的灵敏度）；后验 P(B|A)：看到数据后修正的信念（检测阳性后真正患病的概率）。核心关系式：后验 ∝ 似然 × 先验，分母 P(A) 只是归一化常数。

Q：为什么罕见病的阳性检测结果大概率是假阳性？

A：因为假阳性的绝对数量会压倒真患者的数量。举例：患病率 0.1%、灵敏度与特异性都是 99%，则 1000 人中约有 1 名真患者（检测为真阳）与约 10 名健康人（检测为假阳），阳性者中真患者只占 1/(1+10) ≈ 9%。提高准确率收效有限，提高先验（只筛查高危人群）或做复检才有效——复检本质是把第一次的后验当新先验。

Q：生日悖论为什么「反直觉」？它有什么工程意义？

A：因为人们把问题误想成「有人和我同一天」（需要 253 人），而实际问的是「任意两人」——比较的对数是 C(n,2) ≈ n²/2，随人数平方增长，所以 23 人（253 对）就超过 50%。工程意义：哈希碰撞在 n ≈ √m 时就很常见，这直接给出布隆过滤器容量设计、以及「生日攻击」只需 2^(k/2) 次尝试即可找到 k 位哈希碰撞的结论。

Q：两两独立不等于相互独立，能举例吗？

A：经典反例（伯恩斯坦）：抛两枚公平硬币，令 A =「第一枚正面」、B =「第二枚正面」、C =「两枚结果相同」。可验证 任意两者独立（如 P(A∩B) = 1/4 = P(A)P(B)），但三者不相互独立：P(A∩B∩C) = 1/4 ≠ P(A)P(B)P(C) = 1/8。直觉：知道 A 和 B 后，C 被完全确定——两两独立无法排除这种「联合信息泄露」。工程上这意味着：成对测试通过并不能保证组合行为正确。
