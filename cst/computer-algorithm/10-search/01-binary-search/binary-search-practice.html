二分查找写错是大厂面试高频翻车点：死循环、下溢、边界差一。用『不变式 + 两种标准写法』能一次写对，再用对拍测试兜住。

01两种标准写法

写法一：闭区间 [left,right]，left<=right 时继续，中点命中即返回，否则缩区间。写法二：左闭右开 [left,right)，left

# 写法一：闭区间，找等于 target 的下标（无则 -1）
def bs_close(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2          # 防下溢用 lo + (hi-lo)//2（Python 无此问题）
        if a[mid] == target: return mid
        if a[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1

# 写法二：左闭右开，找第一个 >= target 的插入位置
def bs_lower_bound(a, target):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < target: lo = mid + 1
        else: hi = mid
    return lo

02四个经典 bug

  • 死循环：lo=mid / hi=mid 没 +1/-1，区间不收缩（尤其写法二里 a[mid]
  • 整数下溢：mid=(lo+hi)//2 在 lo+hi 超 INT_MAX 时溢出；C/Java 用 lo+(hi-lo)/2，Python 无需。
  • 边界差一：循环条件用 < 还是 <= 要和区间定义一致，混用必错。
  • 重复元素：找第一个/最后一个出现位置时，命中后不能立即返回，要继续缩区间。
要点：心法：先决定『区间是闭还是开』，再保证『每次循环都严格缩小搜索范围』，两者定下 bug 自然消失。

03怎么测才放心

用暴力线性搜索做对拍，覆盖空数组、单元素、全相同、target 在首尾/缺失等。随机大量用例自动比对，比手搓几个样例可靠得多。

import random
def brute(a, t):                 # 线性暴力，作为基准
    for i, x in enumerate(a):
        if x == t: return i
    return -1
for _ in range(20000):
    n = random.randint(0, 20)
    a = sorted(random.randint(0, 5) for _ in range(n))   # 含重复
    t = random.randint(-1, 6)
    assert bs_close(a, t) == brute(a, t), (a, t)
print("all passed")
