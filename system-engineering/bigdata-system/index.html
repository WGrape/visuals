📊 大数据系统

标准五层划分：① 数据采集层 → ② 数据存储层 → ③ 数据处理 / 计算层（核心）→ ④ 数据治理与管理层 → ⑤ 数据分析与应用层。另一种常见分法是按计算模式：批处理（Hadoop）、流处理（Flink）、交互式查询（Presto）、图计算（GraphX）。
