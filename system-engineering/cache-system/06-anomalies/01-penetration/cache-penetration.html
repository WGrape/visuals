现象

请求查一个根本不存在的 key → 缓存没有 → 每次都打数据库 → DB 被打爆。

对策

  • 空值缓存：查库返空也缓存，设较短 TTL
  • 布隆过滤器：接口前择掉不可能存在的 key
  • 参数校验/限流：拦截恶意请求

🎯 面试问答

Q：穿速和击穿区别？
A：穿速是 key 不存在(查 DB 永远无果)；击穿是 key 存在但过期瞬间高并发。
Q：布隆过滤器误判怎么办？
A：有误判(可能说存在其实无)，但能择掉绝大多数；漏择的靠空值缓存先兆。
Q：空值缓存注意什么？
A：设较短 TTL，防止“后来真有了却一直返回空”。
