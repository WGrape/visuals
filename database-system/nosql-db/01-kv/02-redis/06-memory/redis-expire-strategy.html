三种删除

策略时机代价
定时删除到期立即占 CPU
惰性删除访问时冷 key 占内存
定期删除周期抽样折中

Redis 采用惰性 + 定期结合：访问时检查过期，后台周期性随机抽样删除。

内存淘汰策略

内存达 maxmemory 时按 policy 淘汰：noeviction（拒写）、volatile-lru/random/ttl（仅带过期）、allkeys-lru/random（全体）。常用 allkeys-lru。

🎯 面试问答

Q：为什么不全用定时删除？
A：到点删除太占 CPU。
Q：惰性删除缺陷？
A：冷 key 不被访问就占内存。
Q：allkeys-lru 含义？
A：内存满时对所有 key 用近似 LRU 淘汰。
