第 02 章 · 复杂度分析

时间与空间复杂度

复杂度描述输入规模增长时的资源变化，不是某台电脑上测得的秒数。

先定义规模，再数操作

设输入元素个数为 n，选择最频繁、能代表运行次数的基本操作。顺序扫描最多比较 n 次，是 O(n)；每次把剩余范围减半，最多比较约 ⌈log₂ n⌉ 次，是 O(log n)。常数、低阶项在渐近分析中略去：3n² + 8n + 1 属于 Θ(n²)。

双层循环不一定是 O(n²)：for i in 0..n-1: for j in 0..i-1 总次数为 0 + 1 + … + (n−1) = n(n−1)/2，因此才是 Θ(n²)。若内层指针在整个执行过程中只前进不回退，则总前进次数也可能仅为 O(n)。

O(g(n)) 是渐近上界，Ω(g(n)) 是下界，Θ(g(n)) 同时给出上下界。口语中的“复杂度是 O(n)”通常只承诺上界。

分清场景和空间

维度问的是什么示例
最好／平均／最坏不同输入下的运行次数顺序查找：命中首项 O(1)，最坏 O(n)
辅助空间除输入本身之外额外占用的空间复制数组 O(n)，原地交换 O(1)
均摊代价一串操作的总成本除以操作数动态数组偶尔扩容 O(n)，连续追加均摊 O(1)

递归也占栈空间：递归深度 d、每层局部状态 O(1)，额外栈空间是 O(d)；不要只看显式创建的数组。

分析递归与常见误区

二分查找满足 T(n) = T(n/2) + O(1)，时间 O(log n)。归并排序满足 T(n) = 2T(n/2) + O(n)：每层合并总量 O(n)，层数 O(log n)，时间 O(n log n)。这些是时间结论；归并排序还需要 O(n) 的合并缓冲区。

平均 O(1) 的哈希查询不是最坏 O(1)；两个独立输入大小 m、n 的嵌套循环应写 O(mn)，不能擅自写成 O(n²)。
