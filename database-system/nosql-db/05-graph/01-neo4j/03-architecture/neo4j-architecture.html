🏗️ Neo4j 架构

原生图存储、索引与集群

存储与查询

🗂️

原生图存储

节点/关系/属性分开存储，关系以指针互连。

🔎

索引

对标签属性建索引，加速『起点定位』；之后遍历靠指针。

🧠

缓存

热图数据进 page cache，提升遍历命中率。

集群（企业版）

  • Core（因果集群）：用 Raft 保证数据一致，负责读写。
  • Read Replica：异步复制，承担只读负载、横向扩展读。
  • 写操作在 Core 间达成多数派后返回，保证因果一致性。
💡 Neo4j 单机即可扛很多遍历场景；真正瓶颈常是『超大规模图的内存映射与 GC』，需要按热数据规模规划堆外内存。
