选型思路

OLAP 为什么快

核心是列式存储 + 向量化执行：只读取查询涉及的列，CPU 批量处理一整列，比行存快一个数量级。

🎯 面试问答

Q：ClickHouse 能取代 Hive 吗？
A：取代不了，ClickHouse 适合高并发只读分析；Hive/Spark 适合大规模写和复杂 ETL。
Q：一条 SQL 在多个引擎都能跑，怎么定？
A：看延迟与并发要求：即席低延迟用 Presto，报表高并发用 ClickHouse，重 ETL 用 Spark。
