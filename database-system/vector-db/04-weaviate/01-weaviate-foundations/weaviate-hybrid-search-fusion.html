Weaviate 混合检索：向量与关键词怎样融合

用产品文档检索比较向量相似度、BM25、融合排序与租户过滤，避免只看一条命中样例。

为什么需要两种检索信号 语义向量擅长找到同义表达，例如“账单怎么撤销”与“取消开票申请”；关键词检索擅长匹配精确代号、错误码和产品名。若用户问“ERR-4821”，纯向量可能找到泛泛的错误处理文档，却漏掉精确代码；若用户用自然语言描述概念，纯关键词可能因词汇不一致而召回不足。混合检索把两路候选合并，但融合策略必须考虑分数尺度和召回预算。

检索前先明确文档切块。过大块容易在向量表示中混合多个主题，过小块会丢失上下文；关键词排名也受标题、字段权重和长度影响。每个 chunk 应保留文档 ID、版本、章节位置、更新时间和租户权限，便于结果引用与回源检查。

建索引时的语义一致性 Weaviate 可以使用集成向量化，也可以导入外部生成的向量。无论哪种方式，都要固定 embedding 模型版本、向量维度、文本预处理和语言范围。若一半文档使用旧模型、一半使用新模型，向量距离可能失去可比性。更换模型通常需要重建或迁移相关索引，并在灰度期间保证查询向量与文档向量来自兼容空间。

关键词侧也要明确分词器和字段规则。把产品代号、代码片段和中英文混合文本全部交给默认分词，可能导致精确标识被拆碎。可为标题、正文、错误码字段设计不同索引和权重，并用真实查询检查 token 化结果。索引更新延迟必须纳入“新文档何时可搜到”的契约。

逐步推演

构建两路索引

固定文本切块、向量模型和关键词字段规则。

取候选

分别召回语义和词法结果，保留原始名次。

融合与过滤

按明确算法合并，并执行租户硬过滤与复核。

验证

分查询类型比较相关性、延迟和索引更新可见性。

一次融合排序的算例 假设查询是“支付失败 ERR-4821”。向量候选 A 排名 1，是一篇一般支付排错说明；关键词候选 B 排名 1，是精确错误码手册。若只把原始向量相似度与 BM25 分数直接相加，两个数值尺度可能不同，权重没有直观意义。按名次融合的方式可用 1/(k+排名) 汇总两路贡献；分数归一化方式则先把两路分数映射到可比区间。不同融合算法适合的权重与稳定性不同。

例如 B 在关键词中第 1、向量中第 5，A 在向量中第 1、关键词中第 20。对精确错误码查询，应使 B 更容易靠前；对“如何避免重复支付”这类概念问法，向量候选可能更有价值。可以按查询类型调整策略，但分类错误也会引入新问题，所以先建立固定测试集再比较。

过滤顺序与访问控制 若用户只能看租户 X 的文档，租户过滤必须作为硬约束参与查询，不能检索到全库后只在展示层隐藏。后过滤会使返回的 top K 少于预期，还可能在中间日志或缓存中暴露无权文档。应用层仍应对最终文档 ID 做权威权限复核，处理权限变更与索引延迟。

狭窄过滤条件下候选量可能很少，近似向量检索的参数要针对不同过滤宽度评测。十篇文档的租户精确扫描可能足够快，千万篇文档的租户则需要近似索引和过滤协同。不要用全库平均 Recall@K 推断每个租户的体验。

评测与调参 从真实搜索日志抽样并标注查询意图、相关文档与可访问范围。按错误码、产品名称、自然语言问法、跨语言问法四类报告 Recall@K、MRR 或 NDCG，同时看 P95 延迟。评测集要包含零结果和过期文档，避免只有“本来就容易搜到”的正例。切块大小、向量模型、关键词字段权重、融合参数应一次只变一个维度。

若后续用检索增强生成，生成答案正确率也要独立评测。检索到相关块不保证答案引用了正确版本；模型可能忽略证据或拼接两份冲突文档。返回结果应带版本与来源，过期手册需要降低权重或下线，而不是靠语言模型猜最新规则。

上线观察与回滚 记录每路候选数量、过滤后数量、融合前后名次、点击或人工采纳结果，便于定位“关键词有命中却没进最终列表”的问题。注意日志只存必要的脱敏查询和文档标识，不能把用户隐私原文全部落盘。对热门查询建立回归集合，索引更新或模型升级后立即重跑。

上线时先让混合检索与旧方案并行，对同一查询比较结果和耗时，再逐步切流。若精确码命中率下降或租户过滤发生异常，应能迅速切回旧配置与旧索引。效果改进必须同时满足权限、延迟与更新可见性的底线。

融合参数如何留证据

选取“ERR-4821”“支付重复扣款”“英文产品名加中文症状”等样例，记录向量前十、关键词前十与融合后前十的文档 ID 和名次。若调整权重让一个样例变好，却使另一类查询大幅变差，就需要按查询类型分层报告，而不能只汇总一个平均分。人工标注时至少区分完全相关、部分相关、过期或无权限四种状态；过期和无权限的文档即使语义接近，也不能算成功召回。

若查询同时带时间过滤，应明确文档的创建时间、修订时间和生效时间使用哪一个。法规或产品说明以生效版本为准，最新修改时间不一定代表当前有效版本。时间范围过滤与租户权限都应先于最终展示可靠生效。

自检

把 BM25 分数与向量相似度直接相加，权重就有统一含义吗？

没有。两路分数尺度不同，应选定归一化或排名融合方案，并用标注查询验证。

练习：选一个真实业务样本，写出输入、预期结果、一次失败时的证据，以及可以复现实验的验收标准。
