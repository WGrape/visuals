结构化日志

机器可解析

slog 输出带键值的 JSON/文本，便于采集与检索；相比 fmt/log 更利于后续分析。

logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
logger.Info("request", "path", "/u", "ms", 12)
logger.Error("db", "err", err)
级别

按严重度分流

Debug/Info/Warn/Error 区分语义；生产默认 Info，排障临时开 Debug。slog 支持 SetLogLoggerLevel 调整。

关键路径务必带 request_id/trace_id，便于跨服务串联一次请求。
指标与追踪

量化与定位

Prometheus 风格计数器/直方图看趋势；OpenTelemetry 传播 trace 串联微服务；二者互补。

// 计数 + 直方图是 API 监控的标配
requestsTotal.Inc()
hist.Observe(duration.Seconds())
实践

日志不是调试

日志服务于运行期可观测，不是开发期打印；避免打敏感字段，注意采样与成本。

⚠️ 别用 fmt.Println 做生产日志，既无级别也无结构，难以统一采集。
