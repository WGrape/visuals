🌐 NewSQL 分布式关系型数据库

原生分布式 + 完整 SQL + ACID 事务：让分片、扩缩容与分布式事务对应用透明。

为什么需要 NewSQL

单机三大天花板、分库分表中间件的五个硬伤、自动分片 / Raft / 2PC / HTAP 四大技术。
🔱

TiDB 架构与原理

四大组件与数据流、TiKV Region 与 Raft、PD 调度与 TSO 授时、Percolator 2PC、TiFlash HTAP。
🌊

OceanBase 架构与原理

OBProxy/OBServer/RootService 架构、LSM-Tree 与每日合并、Paxos 与三地五中心、多租户隔离。
🪳

CockroachDB 架构与原理

无中心对等架构、HLC 混合逻辑时钟、Serializable 事务与并行提交、地理分区与三者对比。
