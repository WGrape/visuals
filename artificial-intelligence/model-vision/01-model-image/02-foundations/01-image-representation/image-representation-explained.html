图像基础

图像表示与色彩空间：像素、通道与常见色彩模型

所有图像处理的第一步是「这张图在数学上是什么」。本文讲清像素与通道、RGB/灰度/HSV 等色彩空间的区别与取舍、常见图像格式与压缩策略，以及为什么模型输入几乎总是要做归一化。

图像在模型眼里就是一个多维张量

一张 高×宽 的 RGB 图，在计算机里是一个三维数组，常见形状为 (H, W, 3)（NHWC）或 (3, H, W)（NCHW）。

灰度图
(H, W, 1)

(H, W, 3)

(H, W, 4)
多一个 alpha 透明度通道
像素值通常是 0-255 的 uint8，但模型输入必须转成浮点并归一化（常见做法：/255 归一化到 0-1，或再减均值除标准差）——否则输入尺度过大会让激活饱和、训练不稳。

RGB 不是唯一的表达方式

色彩空间构成适合干什么
RGB红绿蓝三原色叠加显示与存储的事实标准；缺点是亮度与颜色信息混在一起
灰度单一亮度通道只关心形状/边缘的任务（如部分 OCR、边缘检测），省算力
HSV / HSL色相 H、饱和度 S、明度 V把「颜色」和「明暗」解耦，做颜色筛选、光照鲁棒的任务非常好用
YUV / YCbCr亮度 Y + 色度分量视频与图像压缩的基础：人眼对亮度敏感、对色度不敏感
Lab感知均匀的明度与色度颜色差异要接近人眼感知的场景
经验法则：要识别/过滤某种颜色 → 转 HSV；要压缩/编码 → 用 YUV 类；进神经网络 → 通常还是 RGB 归一化后直接喂。

为什么模型一定要做归一化

不归一化的问题
像素 0-255 直接输入，激活函数容易进入饱和区，梯度变小、收敛慢甚至训不动
归一化的收益
输入落在稳定区间（0-1 或均值 0 方差 1），训练平稳、收敛快，也便于迁移学习复用预训练统计量
易错点：推理时的预处理必须和训练完全一致（同样的 resize / 归一化方式 / 通道顺序 BGR vs RGB）。这是工业部署最常见的掉点原因之一。

常见格式与压缩取舍

格式压缩特点与适用
JPEG有损体积小、适合照片；有块状伪影，不支持透明
PNG无损支持透明、边缘锐利；适合截图/线条图，体积大
WebP / AVIF有损+无损同等画质体积更小，Web 端主流
BMP / RAW基本不压缩保真但体积巨大，多用于采集与中间处理
有损压缩会破坏高频细节，对超分辨率、鉴伪、OCR等任务影响明显：训练与推理数据的压缩水平要尽量一致。

面试速记卡

  • 表示：图 = (H,W,3) 张量；uint8 0-255 → 浮点并归一化后再进网络。
  • 色彩空间：RGB 混了亮度与颜色；HSV 解耦便于颜色筛选；YUV 是压缩基础。
  • 归一化：防饱和、稳训练；推理预处理必须与训练一致（含 BGR/RGB 顺序）。
  • 格式：JPEG 有损适合照片；PNG 无损支持透明；有损压缩会伤高频任务。

模型眼里的图，从来不是「一张照片」

人看到的是「一只猫」，模型看到的是一个多维数值数组。理解图像的表示方式有四个层次：像素空间（H×W×C 的字节）、张量（归一化浮点数）、特征图（带语义的中间激活）、向量（可用于检索的嵌入）。所有视觉模型本质上都是在做这几种表示之间的变换。

像素空间H×W×3，0-255 整数，最直观也最冗余
张量 CHWPyTorch 惯例 [C,H,W]，浮点，需归一化
HWC / BGROpenCV/NumPy 惯例，与 PyTorch 顺序不同
特征图下采样后的多通道激活，含语义与上下文
嵌入向量全局池化后的 1×D，用于检索/分类
潜空间编码器压缩后的紧凑表示，扩散在此去噪
四种表示：从像素到语义，维度递减、抽象递增

表示方式对比与陷阱

表示形状典型数值范围用途常见陷阱
原始像素H×W×3 uint80-255存储、显示、数据增强直接喂模型会因数值过大导致训练不稳
归一化张量3×H×W float32[0,1] 或 [-1,1]模型输入训练/推理归一化不一致是头号线上事故
ImageNet 标准化3×H×W均值方差处理后约 [-2,2]复用预训练权重时自训模型不必强行套用，但用了预训练就必须套
特征图C×H/s×W/s无约束检测头/分割头输入下采样率决定小目标能否被检出
全局嵌入D 维常做 L2 归一化检索、聚类、相似度未归一化时内积受模长干扰，要用余弦
潜空间 latentc×h×w约 [-4,4]扩散模型去噪对象潜空间数值范围决定 CFG 与噪声调度
频域幅度谱/相位谱复数压缩、去噪、超分分析直接改幅度谱易产生振铃

通道顺序陷阱：OpenCV 读出来是 HWC + BGR，PyTorch 要 CHW + RGB。忘记转换会得到「颜色诡异但能跑」的模型——训练时看不出来，部署才发现。规范做法：读取后立刻统一成 RGB，并在数据管线里只保留一种约定。

实践要点

① 统一数据管线约定

  • 定一条铁律：进入模型前必须是 RGB + CHW + float32 + 已归一化。
  • 读取（OpenCV/PIL）后立刻转换，不要让约定散落在代码各处。
  • 写单元测试：喂一张纯红图，断言输出通道顺序正确。

② 归一化怎么选

  • 用 ImageNet 预训练权重 → 必须用对应均值方差。
  • 扩散模型 → 通常映射到 [-1,1]。
  • 自己从零训 → 可以用本数据集统计值，或简单 /255。
  • 无论如何，训练与推理必须完全一致。

③ 分辨率与下采样

  • 输入尺寸最好是下采样倍率的整数倍（如 32）。
  • 小目标任务别过度下采样，特征图上小于 1 像素就检不出了。
  • 保持长宽比 vs 强制方形：前者保形变，后者批处理简单。

④ 表示的语义层级

  • 浅层特征：边缘、颜色、纹理（通用、易迁移）。
  • 中层特征：部件、形状（较通用）。
  • 深层特征：物体类别、语义（任务相关）。
  • 迁移学习冻结到哪一层，取决于源域与目标域相似度。

深入自检

为什么不能把 0-255 的图直接喂给神经网络？

数值尺度过大会让激活值饱和、梯度不稳定，优化过程极慢甚至发散。归一化到 [0,1] 或标准正态分布后，各层输入尺度一致，损失曲面更平滑，收敛快得多。

OpenCV 和 PIL 读同一张图，为什么训练结果不一样？

两者通道序（BGR vs RGB）与默认解码库略有差异；若代码里一处用 cv2、一处用 PIL 却没统一转换，训练集内部就会有两种色彩序，模型学到的是混合分布。务必在管线入口统一。

什么是潜空间，为什么扩散要在潜空间做？

潜空间是自编码器把图像压缩后的紧凑表示（如 8×8 下采样、通道数增加）。在潜空间去噪能把计算量降低一个数量级，同时高频噪声被编码器滤掉，训练更稳定。代价是细节上限受编码器限制。

嵌入向量为什么要 L2 归一化？

归一化后内积等于余弦相似度，只衡量方向（语义）不受向量模长影响。不归一化时，某些样本整体模长大就会在检索中霸榜，与语义无关。

特征图分辨率不够，小目标就检不出吗？

基本是。若下采样 32 倍，一个 16×16 的物体在特征图上不到 1 个像素，几乎没有可学习信号。对策：减小下采样率、用 FPN 多尺度融合、增大输入分辨率、或对小目标做 ROI 放大。

图像的频域表示有什么用？

低频决定轮廓与色块，高频决定纹理与边缘。JPEG 压的是高频；超分要补的是高频；模糊与去噪本质是频域滤波。频域分析能直观解释很多图像处理的成败，也常用于检测压缩伪影与 AI 生成痕迹。
