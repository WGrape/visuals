清理策略

定时线程 / 访问时检查

最小实现

用 ConcurrentHashMap<K, V> 存储，value 包装一个 expireAt 时间戳。get 时若已过期则移除并返回 null；后台用 ScheduledExecutorService 周期扫描过期项。

注意点

  • 内存无界：需设上限/淘汰，否则溢出
  • 清理线程开销：扫描频繁影响性能
  • 并发过期惊群：多线程同时发现过期可能集中加载

🎯 面试问答

Q：为什么不直接用 HashMap？
A：需线程安全(用 ConcurrentHashMap)，且要过期/上限，HashMap 无这些能力。
Q：惰性删除有什么问题？
A：冷 key 永远不被访问就不会清理，需配合定时扫描扣底。
Q：手写和用 Caffeine 怎么选？
A：学习/简单场景手写，生产环境直接用 Caffeine / Guava。
