➕ 前缀和与差分详解

区间求和 O(1) · 区间加减 O(1) · 二维扩展 · 前缀和与哈希表

一句话总结

前缀和用于"频繁查询区间和"：预处理 O(n) 后，任意 [l, r] 的和都能 O(1) 算出。差分是它的逆运算，用于"频繁对区间做加减"：每次修改只需 O(1) 打两个标记，最后做一次前缀和还原。两者本质都是用预处理换查询速度。

📊

前缀和

pre[i] = 前 i 个数之和。sum(l, r) = pre[r+1] - pre[l]。

🏷️

差分

diff[l] += v, diff[r+1] -= v。还原后即为区间加 v 的结果。

🔲

二维前缀和

pre[i][j] 表示左上角矩形之和，容斥原理求子矩阵和。

🔑

前缀和 + 哈希表

把"和为 k 的子数组个数"从 O(n²) 降到 O(n)。

一、一维前缀和

1.1 构造与查询

class NumArray: def __init__(self, nums): self.pre = [0] * (len(nums) + 1) for i, x in enumerate(nums): self.pre[i + 1] = self.pre[i] + x # 递推构造 def sumRange(self, left, right): return self.pre[right + 1] - self.pre[left] # O(1) 查询 # 更简洁的写法（Python） from itertools import accumulate pre = [0] + list(accumulate(nums))
💡 为什么 pre 长度是 n+1？为了让 left = 0 时公式 pre[right+1] - pre[left] 依然成立（此时需要 pre[0] = 0）。这个"哨兵位"是前缀和最容易写错的地方。

二、一维差分

2.1 核心思想

如果要对数组区间 [l, r] 里每个元素都加 v，朴素做法是 O(r-l+1)。差分数组只需两个 O(1) 操作：

def range_add(n, operations): # operations: [(l, r, v), ...] 表示对 [l, r] 每个元素 +v diff = [0] * (n + 1) for l, r, v in operations: diff[l] += v if r + 1 < n: diff[r + 1] -= v # r+1 越界则不需要（已到末尾） # 对 diff 做前缀和还原 res, cur = [], 0 for i in range(n): cur += diff[i] res.append(cur) return res # 经典题：1109 航班预订统计（每笔订单给区间 [i, j] 各加 seats 个座位） def corpFlightBookings(bookings, n): diff = [0] * (n + 1) for first, last, seats in bookings: diff[first - 1] += seats # 题目下标从 1 开始 diff[last] -= seats for i in range(1, n): diff[i] += diff[i - 1] # 就地做前缀和 return diff[:n]

三、二维前缀和

3.1 容斥原理

class NumMatrix: def __init__(self, matrix): m, n = len(matrix), len(matrix[0]) self.pre = [[0] * (n + 1) for _ in range(m + 1)] for i in range(m): for j in range(n): self.pre[i + 1][j + 1] = (matrix[i][j] + self.pre[i][j + 1] + self.pre[i + 1][j] - self.pre[i][j]) def sumRegion(self, row1, col1, row2, col2): return (self.pre[row2 + 1][col2 + 1] - self.pre[row1][col2 + 1] - self.pre[row2 + 1][col1] + self.pre[row1][col1])

四、前缀和 + 哈希表：和为 K 的子数组

4.1 从 O(n²) 到 O(n)

560. 和为 K 的子数组。暴力枚举所有区间是 O(n²)。利用前缀和：区间 [j+1, i] 的和 = pre[i] - pre[j]。我们要它等于 K，即 pre[j] == pre[i] - K。于是遍历到 i 时，只需查"之前出现过多少次前缀和等于 pre[i] - K"。

from collections import defaultdict def subarraySum(nums, k): count = defaultdict(int) count[0] = 1 # ★ 关键：前缀和为 0 出现过 1 次（空前缀） pre = 0 ans = 0 for x in nums: pre += x # 当前前缀和 ans += count[pre - k] # 之前有多少个 pre[j] == pre - k count[pre] += 1 # 记录当前前缀和 return ans # 时间 O(n)，空间 O(n)
⚠️ 两个易错点：
① count[0] = 1 必须有——它代表"从第 0 个元素开始的子数组"这种情况；
② 必须先查询再插入。如果先 count[pre] += 1 再查 count[pre-k]，当 k=0 时会把自己也算进去，导致多算。

多次区间加减，最后一次性输出差分O(1) 每次还原 O(n)
边修改边查询（动态）线段树 / 树状数组O(n)O(log n)
矩阵多次查子矩阵和二维前缀和O(mn)O(1)
矩阵多次子区域加减二维差分O(1) 每次还原 O(mn)

一句话记住：前缀和是"差分"的逆，差分是"前缀和"的逆。查询多用前缀和，修改多用差分。两者结合（先差分打标记，再前缀和还原）能 O(n) 完成任意次区间加减。
与滑动窗口的关系：《滑动窗口》一篇中提到"有负数时不能滑动窗口求最短和 ≥ target"——那种情况的正确解法就是前缀和 + 单调队列 / 二分。前缀和不要求元素非负，是更通用的区间和工具。

第一层 · 概念与判定：前缀和与差分分别解决什么

一句话判据：「区间求和」用前缀和，「区间整体加/减」用差分。两者互为逆运算。

问题形态用哪个预处理单次操作关键特征
多次查询 [l, r] 的和前缀和O(n)O(1)数组不变，查很多次
多次对 [l, r] 整体加 v差分O(n)O(1)多次修改，最后统一求结果
边改边查都不行——上线段树或树状数组（O(log n)）
二维区域求和二维前缀和O(n·m)O(1)容斥原理
  • 信号一：题目描述里出现「多次询问」「q 次查询」且数组不变 → 前缀和。
  • 信号二：出现「把区间 [l,r] 都加上 x」「最后问每个位置的值」→ 差分。
  • 信号三：既改又查 → 前缀和/差分都不够，需要更高级的数据结构。

记忆口诀：前缀和查、差分改。前缀和是「提前算好累积」，差分是「只在端点打标记、最后再累积」。

第二层 · 参数·命令·量化：模板、下标约定与复杂度

前缀和与差分模板

# 一维前缀和（推荐 1-based，pre[i] = 前 i 个元素的和）
def build_prefix(a):
    n = len(a)
    pre = [0] * (n + 1)
    for i in range(1, n + 1):
        pre[i] = pre[i - 1] + a[i - 1]
    return pre

# 查询 [l, r]（闭区间，1-based）
def query(pre, l, r):
    return pre[r] - pre[l - 1]

# 一维差分：区间 [l, r] 加 v（1-based）
def range_add(diff, l, r, v):
    diff[l]     += v
    diff[r + 1] -= v        # 注意 r+1 不能越界，数组开 n+2

# 差分还原成最终数组
def restore(diff):
    for i in range(1, len(diff)):
        diff[i] += diff[i - 1]
    return diff[1:-1]

# 二维前缀和：pre[i][j] = 左上角 (1,1) 到 (i,j) 的矩形和
# pre[i][j] = a[i][j] + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1]
# 查询矩形 (x1,y1)-(x2,y2)：
#   pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]
操作时间复杂度空间复杂度说明
构建前缀和O(n)O(n)可原地（复用原数组）
单次区间查询O(1)—两次减法
差分打标记O(1)—两端各改一次
差分还原O(n)O(1)（原地）一次前缀累加
暴力区间求和O(n)O(1)查询多时必超时

下标约定是最大坑源：推荐统一用 1-based——pre 开 n+1，diff 开 n+2，查询闭区间 [l,r] 时 consistently 用 pre[r] - pre[l-1]。

第三层 · 排障与边界：下标与越界

坑后果正确做法
0-based 与 1-based 混用结果整体偏移一位全程统一一种，推荐 1-based
查询 pre[r] - pre[l-1] 时 l=0下标 -1（Python 会静默取最后一个元素）l 从 1 起；或特判 l==0
差分 diff[r+1] 越界IndexError 或覆盖其他数据diff 数组开 n+2
差分忘了还原拿到的是标记数组不是结果最后必须做一次前缀累加
多次 add 后只还原一次结果不对所有 add 打完标记后统一还原一次即可（这是差分的优势）
  • 排查顺序：先用最小样例 [1,2,3] 手工验证 query(1,3)=6 → 再测边界 l=1、r=n → 再看 diff 数组长度。
  • 边界一：前缀和容易溢出——n=1e5、每个值 1e9 时，和可达 1e14，32 位 int 装不下，要用 long / Python 无所谓但 C++ 要注意。
  • 边界二：差分处理的是「最后统一还原」的场景；如果每加一次就要立刻知道某个位置的值，差分不适用。
  • 边界三：二维前缀和的容斥公式容易写错符号，记忆方式是「加上大的、减去两个缺一角的、加回重复减的」。

对拍验证

# 自测：用暴力法对拍验证前缀和
import random
a = [random.randint(0, 100) for _ in range(50)]
pre = [0]
for v in a: pre.append(pre[-1] + v)
for _ in range(100):
    l, r = random.randint(1, len(a)), random.randint(1, len(a))
    if l > r: l, r = r, l
    assert pre[r] - pre[l-1] == sum(a[l-1:r])     # 与暴力结果比对

第四层 · 原理与取舍：为什么能省一个量级

本质是用空间换时间 + 把重复计算折叠掉：区间和 sum(l..r) 本来要加 r-l+1 个数，但两个前缀和相减时，1..l-1 这一段被减掉了，剩下正好是 l..r。查多少次都只做两次减法。

方法预处理单次查询修改代价适用
暴力求和无O(n)O(1)只查一两次
前缀和O(n)O(1)O(n)（要重建）静态数组、查很多次
差分O(n)O(n)（要还原）O(1)改很多次、最后看结果
树状数组 / 线段树O(n)O(log n)O(log n)边改边查
前缀和和差分是什么关系？

互为逆运算：对原数组求前缀和得到 pre；对 pre 求差分得到原数组。差分是「记录相邻差值」，前缀和是「把差值累积回去」。所以差分打完标记后，做一次前缀累加就还原了。

数组会被修改时还能用前缀和吗？

单点修改可以（但要 O(n) 更新后续所有前缀和，不划算）；区间修改就不行了。这种情况换树状数组（单点/区间修改 + 区间查询，均 O(log n)）或线段树（更强）。

二维前缀和怎么记忆容斥公式？

把矩形和想成四个角的组合：S(x2,y2) - S(x1-1,y2) - S(x2,y1-1) + S(x1-1,y1-1)。减掉左边一块和上边一块，被重复减掉的左上角那一块要加回来。
