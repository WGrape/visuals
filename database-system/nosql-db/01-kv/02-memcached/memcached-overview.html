🧱 Memcached 概览

高性能、多线程的分布式内存对象缓存系统

核心定位

⚡

纯内存缓存

把热点数据放在内存中，挡在数据库前面，极大降低读延迟。

🧵

多线程模型

基于 libevent + 多线程 worker，充分利用多核，与 Redis 单线程不同。

🗑️

LRU 淘汰

内存满时按 LRU 淘汰，没有持久化，重启即丢失。

🔑

极简 KV

只支持 key-value，key ≤ 250B，value ≤ 1MB。

为什么需要它

典型场景：缓存数据库查询结果、Session、页面片段、计数器等读多写少的热点数据。它是『旁路缓存（Cache-Aside）』模式最常见的承载者。

💡 Memcached 与 Redis 的关键差异：Memcached 只有 KV、多线程、无持久化、无数据结构；Redis 单线程（部分多线程）、支持丰富数据结构与持久化。两者并非替代关系，而是各有侧重。
