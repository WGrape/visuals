函数与装饰器

Python 把函数当成「一等公民」：能赋值、能传参、能返回、能嵌套。装饰器不过是把「函数包函数」这件事语法糖化——理解它，才算真正入门 Pythonic 写法。

一等公民

函数可以像变量一样被对待

「一等公民（first-class）」指函数能被赋给变量、作为实参传入、作为返回值、存进容器。这是装饰器和很多高级写法的基础。

📦
赋值
把函数绑到另一个名字，原名字仍在
➡️
传参
把函数当回调传给 map/sorted/别的函数
🏭
返回
函数里 return 另一个函数（工厂/闭包）
def greet(name): return f"hi {name}"

say = greet          # 赋值给变量
print(say("a"))       # hi a

def run(f, x): return f(x)   # 作为实参传入
print(run(greet, "b"))  # hi b

fs = [greet, len]      # 存进容器
print([f("xy") for f in fs])  # ['hi xy', 2]

函数也是对象（详见名称绑定与对象语义）：它身上挂着 __name__、__doc__、闭包变量等属性，所以装饰器才能「读改写」它。

参数解构

*args 收集位置参数，**kwargs 收集关键字参数

Python 用 * 和 ** 把「任意数量」的参数聚成元组 / 字典，反过来也能把它们「打散」传给别的函数。这是写装饰器、包装函数的必备技能。

def f(a, b, *args, **kwargs):
    print(a, b, args, kwargs)

f(1, 2, 3, 4, x=5)   # 1 2 (3, 4) {'x': 5}

# 反向打散：把序列/字典拆成实参
nums = [1, 2, 3]
print(range(*nums))     # range(1, 2, 3)
d = {"x": 1, "y": 2}
f(0, 0, **d)         # 0 0 () {'x': 1, 'y': 2}
⚠️ 危险顺序（Python 3 强制）：位置 / *args / 仅关键字 / **kwargs。关键字-only 参数要写在 * 之后，例如 def f(a, *, b)——调用时 b 必须显式写名字。
可变默认参数的坑（列表当默认值会被共享）放在语言特性篇讲过；这里只需记住：默认值在定义时求值一次，别用可变对象当默认。
闭包

内层函数「记住」了外层变量

闭包 = 内层函数 + 它捕获的外层作用域变量。即使外层函数已经返回，这些变量依然活着。装饰器正是建立在闭包之上。

def make_adder(n):
    def add(x):
        return x + n      # add 捕获了外层的 n
    return add

plus3 = make_adder(3)
print(plus3(10))      # 13 —— n=3 被记住了
print(plus3.__closure__)  # 闭包单元，存着 n

闭包捕获的是变量本身不是当时的值，所以循环里挂闭包要小心「延迟绑定」（见作用域与命名空间的坑）。想冻结值，用默认参数：def f(x=i): ...。

装饰器

@ 只是「函数包函数」的语法糖

@deco 等价于 func = deco(func)：把原函数塞进一个包装函数，再把这个包装函数绑回原名。包装函数里先做事、再调用原函数、可改返回值。

import functools, time

def timer(func):
    @functools.wraps(func)      # 保留原函数的 __name__/__doc__
    def wrapper(*args, **kwargs):
        t0 = time.time()
        r = func(*args, **kwargs)  # 调用原函数
        print(f"{func.__name__}: {time.time()-t0:.3f}s")
        return r
    return wrapper

@timer
def slow():
    time.sleep(0.1)

slow()   # slow: 0.100s
带参装饰器是「三层嵌套」：外层收参数返回真正装饰器。常见套路 def deco(arg): def deco2(f): ... return deco2。永远记得 @functools.wraps(func)，否则原函数的名字和文档会被包装函数覆盖，调试时很坑。
内置装饰器

四个最常用的「语言级」装饰器

这些是 Python 标准库直接提供的装饰器，理解它们能少写很多样板代码。

装饰器作用典型用途
@property把方法当属性访问（只读）计算型字段、惰性属性
@staticmethod不绑定实例/类的方法工具函数，放类里只为归类
@classmethod首参是类 cls工厂方法、替代重载构造
@functools.lru_cache记忆化缓存返回值斐波那契、递归、查表
class Circle:
    def __init__(self, r): self.r = r
    @property
    def area(self): return 3.14 * self.r ** 2

    @classmethod
    def unit(cls): return cls(1)   # 工厂

c = Circle(2)
print(c.area)          # 像属性一样访问，不用 c.area()
u = Circle.unit()      # 类方法构造

装饰器不是魔法，本质就是「接收函数、返回函数」的高阶函数。把这一篇和作用域、对象语义串起来看，Python 的函数模型就通了。
