🏗️ Memcached 架构

多线程、事件驱动与 Slab 内存分配

整体架构

Memcached 采用『主线程 + 多个 worker 线程』：主线程负责监听端口并接受连接，通过管道把连接分发给 worker；每个 worker 用 libevent 跑事件循环，处理自己分到的连接上的读写。

Slab Allocator 内存模型

Memcached 把内存预先切成若干 slab class，每个 class 只存放固定尺寸的 chunk（如 96B、120B、152B…按 1.25 倍增长）。写入时选择能容纳该 value 的最小 chunk，避免内存碎片。

  • 每个 item = chunk 头 + key + value + flags + expire + cas。
  • 内存页（默认 1MB）按 slab class 归组；某 class 满时无法借用其他 class 的空间 → 可能『内存有空余却 evict』。
  • 可用 slab_reassign / slab_automove 缓解热点 class 不足。
💡 调优口诀：根据业务 value 分布选择初始 chunk 大小与增长因子（-f），减少跨 class 浪费；监控 evictions 与 OOM 计数。
