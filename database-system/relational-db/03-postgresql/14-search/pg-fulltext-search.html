全文检索

tsvector / tsquery、GIN 索引、权重与排名，以及中文分词。

核心类型索引与查询权重与排名中文分词

① 核心类型

  • tsvector：文档的“词素向量”（已分词、归一化）。
  • tsquery：查询（词 + & | ! 操作符）。
  • @@：匹配操作符，返回布尔。
  • to_tsvector() / to_tsquery()：文本转换。
SELECT 'PG 的全文检索很强大' @@ to_tsquery('全文 & 检索');  -- true

② 索引与查询

为加速，给 to_tsvector 建 GIN 索引（见 02-indexes）。

CREATE INDEX idx_ft ON docs USING gin(to_tsvector('zhcfg', body));
SELECT * FROM docs WHERE to_tsvector('zhcfg', body) @@ to_tsquery('zhcfg', '搜索');

③ 权重与排名

用 setweight 给标题/正文设不同权重（A>B>C>D），ts_rank 计算相关性排序：

SELECT title, ts_rank(...)
FROM docs
WHERE to_tsvector('zhcfg', body) @@ to_tsquery('zhcfg', 'pg')
ORDER BY ts_rank(...) DESC LIMIT 10;

④ 中文分词

内置词典对中文支持弱，需用 zhparser（基于 SCWS） 或 pg_jieba 扩展注册中文分词配置 zhcfg，否则中文会被当成一个词。

对比 MySQL：PG 全文是“真分词 + 可定制词典 + GIN 高效”，比 MySQL FULLTEXT 的中文支持更可控，且能与 JSONB/数组混合检索。
