DFA 最小化手算：哪些状态看起来不同却能合并

用四状态奇偶自动机演示可达性、接受状态分组、分割细化与 Myhill–Nerode 直觉。

先问状态代表什么未来

有限自动机读完一段输入后停在某个状态。两个状态能否合并，关键不在名称、画图位置或到达它们的前缀是否相同，而在“未来继续读任意字符串时，接受结果是否总相同”。如果存在某个后缀能让一个状态接受、另一个拒绝，这个后缀就把它们区分开，二者绝不能合并；如果对所有后缀的结果都一样，它们对识别语言来说等价。DFA 最小化就是把所有等价状态合并，同时保留原语言。

开始前先移除从初态根本到不了的状态。不可达状态即使被画在图上，也不会参与任何实际输入的运行；把它留在分组里会让“最小状态数”虚高。输入字母表必须明确，本课只用 0 和 1；缺少转移时要按完整 DFA 的要求处理死状态，不能悄悄把失败边忽略。

图解：奇偶 1 自动机的最小化

沿箭头逐步核对输入、变换和输出；下面的推演可以逐步切换。

四个状态读二进制串

设计 A、C 为接受状态，表示目前读到的 1 的数量为偶数；B、D 为拒绝状态，表示奇数。转移为：A 遇 0 到 C、遇 1 到 B；C 遇 0 到 A、遇 1 到 D；B 遇 0 到 D、遇 1 到 A；D 遇 0 到 B、遇 1 到 C。初态 A。读入“101”时 A→B→D→C，最终接受，因为两个 1 为偶数。四个状态都可由某些输入到达，却有冗余：0 会在 A/C 或 B/D 内来回切换，并未改变“1 的奇偶性”。

若只凭“状态 A 和 C 转移目标不同”就判定不可合并，会漏掉目标本身也可能等价。最小化比较的是目标落在哪个等价组，而不是目标字母名称是否相同。

逐步推演

剔除不可达

从初态沿 0、1 探索，只保留可能运行到的状态。

先分接受性

A/C 接受，B/D 拒绝，空后缀可区分两组。

检查目标组

同组状态读 0、1 后总落到相同的组。

合并并验证

A/C 合为偶态，B/D 合为奇态，再抽样测试。

分割细化一步步做

初始分组先按是否接受切成 {A,C} 与 {B,D}，因为空后缀就能区分接受与拒绝。接着检查同组状态对每个输入符号的目标组：A 和 C 遇 0 都仍在接受组，遇 1 都到拒绝组，因此暂时不用拆；B 和 D 遇 0 都在拒绝组，遇 1 都到接受组，也不用拆。再做一轮仍无变化，分组稳定，合并 A/C 为 E、B/D 为 O。

得到的两状态 DFA 是：E 遇 0 留 E，遇 1 到 O；O 遇 0 留 O，遇 1 到 E，E 是初态和接受态。它精确识别“1 的个数为偶数”的语言。随便抽测空串、0、1、10、101、111，与原四状态机逐条比较，可以帮助发现手算转移写错。

ACB是
CAD是
BDA否

什么情况要继续拆组

设同一当前组中的 P 和 Q，读符号 1 后 P 到接受组、Q 到拒绝组，那么后缀“1”就直接区分 P 与 Q，必须拆开。分割后，其他组原本看似相同的状态可能因为它们指向 P/Q 的不同新组而被下一轮拆开。因此算法需反复细化直到稳定，不能只做第一轮。构造等价类时每轮都以当前分组为准，避免在一次扫描中随意使用半更新状态产生难以复核的结果。

表填充法从状态对出发，先标记接受/拒绝不同的对，再传播“某输入转到已标记的一对”的区别；它和分割细化表达的是同一等价关系。小题手算可任选一种，但答卷应写出为何不能合并的后缀或稳定分组。

Myhill–Nerode 的意义

从语言本身看，两个前缀等价，指的是它们后面接任何后缀，是否属于语言的答案都一致。对于奇偶 1 的语言，所有前缀只分成“偶数个 1”和“奇数个 1”两类，所以最少需要两个状态。空串与“1”不同类，空后缀就能区分：空串被接受，“1”不被接受。这个观点解释了为什么任何识别同一语言的 DFA 最小状态数都相同，尽管状态名字和画法可以不同。

若某语言能产生无限多个两两可区分的前缀，它就不能由有限状态数的 DFA 识别。这是判断非正则语言的另一种思路，但使用时必须证明“对任意不同前缀都有某个区分后缀”，不能只举几个例子。

与 NFA、正则表达式的边界

NFA 可以同一符号走多条边，也可有 ε 转移；直接套本课的 DFA 分组表会遗漏非确定性。常见路线是先把 NFA 子集构造成 DFA，去掉不可达状态，再最小化。子集构造在最坏情况下可能指数膨胀，实际实现可按需要生成可达子集。正则表达式同样可以编译成自动机，词法分析器常合并并最小化状态以减少转移表空间。

最小 DFA 优化的是状态数量，不保证运行时每个输入最省内存或最快：稀疏转移存储、Unicode 字符类别和生成器实现仍会改变开销。验收时首先确保语言保持不变，再比较实际性能。

填表法（table-filling）的判定规则

步骤操作复杂度
1删除从初态不可达的状态O(n + m)
2标记所有「接受态 × 非接受态」的状态对为可区分O(n²)
3反复扫描：若 (p,q) 在某个输入 a 下转移到已标记可区分的对，则标记 (p,q)每轮 O(n²·|Σ|)，最多 n 轮
4未被标记的状态对即等价，合并为同一状态O(n²)
总计朴素填表法O(n²·|Σ|)；Hopcroft 算法 O(n·log n)

核心不变式：两个状态等价 ⟺ 对所有输入串，从二者出发的接受性完全一致。填表法就是从长度为 0 的串（接受/非接受）开始，逐步用长度为 k 的串区分出更多状态对。

手算示例：状态对标记表

设 DFA 状态 {A,B,C,D,E,F}，字母表 {0,1}，接受态 {C,D,E}：

状态对初始标记（接受性不同）第 1 轮（经 0/1 转移）结论
(A,B)否（都非接受）δ(A,0)=B, δ(B,0)=C → (B,C) 可区分可区分
(A,C)是—可区分（初始即为是）
(B,C)是—可区分
(C,D)否（都接受）转移均落在接受态内，无法区分等价，可合并
(D,E)否（都接受）δ(D,1)=D, δ(E,1)=E → 回到自身对，无新信息等价，可合并
(A,F)是—可区分
  • 合并后状态数从 6 降到约 3~4，最小化 DFA 在同构意义下唯一。
  • 判定技巧：若一对状态转移到自身或转移到已被判定等价的对，就不会被标记（不动点即等价）。
  • 不可达状态必须先删除，否则会被误当作独立状态保留，导致结果不是最小 DFA。

可执行的最小化实现

实现

def minimize(states, sigma, delta, start, accept):
    """填表法：delta[(state, ch)] -> state；states 为已去不可达的状态集合。"""
    pairs = {(p, q) for p in states for q in states if p < q}
    # 1) 初始标记：接受性不同
    marked = {(p, q) for (p, q) in pairs
              if (p in accept) != (q in accept)}
    # 2) 反复传播直到不动点
    changed = True
    while changed:
        changed = False
        for (p, q) in pairs - marked:
            for a in sigma:
                np_, nq = delta[(p, a)], delta[(q, a)]
                if np_ == nq:
                    continue
                key = (np_, nq) if np_ < nq else (nq, np_)
                if key in marked:
                    marked.add((p, q)); changed = True; break
    # 3) 未被标记的对合并：用并查集或直接按等价类分组
    parent = {s: s for s in states}
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    for (p, q) in pairs - marked:
        parent[find(p)] = find(q)
    groups = {}
    for s in states:
        groups.setdefault(find(s), []).append(s)
    return groups                      # 每个 group 就是最小化后的一个状态

# 复杂度：状态数 n、字母表 |Σ|
#   朴素填表 O(n^2 * |Σ|)；Hopcroft 划分精化 O(n log n)

常见错误与排障清单

症状原因处理
结果仍有冗余状态没先删除不可达状态从初态做 BFS/DFS 只保留可达状态
把不等价的状态合并了传播循环没跑到不动点用 while changed 直到无新增标记
接受态与非接受态被合并初始标记漏了第 1 步就标记所有接受性不同的对
转移函数合并后不完整合并后没重算 δ新状态用代表元的转移，并验证所有输入都有定义
有死状态残留死状态（到不了接受态）没清理删除所有无法到达接受态的状态（它们与任何状态都不等价）
NFA 直接套用NFA 需先确定化（子集构造）先子集构造转 DFA，再最小化

深入自检

为什么「接受态和非接受态」一定可区分？

因为存在长度为 0 的串 ε 就能区分：从接受态读 ε 接受，从非接受态读 ε 不接受。这是填表法的初始种子，之后逐步用更长的串区分更多状态对。

填表法什么时候停止？

当某一整轮扫描没有新增任何标记时达到不动点。最多 n−1 轮（每轮至少新增一对或结束），总复杂度 O(n²·|Σ|)。

最小化后的 DFA 唯一吗？

在同构意义下唯一：任何接受同一语言的最小 DFA 状态数相同，且结构只差状态命名。这一定理是 DFA 最小化可作为等价性判定工具的基础。

如何判断两个 DFA 是否等价？

两个办法：一是分别最小化后比较（同构即等价）；二是构造乘积自动机，看是否存在一个串使两者接受性不同（BFS 搜索区分串）。

Hopcroft 算法为什么更快？

它不做 O(n²) 的状态对枚举，而是维护划分并用「较小的半集」去精化，每个状态被处理的次数是 O(log n) 量级，总复杂度 O(n log n)，适合状态数很大的自动机（如词法分析器的 DFA）。

自检

A 遇 0 到 C、C 遇 0 到 A，目标状态名字不同，能否仅据此断定 A/C 不等价？

不能。应比较目标落入的等价组；A 和 C 遇 0 后都仍在接受组，遇 1 后都到拒绝组。
