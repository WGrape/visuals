Transformer 架构

归一化：BatchNorm / LayerNorm / RMSNorm 与 Pre-LN

归一化用来稳定训练、加速收敛。NLP/LLM 主流从 BatchNorm 转向 LayerNorm，再到更省计算的 RMSNorm，并把位置从残差后挪到残差前（Pre-LN）。本文一次理清。

一句话回答

归一化把神经元激活拉回稳定分布，防止梯度爆炸/消失、加速收敛。LLM 时代主线是：BatchNorm（不适合序列） → LayerNorm（按特征维） → RMSNorm（去掉均值中心，更省）；位置普遍用 Pre-LN（放残差之前更稳）。

BatchNorm 为什么不适合 NLP

BN 在一个 batch 内、跨样本对同一个特征维度求均值方差。问题：

  • 序列长度不一：每个样本 token 数不同，跨 batch 对齐某位置很别扭。
  • 依赖 batch 大小：小 batch 或推理时（batch=1）统计不准，训推不一致。
  • 破坏时序关系：跨样本归一化把"第 i 个位置"和其他样本的同一位置混在一起。
结论：CV 里 BN 很香，但序列模型几乎不用 BN，改用 LayerNorm（只在一个样本内部、跨特征维归一化，与 batch 无关）。

LayerNorm：按特征维归一化

对单个样本的整条隐藏向量（d 维）求均值 μ 和方差 σ²，再标准化、缩放平移：

x̂ = (x − μ) / √(σ² + ε)    y = γ ⊙ x̂ + β
优点：与 batch 大小无关、推理一致、适合变长序列。BERT、GPT-2、原始 Transformer 都用 LN。

RMSNorm：LLM 的主流

RMSNorm（Zhang 2019，被 Llama、Qwen、GPT-J 等采用）发现：LayerNorm 里的均值中心化（减 μ）收益不大，于是去掉它，只除以均方根 RMS：

RMS(x) = √( (1/d)·Σ xᵢ² + ε )    x̂ = x / RMS(x)    y = γ ⊙ x̂
收益：少算一次均值和一次减法，计算更省、数值更稳，在超大模型上积少成多。质量与 LN 基本持平，所以成为 LLM 默认。

Pre-LN vs Post-LN

归一化放在残差连接的里面还是外面，影响训练稳定性：

Post-LN（原版）
输出 = x + Sublayer(LN(x))。深层易梯度消失，需要精细 warmup、学习率调度。
Pre-LN（主流）
输出 = x + Sublayer(x)，内部先 LN。梯度路径更直，训练更稳，几乎不需 warmup。
现代 LLM 几乎都用 Pre-LN + RMSNorm 组合。

总结

  • 归一化稳定训练；序列模型弃用 BN（跨 batch 不适合）。
  • LN 按特征维、与 batch 无关；RMSNorm 去掉减均值、更省，成 LLM 默认。
  • Pre-LN 比 Post-LN 梯度更稳，是工程标配。
  • 记忆口诀：LN→RMSNorm，Post→Pre。

一、为什么是 LayerNorm 而不是 BatchNorm

BatchNormLayerNorm
统计维度跨 batch、按特征通道跨特征、按单个样本
依赖 batch 大小强依赖，小 batch 效果差无关
推理时要用训练期累积的移动统计量直接算，训练推理一致
变长序列padding 会污染统计量每个位置独立，天然适配
适用CNN / 固定长度输入Transformer / RNN / 变长序列

序列任务里 batch 内样本长度不一、padding 比例变化，BatchNorm 的统计量会被 padding 严重污染；而小 batch 又是大模型训练的常态。这两个原因让 LayerNorm 成为 Transformer 的唯一选择。

二、公式与实现

# LayerNorm mean = x.mean(dim=-1, keepdim=True) var = x.var(dim=-1, unbiased=False, keepdim=True) x_hat = (x - mean) / torch.sqrt(var + eps) out = gamma * x_hat + beta # gamma/beta 是可学习参数，逐特征 # RMSNorm（LLaMA / Qwen / Mistral 等主流 LLM 用这个） rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + eps) out = gamma * (x / rms) # 只做缩放，不做平移、不减均值 # 区别：RMSNorm 省掉了「减均值」和「加 beta」 # 效果：略快（少两次逐元素操作），实践中效果相当 # 直觉：归一化真正关键的是<b>缩放尺度</b>，把均值拉到 0 不是必需的
eps 不是可有可无的

eps（通常 1e-5 或 1e-6）防止方差为 0 时除零。但它还会影响数值稳定性：在低精度训练（fp16/bf16）里 eps 太小会让归一化后的值过大，这也是为什么 fp16 训练有时需要把 eps 调大一点。

三、Pre-LN 还是 Post-LN

这是 Transformer 结构里最关键的一个位置选择，直接决定训练稳定性：

Post-LN（原版）Pre-LN（现代默认）
顺序x + Sublayer(LN(x)) 的输出再 LNx + Sublayer(LN(x))
残差分支输出被归一化，残差路径被缩放残差路径是恒等直通
训练稳定性差，必须精心 warmup好，warmup 可大幅缩短甚至去掉
最终效果略好（同等调参下）略差但差距很小
现代选择基本不用几乎所有 LLM 的默认
# Post-LN（原版 Transformer） x = x + dropout(attn(x)) x = LayerNorm(x) # 归一化在残差之后 # Pre-LN（GPT-2 之后、所有现代 LLM） x = x + attn(LayerNorm(x)) # 归一化在子层之前，残差路径恒等 x = x + ffn(LayerNorm(x)) # 为什么 Pre-LN 更稳？ # 因为残差连接提供了「梯度高速公路」： # 深层网络的梯度可以不经过任何归一化直接回传， # 避免逐层缩放导致的梯度消失。

四、归一化在现代 LLM 里的变体

RMSNorm去掉减均值与 beta，主流 LLM 默认
DeepNorm在残差里加一个大于 1 的系数，用于超深网络（1000 层）
QK-Norm对注意力里的 Q、K 单独归一化，防止 logits 爆炸
Sandwich Norm在子层前后各放一个 Norm，进一步稳定

五、深入自检

为什么归一化能加速训练？

它让每一层输入的分布保持稳定（不会随层数加深而漂移），从而使损失曲面更平滑、可用更大的学习率。本质上是把「内部协变量偏移」问题解决了。

gamma 和 beta 不就把归一化抵消了吗？

理论上如果 gamma = sqrt(var)、beta = mean，输出确实等于输入。但这两个参数是学出来的，网络可以自由选择「归一化到什么程度」，甚至可以学会在某些特征上几乎不归一化。这保留了模型的表达能力。

RMSNorm 为什么效果差不多还更快？

研究表明 LayerNorm 的性能增益主要来自重新缩放（re-scaling）而非重新居中（re-centering）。去掉减均值和 beta 只损失很小一部分效果，却省掉了两次逐元素运算。

归一化放在注意力之后可以吗？

可以，而且有 QK-Norm 这种做法：只对 Q、K 做归一化，目的是防止点积 logits 的绝对值过大导致 softmax 饱和（梯度消失）。

推理时可以去掉归一化吗？

不能。它是模型结构的一部分，权重里包含了在特定归一化方式下学到的参数。不过 RMSNorm 这类操作可以和相邻的线性层做算子融合，减少访存，提升推理速度。
