🔤 Cypher 查询

声明式图查询语言

基本语法

用『模式』表达图结构：MATCH (p:Person)-[:KNOWS]->(f:Person) RETURN f 意思是『找到所有被某人 KNOWS 的人』。

  • CREATE / MERGE：建节点/关系，MERGE 等价于『存在则匹配，否则创建』。
  • WHERE：过滤条件。
  • RETURN：指定返回内容，可配合聚合、排序、分页。
  • 关系模式用 -[:TYPE]-> 表示方向，-[:TYPE]- 表示无向。

示例

MATCH (a:Person {name:'Alice'})-[:KNOWS*1..2]-(b) RETURN b：查 Alice 的 1~2 度人脉——这类『多跳』正是图数据库的强项。

💡 给高频过滤/起始点建索引（如 CREATE INDEX FOR (p:Person) ON (p.name)），否则 MATCH 会全图扫描。
