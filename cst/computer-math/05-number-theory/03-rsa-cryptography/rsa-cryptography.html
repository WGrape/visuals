RSA 与密码学应用

用最朴素的参数，看清公钥加密如何"人人可加密、唯有私钥能解密"。

公钥密码学思想

传统加密要求收发双方共享同一把钥匙（对称加密），但"如何安全地把钥匙交给对方"本身是个难题。公钥密码学的突破在于：生成一对钥匙——公钥公开（谁都能用来加密），私钥保密（只有持有者能解密）。

类比：公钥像一把人人能往里投信的公用邮箱（锁上的投信口），私钥是你手里唯一能打开它的钥匙。别人投进去的信，只有你能取。

RSA 密钥生成

  1. 选两个大素数 p、q（演示用小素数）。
  2. 计算 n = p·q，n 的位数决定安全性。
  3. 计算欧拉函数 φ(n) = (p−1)(q−1)。
  4. 选公钥指数 e，满足 1<e<φ(n) 且 gcd(e, φ(n))=1（常取 65537）。
  5. 用扩展欧几里得求私钥 d，使 e·d ≡ 1 (mod φ(n))，即 d = e⁻¹ mod φ(n)。

公钥是 (e, n)，私钥是 (d, n)。加密 c = m^e mod n，解密 m = c^d mod n。

安全性：大数分解的困难

公钥里只有 n 和 e。攻击者若能把 n 分解回 p、q，就能算出 φ(n) 和 d。但对足够大的 n（如 2048 位），目前没有实用算法能在合理时间内完成分解。这正是 RSA 的全部安全假设。

它与前面内容的联系：模幂（快速幂）让加解密高效；素数提供"易乘难分解"；gcd 与扩展欧几里得负责生成私钥 d。

总结与延伸

RSA 只是公钥密码学的代表之一。现实中它常与对称加密、哈希配合使用：用 RSA 安全交换对称密钥，再用对称密钥加密大量数据。理解 RSA，你就握住了现代网络安全（HTTPS、数字签名）的一把钥匙。
