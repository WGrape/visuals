概述

go 工具链是入口

go 命令把编译、测试、依赖、格式化、静态检查、文档等能力统一到一个二进制里，几乎不需要第三方构建工具。

🔨

🧪
go test
跑测试与基准
📦
go mod
管理依赖
🧹

格式与检查
构建与运行

编译即交付

go build 直接产出静态链接的可执行文件；go run 编译到临时目录并立即执行；交叉编译只需设置 GOOS/GOARCH。

go build ./...            # 编译当前模块所有包

# 交叉编译：在 macOS 上构建 Linux 二进制
go build -o app-linux GOOS=linux GOARCH=amd64 .

# 裁剪体积：去掉符号表与调试信息

  go build -ldflags="-s -w" .
模块管理

go.mod 是事实来源

go mod init 初始化模块，go mod tidy 清理并补全依赖，go get 升级版本。版本选择遵循语义化版本与最小版本选择（MVS）。

go mod init example.com/app
go mod tidy              # 根据 import 整理 go.mod / go.sum
go get github.com/gin-gonic/gin@v1.9.1

# 查看依赖图
go mod graph | head
格式与静态检查

提交前必跑

gofmt 统一格式（IDE 通常保存即格式化）；go vet 发现可疑代码（如 Printf 占位符不匹配、不可达分支）。

gofmt -w .               # 就地格式化
go vet ./...             # 静态检查
goimports -w .           # 顺手整理 import（需安装）
环境与缓存

可复现的构建

go env 查看/设置环境变量；GOFLAGS、GOPROXY、GOMODCACHE 影响下载与缓存；go clean 清理构建缓存。

go env GOPROXY GOFLAGS GOMODCACHE
go env -w GOPROXY=https://proxy.golang.org,direct
go clean -cache -testcache   # 清掉构建与测试缓存
安装与获取

go install 装工具

go install 把带 main 的包编译并安装到 GOBIN；go get 现在主要用来拉取/升级库依赖而非安装工具。

go install golang.org/x/tools/cmd/goimports@latest

# 一条命令跑测试（带竞态检测）
go test -race ./...
