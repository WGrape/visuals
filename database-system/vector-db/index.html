向量数据库

从相似度与 ANN 索引的算法层，到量化压缩与召回评测的调优层，再到 Milvus、Qdrant、Weaviate、pgvector 的产品实践与容量、压测、迁移、排障的工程层。

📄

向量数据库是什么

从「为什么 B+ 树对高维向量失效」讲起：精确 vs 近似、HNSW 直觉、与 RAG 的位置关系，以及与传统数据库在索引结构、一致性、更新语义上的四条边界。

Embedding 模型选型

向量检索基础

沿「编码、建索引、候选召回到结果排序」拆解检索链路，指出每一步引入的误差，并说明为什么召回率必须分层测量（粗筛看 recall@100、排序看 recall@10）。

 📄

相似度度量

余弦、内积、欧氏三者的数学关系：向量归一化后余弦与内积等价、L2 与余弦单调对应。重点讲「用内积却忘了取负」「归一化没做导致余弦失真」两类线上事故。
📄

ANN 近似最近邻概览

近似最近邻的目标函数是什么：在给定召回率下最小化扫描量。把「召回率—延迟—内存」三者画成一张三角取舍图，说明为什么不存在三项全优的索引。

 📄

向量索引

Flat、IVF、HNSW 三种索引的搜索流程逐层拆解；IVF 的 nlist/nprobe 与 HNSW 的 M/ef 各自作用在哪一步；以及为什么 HNSW 查询快但内存高、IVF 省内存但召回对数据分布敏感。

 📄

向量索引选型

按「数据规模 × 召回目标 × 内存预算 × 更新频率」四维给出索引选型矩阵，并给出 nlist = 4×√N、ef 从 64 起手等可直接抄的经验值。
📄

混合检索

BM25 与向量召回的互补性：关键词擅长精确匹配与稀有词，向量擅长语义泛化。对比 RRF（按排名融合，无需调权重）与加权融合（需要标定分数）的适用条件。

 📄

Rerank 重排序

双塔（可预计算、快）与交叉编码器（不可预计算、准）的分工；何时值得付出重排延迟、候选数取多少、以及重排能把 nDCG 提升多少的量级。

 📄

过滤向量检索

pre-filter / post-filter / in-filter 三种实现路径的差异；过滤选择率低于 1% 时 HNSW 为什么几乎失效；以及「过滤后结果不足 K 条」的两类兜底策略。
📄
