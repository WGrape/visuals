异步上下文

async with：异步资源的安全开关

需要「异步地」开/关资源（数据库连接、HTTP 会话、文件）时，用 async with。它调用对象的 __aenter__ / __aexit__（注意是 a 前缀，和同步的 __enter__ 不同）。

class Conn:
    async def __aenter__(self):
        await self.connect(); return self
    async def __aexit__(self, *exc):
        await self.close()

async with Conn() as c:    # 进/出都走异步
    await c.query()
同步的 with 调用的是 __enter__/__exit__；异步对象若实现的是 __aenter__，必须用 async with，混用会直接报错。
异步迭代

async for 与异步生成器

async for 遍历「异步迭代器」（有 __aiter__ / __anext__）；async def 里用 yield 就是「异步生成器」，适合流式吐数据（如分片读大响应）。

async def fetch_pages():
    for i in range(1, 4):
        await asyncio.sleep(0.1)
        yield i                 # 异步生成器

async for page in fetch_pages():   # 每条都 await 取
    print(page)

这和同步生成器是同一套心智模型（见迭代器与生成器），只是「产出」的过程本身也能 await。它天然适配「边等网络边吐数据」的流式场景。

阻塞污染

一个 time.sleep 卡死整个事件循环

事件循环是单线程，协程只在 await 点让出。若在协程里调了同步阻塞函数（time.sleep、重 CPU 计算、同步 requests.get），循环在这期间没法切走，所有并发任务全卡住。

async def bad():
    time.sleep(3)        # 同步阻塞！整个循环冻结 3 秒

async def good():
    await asyncio.sleep(3)  # 正确：挂起，循环去跑别的

# CPU 密集 / 同步库：丢进线程池，别占循环
async def offload():
    r = await asyncio.to_thread(sync_cpu_task)  # 3.9+
    # 或 loop.run_in_executor(ThreadPoolExecutor(), f)
⚠️ 用 asyncio.to_thread（3.9+）或 run_in_executor 把阻塞调用挪到别的线程，循环才能继续调度其它协程。这是异步性能的第一红线。
忘了 await

调用协程却没 await = 什么都没发生

协程函数不加 await 调用，返回的是个「没被执行的协程对象」，不会报错但逻辑完全没跑。这是最隐蔽也最高频的 bug。

async def save():
    await db.write()

save()            # ❌ 返回 coroutine，啥也没存
await save()       # ✅ 真正执行

# 运行时告警：coroutine 'save' was never awaited
⚠️ 在 async 函数里调别的 async 函数，必须 await；在普通函数里要并发跑，得用 asyncio.run / create_task。类型检查器（mypy + 异步插件）能提前抓出这类遗漏。
实战

并发抓取：aiohttp + gather

异步最经典的场景就是高并发网络 I/O。用 aiohttp 的异步会话，配合 gather 并发几十上百个请求，吞吐远超同步 requests。

import aiohttp, asyncio

async def fetch(session, url):
    async with session.get(url) as resp:
        return await resp.text()

async def main():
    async with aiohttp.ClientSession() as s:
        tasks = [fetch(s, u) for u in urls]
        htmls = await asyncio.gather(*tasks)
    return htmls

把本篇和任务与并发连起来：gather 编排并发、async with 管会话生命周期、to_thread 兜住阻塞、别忘了 await。选型上它对应并发选型里的「高并发网络用协程」。
