组合数学：把「有多少种」算清楚

加法原理与乘法原理、排列组合、鸽巢原理、容斥原理、递推关系——这些计数工具是算法分析、概率计算和密码学的基础。

核心速览

加法原理

分类完成：各类方式数相加

乘法原理

分步完成：各步方式数相乘

排列 P(n,k)

有序选取：n!/(n−k)!

组合 C(n,k)

无序选取：n!/(k!(n−k)!)

两个最基本的原理

判别口诀：如果各种方式之间是「或」的关系（任选其一即可完成），用加法；如果是「且」的关系（每一步都要做），用乘法。算法分析中的直接体现：分支（if/else）对应加法，嵌套循环对应乘法。

排列与组合

模型公式是否考虑顺序是否放回
n 个不同元素全排列n!✅不放回
选 k 个排列 P(n,k)n!/(n−k)!✅不放回
选 k 个组合 C(n,k)n!/(k!(n−k)!)❌不放回
可重复排列nᵏ✅放回
可重复组合C(n+k−1, k)❌放回
多重集排列n!/(n₁!n₂!…)✅有重复元素
圆排列(n−1)!✅（旋转等价）不放回
from math import comb, perm, factorial

print(perm(10, 3))            # 720：10 选 3 有序（冠军/亚军/季军）
print(comb(10, 3))            # 120：10 选 3 无序（抽 3 张牌）
print(perm(10, 3) == comb(10, 3) * factorial(3))   # True：先选后排序

# 对称性：C(n,k) = C(n,n−k)   —— 选 k 个 = 排除 n−k 个
# 递推式（杨辉三角 / 帕斯卡法则）：C(n,k) = C(n−1,k−1) + C(n−1,k)
#   组合解释：是否包含「第 n 个元素」分两类

def comb_dp(n, k):
    """O(nk) 递推求组合数，可配合取模避免溢出"""
    C = [[0]*(k+1) for _ in range(n+1)]
    for i in range(n+1):
        C[i][0] = 1
        for j in range(1, min(i, k)+1):
            C[i][j] = C[i-1][j-1] + C[i-1][j]
    return C[n][k]

print(comb_dp(10, 3))         # 120
「可重复组合」的隔板法：从 n 种物品中可重复地选 k 个（不计顺序），等价于把 k 个相同的球放入 n 个盒子，用 n−1 块隔板分隔，于是答案 = C(n+k−1, k)。典型应用：方程 x₁+x₂+…+xₙ = k 的非负整数解个数。

二项式定理与重要恒等式

(a + b)ⁿ = Σ_{k=0}^{n} C(n,k) · aᵏ · b^(n−k)
恒等式表达式组合解释
行和为 2ⁿΣ C(n,k) = 2ⁿn 个元素的子集总数
对称性C(n,k) = C(n,n−k)选 k 个 ⟺ 排除 n−k 个
帕斯卡法则C(n,k) = C(n−1,k−1)+C(n−1,k)是否含第 n 个元素
范德蒙德Σ C(r,k)C(s,n−k) = C(r+s,n)从两堆里共选 n 个
交替和Σ (−1)ᵏC(n,k) = 0（n>0）奇偶子集数相等
# 二项式定理的实用推论
# ① 2ⁿ = Σ C(n,k)      → 幂集大小，状态压缩 DP 的状态数
# ② (1+x)ⁿ 的系数即 C(n,k)  → 生成函数视角
# ③ 快速计算大组合数取模：预处理阶乘 + 逆元，O(1) 查询
MOD = 10**9 + 7
def prepare(n, mod=MOD):
    fac = [1]*(n+1); ifac = [1]*(n+1)
    for i in range(1, n+1): fac[i] = fac[i-1]*i % mod
    ifac[n] = pow(fac[n], mod-2, mod)          # 费马小定理求逆
    for i in range(n, 0, -1): ifac[i-1] = ifac[i]*i % mod
    return fac, ifac
# C(n,k) = fac[n] * ifac[k] * ifac[n-k] % MOD

鸽巢原理与容斥原理

鸽巢原理（抽屉原理）

n+1 个物体放入 n 个盒子 ⟹ 必有一盒 ≥ 2 个。推广：m 个物体放 n 个盒子 ⟹ 必有一盒 ≥ ⌈m/n⌉ 个。

容斥原理（两集合）

|A∪B| = |A| + |B| − |A∩B|

容斥原理（三集合）

|A∪B∪C| = |A|+|B|+|C| − |AB|−|AC|−|BC| + |ABC|

一般形式

奇数个集合的交加、偶数个集合的交减，交替进行

# 鸽巢原理的经典应用
# ① 367 人中必有 2 人生日相同
# ② n+1 个 key 放入 n 个桶 ⟹ 必有哈希碰撞
# ③ 任意 6 人中必有 3 人互相认识或互不认识（R(3,3)=6）
# ④ 长度为 n²+1 的序列必含长度 n+1 的单调子序列（Erdős–Szekeres）
# ⑤ 任意 n 个整数中，必存在连续若干个数其和能被 n 整除（前缀和 + 鸽巢）

# 容斥：求 1..100 中不能被 2、3、5 整除的数有多少个
def count_coprime(n, primes=(2,3,5)):
    """容斥原理：能被任一素数整除的个数"""
    from itertools import combinations
    total = 0
    for r in range(1, len(primes)+1):
        for combo in combinations(primes, r):
            prod = 1
            for p in combo: prod *= p
            cnt = n // prod
            total += cnt if r % 2 == 1 else -cnt     # 奇加偶减
    return n - total

print(count_coprime(100))      # 26
容斥原理是「有重叠时如何不重不漏」的通用解法，在概率论（并事件概率）、数论（欧拉函数 φ 的推导）、算法（满足至少一个约束的计数）中反复出现。其代价是 2ᵐ 项，m 大时要用 DP 或莫比乌斯反演。

递推关系：算法复杂度的数学工具

把规模 n 的问题写成更小规模的组合，就得到递推式。求解后即得复杂度。

递推式解对应算法
T(n) = T(n−1) + O(1)O(n)线性扫描、顺序查找
T(n) = T(n−1) + O(n)O(n²)插入排序（最坏）
T(n) = T(n/2) + O(1)O(log n)二分查找
T(n) = T(n/2) + O(n)O(n)快速选择（平均）
T(n) = 2T(n/2) + O(1)O(n)遍历二叉树
T(n) = 2T(n/2) + O(n)O(n log n)归并排序、快速排序（平均）
T(n) = T(n−1) + T(n−2)O(φⁿ)朴素斐波那契（指数！）
主定理：T(n) = aT(n/b) + O(nᵈ)　⟹　Θ(n^(log_b a))（d < log_b a）／ Θ(nᵈ log n)（相等）／ Θ(nᵈ)（d 更大）
# 递推的两种解法
# ① 展开法（递归树）：T(n) = 2T(n/2) + n
#    = 2(2T(n/4) + n/2) + n = 4T(n/4) + 2n
#    = ... = 2ᵏT(n/2ᵏ) + kn，取 k = log₂n 得 n·T(1) + n log n = O(n log n)

# ② 特征方程法（线性递推）：F(n) = F(n−1) + F(n−2)
#    特征方程 r² = r + 1 → r = (1±√5)/2
#    F(n) = (φⁿ − ψⁿ)/√5，φ ≈ 1.618（比奈公式）

def fib(n):                    # 矩阵快速幂可做到 O(log n)
    def mul(A, B):
        return [[A[0][0]*B[0][0]+A[0][1]*B[1][0], A[0][0]*B[0][1]+A[0][1]*B[1][1]],
                [A[1][0]*B[0][0]+A[1][1]*B[1][0], A[1][0]*B[0][1]+A[1][1]*B[1][1]]]
    def mpow(A, k):
        R = [[1,0],[0,1]]
        while k:
            if k & 1: R = mul(R, A)
            A = mul(A, A); k >>= 1
        return R
    return mpow([[1,1],[1,0]], n)[0][1]

print(fib(90))                 # 2880067194370816120

# 经典计数下界：比较排序 Ω(n log n)
# 决策树是一棵二叉树，每个叶子对应一种排列 → 至少 n! 个叶子
# 树高 h 的二叉树最多 2ʰ 个叶子 ⟹ 2ʰ ≥ n!
# ⟹ h ≥ log₂(n!) ≥ log₂((n/e)ⁿ) = n log n − n log e = Ω(n log n)
# 结论：任何基于比较的排序算法都不可能快过 Ω(n log n)
# （计数排序、桶排序不受此限，因为它们不做比较，利用了值域信息）

常见误区

  • 混淆排列与组合：判断标准是「交换顺序算不算新方案」。排队是排列，组队是组合。
  • 重复计数：同一个方案被多条路径数到。经典错误：「从 5 男 3 女中选 2 人」若先选男再选女会漏掉「两男/两女」的情形——要按「分类」穷尽所有情形。
  • 递归地用加法原理时没保证分类互斥：分类必须不重不漏，否则要用容斥。
  • 把「可重复」当成「不可重复」：密码长度 8 位、每位 62 种可能是 62⁸（可重复排列），不是 P(62,8)。
  • 递推式直接套主定理：主定理只适用于 T(n) = aT(n/b) + f(n) 的形式；子问题规模不等（如 T(n)=T(n/3)+T(2n/3)）要用递归树或 Akra-Bazzi。

🎯 常见问法与答题要点

Q：加法原理和乘法原理怎么区分？

A：看方式之间是「或」还是「且」：分类完成（任选其一即可）用加法——从北京到上海可乘飞机 3 班、高铁 5 班、大巴 2 班，共 3+5+2 = 10 种；分步完成（每步都要做）用乘法——先从中转城市 A 到 B 有 4 种、再从 B 到 C 有 6 种，共 4×6 = 24 种。算法中的对应：if/else 分支对应加法，嵌套循环与顺序步骤对应乘法。混合问题时先分步、步内再分类。

Q：排列和组合的区别是什么？怎么快速判断用哪个？

A：排列考虑顺序，组合不考虑。判断方法：把选出的元素交换位置，算不算一种新方案？算 → 排列（如冠军/亚军/季军、排队、密码）；不算 → 组合（如抽奖、组队、选委员会）。数量关系：P(n,k) = C(n,k) × k!，即「先选出 k 个，再把它们排好序」。典型误区：栈的合法出栈序列数、圆排列 (n−1)!（旋转视为相同）都属于排列的变体。

Q：「可重复组合」C(n+k−1, k) 是怎么来的？

A：用隔板法（stars and bars）：从 n 种物品中可重复选 k 个且不计顺序，等价于「把 k 个相同的球放入 n 个盒子」，即方程 x₁+x₂+…+xₙ = k 的非负整数解个数。解法是把 k 个球与 n−1 块隔板排成一列，共 k+n−1 个位置，从中选 k 个位置放球（或选 n−1 个放隔板），故为 C(n+k−1, k) = C(n+k−1, n−1)。应用：多重集计数、容量分配问题、某些 DP 的闭式解。

Q：鸽巢原理能证明什么？为什么说它是非构造性的？

A：它证明形如「必然存在」的命题：n+1 个物体放入 n 个盒子必有一盒 ≥ 2 个；推广为 m 个物体放 n 个盒子必有一盒 ≥ ⌈m/n⌉ 个。经典结论：367 人必有同生日、n+1 个 key 放入 n 个桶必有哈希碰撞、任意 6 人必有 3 人互相认识或互不认识（R(3,3)=6）、长度 n²+1 的序列必含长度 n+1 的单调子序列。非构造性指它只保证存在，不指出是哪一个、也不给寻找方法。

Q：容斥原理怎么用？什么时候该用它？

A：当要计数「满足至少一个条件」的对象、但各条件有重叠时使用，做法是奇加偶减：|A∪B| = |A|+|B|−|A∩B|；三集合再加回三重交集。典型场景：① 求 1..n 中不能被某些素数整除的数（推导欧拉函数 φ）；② 概率中求并事件 P(A∪B∪C)；③ 约束满足计数（满足至少一个约束的方案数）；④ 错排问题 D(n) = n!·Σ(−1)ᵏ/k!。注意代价是 2ᵐ 项，条件数 m 大时需改用 DP 或莫比乌斯反演。

Q：主定理怎么用？有什么限制？

A：主定理求解形如 T(n) = aT(n/b) + O(nᵈ) 的递推：比较 d 与 log_b a——d 较小则 Θ(n^(log_b a))（子问题数主导）；相等则 Θ(nᵈ log n)（每层代价相当）；d 较大则 Θ(nᵈ)（合并代价主导）。限制：① 只适用于子问题规模相等的分治形式，T(n)=T(n/3)+T(2n/3)+n 不适用（要用递归树或 Akra-Bazzi）；② 要求 f(n) 满足正则性条件；③ b 与 a 是常数。不熟练时画递归树最稳妥。

Q：为什么比较排序的下界是 Ω(n log n)？计数排序为什么能突破？

A：决策树论证：任何基于比较的排序都对应一棵二叉决策树，每个叶子是一种可能的排列，因此叶子数至少 n!；而高度 h 的二叉树最多 2ʰ 个叶子，故 2ʰ ≥ n!，取对数得 h ≥ log₂(n!) ≈ n log n − 1.44n = Ω(n log n)。计数排序能突破是因为它不做比较，而是利用「值域较小」这一额外信息直接把元素放到正确位置，复杂度 O(n + k)，代价是需要 O(k) 额外空间且要求值域有界——下界只针对「仅通过比较获取信息」的模型。

Q：组合数很大时怎么计算？如何避免溢出？

A：三种常用方法：① 递推（杨辉三角） C(n,k) = C(n−1,k−1)+C(n−1,k)，O(nk)，可配合每步取模；② 阶乘 + 逆元：预处理 fac 与 ifac，C(n,k) = fac[n]·ifac[k]·ifac[n−k] mod p，查询 O(1)，要求 p 为素数（用费马小定理求逆）；③ 乘法逐步约分：C(n,k) = Π(n−k+i)/i，边乘边除并配合 gcd 约分，避免中间溢出。关键点：不要先算出完整的 n!（会溢出），要在过程中取模或约分。
