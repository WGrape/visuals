函数声明

参数可合并类型，返回值可命名

相邻同类型参数可省略重复类型；返回值可命名，命名返回在 defer 中可被修改。

func add(a, b int) int { return a + b }

// 命名返回值
func divmod(a, b int) (q, r int) {
    q = a / b
    r = a % b
    return   // 裸 return，返回 q, r
}
多返回值与 error

Go 的错误契约

函数要报告失败，就返回 (结果, error)；调用方必须检查 err。这是 Go 最鲜明的风格。

func find(id int) (*User, error) {
    if id <= 0 {
        return nil, errors.New("bad id")
    }
    return &User{ID: id}, nil
}

u, err := find(1)
if err != nil {
    return err   // 立刻处理错误
}
可变参数

...T 把实参收成切片

可变参数必须放最后；可传多个值，也可直接传一个同类型切片（加 ... 展开）。

func sum(nums ...int) int {
    s := 0
    for _, n := range nums { s += n }
    return s
}

sum(1, 2, 3)
slice := []int{1, 2, 3}
sum(slice...)   // 展开传入
递归

注意终止与栈深度

递归写法和其它语言一致；但要注意 Go 没有尾递归优化，深递归可能栈溢出，必要时改迭代或用显式栈。

func fact(n int) int {
    if n <= 1 { return 1 }   // 终止条件
    return n * fact(n-1)
}
函数类型

把函数当值传递

函数签名可定义成类型，从而作为变量、参数、返回值，实现回调与策略模式。

type Op func(int, int) int
func apply(a, b int, f Op) int { return f(a, b) }
apply(3, 4, func(x, y int) int { return x + y })
