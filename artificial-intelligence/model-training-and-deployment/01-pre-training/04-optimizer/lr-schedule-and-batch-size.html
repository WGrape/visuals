学习率调度与批量大小：怎么配

三段式学习率、缩放法则、梯度累积与可直接抄的训练配方

学习率batch sizewarmup训练配方
① 学习率 ② 批量 ③ 配方 ④ 疑问
学习率和批量必须一起定。单独调其中一个，很容易得出「学习率越大越好」或「批量越大越稳」这类错误结论。

01学习率的三段结构

阶段做什么典型取值作用
Warmup学习率从 0 线性升到峰值总步数的 1%~5%（大模型常用 2%）避免训练初期梯度方差过大导致发散
峰值保持或缓慢下降预训练 1e-4 ~ 1e-3；微调 1e-5 ~ 5e-5决定收敛速度
衰减降到峰值的 10% 或 0余弦衰减最常用后期用小学习率精细收敛
# PyTorch：带 warmup 的余弦衰减（最常用组合）
from torch.optim.lr_scheduler import LambdaLR

def lr_lambda(step):
    warmup = 2000
    total  = 100000
    if step < warmup:
        return step / warmup                       # 线性 warmup
    progress = (step - warmup) / (total - warmup)
    return 0.1 + 0.9 * 0.5 * (1 + math.cos(math.pi * progress))   # 余弦衰减到 10%

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4, weight_decay=0.1)
scheduler = LambdaLR(optimizer, lr_lambda)

for step, batch in enumerate(loader):
    loss = model(batch).loss
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)   # 梯度裁剪：大模型必备
    optimizer.step(); scheduler.step(); optimizer.zero_grad()
要点：梯度裁剪（clip_grad_norm_，常用 1.0）是大模型训练的必需品：它能在学习率偏大时兜住梯度爆炸，让训练不至于直接崩掉。

02批量大小怎么定

批量优点缺点适用
小（8~32）泛化更好（梯度噪声有正则作用）、显存占用低收敛慢、吞吐低、梯度抖动大微调、数据量小
中（64~512）吞吐与泛化的平衡点需要调学习率微调的常见区间
大（1k~数 M tokens）GPU 利用率最高，训练最快泛化可能变差、需要放大学习率预训练（按 token 计批量）

缩放法则：批量放大 N 倍时，学习率按线性缩放（×N）是激进做法，按 sqrt 缩放（×√N）是保守做法。实践中大批量常用线性缩放配上更长的 warmup。注意这个法则只在「批量不太大」时成立，批量超过某个点后继续放大的收益会迅速衰减。 

# 批量与学习率的配合（示意）
base_batch, base_lr = 64, 1e-4

for scale in (1, 4, 16):
    batch = base_batch * scale
    lr_linear = base_lr * scale      # 线性缩放（激进）
    lr_sqrt   = base_lr * scale**0.5 # sqrt 缩放（保守）
    print(f'batch={batch:4d}  lr线性={lr_linear:.2e}  lr开方={lr_sqrt:.2e}')
#   batch=  64  lr线性=1.00e-04  lr开方=1.00e-04
#   batch= 256  lr线性=4.00e-04  lr开方=2.00e-04
#   batch=1024  lr线性=1.60e-03  lr开方=4.00e-04

# 放大 batch 时一定要同步加长 warmup（否则初期更容易发散）
warmup_steps = max(100, int(0.02 * total_steps))
要点：更实用的做法是梯度累积：显存不够时用小 batch 累积多次再更新，等价于大 batch 但显存占用小。accumulation_steps × batch = 有效批量，学习率按有效批量来定。

03可直接抄的配方

场景优化器学习率调度批量
预训练（小模型）AdamW1e-3 ~ 3e-4warmup 2% + 余弦到 10%按 token：0.5M~4M
预训练（大模型）AdamW1e-4 ~ 6e-4warmup + 余弦数 M tokens
全参数微调AdamW1e-5 ~ 5e-5warmup 3% + 余弦32~128
LoRA 微调AdamW1e-4 ~ 3e-4（比全参数大一个量级）余弦16~64
指令微调（SFT）AdamW1e-5 ~ 2e-5warmup + 余弦到 0按样本打包
分类头微调AdamW1e-4 ~ 1e-3阶梯或余弦32~256
  • β 与权重衰减：AdamW 默认 β=(0.9, 0.95)（大模型）、weight_decay=0.1；bias 与 LayerNorm 参数通常不做权重衰减。
  • ε：默认 1e-8，混合精度下有时需要提到 1e-6 以避免除零导致的不稳定。
  • 学习率先粗扫：用 1e-5、3e-5、1e-4、3e-4 几个量级各跑一小段，看 loss 曲线选最稳的峰值。
  • 损失突然变 NaN：先降学习率（÷2~÷10）、确认梯度裁剪开着、检查是否有脏数据。
# 学习率粗扫（找峰值）：短时间跑几个量级看 loss 是否稳定下降
for lr in 1e-5 3e-5 1e-4 3e-4; do
  python train.py --lr $lr --max_steps 2000 --warmup 100 --log_every 100
done
# 判据：loss 平稳下降且无尖峰的最大 lr 就是峰值候选
#     出现 NaN 或 loss 反弹 → 太大
#     下降极慢 → 太小

04常见疑问

问：为什么大模型一定要 warmup？

训练初期参数是随机的、梯度方差很大，直接用大学习率会让参数一步走偏到不可逆的区域。warmup 让模型先用小步走稳，再加速。批量越大warmup 越要长。

问：batch 越大越好吗？

不是。批量大到一定程度后，同样的 epoch 数下更新次数变少，泛化会变差，而且收益递减（GPU 已经跑满，再大也不会更快）。实践中常有一个「临界批量」，超过后继续放大需要同步加大学习率且收益有限。

问：微调时学习率为什么比预训练小？

因为预训练权重已经接近一个好的解，大学习率会把已学到的表示破坏掉。类比：预训练是「从零建楼」，微调是「在楼里改装修」，后者不能用大锤。

问：LoRA 的学习率为什么能比全参数微调大？

因为 LoRA 只训练少量新增参数（通常是原模型的 0.1%~1%），需要更大的学习率才能在有限步数内收敛，而且不会破坏原权重。典型值是全参数微调的 5~10 倍。
