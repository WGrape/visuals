BI 流程

BI 工具连接数据仓库，业务人员自助拖拽生成图表与看板，无需写 SQL，把分析能力下放到一线。

常见图表选型

设计原则

  • 一图一事，别堆砌。
  • 先结论后细节，看板突出核心指标。
  • 颜色克制，避免误导。

🎯 面试问答

Q：BI 和直接查 SQL 的区别？
A：SQL 是取数，BI 是把取数结果组织成可交互、可监控的视图，面向业务决策。
Q：看板指标越多越好吗？
A：不是，核心指标 3-7 个足够，过多反而让人抓不住重点。
