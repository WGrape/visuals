🍃 MongoDB 概览

面向文档的通用 NoSQL 数据库

核心定位

📄

文档模型

以 BSON 文档（类 JSON）存储， schema 灵活，适合半结构化数据。

🧩

动态模式

同一集合内文档结构可不同，迭代快、改字段零成本。

🔁

副本集

原生主从复制 + 自动故障转移（高可用开箱即用）。

🧮

分片

横向扩展，按 shard key 把数据分布到多分片。

与关系型对比

关系型：表 → 行 → 列；MongoDB：数据库 → 集合（Collection）→ 文档（Document）。文档天然嵌套，避免了大量 JOIN 与多表关联。

💡 MongoDB 不是『不要模式』，而是『模式由应用层约束』。生产上建议用 Schema Validation 兜底，避免脏数据泛滥。
