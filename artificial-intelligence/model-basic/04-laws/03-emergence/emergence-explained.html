涌现能力 Emergence：量变到质变的临界点

小模型完全不会、大模型突然就会——能力为什么不是随规模线性增长的？

定义

非线性跃迁 + 临界点效应

涌现（Emergence）指某些能力在小模型上接近零、随机水平，当参数量或训练量突破某个临界阈值后突然出现且快速变强——无法通过小模型的表现外推预测。Wei 等人（Google，2022）在《Emergent Abilities of LLMs》中系统提出这一概念。

例子

常被引用的涌现能力

Few-shot 上下文学习
给几个示例就能照猫画虎，百亿级以下模型基本学不会格式
思维链 CoT
"让我们一步步思考"带来的提升，大约千亿参数以上才显著
多步指令跟随
一次执行多个约束（"用三句话、面向初中生、带一个类比"）
跨任务泛化
没专门训练过的任务上突然出现零样本能力
争议

"涌现"可能是度量的伪影？

Schaeffer 等（斯坦福，2023）的反驳：很多"涌现"用的指标是不连续的（精确匹配、多选题得分对错）。能力其实在小模型上平滑增长，只是没达到"答对就算过"的阈值才显得"从零出现"。换连续指标（如 token 级对数似然）后，曲线是平缓的。
两派怎么理解：这不是玄学与科学的对立，而是"该用什么指标定义能力"之争。实践上两边都有价值：对用户可见的能力确实像跳变；对研究者，用连续指标监控小模型更能提前预测大模型表现。
含义

对实践的三点启示

① 小模型评估会低估：小模型测不出来的能力，大模型可能有——架构选型不能只看小规模消融。② 别指望"再练练就涌现"：临界点位置不由人控制，为涌现而堆参数是赌博。③ 产物级指标会放大焦虑：评测时用连续指标更能看见真实进步。

面试问答

高频问题

Q1：什么是大模型的涌现能力？
某些能力在小模型上接近随机水平，规模突破临界阈值后突然出现并快速增强，无法由小模型表现外推。典型如 few-shot 学习、思维链推理。
Q2：为什么会有涌现？主流解释有哪些？
可能的解释包括：多步任务需要组合多个子技能，全部就绪前成功率接近零；知识量突破临界后才能支撑推理；以及指标不连续造成的"伪涌现"。
Q3：「涌现是度量伪影」是什么意思？
Schaeffer 等人指出，用精确匹配这类不连续指标衡量能力，平滑的进步在阈值前都显示为 0 分，跨过阈值显得"突然涌现"；换连续指标后曲线是平滑的。
Q4：涌现现象对工程实践有什么影响？
小规模实验的结论不能直接外推到大模型；能力规划不能依赖"到某个规模就会涌现"；评测应使用连续指标以观察真实趋势。
Q5：涌现和 Scaling Law 矛盾吗？
不矛盾。Scaling Law 描述的是损失随规模平滑下降；涌现描述的是下游任务指标（常常不连续）随规模的跳变。平滑的损失改善在任务层可能表现为跳变，二者可在同一框架下调和。

「涌现」指的是什么现象

通俗地说，涌现指的是：某个能力在小模型上完全没有（接近随机猜测水平），模型规模到了某个量级后突然出现、并且陡峭上升。最有名的一组例子来自 2022 年的 BIG-bench 研究：某些任务在模型规模跨越某个点后，准确率从接近 0 跳到几十个百分点。

阶跃 vs 平滑：差别往往来自「用哪把尺子量」

一场重要的质疑：是不是尺子的错觉

2023 年斯坦福的工作给出了一个很有说服力的反驳：把度量从「离散对错」换成「连续指标」，跃升就消失了。

度量方式例子曲线形态为什么
离散 / 非此即彼精确字符串匹配 Exact Match、单 token 多选、个位数加法全对阶跃中间不存在「部分正确」的表达，小幅改进被压平成 0，积累到位才一次性显现
连续序列的地化准确率、对数似然、Token 级编辑距离、Brier 分数平滑每一步微小改进都能被记录，累积起来是一条平滑曲线

一个直观比喻：用「能不能一口气跑完马拉松」做指标，你会看到某天某人突然从 0 变成 1；用「能跑多少公里」做指标，则是一条持续上升的曲线。能力是渐渐长的，台阶是被测量方式切出来的。

此外还有两条补充解释常常被忽略：

  • 复合任务的连乘效应。题要做对需要同时完成 3 个中间子步骤，每步成功率各自从 0.5 平滑爬到 0.9，整题做对率就是三者相乘：0.125 → 0.729。单个看是平滑的，相乘后呈现出明显的「某个点之后陡涨」。
  • 评测集本身的截断。某些任务在小模型上低于随机基线而被记为 0，它们的「零」其实是数据缺失，不是真实的能力为零。

不管争议如何，工程上该怎么看

别指望开窍把产品架构建立在「模型再大一点就会自动具备某能力」上非常危险。能力应当逐个验证。
能力预测要抽样验证在目标尺度的一半以上做验证，比外推更可靠。
困难任务先分解既然「复合」才是瓶颈，把任务拆成子步骤通常比等模型变大更有效。
度量要连续自建评测优先用连续指标（相似度、对数似然、加权打分），能更早看到趋势，也更容易做回归分析。

一个实操判断：如果你在两代模型之间观察到指标从 5% 跳到 40%，先别急着庆祝「涌现」。做三件事 —— ① 换一个更细的度量再看；② 抽查错误样例是「完全不会」还是「差一点」；③ 检查是不是换了训练数据或后处理。多数情况下会找到平滑的真相。

深入自检

如果涌现是错觉，那「能力突变」的说法全是错的吗？

不能这么绝对。学术质疑主要针对的是「被离散度量放大的假阶跃」，但确实存在架构或训练方法变更带来的真实阶段性变化（例如引入某种位置编码、改变稳定性的技巧）。区别在于：真突变应该能在同一个连续度量下复现，而假阶跃只在特定指标下出现。

为什么大家还是爱用「涌现」这个词？

因为它描述的产品体验是真实的：从「完全不可用」到「能干活」的转变，对使用者来说确实像开关。这个词作为体验描述没问题，作为物理机制的断言就过头了。

这对提示工程有什么启示？

既然能力常常是被「释放」而不是「新增」，提示的价值就在于给模型足够的结构，让已有的能力被激活：给出示例、拆分步骤、指定输出格式。这就是为什么 chain-of-thought 这类方法能在同一模型上显著提高表现。

怎么设计一个不容易被骗的自建评测？

三层：① 任务层面用连续或加权打分，避免纯 0/1；② 保留中间输出的检查点（可诊断到底是检索错还是推理错）；③ 每份评测至少包含一组明显应该失败的控制题，用来验证评测本身没有被作弊或泄漏。

涌现现象的可观测事实

现象观察争议点
少样本学习能力的突变某些任务在小模型上接近 0，跨过规模阈值后陡升是否只是指标选择造成的假象？
链式思考（CoT）约 100 亿参数以上才明显受益小模型经专门训练也能有 CoT

涌现的「相变」外观损失平滑下降，但准确率指标突变这是关键：见下方说明

最重要的澄清（2023 年斯坦福的 Are Emergent Abilities a Mirage?）：很多「涌现」其实是指标选择造成的假象。用不连续指标（如 Exact Match 精确匹配）衡量时，模型的错误率随规模平滑指数下降，但 EM 会在某个点从 0 跳到非 0，看起来像突变；换成连续指标（如 token 级编辑距离、log-prob）后，曲线是平滑的。

这不意味着规模无用——能力确实随规模提升，只是「突然出现」这个描述很可能是度量假象。实践中更可靠的做法是：用连续指标评估，别依赖「跨过某个规模就解锁」的预期。

可验证的实验与分析

# 用连续指标替代离散指标，看能力是否真的突变
import numpy as np

# 假设：单 token 错误率 p 随参数量 N 平滑下降（指数律）
def token_err(N, N0=1e9, alpha=0.3):
    return np.exp(-alpha * np.log(N / N0))

# 不连续指标（EM）：要求整个序列每个 token 都对
def exact_match(N, seq_len=10, **kw):
    p = token_err(N, **kw)
    return (1 - p) ** seq_len          # 全部正确的概率

# 连续指标：正确 token 比例
def token_acc(N, **kw):
    return 1 - token_err(N, **kw)

for N in [1e8, 1e9, 1e10, 1e11, 1e12]:
    print(f"N={N:.0e}  token_acc={token_acc(N):.3f}   EM={exact_match(N):.4f}")
# 可以看到：token_acc 平滑上升，而 EM 在 N 较小时几乎是 0，
# 到某个点突然变非零 —— 这就是「涌现」外观的来源：
# 序列越长，(1-p)^L 的非线性越强，突变越明显
# 实践建议：评估模型能力时如何选指标
# ❌ 只用 EM（精确匹配）：小模型的微小改进完全看不见，误以为「到某个规模才解锁」
# ✅ 同时看：
#    1) token 级准确率 / BLEU / ROUGE      —— 连续，能看到渐变
#    2) 部分正确的比例（如 5 个选项对 3 个）
#    3) log-prob 或 perplexity             —— 最平滑
#    4) 多档阈值：给「答对一半也算」的宽松指标

# 判断「真涌现」的严格标准（学界共识）：
#   1. 指标本身连续
#   2. 在多个独立任务上一致出现
#   3. 不是由数据/训练策略的突变造成
#   4. 换评测集后依然成立

深入自检

涌现是真的吗？

现象是真的（能力确实随规模提升），但「突然出现」这个描述很可能是假象。2023 年的研究指出，多数涌现曲线来自不连续指标（EM/多选正确率）的非线性放大。

为什么 (1-p)^L 会造成突变？

序列正确率 = 单 token 正确率的 L 次方。p 从 0.5 降到 0.1 时，L=10 的 EM 从 0.001 涨到 0.35——中间那段在图上看起来几乎是「从无到有」的跳变。

这对工程实践有什么影响？

① 不要用「跨过 X 亿参数就能做 Y」来做技术选型，实测为准；② 评估要用连续指标，否则看不到小模型的渐进改进；③ 长输出任务（长推理链、长代码）天然更容易「看起来涌现」，因为 L 大。

规模定律（Scaling Law）与涌现矛盾吗？

不矛盾。规模定律描述的是损失随规模平滑下降（幂律），而涌现讨论的是下游任务指标。前者是连续的，后者的突变是度量造成的。

那为什么大家还在讨论涌现？

因为即使是指标假象，实践上仍有意义——对使用者而言，「EM 从 0 变成 30%」确实意味着这个任务从「不可用」变成「勉强可用」。只是别把它理解成模型内部发生了质变。
