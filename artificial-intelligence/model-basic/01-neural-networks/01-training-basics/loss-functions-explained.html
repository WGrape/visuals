损失函数全景：MSE / 交叉熵 / KL 散度 / InfoNCE 各自解决什么问题

损失函数定义了"什么叫做得好"，它直接决定模型会变成什么样。从回归的 MSE 到大模型预训练的交叉熵、蒸馏用的 KL 散度、对比学习的 InfoNCE —— 本文一次讲清每种损失的形状、适用场景和坑。

损失函数在训练循环里的位置

前向传播得到 ŷ → 损失函数拿 ŷ 和真实 y 算出一个标量 L → 反向传播从 L 出发算所有梯度 → 优化器更新参数。

它是整个学习的"指挥棒"：你选什么损失，模型就朝什么方向长。

回归任务：MSE 与 MAE

MSE / L2
L = (y - ŷ)²
  • 对大误差惩罚极重（平方放大）
  • 处处可导，优化友好
  • 对离群点敏感：一个异常值就能带偏整个模型
MAE / L1
L = |y - ŷ|
  • 误差线性增长，对离群点稳健
  • 在 0 点不可导，且梯度恒定 → 收敛末期容易在最优解附近抖
折中方案 Huber Loss：误差小的时候像 MSE（梯度平滑），误差大的时候像 MAE（不被离群点绑架）。

分类任务：交叉熵（大模型的核心）

交叉熵衡量"模型给出的概率分布"与"真实分布"的差距。对单标签分类，真实答案是 one-hot，于是退化成一句非常好懂的话：

L = -log( P(正确类别) )
答对且很自信
P=0.99 → L≈0.01
几乎不产生梯度
答对但犹豫
P=0.5 → L≈0.69
有中等梯度
答错且很自信
P=0.01 → L≈4.6
梯度巨大，重点被纠正
这就是为什么交叉熵适合分类：它天然把学习资源集中在"错得最离谱、最自信的错误"上，而不是平均用力。

在大模型里

大语言模型的预训练就是把整段文本拆成 token，对每个位置做一次词表大小的多分类，损失是所有位置的交叉熵平均：

L = -1/N · Σ log P(tᵢ | t₁…tᵢ₋₁)

训练中常报告的 困惑度 Perplexity = exp(L)，直观理解为"模型在每个位置上平均有多纠结"，越低越好。

KL 散度：衡量两个分布的差距

D_KL(P || Q) = Σ P(x) · log( P(x) / Q(x) )
  • 它衡量"用分布 Q 去近似真实分布 P 会多损失多少信息"。
  • 非对称：D_KL(P||Q) ≠ D_KL(Q||P)，顺序不能随便换。
  • 知识蒸馏就是用 KL 散度，让学生模型的输出分布去逼近教师模型（而且要用带温度 T 的软化分布，才能学到"教师认为哪些错误答案也比较接近正确"这种暗知识）。
  • RLHF / DPO 里的 KL 惩罚项，也是为了防止策略模型偏离参考模型太远。
交叉熵和 KL 的关系：H(P,Q) = H(P) + D_KL(P||Q)。真实分布固定时 H(P) 是常数，所以最小化交叉熵等价于最小化 KL 散度——这也是为什么分类任务说"用交叉熵"和"用 KL"常常是一回事。

对比学习：InfoNCE

Embedding 模型、CLIP、RAG 的向量检索都靠它。目标不是"预测类别"，而是在向量空间里拉近正样本、推远负样本：

L = -log [ exp(sim(q, k⁺)/τ) / ( exp(sim(q, k⁺)/τ) + Σ exp(sim(q, k⁻)/τ) ) ]
关键工程点：负样本通常直接取同一个 batch 里的其他样本，所以 batch size 越大，负样本越多，对比学习效果越好——这就是对比学习训练往往要很大 batch 的原因。温度 τ 太小会导致梯度集中到最难负样本上、训练不稳。

面试速记卡

  • 回归：MSE（对离群点敏感）/ MAE（稳健但末期抖动）/ Huber（折中）。
  • 分类与大模型：交叉熵 -log P(正确)，天然聚焦最离谱的错误；大模型把它用在"预测下一个 token"上，困惑度 = exp(交叉熵)。
  • KL 散度：非对称，用于蒸馏（软标签 + 温度）和 RLHF 的偏离惩罚。
  • InfoNCE：对比学习，拉近正、推远负，batch 越大负样本越多效果越好。
  • 交叉熵 = 熵 + KL，真实分布固定时二者等价，所以分类里经常混着说。

损失函数速查：公式、适用与坑

选损失的三个判断点：输出是连续值还是类别、要不要概率校准、样本平不平衡。

损失公式适用坑
MSE L2mean((y-ŷ)²)回归对异常值极敏感（误差平方放大）；与 sigmoid 搭配会梯度消失
MAE L1mean(|y-ŷ|)回归，有异常值0 点不可导（需 Huber 平滑）；梯度恒定，收敛末期抖动
Huber误差<δ 用 L2，否则 L1回归（鲁棒）多一个超参 δ，常取 1.0
BCEWithLogits二分类交叉熵（含 sigmoid）二分类 / 多标签必须用这个而不是 BCE+Sigmoid：前者用 log-sum-exp 技巧，数值稳定
CrossEntropy-log softmax(logits)[y]单标签多分类PyTorch 的 CrossEntropyLoss 输入是 logits，不要先 softmax
Focal LossCE × (1-p)^γ极度不平衡（如 1:1000）γ 常取 2，α 常取 0.25；简单样本权重被压低
KL 散度Σ p log(p/q)分布匹配、蒸馏非对称：KL(p‖q) ≠ KL(q‖p)；q 为 0 处会爆
InfoNCE-log exp(s+/τ)/Σexp(s/τ)对比学习 / 向量召回τ（温度）是关键，常取 0.05~0.1；批越大越好
Tripletmax(0, d(a,p)-d(a,n)+margin)度量学习难样本挖掘决定成败；margin 常取 0.2~0.5
Dice / IoU集合重叠度分割（前景极小）空目标会产生 nan，需加平滑项

PyTorch 常用写法

import torch, torch.nn as nn
import torch.nn.functional as F

# 回归
F.mse_loss(pred, target)                       # 或 F.l1_loss / F.smooth_l1_loss(beta=1.0)

# 二分类：永远用 WithLogits 版本（logits 直接进，不要自己 sigmoid）
crit = nn.BCEWithLogitsLoss(pos_weight=torch.tensor([10.0]))   # 正样本少时加权
loss = crit(logits, target.float())

# 多分类：输入是 logits，target 是 LongTensor 类别 id（不是 one-hot）
loss = F.cross_entropy(logits, target, label_smoothing=0.1)
# 类别不平衡：按频次反比加权
loss = F.cross_entropy(logits, target, weight=torch.tensor([1.0, 5.0, 3.0]))

# Focal loss（多分类版）
def focal(logits, y, alpha=0.25, gamma=2.0):
    ce = F.cross_entropy(logits, y, reduction='none')
    pt = torch.exp(-ce)
    return (alpha * (1 - pt) ** gamma * ce).mean()

# InfoNCE / 对比学习（sim 已算好相似度矩阵，对角线为正样本）
def infonce(sim, tau=0.07):
    labels = torch.arange(sim.size(0), device=sim.device)
    return F.cross_entropy(sim / tau, labels)

最容易踩的三个坑：① BCELoss + 自己 sigmoid → 概率接近 0/1 时 log(0) 变 nan，改用 BCEWithLogitsLoss；② CrossEntropyLoss 又套了一次 softmax → 梯度被压扁、学不动；③ 多标签分类用 CrossEntropyLoss → 语义就错了，多标签要各标签独立 sigmoid，用 BCEWithLogitsLoss。

loss 出问题时怎么查

现象最常见原因排查动作
loss = nan（第 1 步就 nan）数据里有 nan/inf；除零torch.isnan(x).any() 逐层查；检查归一化分母
loss = nan（训练中途变 nan）学习率过大导致梯度爆炸lr 降 10 倍；加 grad_clip_norm_(1.0)
loss 不降，卡在某个值lr 太小 / 死锁在鞍点 / 标签错lr 扫描（1e-5→1e-1）；检查标签是否全同一类
loss 剧烈震荡batch 太小 / lr 太大batch 翻倍或 lr 减半；加 warmup
train 降、val 升过拟合加 dropout / weight decay / 数据增强；早停
分类 loss 卡在 ln(C)模型输出常数（没学到）C=2 时 ln2≈0.693、C=10 时 ≈2.303；检查最后一层初始化与 lr
验证 loss 比训练 loss 还低训练时开了 dropout/augment，验证没开正常现象；也可对比 train 模式下的 eval

MSE 和交叉熵本质区别是什么？

是对输出分布的假设不同。MSE 等价于假设噪声服从高斯分布的极大似然；交叉熵等价于假设标签服从伯努利/类别分布的极大似然。所以回归用 MSE、分类用 CE 不是惯例，是概率模型推导的结果。分类用 MSE 会怎样？sigmoid 饱和区梯度接近 0，学得极慢——这就是早期神经网络的经典问题。

标签不平衡一定用 Focal Loss 吗？

不一定，优先级是：① 先试加权（pos_weight / class weight），简单有效；② 再试重采样（过采样少数类或欠采样多数类）；③ 最后才上 Focal。Focal 的 γ 很敏感，且会让校准变差（输出概率不再可靠），如果下游要用概率阈值做决策，反而要慎用。

蒸馏里的 KL 为什么要除以温度 T？

温度 T 把 teacher 的 logits 压缩后再 softmax，让非正确类别的相对关系（暗知识 dark knowledge）暴露出来。T→∞ 时分布趋于均匀，信息只剩类别关系；T=1 时就是普通 softmax，非正确类概率都接近 0，学不到东西。典型 T 取 2~4，且梯度要乘 T² 补偿缩放。
