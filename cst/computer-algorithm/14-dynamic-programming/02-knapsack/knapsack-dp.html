一维数组里的遍历方向

01 背包倒序遍历保证每件只用一次，完全背包正序遍历允许重复取，多重背包用二进制拆分降到对数，三种问法对应不同初始化。

01 背包：每件只有一个，选或不选

容量 W，n 件物品，第 i 件重量 wi、价值 vi，每件只能用一次，求最大价值。

状态定义：dp[i][w] = 只考虑前 i 件、容量为 w 时的最大价值。转移就是第 i 件选还是不选：

dp[i][w] = max(dp[i-1][w],                    # 不选
              dp[i-1][w-wi] + vi)          # 选（需 w ≥ wi）

可以压缩成一维数组，但遍历顺序必须反过来：

def knapsack_01(W, wt, val):
    dp = [0] * (W + 1)
    for i in range(len(wt)):
        for w in range(W, wt[i] - 1, -1):   # 必须倒序！
            dp[w] = max(dp[w], dp[w - wt[i]] + val[i])
    return dp[W]

为什么必须倒序？倒序时 dp[w - wt[i]] 读到的是上一轮（i−1）的旧值，保证每件只用一次。若正序，dp[w - wt[i]] 可能已经在本轮被更新过，同一件物品会被反复装入——那就变成了完全背包。

复杂度 O(nW)，空间 O(W)。注意它是伪多项式：W 很大（如 10⁹）时即使 n 很小也跑不动。

完全背包：每件无限个，正序遍历

同一件可以取多次，转移变成 dp[i][w] = max(dp[i-1][w], dp[i][w-wi] + vi)——注意第二项用的是 dp[i] 而不是 dp[i−1]，正好对应一维数组下的正序遍历。

def knapsack_complete(W, wt, val):
    dp = [0] * (W + 1)
    for i in range(len(wt)):
        for w in range(wt[i], W + 1):   # 正序，允许重复取
            dp[w] = max(dp[w], dp[w - wt[i]] + val[i])
    return dp[W]

01 与完全背包的唯一代码差别就是内层循环方向。理解这一点比背模板重要：方向决定了你读到的是「上一轮」还是「本轮」的状态。

多重背包：二进制拆分降复杂度

第 i 件最多取 ci 个。朴素做法是把它展开成 ci 个独立物品跑 01 背包，复杂度 O(W·Σc)，c 大时不可行。

二进制拆分：把 c 拆成 1、2、4、…、2k 和余数，这些组能组合出 0~c 的任意个数，于是 c 件变成 log c 个「打包后的物品」，再跑 01 背包即可，复杂度降到 O(W·Σ log c)。

def knapsack_multi(W, wt, val, cnt):
    items = []
    for w, v, c in zip(wt, val, cnt):
        k = 1
        while k <= c:
            items.append((w * k, v * k)); c -= k; k *= 2
        if c: items.append((w * c, v * c))
    dp = [0] * (W + 1)
    for w, v in items:
        for cap in range(W, w - 1, -1):
            dp[cap] = max(dp[cap], dp[cap - w] + v)
    return dp[W]

三种变体与常见问法

问法改什么
最大价值dp 存价值，转移取 max（上面全是这种）
能否恰好装满dp 存布尔可行性，初始化只有 dp[0] = True
装满的方案数dp 存计数，转移改成累加；初始化 dp[0] = 1
输出具体选了哪些保留二维 dp，从 dp[n][W] 反推：若 dp[i][w] ≠ dp[i−1][w] 则选了第 i 件
二维费用（重量 + 体积）dp 开二维费用，两层倒序

「最大价值」和「恰好装满」的初始化不同：前者全部置 0（允许装不满），后者除 dp[0] 外全部置为不可达（-∞ 或 False）。混用会得出错误答案。
