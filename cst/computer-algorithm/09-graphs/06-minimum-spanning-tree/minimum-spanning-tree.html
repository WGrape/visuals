最小生成树

怎样用最少的「线」把一群点连成一张连通网，且总长度最小？这就是最小生成树（MST）的故事。

一、什么是生成树与最小生成树

在一张连通无向图里，生成树是选出一个包含所有 V 个节点、恰好 V−1 条边、且没有环的子图——它把整张网连起来，又不浪费任何一圈冗余连线。

最小生成树（MST）则是所有生成树中，边权之和最小的那一棵。类比：把若干栋楼接入局域网，布线要连通又不能成环（否则广播风暴），还要总长度最短、最省钱。

示例图（无向带权）。本页演示的 MST 边为 A-C(2)、D-E(2)、E-F(3)、A-B(4)、B-D(5)，总权 16。

二、Kruskal：贪心选边 + 并查集

Kruskal 的思路像「铺路工」：先把所有边按权值从小到大排序，然后依次尝试加入——只要这条边不会和已选边构成环就保留，否则丢弃。判断是否成环靠并查集（Union-Find）：两节点若已在同一连通块，再加边必成环。

def kruskal(edges, V):
    edges.sort(key=lambda e: e.w)     # 边按权升序
    uf = UnionFind(V)
    mst = []
    for u, v, w in edges:
        if uf.find(u) != uf.find(v):  # 不在同一连通块
            uf.union(u, v)
            mst.append((u, v, w))
    return mst

交互演示：点击「下一步」，逐条考察排序后的边。绿色表示选入 MST，红色虚线表示会成环被跳过。

准备开始：边已按权值排序。

三、Prim：从一点长出的树

Prim 是另一种贪心：先随便选一个起点，把它「种」进树里，之后每一步都从树外节点里挑一条连到树内代价最小的跨界边，把新节点接进来。用最小堆维护候选边，效率很高。它和 Kruskal 殊途同归——都依赖 MST 的两条性质。

切割性质

把节点分成两堆（一个切割），跨越切割的最短边必属于某个 MST。这是贪心的正确性根基。

环性质

任意一个环里最长的边一定不属于任何 MST，因为它可被环上更短的边替代。

四、应用与对比

算法策略关键数据结构复杂度
Kruskal全局选最短边、避环并查集 + 排序O(E log E)
Prim从树长出去、选最短跨界边最小堆O((V+E) log V)
应用：网络布线、电路布线、聚类（把距离近的点归为一类）、图像分割。记住——MST 总权最小，且天然无环。
