向量与矩阵

一切线性代数的零件——从一根带方向的箭头，到一个能搬动整个平面的“机器”。

向量：带方向的量

在 CS 里，向量常常只是一列（或一行）数字，例如 [3, 4] 可以表示一个二维平面上的点，或一股向右 3、向上 4 的力。它既是“位置”，也是“方向 + 长度”。

核心运算

加减

对应分量相加，几何上首尾相接（平行四边形法则）。

数乘

每个分量乘同一个数，把向量拉长 / 缩短 / 反向。

点积

u·v = u₁v₁+u₂v₂，衡量“同向程度”，为 0 时两向量垂直。

几何意义：点积 u·v = |u||v|cosφ。当 φ=90° 时点积为 0，这正是判断“正交 / 垂直”的廉价方法。

矩阵：数字的表格与规则

矩阵是 m 行 n 列的矩形数阵，记作 m×n。它既能当“数据的表格”（如一张用户特征表），也能当“运算的说明书”（线性变换）。

加减与乘法

加减要求同形状，逐元素进行。乘法 C = AB 则要求 A 的列数 = B 的行数：结果 C 的第 i 行第 j 列，是 A 的第 i 行与 B 的第 j 列的点积。

若 A 为 2x3，B 为 3x2，则 AB 是 2x2：
   (A 的行) · (B 的列) → 一个数

转置 Aᵀ：把矩阵沿主对角线“翻折”，行变列、列变行。
记忆法：矩阵乘法像“喂纸条”——A 是食谱，B 是食材列；每一口菜 C[i][j] 都是把第 i 道食谱套到第 j 列食材上算出来的。

矩阵即线性变换
