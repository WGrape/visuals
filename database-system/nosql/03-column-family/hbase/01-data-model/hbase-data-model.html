🧬 HBase 数据模型

表、行键、列族与版本

基本概念

🗝️

RowKey

每行唯一主键，按字典序排序，是查询与分布的核心。

📚

列族 CF

列的物理分组（如 info、data），同一 CF 的列存一起。

🔤

列限定符

CF 内的列名，可动态增删，无需预定义。

⏱️

版本

每个单元格按 timestamp 保留多个版本（默认 1）。

模型要点

  • 表 = 多个列族；列族需在建表时定义，列限定符运行时随意加。
  • 物理上同一列族的数据存同一个 HFile，不同列族分开存储——不要把不常一起读的列放同一 CF。
  • 单元格由 (rowkey, CF:qualifier, ts) 唯一确定，本质是『超稀疏的多维映射』。
💡 RowKey 设计是 HBase 成败关键：要避免热点（如加盐 / 反转时间戳），又要让查询模式能利用字典序范围扫描。
