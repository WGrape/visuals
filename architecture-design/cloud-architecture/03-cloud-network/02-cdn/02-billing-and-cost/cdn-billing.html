CDN 流量计费详解

按流量 / 按带宽(95计费) / 按请求 / 资源包 —— 怎么算、怎么选、怎么省

① 计费模式② 95计费法③ 加速vs回源 ④ 选型对比⑤ 成本优化⑥ 计费计算

1主流计费模式

① 按流量计费

按实际下行流量（GB）× 阶梯单价。用多少付多少，单价随用量递减。最直观，适合流量平稳、可预估的业务。

② 按带宽峰值计费

按月 95 峰值带宽（Mbps）× 月单价。突发型业务友好——只看峰值不看均值，详见第 2 节。

③ 按请求数计费

按 HTTP 请求次数 计费（常叠加在流量费之上）。海量小请求（如 API、埋点）要注意此项。

④ 资源包 / 预付

先买流量包（如 1TB/年），包内免额、超出按量。用量大且稳定时单价更低，相当于批发。

⑤ 混合 / 保底

保底带宽 + 超量按流量，或「带宽包 + 流量包」组合。大客户谈判常用，平衡突发与成本。

⑥ 增值服务

HTTPS 请求、QUIC、WAF、专属节点等常单独计费，别只看「流量单价」就下结论。

计费维度区分：「流量(GB)」是总量，「带宽(Mbps)」是瞬时速率。1 Mbps 跑满 30 天 ≈ 0.32 TB 流量。两者通过时间换算，但计费口径不同。

295 计费法：为什么对突发友好

把一个月按 5 分钟采样，得到约 8640 个带宽点，从小到大排序，去掉最高的 5%（约 432 个点），取剩下的最高值作为「月 95 峰值」来计费。也就是——你每天偶发的那几次尖峰不算钱。

3加速流量 vs 回源流量（别算错账）

加速流量（下行）

CDN 边缘节点响应给用户的流量，是账单大头，按 CDN 单价计。

回源流量

边缘未命中、向源站拉取产生的流量，通常也计费（且源站出口带宽/对象存储读也可能单独收费）。提升命中率 = 同时省两笔钱。

易踩的坑：只盯着「CDN 加速流量费」，忽略了回源流量 + 源站出口费 + 对象存储读费，月底发现「CDN 不贵但源站账单爆了」。算总账要看「用户侧下行 = 加速 + 回源」全链路。

突发成本尖峰会推高总量尖峰多被舍去
预算可预测性随业务波动较稳（看峰值）
典型场景官网、平稳 API、资源包兜底直播、大促、下载站、视频突发
经验公式：平均带宽(Mbps) ≈ 月流量(GB)×8 ÷ (30×24×3600)。若平均带宽 ≪ 95 峰值（突发明显）→ 选带宽计费更省；若两者接近（平稳）→ 选流量计费或资源包更省。下一节计算器直接给你答案。

5成本优化：省流量的正确姿势

① 提升缓存命中率

命中率每升一点，加速+回源同时下降。长缓存不变资源、避免缓存键爆炸。

② 开启压缩

gzip/brotli 让文本体积降 60%~80%，直接少计流量。

③ 资源合并 / 去冗余

合并小文件、删无用资源、用雪碧图/字体子集，减少请求数与字节数。

④ 冷热分离

极热资源用 CDN，冷数据放对象存储直链或低频存储，避免为低频访问持续付费。

⑤ 资源包 + 监控

用量稳就买资源包摊薄单价；实时监控命中率与 TOP URL，异常及时止损。

⑥ 防盗链 / 限频

别人盗刷的流量最终算在你账上，防盗链即省钱（见安全篇）。

核心速览

一句话CDN 主要按流量或带宽峰值收费，两者选哪个取决于流量曲线形状
按流量用多少付多少，适合平稳或波动无尖峰的业务
按带宽峰值按周期内的最高点收费，适合尖峰极高但总量小的业务
隐藏成本回源流量、请求数、HTTPS 请求、跨区域、跨境
CDN 成本 = 分发流量 + 回源流量 + 请求次数 + 增值功能

一、两种计费口径怎么选

口径计费方式优点坑适合
按流量（95 之外的月累计）月总流量 × 单价直观，和用量成正比突发大流量直接体现在账单流量平稳、可预测
按带宽峰值日/月峰值带宽 × 单价总量大但平稳时便宜一次突发抬高整月账单日常平稳、偶发尖峰被削平后
按 95 峰值取月内带宽点排序后去掉最高 5%容忍短时尖峰计算复杂，需自己核对大客户常用，最划算
按请求数每万次 HTTPS 请求计价小文件业务适用请求多时反超流量费用大量小图片、小文件
一个粗糙但好用的判断法

把一个月每秒带宽从小到大排序。如果最高值是中位数的 3 倍以内，按流量通常更便宜；如果尖峰是中位数的 5 倍以上、且尖峰持续时间很短，按带宽峰值会被尖峰绑架，按流量更稳。大多数中小业务直接按流量起步最省心。

二、成本大头往往不在分发流量

回源流量缓存命中率低时，回源流量可能接近分发量，白付一次
跨区域 / 跨境海外节点、中国大陆到海外回源单价差异极大
HTTPS 请求数小文件业务里请求费可能超过流量费
动态加速动态请求不缓存，走的是加速链路，单价更高
图片处理 / 视频转码按处理次数或处理时长额外计费
存储与预热边缘存储、内容预热也有费用

三、降本的六个抓手（按收益排序）

手段怎么做典型收益
提高缓存命中率合理 Cache-Control、忽略无关 query、延长静态资源 TTL最大，直接砍掉回源流量
资源压缩与格式升级Brotli/gzip、WebP/AVIF、视频 H.265流量下降 30%~60%
文件名带 hash + 长缓存内容变了文件名才变，可设一年缓存命中率接近 100%
合并小文件雪碧图、资源合并、减少请求数省请求费
按区域/运营商选供应商不同厂商在不同区域价格差异明显单价下降 10%~30%
削峰填谷大文件下载限速、错峰预热按峰值计费时收益显著

五、深入自检

为什么命中率已经 95% 了账单还高？

三项可能：① 请求数费用被忽略，小文件业务里它常常和流量费同量级；② 存在跨区域/跨境流量，单价是境内的数倍；③ 走了动态加速或图片处理等增值服务。

按流量和按带宽能中途切换吗？

多数厂商按月或按合约周期切换，不能随时改。签约前用历史带宽曲线算一遍两种口径，选择更划算的那种，并留意合约期。

95 峰值到底怎么算？

通常每 5 分钟取一个带宽采样点，一个月约 8640 个点，去掉最高的 5%（432 个点），剩下的最大值就是计费带宽。它本质上是「允许你每月有约 36 小时的尖峰不计入」。

CDN 一定能省钱吗？

不一定。如果流量极小（比如每天几 GB），CDN 的单价可能高于源站带宽单价；CDN 的价值主要在加速与抗突发，省钱是命中率高之后的副产品。

怎么防止被盗刷导致天价账单？

四道防线：① 配置带宽/流量封顶告警与自动断流；② 开启 Referer / UA / IP 访问控制；③ 对大文件启用鉴权 URL（带过期时间）；④ 大额资源走签名与单 IP 限速。
