整型

平台相关 vs 固定位宽

int/uint 的位宽跟随平台（64 位机为 64 位）；需要确定位宽时用 int32/int64 等固定类型。

var a int = 10          // 平台相关
var b int64 = 1<<40     // 固定 64 位
var c byte = 255        // byte = uint8
var r rune = '中'        // rune = int32（见字符串篇）

// 必须显式转换，无隐式
var x int64 = int64(a)
⚠️ 在序列化、网络协议、跨平台文件中，务必用固定位宽类型，否则 32 位与 64 位机器上 int 行为不同，导致数据错位。
浮点数

float32 与 float64 的精度差异

float32 约 7 位十进制有效数字，float64 约 15 位。金钱、计数等场景不要用浮点，改用整数分或 decimal 库。

var f1 float32 = 0.1
var f2 float64 = 0.1
fmt.Println(f1 == 0.1)  // 可能为 false（精度误差）

// 比较浮点请用误差范围
func close(a, b float64) bool { return math.Abs(a-b) < 1e-9 }
复数

complex64 / complex128

复数由实部+虚部构成，complex128 精度更高。常见于信号、图像处理。

var z complex128 = complex(3, 4) // 3+4i
fmt.Println(real(z), imag(z))   // 3 4
fmt.Println(cmplx.Abs(z))       // 5
布尔型

只有 true / false

Go 的 bool 不能和 0/1 互转，也没有「非零即真」。条件表达式必须返回 bool。

var ok bool = true
if ok { }            // 合法
// if 1 { }          // 非法：1 不是 bool
常量与 iota

编译期常量与枚举模拟

常量在编译期确定，可用 iota 在 const 块里生成自增枚举值。

const (
    A = iota // 0
    B        // 1
    C        // 2
)

// 常用：定义带前缀的枚举
type Weekday int
const (
    Mon Weekday = iota + 1 // 1
    Tue                   // 2
)
字符串基础

字符串是只读字节序列

Go 字符串底层是 UTF-8 字节切片，不可变；按「字符」处理要理解 rune。更深的 Unicode/字节视角我们单独写了 Rune 篇。

s := "Go语言"
fmt.Println(len(s))                  // 8（字节数）
fmt.Println(utf8.RuneCountInString(s)) // 4（字符数）
// 字符串不可变，只能生成新字符串
ns := s + "!"
