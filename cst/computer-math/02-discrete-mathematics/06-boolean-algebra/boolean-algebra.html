布尔代数

布尔代数是「只有 0 和 1」的代数系统。它把集合运算和命题逻辑统一起来，并直接变成电路。

公理与对偶原理

布尔代数建立在两个运算 ∧(与)、∨(或) 和一个补运算 ¬(非) 之上，取值 0 或 1。它和集合论、命题逻辑是同构的：

布尔代数集合论命题逻辑
a ∧ bA ∩ Bp ∧ q
a ∨ bA ∪ Bp ∨ q
¬aA̅（补集）¬p
0 / 1∅ / 全集F / T
对偶原理：把任一恒等式里的 ∧↔∨、0↔1 互换，得到的新恒等式依然成立。例如 a∨0=a 的对偶是 a∧1=a。

重要恒等式

德摩根律

¬(a∧b)=¬a∨¬b
¬(a∨b)=¬a∧¬b

吸收律

a∨(a∧b)=a
a∧(a∨b)=a

支配 / 同一

a∨1=1, a∧0=0
a∨0=a, a∧1=a

布尔函数就是由变量通过 ∧、∨、¬ 构成的式子，例如 f(a,b)=a∧¬b ∨ ¬a∧b（这就是异或）。任何一个布尔函数都对应一个逻辑电路。

卡诺图化简

卡诺图（K-map）把真值表画成方格，相邻格只差一个变量取反。把相邻的「1」圈成 2、4、8 个一组，每组就能消掉一个变量，得到最简与或式。

三变量示例（静态）

函数 F = A'B' + AB。其卡诺图中，左上 2 格和右下 2 格为 1，其余为 0。两个圈各消去一个变量，直接得到原式。

互动：二变量卡诺图化简

点格子在 0/1 之间切换，构造一个二变量（A,B）的真值表，再点「化简」得到最简与或式。

列 → B（左0 右1）　行 ↓ A（上0 下1）
// 化简思路：尽量用大的相邻圈覆盖所有 1
// 整块为 1 → "1"；整行 → 固定 A；整列 → 固定 B；孤立 1 → 保留完整项

与组合逻辑电路的联系

布尔函数直接映射成「与门、或门、非门」搭成的电路。半加器（half adder）就是一个经典例子：输入两位 a、b，输出「和」与「进位」。

sum   = a ⊕ b = a∧¬b ∨ ¬a∧b
carry = a ∧ b

CPU 里的加法器、比较器，乃至整个 ALU，本质上都是用布尔代数化简后搭出的大规模逻辑网络。
