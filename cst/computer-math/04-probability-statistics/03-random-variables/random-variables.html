随机变量与分布

把随机结果编号成数字，再用分布描述它"长什么样"。

离散 vs 连续随机变量

随机变量是把随机试验结果映射为数值的函数。按取值方式分两类：

离散型

取值可数，如掷骰子点数、一天内到达的请求数。用概率质量函数 PMF：P(X=k)。

连续型

取值充满一段区间，如响应延迟、文件大小。用概率密度函数 PDF：f(x)，概率看面积。

期望 E[X]是"长期平均值"，方差 Var(X)衡量"波动大小"。直觉：期望是重心，方差是胖瘦。

常见分布及其 CS 场景

分布类型典型 CS 场景
伯努利离散单次请求成功/失败
二项离散n 次请求中成功次数
泊松离散单位时间内请求到达数
均匀连续随机负载均衡、哈希扰动
正态连续测量延迟、噪声、聚合指标
类比：泊松分布描述"随机事件在固定时间窗口里来了几个"；正态分布描述"大量微小因素叠加后的总体表现"，如网络延迟。

为什么 CS 工程师要会这些

当你为服务设超时阈值、做容量规划、或解读 A/B 实验指标时，分布假设早已隐含其中：

  • 把"每秒请求数"当泊松过程，才能算队列排满的概率。
  • 把延迟当正态，才能用均值±几倍标准差设告警线。
  • 理解方差，才不会把一次偶然抖动当成系统退化。
# 用 Python 快速看一个样本像不像正态
import statistics
data=[12.1,11.8,12.4,12.0,11.9,12.2,12.5,11.7]
print('均值',statistics.mean(data),'标准差',statistics.pstdev(data))
