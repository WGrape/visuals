复杂度类与 P/NP

同样是「可计算」的问题，有的秒回，有的却随规模爆炸式变慢。复杂度类帮我们给难度分门别类。

一、P 与 NP 的直觉

P（多项式时间）

存在算法能在 n 的多项式 步内求解的问题，如排序、最短路径。规模翻倍，时间只是温和增长。

NP（多项式时间可验证）

不一定好解，但一旦给出答案，能在多项式时间内验证对错。如「这个数独有解吗」，给一个填法立刻能核对。

显然 P ⊆ NP（能轻松求解的，必然能轻松验证）。真正的问题是：NP 是否等于 P？即「验证容易」是否意味着「求解也容易」？

二、NP 完全：最难的那一群

NP 完全（NP-Complete）问题是 NP 里「最难的」：NP 中任何一个问题都能在多项式时间内归约到它。SAT（布尔可满足性）是历史上第一个被证明 NP 完全的问题（Cook-Levin 定理）。

归约（Reduction）直觉：若问题 A 能「快速翻译」成问题 B，那么只要 B 有高效解法，A 也就有了——于是 B 至少和 A 一样难。把一堆问题都归约到 SAT，SAT 就成了难度的「汇聚点」。

为什么重要：现代密码学（如 RSA）的安全性，正是建立在「某些问题（如大数分解）难以在多项式时间内求解」的假设之上。若某天证明 P = NP，大量密码体系将瞬间不攻自破。
