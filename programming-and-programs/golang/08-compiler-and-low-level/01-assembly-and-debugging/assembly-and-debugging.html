-S 输出汇编

go build -gcflags=-S 或 go tool compile -S 能看到每个函数的 Plan9 汇编，对照源码理解内联、边界检查消除等。

go build -gcflags="-S" main.go
# 或只编一个文件
echo package main > /tmp/x.go
GOSSAFUNC=main go build  # 生成 SSA 可视化 HTML

dlv 支持断点、单步、查看变量与 goroutine 栈；可 attach 到进程或调试测试。

dlv debug ./cmd/app

(dlv) locals
(dlv) goroutines
Plan9 汇编约定

不是 Intel 语法

Go 汇编是抽象的 Plan9 风格（如 MOVL、函数栈帧用 FP/SP 伪寄存器），与具体 CPU 语法不同，主要用于 runtime 手写优化。

业务代码几乎不需要手写汇编；了解即可，遇到 runtime 源码里的汇编函数知道它在做什么。
