管道-过滤器模式

把处理流程拆成一段段独立的『过滤器』，由『管道』串联，数据流式通过。

管道-过滤器 Pipe & Filter

每个过滤器只做一件事，可任意重组顺序

每个<b>过滤器</b>是无状态、独立的处理单元（如压缩、加密、日志、校验），<b>管道</b>负责把前者的输出接成后者的输入。Unix 的 `cat | grep | sort` 就是经典范例。

适用与优势

  • 高复用：过滤器可像乐高一样重组。
  • 并行友好：相邻过滤器可流水线并行。
  • 可演进：增删环节不影响其他。
  • 常用于编译器前端、ETL、多媒体处理。

面试高频问答

Q：管道-过滤器和职责链有什么区别？
A：管道-过滤器是『数据流经一串变换、产出新数据』；职责链是『请求在链上传递、由某节点处理或不处理』。前者变换数据，后者传递/拦截请求。
Q：过滤器为什么要求无状态？
A：无状态才能保证任意排序与并行都不影响结果，也便于水平扩展与故障重试。
