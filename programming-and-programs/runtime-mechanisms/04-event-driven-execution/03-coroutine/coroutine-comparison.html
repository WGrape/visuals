2Python：生成器协程

def gen():
    x = yield "start"   # 这里挂起，外部 send(x) 恢复并赋值
    yield x * 2

g = gen()
print(next(g))      # start
print(g.send(10))   # 20

3Go：goroutine

go func() {
    for i := 0; i < 3; i++ {
        fmt.Println(i)
    }
}()  // 立即返回，函数并发执行
要点：Go 的 goroutine 由 runtime 调度到少量 OS 线程；阻塞系统调用时 runtime 把其他 goroutine 移到别的线程，不卡住。

4栈归属：为什么重要

  • 无栈协程（Python async / C++20）：切换不换栈，状态存在堆上，单线程内并发。
  • 有栈协程（Go）：每个 goroutine 有自己的栈，能调用任意深度的同步代码而不爆栈。
  • 有栈使你能在 goroutine 里写『看起来同步』的代码，runtime 在底层帮你异步化。

5怎么选

问：想写同步风格却要并发？

Go 的 goroutine 最自然：直接 go func()，runtime 接管调度。

问：单线程高并发 IO？

Python asyncio / Node 事件循环足够，且无需考虑数据竞争。
