目标检测：把对象定位在图像里

类别、边界框、重叠处理与检测指标是一条完整的推理链。

学完能解释什么

  • 说清分类与检测在输出上的区别
  • 理解 IoU 和非极大值抑制 NMS 的使用条件
  • 阅读 precision、recall 与 mAP 而不误把置信度当准确率

逐步看机制

模型预测可能的目标位置

单阶段模型在特征图上密集预测，双阶段模型先生成候选区域；端到端集合预测也可直接输出有限个目标。

一个框包含哪些信息

检测输出通常是 (类别, 置信分数, 左上角, 右下角) 的集合，而不是单个整图标签。边界框只是矩形近似，无法精确表达发丝或透明物体的轮廓。图像缩放和裁剪后必须把模型坐标正确映射回原图，否则框看似“偏移”。

IoU 与 NMS 的玩具例子

IoU = 两个框的交集面积 / 并集面积。假设同类的框 A（分数 0.92）与 B（0.81）重叠 IoU 为 0.78，NMS 阈值设 0.50：先保留 A，再压掉 B，避免同一物体被报两次。若两框包围不同相邻物体，阈值过低可能误删真实目标；因此 NMS 不是“重叠就删除”的普适规则。

小目标因像素少，轻微偏移就会明显降低 IoU；检测难点也包括密集遮挡、尺度变化与类别混淆。

怎样读检测评估

调整分数阈值通常会改变精确率与召回率；AP 概括一类目标在不同召回位置的精确率表现，mAP 再汇总多个类别。评估时必须写清 IoU 阈值约定：AP@0.5 与跨 0.50—0.95 多阈值平均的指标不能直接当成同一个数比较。

除了总体分数，还应按类别、目标大小、遮挡和拍摄场景拆开看。产品只需要回答“有没有车”时可能不必支付检测框标注和定位计算的成本。

自检

两个高度重叠的检测框总要二选一吗？

不一定。传统同类框可按 NMS 阈值去重，但相邻真实目标可能高度重叠；端到端集合预测模型也可能不采用 NMS。
