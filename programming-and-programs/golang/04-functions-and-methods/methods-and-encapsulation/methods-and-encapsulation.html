方法声明

值接收者与指针接收者

接收者是值：操作副本；是指针：操作原值且可修改。两者可共存于同一类型。

type Counter struct{ n int }

func (c Counter) Get() int { return c.n }      // 值接收者
func (c *Counter) Inc() { c.n++ }             // 指针接收者，可改

var c Counter
c.Inc(); c.Inc()
fmt.Println(c.Get())  // 2
选值还是选指针

一致性优先，再谈语义

经验：需要修改接收者、或结构体较大避免拷贝时用指针；否则用值。同一类型的多个方法接收者风格必须统一。

用指针接收者用值接收者
方法会修改接收者只读且不关心副本
含 mutex 等不可拷贝字段小的值类型
为一致性（已有指针方法）想表达不可变语义
嵌入扩展类型

复用字段与方法（组合）

把已有类型匿名嵌入，外层可直接调用其方法，实现「has-a 复用」而非继承。结合接口可形成多态。

type Logger struct{}
func (l Logger) Log(s string) { fmt.Println(s) }

type Server struct {
    Logger   // 嵌入
    Addr string
}

s := Server{Addr: ":8080"}
s.Log("started")   // 调用提升的方法
方法值与表达式

方法也可当值传递

「方法值」绑定了具体接收者；「方法表达式」把方法变成普通函数，第一个参数变成接收者，常用于泛型式调用。

c := Counter{}
f := c.Inc        // 方法值（已绑定 c）
f()

// 方法表达式：func(*Counter)
g := (*Counter).Inc
var c2 Counter
g(&c2)

小写即私有

通过只暴露大写的方法、隐藏小写字段，控制外部如何读写内部状态——这就是 Go 的「封装」。
