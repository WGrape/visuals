环境变量

部署友好

os.Getenv / LookupEnv 读环境；容器与 PaaS 下最自然，敏感信息走 Secret 注入，不进代码库。

port := os.Getenv("PORT")
if port == "" { port = "8080" }
v, ok := os.LookupEnv("DEBUG")  // 区分未设置
flag 包

命令行优先

flag 包定义命令行参数，os/flag 支持 -port=8080 与 -port 8080；可用 flag.StringVar 绑定到变量。

var port string
flag.StringVar(&port, "port", "8080", "listen port")
flag.Parse()
配置文件

结构化配置

复杂配置用 yaml/json/toml 文件；可结合 viper 统一读取多源并支持热重载。

// viper 示例
viper.SetConfigFile("config.yaml")
viper.ReadInConfig()
port := viper.GetInt("server.port")
实践

优先级与校验

典型优先级：flag > env > 文件 > 默认值；启动时校验必填项，缺失早失败（fail fast）。

⚠️ 不要把密钥写进配置文件入库；用环境/密钥管理注入，并在启动时校验。
