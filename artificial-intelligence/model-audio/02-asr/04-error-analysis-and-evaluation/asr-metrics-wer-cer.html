ASR 评测指标：WER、CER 与归一化口径

编辑距离公式、为什么归一化决定数字可信度、可运行计算代码，以及评测集怎么建

一句话总结：WER（词错误率）和 CER（字错误率）都是编辑距离除以参考答案长度。公式很简单，但数字可不可信，几乎完全取决于归一化规则——两套不同的归一化能把同一个系统的 WER 差出好几个百分点。所以报 WER 时一定要同时说明归一化口径。

01公式与三种错误

把识别结果和参考答案对齐，统计三种编辑操作：

符号含义例子（参考 → 识别）
S（Substitution）替换参考「今天天气」→ 识别「今天天汽」
D（Deletion）删除（漏识别）参考「今天天气很好」→ 识别「今天天气」
I（Insertion）插入（多识别）参考「今天天气」→ 识别「今天天气很好」
N参考答案的长度（词数或字数）上面的例子 N = 4 或 6
WER = (S + D + I) / N      # 词级别，N 按「词」数
CER = (S + D + I) / N      # 字符级别，N 按「字符」数

# 例子：
#   参考：  the quick brown fox jumps
#   识别：  the quick brown fax jump
#   对齐：  fax→fox 是 1 次替换，jump→jumps 是 1 次删除
#   S=1  D=1  I=0  N=5
#   WER = 2 / 5 = 40%

# 注意：WER 可以超过 100%（插入很多时），这不是 bug
要点：英文用 WER，中文一般用 CER（中文分词不统一，按字更客观）。中英混排场景要统一说明，最好两个都报。

02归一化：决定数字可不可信的关键

处理项为什么常见做法
大小写The vs the 不该算错统一转小写
标点标点识别不稳定去掉全部标点，或统一列举白名单
数字展开"$3.50" 应该读成什么最坑的一项：需定义成 "three dollars and fifty cents" 之类
填充词uh / um / 呃 / 那个是否计入要事先约定
多音与异形同音字替换算不算错中文场景常需人工判定或词表
口音与方言方言发音对应的标准字按标注规范统一
要点：同一批识别结果，换一套归一化规则 WER 差 2~5 个百分点很常见。所以：① 换模型前后必须用同一套规则；② 引用别人的数字先问清口径；③ 上线前把规则写成文档固定下来。

03怎么算：用库还是自己写

# 方案一：用成熟库（推荐，边界情况处理更全）
# pip install jiwer
import jiwer

ref  = "the quick brown fox jumps over the lazy dog"
hyp  = "the quick brown fax jump over the lazy dog"

# 归一化 + 计算一步完成
wer = jiwer.wer(
    ref, hyp,
    truth_transform=jiwer.Compose([
        jiwer.ToLowerCase(),
        jiwer.RemovePunctuation(),
        jiwer.RemoveMultipleSpaces(),
        jiwer.Strip(),
    ]),
    hypothesis_transform=jiwer.Compose([
        jiwer.ToLowerCase(),
        jiwer.RemovePunctuation(),
        jiwer.RemoveMultipleSpaces(),
        jiwer.Strip(),
    ]),
)
print(f"WER = {wer:.2%}")

# 想要 S/D/I 的明细
out = jiwer.process_words(ref, hyp)
print("替换 S =", out.substitutions, " 删除 D =", out.deletions, " 插入 I =", out.insertions)


# 方案二：中文 CER 可以自己写（按字切，不需要分词）
def cer(ref: str, hyp: str) -> float:
    r, h = list(ref), list(hyp)
    n = len(r)
    if n == 0:
        return 0.0 if len(h) == 0 else 1.0
    # dp[i][j] = r[:i] 变成 h[:j] 的最少编辑次数
    dp = [[0] * (len(h) + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(len(h) + 1):
        dp[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, len(h) + 1):
            if r[i - 1] == h[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],       # 删除
                                   dp[i][j - 1],       # 插入
                                   dp[i - 1][j - 1])   # 替换
    return dp[n][len(h)] / n

print(f"CER = {cer('今天天气很好', '今天天汽很好'):.2%}")   # 1/6 ≈ 16.67%

04只看 WER 不够：还要看这些

指标定义反映什么
CER字错误率中文场景的主指标
SER（句错误率）完全正确的句子占比最贴近用户体验——一句错一个字用户就得改
关键实体准确率人名、地名、金额、术语的准确率业务真正关心的往往是这些
RTF处理耗时 / 音频时长能否实时
首字延迟开始说话到出首字的时间交互体验的关键
分场景 WER按口音/噪声/领域分组统计比总指标有用得多，能直接定位短板
要点：总 WER 会被高频简单样本稀释，一定要按场景分组看。一个总 WER 5% 的系统，在带口音子集上可能是 20%。

05评测集怎么建

  1. 与线上分布一致：口音、噪声、设备、语速的比例要贴近真实流量，否则测出来的数字没意义。
  2. 分层抽样：至少分出「安静近场 / 噪声远场 / 带口音 / 专业术语」几组。
  3. 标注要双录校验：人工转写的错误会直接污染 WER，抽样做一致性检验。
  4. 量级要够：样本太少，1~2 个百分点的差异没有统计意义。
  5. 固定为回归集：每次发版跑同一批，才能判断「变好了还是变差了」。
  6. 保留 badcase 子集：把历史上出过问题的样本单独留一份，作为重点回归对象。
  • 不要把训练集当评测集——这是最严重也最常见的错误。
  • 不要只看平均值——P95 和分场景往往更能说明问题。
  • 不要在归一化口径变了之后直接对比历史数字——先重跑基线。

06常见疑问

问：WER 多少算好？

取决于场景。安静近场的通用语音，个位数百分比是常见水平；噪声远场、强口音、专业术语场景会明显更高。跨场景比较 WER 没有意义，要在同一评测集上对比才有效。

问：WER 超过 100% 是怎么回事？

插入错误太多时会出现，说明模型在「胡说」（如长静音段幻觉出文本）。这是严重问题的信号，常见于 VAD 不给力或长音频未分段。

问：为什么人工听感不错，WER 却很高？

多半是归一化口径问题：标点、数字读法、「呃/那个」这类填充词被算了错误。也可能是对齐时同音字被判为替换——中文场景尤其常见。

问：热词加了一大堆，为什么 WER 没降？

先确认评测集里这些热词到底出现了多少次——如果占比极低，对总 WER 的影响本来就看不出来。应该单独统计「热词子集准确率」，而不是看总 WER。

第一层 · 概念与判定：WER 与 CER 怎么选

WER（词错率）和 CER（字错率）都基于编辑距离：把识别结果变成参考文本所需的最少增/删/改次数。英文按词用 WER，中文等无空格语言按字用 CER。

语言形态用原因
英文/空格分词WER词是天然单位
中文/日文CER无词边界，按字
中英混排CER 或按语种分分词不稳定
只看准确率1-WER/CER越接近 1 越好

第三层 · 排障与边界：四个坑

  • 没做归一化就比：大小写、标点、空格、繁简、数字格式（『一』vs『1』）不统一，WER 虚高且不可比——先统一清洗
  • 中文误用 WER：按空格分词中文会把整句当一个词，细微错字也记一大笔——中文必须 CER
  • 插入错误(I)被忽视：模型多吐字会拉高 I，但只看准确率容易漏，要拆解 S/D/I 三项
  • 测试集分布偏移：用干净朗读集测出的低错率，到了真实电话/口音场景完全失效——评测集要贴近业务

第四层 · 原理与取舍

为什么中文必须用 CER 而不是 WER？

因为中文没有词间空格，没有天然的「词」边界，强行分词既不准又不稳定（分词本身会错）。按字符（字）计算编辑距离，单位统一、对齐简单、不受分词误差污染。所以中文 ASR 评测的事实标准是 CER；英文因为有空格分词，WER 才有意义。

为什么归一化（小写/去标点/空格）这么关键？

因为编辑距离对表面差异极其敏感：『Hello.』和『hello』若不算归一化会被记成多处错，但语义一致。统一小写、删标点、标准化空格/数字格式，是为了让指标反映「识别内容对不对」而非「格式像不像」。不归一化的 WER/CER 会因格式偏好虚高，跨系统对比时尤其失真。

WER/CER 越低就一定越好吗，有哪些盲区？

不一定。它是字符级对齐指标，看不到语义：把『银行』识别成『很行』（一字之差，CER 很低）可能比多几个字后果严重得多；也看不到停顿、标点语义、长句连贯性。所以工程上常配合人工评测、语义相似度、下游任务准确率一起看，单看 CER 会漏掉语义级错误。
