模运算

同余、模幂与逆元：把整数"绕回"到一个有限环上计算。

同余：余数相同即等价

定义：若 n 整除 (a−b)，记作 a ≡ b (mod n)，读作"a 与 b 模 n 同余"。换句话说，a、b 除以 n 的余数相等。

例如 17 ≡ 5 (mod 12)，因为两者除以 12 都余 5。钟表就是模 12 的世界：13 点就是 1 点。

类比：模运算像把长长的数轴卷成一个周长为 n 的圆环，超出一圈就绕回来。所有整数被映射到 0,1,…,n−1 这 n 个"格子"里。

模加、减、乘

好消息：加减乘在模 n 下都能"先算后取模"或"边算边取模"，结果一致：

(a + b) mod n = ((a mod n) + (b mod n)) mod n
(a * b) mod n = ((a mod n) * (b mod n)) mod n

这一性质让我们可以在处理超大数时始终只保留余数，避免溢出——加密运算天天靠它。

模幂与快速幂

计算 a^k mod n。 naïve 做法是先算 a^k 再取模，但 a^k 会爆炸式增长。快速幂利用"平方"把指数 k 拆成二进制，复杂度从 O(k) 降到 O(log k)：

def modpow(a, k, n):
    res = 1
    a = a % n
    while k > 0:
        if k & 1:        # k 是奇数
            res = (res * a) % n
        a = (a * a) % n
        k >>= 1
    return res
直觉：与其连乘 k 次，不如"平方再平方"，只在当前位为 1 时把结果乘进去。这是 RSA 加密能秒级完成的根本原因。

模逆元与费马小定理

模逆元 x 满足 a·x ≡ 1 (mod n)，记作 a⁻¹。它存在当且仅当 gcd(a,n)=1（即 a、n 互素）。

当 n 是素数 p 且 a 不被 p 整除时，费马小定理给出捷径：a^(p−1) ≡ 1 (mod p)，于是 a⁻¹ ≡ a^(p−2) (mod p)，再用快速幂就能求逆元。

应用：哈希、校验和、循环缓冲区

哈希下标

hash(key) mod 表长 → 把任意键映射到数组下标。

校验和

把数据块逐字节模加/模乘，得到可快速比对的摘要。
