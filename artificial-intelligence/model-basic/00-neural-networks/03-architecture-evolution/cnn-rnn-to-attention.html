神经网络地基

架构演进：从 MLP / CNN / RNN / LSTM 到注意力

为什么最后是 Transformer 赢了？因为每一代架构都在解决上一代的一个致命瓶颈：MLP 不懂结构、CNN 不懂长程、RNN 不能并行、LSTM 仍受限于串行。本文顺着这条演进线讲清每种结构的归纳偏置与它解决的核心问题。

演进全景

核心脉络：谁能更好地利用"结构先验"，同时还能并行计算，谁就赢。

MLP：不懂结构

每个输入维度连到每个神经元，没有任何关于"数据长什么样"的假设。

问题：① 参数量随输入维度爆炸；② 对图像来说，把像素顺序打乱它照样学，完全浪费了"相邻像素相关"这一先验；③ 对序列来说，输入长度必须固定。所谓"归纳偏置太弱"。

CNN：局部性 + 权值共享

卷积核只扫一小块区域，且同一个核在全图复用。两大先验：

局部性：相邻像素才有强相关，远端像素不必一上来就连。
→ 层数加深后感受野逐层扩大，等价于"先看边角、再拼部件、最后成物体"。
平移不变 / 权值共享：同一个特征（比如"竖边"）出现在图的哪个位置都用同一套参数识别。
→ 参数量暴降，且天然泛化。
CNN 的局限：感受野有限，不擅长建模长程依赖；而且它本质是为网格数据设计的，处理文本序列很别扭。

RNN：为序列而生，但有两个致命伤

按时间步逐步推进，把上一步的隐藏状态传给下一步，理论上能处理任意长度：

h_t = f(W·x_t + U·h_{t-1})
伤一：长程遗忘
信息要穿过一连串矩阵乘法才能传到远处，梯度消失导致学不会远距离依赖。
伤二：无法并行
h_t 依赖 h_{t-1}，必须一步步串行算。训练速度被序列长度卡死，没法用 GPU 大规模堆数据。

LSTM / GRU：用门控修长程依赖

LSTM 引入一条"细胞状态"的高速公路，并用三个门来控制信息流：

遗忘门
决定丢弃多少旧记忆
输入门
决定写入多少新信息
输出门
决定对外暴露多少
因为记忆主要在一条加法通道上传（而不是反复矩阵乘），梯度能相对顺畅地流动，长程依赖问题解决了一大半。GRU 是它的简化版（两个门），更快、参数更少。
但 串行计算这个伤没治好：LSTM 依然是逐步推进的，训练吞吐上不去。这是它被 Transformer 取代的根本原因——不是能力不够，而是不适合规模化。

Attention 的第一次登场：给 Seq2Seq 解瓶颈

Seq2Seq（编码器-解码器）要把整个句子压成一个定长向量再解码，长句信息必然挤爆。注意力机制的解法很直接：

别压缩了——解码每一步时，让解码器直接去看编码器的所有位置，并按相关性加权取用。

Attention(Q, K, V) = softmax( QKᵀ / √d_k ) · V

Transformer：把注意力当主干，彻底丢掉循环

2017 年的关键洞察是：既然注意力这么好，为什么还要 RNN？ 于是直接用纯注意力 + FFN 堆叠：

任意两位置距离都是 1
不再需要信息穿过多层传递，长程依赖天然解决
全序列可并行
所有位置同时算，训练吞吐彻底释放，才有了后来"堆数据、堆参数"的规模化可能
丢掉循环也丢掉了顺序信息，所以必须显式加位置编码；代价是注意力的计算和显存随序列长度呈 平方 增长，这才引出后续 FlashAttention、MQA/GQA、KV Cache、长上下文外推等一系列工程优化。

面试速记卡

  • MLP：无结构先验，参数爆炸。
  • CNN：局部性 + 权值共享 + 平移不变；擅长网格数据，不擅长长程。
  • RNN：天然序列，但梯度消失 + 无法并行。
  • LSTM/GRU：门控 + 加法记忆通道，修好长程遗忘，但串行依旧。
  • Attention 首次登场：解决 Seq2Seq 定长向量瓶颈。
  • Transformer：纯注意力，任意位置距离 1 + 全并行 → 规模化成为可能；代价是 O(n²) 与需显式位置编码。
