🧬 Neo4j 数据模型

属性图、节点、关系与标签

模型要素

🔘

节点 Node

实体，可带若干 Label（如 Person、Movie）。

➡️

关系 Relationship

有类型、有方向、可带属性（如 KNOWS、ACTED_IN）。

🏷️

标签 Label

节点的类别，便于索引与分类。

📌

属性 Property

节点 / 关系的键值属性。

Index-free Adjacency

Neo4j 在存储层把关系实现为『物理指针』：每个节点直接持有指向相邻节点/关系的指针，遍历时顺着指针走，无需在运行时做表连接或索引查找——这是图遍历高性能的根本原因。

💡 设计图模型时优先『以关系为中心』：把业务里反复要遍历的连接显式建成关系，而不是藏在某个 JSON 字段里。
