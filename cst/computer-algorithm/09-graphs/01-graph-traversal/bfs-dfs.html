🔎 BFS 与 DFS 图搜索详解

队列 vs 栈：无权图最短路、层序遍历、连通性与拓扑

一句话总结

BFS 和 DFS 是遍历图 / 树 / 网格的两种基本策略。唯一差别是用队列还是用栈来决定"下一个访问谁"：

🎢

BFS（广度优先）

用队列，一圈一圈向外扩散。首次到达某点的路径就是最短路径（边权相同时）。

🕳️

DFS（深度优先）

用栈 / 递归，一条路走到黑再回头。擅长找连通块、判环、拓扑排序。

🚫

visited 集合

两者都必须有。图有环，不标记已访问就会无限循环 / 指数级重复。

⚖️

复杂度

时间 O(V + E)，空间 O(V)。V 顶点数、E 边数。

二、代码模板

2.1 BFS：队列 + visited（无权图最短路）

from collections import deque def bfs(graph, start): visited = {start} q = deque([start]) dist = {start: 0} # 记录到起点的最短距离 while q: node = q.popleft() # 队首出队（先来的先扩散） for nxt in graph[node]: if nxt not in visited: visited.add(nxt) # ★ 入队时就标记，防止重复入队 dist[nxt] = dist[node] + 1 q.append(nxt) return dist # 层序遍历写法（需要区分"第几层"时） def bfs_level(graph, start): visited, q, level = {start}, deque([start]), 0 while q: for _ in range(len(q)): # 一次性处理完当前这一层 node = q.popleft() for nxt in graph[node]: if nxt not in visited: visited.add(nxt) q.append(nxt) level += 1 return level
💡 关键细节：必须在入队时就加入 visited，而不是出队时。否则同一节点可能被多个前驱重复入队多次，队列膨胀，复杂度退化。

2.2 DFS：递归 / 显式栈

# 写法一：递归（最简洁，本质是系统调用栈） def dfs_recursive(graph, node, visited): visited.add(node) for nxt in graph[node]: if nxt not in visited: dfs_recursive(graph, nxt, visited) # 写法二：显式栈（避免递归过深爆栈） def dfs_iterative(graph, start): visited, stack = set(), [start] while stack: node = stack.pop() # 栈顶出栈（后入先出 → 往深处钻） if node in visited: continue visited.add(node) for nxt in graph[node]: if nxt not in visited: stack.append(nxt) return visited
⚠️ 递归 DFS 的栈溢出：Python 默认递归深度约 1000。图/网格规模大时（如 300×300 的岛屿题）会 RecursionError，此时改用显式栈迭代或 sys.setrecursionlimit(10000)。

三、网格（矩阵）上的 BFS/DFS

3.1 岛屿问题（LeetCode 200）：DFS 洪水填充

def numIslands(grid): if not grid: return 0 m, n = len(grid), len(grid[0]) count = 0 def dfs(r, c): if (r < 0 or r >= m or c < 0 or c >= n or grid[r][c] != '1'): # 越界 or 非陆地 → 返回 return grid[r][c] = '0' # ★ 就地标记：把陆地"淹成"水，省去 visited 数组 for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)): # 四个方向 dfs(r + dr, c + dc) for r in range(m): for c in range(n): if grid[r][c] == '1': count += 1 dfs(r, c) # 淹掉整座岛 return count

四、怎么选：BFS 还是 DFS？

场景推荐理由
无权图最短路径 / 最少步数BFS首次到达即最短，层数就是距离
二叉树层序遍历BFS按层输出天然契合队列
数连通块 / 岛屿 / 洪水填充DFS（或 BFS 皆可）只需遍历完整块，不关心距离
判环 / 拓扑排序DFS需要"后序遍历"和递归栈判断回边
找所有路径 / 排列组合DFS（回溯）需要完整走完一条路再回退
矩阵最长递增路径DFS + 记忆化需要子问题结果，DFS 天然支持
迷宫最短步数 / 单词接龙BFS求最少变换次数
一句话决策：问"最少几步 / 最短多远 / 按层输出" → BFS；问"是否存在 / 有多少个 / 找出所有方案 / 拓扑关系" → DFS。

4.1 复杂度对比

维度BFSDFS
数据结构队列（FIFO）栈（LIFO）或递归
时间复杂度O(V + E)O(V + E)
空间复杂度O(V)（队列最宽一层的规模）O(V)（递归深度，最坏等于图高）

BFS / DFS 的代价与适用

维度BFSDFS
数据结构队列（queue）栈（stack）/ 递归
时间复杂度O(V + E)O(V + E)
空间复杂度O(V)（队列最宽一层）O(V)（递归深度 = 最长路径）
最坏空间完全图时 O(V)链状图时 O(V)；递归可能爆栈
最短路径保证无权图最短不保证
找到解的质量最先找到的是最优（层序）第一个解可能很深
内存访问队列连续，缓存友好跳跃访问，缓存不友好
典型应用最短路径、层序遍历、 Flood Fill拓扑排序、连通分量、回溯、找环

递归 DFS 的栈深度风险：默认栈 8MB，若图是一条 10 万节点的链，每层栈帧约 100 字节 → 需要 10 MB，会栈溢出。Python 默认递归上限 sys.getrecursionlimit() = 1000，更早就报 RecursionError。生产代码处理大图必须用显式栈的迭代 DFS。

代码对照

# BFS：最短路径（无权图）
from collections import deque

def bfs_shortest(graph, s, t):
    dist = {s: 0}
    q = deque([s])
    while q:
        u = q.popleft()
        if u == t:
            return dist[u]                  # BFS 首次到达即最短
        for v in graph[u]:
            if v not in dist:               # 入队时标记，避免重复入队
                dist[v] = dist[u] + 1
                q.append(v)
    return -1

# 双向 BFS：起点终点都已知时可大幅减少搜索量
# 单向 BFS 复杂度 O(b^d)，双向是 O(b^(d/2))，分支因子 b=10、深度 d=6 时
# 从 10^6 降到 10^3，约 1000 倍差距
# DFS 迭代版（避免递归爆栈）
def dfs_iter(graph, s):
    seen = {s}
    stack = [s]
    while stack:
        u = stack.pop()
        for v in graph[u]:
            if v not in seen:
                seen.add(v)
                stack.append(v)
    return seen

# DFS 递归版（简洁但深度受限）
def dfs_rec(u, graph, seen, out):
    seen.add(u); out.append(u)
    for v in graph[u]:
        if v not in seen:
            dfs_rec(v, graph, seen, out)

# 用 DFS 判环（有向图）：用「在栈中」标记而不是「访问过」
def has_cycle(graph):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = {u: WHITE for u in graph}
    def visit(u):
        color[u] = GRAY                    # 正在访问（在当前递归栈里）
        for v in graph[u]:
            if color[v] == GRAY: return True    # 回到栈中的节点 = 有环
            if color[v] == WHITE and visit(v): return True
        color[u] = BLACK                   # 完成
        return False
    return any(color[u] == WHITE and visit(u) for u in list(graph))
# 注意：只用 visited 集合判环会漏判（分不清「回边」和「前向边」）

排查与选择

症状原因处理
BFS 内存爆了队列里存了太多节点（宽图）改用 IDDFS 或 A*；或用双向 BFS
DFS 栈溢出递归太深改迭代版；Python 调 sys.setrecursionlimit（治标）
BFS 结果不是最短带权图用了 BFS带权图必须用 Dijkstra（正权）或 Bellman-Ford（有负权）
重复访问同一个节点只在 pop 时标记 visited必须在入队/入栈时就标记，否则同一节点会被加入多次
判环漏判只用了 visited，没区分「在栈中」用三色标记（白/灰/黑）
要找所有路径而不是最短用了 BFS改用 DFS 回溯枚举
100 万节点跑不动邻接矩阵 O(V²) 空间用邻接表；或压缩表示
  • 选择判据：求最短/最少步数 → BFS；求是否存在/枚举所有/拓扑序/连通性 → DFS。
  • 空间对比的实际意义：BFS 的空间取决于最宽的一层（完全图是 O(V)），DFS 取决于最长路径（链状是 O(V)）。选哪个要看图的形状。
