排序

任意类型可排

sort.Slice 按比较函数排序最常用；sort.Ints/Strings 有专门快路径；sort 不稳定排序，需稳定用 sort.SliceStable。

people := []User{{Age: 30}, {Age: 20}}
sort.Slice(people, func(i, j int) bool {
    return people[i].Age < people[j].Age
})

sort.Strings([]string{"b","a"})  // [a b]
容器

堆/链表/环

container/heap 提供最小堆接口（实现 Len/Less/Swap/Push/Pop）；container/list 双向链表；container/ring 环形缓冲。

// 用 heap 实现优先队列，需实现 heap.Interface
h := &IntHeap{2,1,5}
heap.Init(h)
heap.Push(h, 3)
min := heap.Pop(h)
正则

RE2 语法

regexp.Compile 编译正则（注意错误处理）；MatchString/FindAllString 提取；Go 正则不支持回溯，安全但功能受限。

re := regexp.MustCompile(`\d+`)
nums := re.FindAllString("a12b34", -1)  // [12 34]
字符串

strings 工具箱

strings.HasPrefix / Split / Replace / Builder 覆盖多数场景；频繁拼接用 strings.Builder 避免多次分配。

strings.Builder 在循环拼接时远胜 + 运算符，是性能优化的常见落点。
