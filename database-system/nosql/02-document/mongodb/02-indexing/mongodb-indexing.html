🔎 MongoDB 索引

从单字段到复合、多键与 TTL

索引类型

🔑

单字段

对单个字段建索引，最常见的等值/范围查询加速。

🧱

复合索引

多字段组合，遵循最左前缀原则。

📚

多键索引

对数组字段自动展开，每个元素建索引。

⏳

TTL 索引

按时间自动过期删除，适合日志/会话。

要点

  • 默认 _id 自带唯一索引。
  • 复合索引顺序很关键：等值字段在前，范围字段在后。
  • 文本索引支持全文检索；2dsphere 支持地理查询。
  • 索引降低写性能、占用内存，用 explain() 看是否命中、是否 IXSCAN。
💡 避免『索引太多拖慢写入』与『没索引全表扫』两端：按真实查询模式建索引，定期清理冗余。
