⛰️ 缓存雪崩

大批 key 同时失效或缓存集群垟机，请求全部落到数据库

⛰️

定义

大批 key 同时失效/垟机

🎲

过期打散

随机 TTL

🏯

多级缓存

本地+Redis

💡

炉断降级

保护 DB

现象

大量 key 同一时刻过期，或缓存集群垟机 → 请求全部落到 DB → DB 被冲圸。

对策

  • TTL 加随机抖动：避免集中失效
  • 多级缓存：本地 + Redis 分层
  • 限流炉断降级：保护 DB
  • Redis 高可用：集群/哨兵

🎯 面试问答

Q：怎么预防雪崩？
A：过期时间加随机抖动、多级缓存、限流炉断、Redis 集群高可用。
Q：雪崩和击穿会同时发生吗？
A：可能；击穿是局部触发点，雪崩是全局失效面，对策互补。
Q：缓存垟机怎么先兆？
A：降级返回默认/静态值、本地缓存承、限流保护 DB。
