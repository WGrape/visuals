图像生成评测：分布、指令与人工判断

FID、CLIP 类指标回答不同问题，单个高分不能证明图像可靠。

学完能解释什么

  • 说明 FID 衡量数据集分布而非单张图片质量
  • 区分文本对齐、视觉质量、多样性与组合正确性
  • 设计避免测试集泄漏的人工盲评

逐步看机制

定义提示词与生成条件

按人物、文字、复杂关系、罕见组合分层选题；锁定模型、采样设置与随机种子。

FID 不能给单图打可靠分

Fréchet Inception Distance 用特征空间中的均值与协方差近似两批图像分布，再比较距离。较低的 FID 常代表生成分布与参考分布更接近，但它依赖特征网络、图像预处理、样本数量和真实参考集。它不是单张图像“真伪概率”，也无法保证指定文字被正确拼写。模型记住训练图可能让某些指标好看，评测集应去重并与训练来源隔离。

“像图”与“听话”分开测

基于图文嵌入的相似度可帮助测提示词总体相关性，但对数量、左右、否定词和文字细节可能不敏感。要构造属性绑定、空间关系和组合式提示词，并逐条件核验。高真实感图片可能完全违反指令；正确的对象和文字也可能有糟糕的结构与手部细节。多样性还要看不同种子之间是否坍缩成同一模式。

可复现的评测记录

  1. 公布提示词分层、样本数、随机种子、分辨率和生成次数。
  2. 同一参考数据与预处理下计算分布指标，不跨设置直接比较 FID。
  3. 设置可核对的任务级指标：OCR 文字、计数、属性和空间关系。
  4. 人工盲评采用统一尺度，保留失败案例与评审一致性，而非只展示精选图。

安全与来源评价另行报告；“漂亮”和“无害”不是同一个维度。

自检

模型在一张生成图片上得到一个“FID 分数”，说这张图质量很高，对吗？

不对。FID 是两组图像的分布比较，不能给单张图独立赋予可靠的质量分。

核心速览

FIDFréchet Inception Distance，越低越好，衡量生成分布与真实分布的距离
ISInception Score，越高越好，衡量清晰度与多样性（有局限）
CLIP Score生成图与 prompt 的 CLIP 相似度，衡量图文对齐
LPIPS感知相似度，常用于衡量多样性/两两差异
人眼评价最终标准，自动指标只是代理

FID 是怎么算的

均值（整体风格）与协方差（多样性） ⚠️ FID 依赖样本量（通常需 5 万张以上才稳定）与特征提取器的选择，跨论文比较必须确认两者一致
图：FID 把两个图像集合各自拟合为高斯分布，再算它们的距离

指标对照表

指标方向衡量什么局限
FID越低越好生成分布与真实分布的整体距离（兼顾质量与多样性）需大样本；对特征提取器敏感；无法反映单张质量
IS（Inception Score）越高越好清晰度（单张可分类）+ 多样性（整体分布均匀）不看真实数据，模式崩塌时也可能高分；已较少单独使用
CLIP Score越高越好生成图与文本 prompt 的语义对齐度依赖 CLIP 自身能力；对细粒度属性不敏感
LPIPS越低越好（相似度）感知层面的相似程度常用于多样性（两两距离均值）而非质量
Precision / Recall越高越好生成样本的保真度 / 对真实分布的覆盖率需定义流形，实现有多种版本
人眼偏好（HPS）越高越好基于人类偏好数据训练的打分模型可被「刷分」，需配合人工抽查

怎么正确地评估

① 样本量要够

FID 在小样本（几百张）上极不稳定。至少 5000 张，推荐 5 万张；论文间的数值比较必须确认样本量一致。

② 固定提取器与预处理

不同实现（PyTorch 官方 Inception vs 各 repo 的）算出的 FID 差异很大。比较时必须用同一份代码和权重，否则数字没有可比性。

③ 多指标组合

单看 FID 会被"平庸但安全"的生成刷高。建议组合：FID（整体）+ CLIP Score（对齐）+ 多样性指标 + 人工抽查。

④ 建自己的评测集

通用指标无法反映业务需求（如"能不能生成符合品牌调性的图"）。做法：建 50~200 条业务典型 prompt，定期人工打分做回归测试。

常见误读

❌ FID 低 = 每张都好看它是分布指标，可能包含少量极好 + 少量极差
❌ IS 高 = 多样性好IS 容易被模式崩塌欺骗，需配合 FID
❌ CLIP Score 高 = 图正确CLIP 对数量、空间关系、文字渲染不敏感
✅ 看分布也看极值同时抽样目视最差的那批，往往能发现系统性问题
✅ 分维度评估按 prompt 类型（人像/场景/文字/多物体）分开统计

深入自检

FID 到底在衡量什么？为什么越低越好？

FID 把真实图像集和生成图像集分别过一遍 Inception 网络提取特征，各自拟合成一个多元高斯分布（均值 μ + 协方差 Σ），然后算这两个高斯之间的 Fréchet 距离。均值项反映「整体风格是否一致」，协方差项反映「多样性是否匹配」。距离越小说明生成分布越接近真实分布，即既真实又多样。它是目前最主流的生成图像指标，但注意它衡量的是分布而不是单张质量——FID 低的模型也可能生成一部分很差的单张。

为什么 IS（Inception Score）逐渐被弃用？

IS 有两个硬伤：①完全不看真实数据——它只评估生成图「是否容易被分类（清晰）」和「整体类别分布是否均匀（多样）」，所以一个模式崩塌但每类只生成一张完美图的模型，IS 会很高；②无法检测与真实分布的偏差。相比之下 FID 直接比较生成分布与真实分布的距离，能捕捉模式崩塌和质量下降。所以现在论文基本以 FID 为主，IS 最多作为辅助。

CLIP Score 高就一定说明图符合 prompt 吗？

不一定。CLIP 擅长整体语义，但对三类内容很不敏感：①数量（「三只猫」和「五只猫」的 CLIP 分数可能几乎一样）；②空间关系（「猫在桌子左边/右边」CLIP 常常分不清）；③属性绑定（「红色的车和蓝色的房子」可能被理解成「红色+蓝色+车+房子」）。所以 CLIP Score 高只能说明「大方向对」，细粒度正确性需要更专门的评测（如专门的构图/计数评测集）或人工判断。

评估生成模型应该建什么样的流程？

建议三层：①自动指标层——固定一批 prompt（几百到几千条）批量生成，算 FID / CLIP Score / 多样性，用于快速回归（每次改模型都跑，发现明显退化）；②人工评测层——建 50~200 条业务典型 prompt，定期让人按 1~5 分打分（质量、对齐度、美观度），这是最终标准；③A/B 盲测——上线前把新旧模型的图随机打乱让人选更喜欢哪个，得到偏好率。三层结合才能既快又准。

为什么我的模型 FID 很好但用户觉得差？

典型原因：①分布指标掩盖了个体问题——FID 好可能意味着「大部分平庸、少数极好」，而用户遇到的是平庸那批；②指标与业务目标不一致——FID 在通用数据上算，而你的业务需要的是特定风格/构图；③用户关注点不同——用户更在意「是否好看/是否有用」（美学、可用性），而 FID 只关心「是否像真实分布」；④提示词分布差异——评测用的 prompt 与实际用户的 prompt 差很远。解决：建业务自己的评测集和指标（如人工偏好分、任务成功率），不要只盯通用指标。

图像生成核心指标

指标衡量什么计算基础方向
FID生成分布与真实分布的距离Inception-V3 pool3 特征的 Fréchet 距离越低越好
IS清晰度 + 多样性exp(E_x KL(p(y|x) || p(y)))越高越好
CLIP Score图文一致性图像与文本 CLIP 嵌入的余弦相似度越高越好
LPIPS（多样性）样本间差异生成图两两感知距离适中为好
KID同 FID，无偏估计MMD（最大均值差异）越低越好

FID 的样本量要求：计算 FID 需要估计两个高维高斯分布，样本不足会严重偏差。经验是至少 1 万张（常用 5 万），低于 1000 张的数值不可信。这是很多论文用 5 万张 COCO 或 ImageNet 样本的原因。

FID 计算

import numpy as np
from scipy.linalg import sqrtm

def calculate_fid(feat_real, feat_gen):
    '''feat_* : (N, 2048) Inception-V3 pool3 特征'''
    mu1, mu2 = feat_real.mean(0), feat_gen.mean(0)
    s1 = np.cov(feat_real, rowvar=False)
    s2 = np.cov(feat_gen, rowvar=False)
    diff = mu1 - mu2
    # Fréchet 距离 = |mu1-mu2|² + tr(S1 + S2 - 2(S1·S2)^(1/2))
    covmean = sqrtm(s1.dot(s2))
    if np.iscomplexobj(covmean):        # 数值误差导致的复数
        covmean = covmean.real
    return diff.dot(diff) + np.trace(s1 + s2 - 2*covmean)

# 参考量级（COCO 上）：
#   FID < 10   极佳（当前 SOTA 级别）
#   FID 10~30  良好
#   FID > 50   明显可辨的质量差距
# <strong>注意：FID 依赖特征提取器与数据集，跨论文比较要确认设置一致</strong>

指标失效的场景与补充

场景FID/IS 的问题补充指标
模式崩塌IS 可能仍然高（生成清晰但千篇一律）LPIPS 多样性、recall
记忆训练图FID 极低（因为就是原图）最近邻检索比对训练集
图文对齐差FID 不衡量文本一致性CLIP Score
文本渲染所有指标都不敏感OCR 后再比对文字
人脸/人体结构FID 不反映结构合理性人工评测、关键点检测

最重要的提醒：FID 低不等于图好看。FID 衡量的是分布层面的统计距离，单张图的观感、细节合理性、是否符合提示词都不在其中。所以完整评测必须是自动指标 + 人工评测结合：自动指标看整体分布与一致性，人工评测看结构合理性与审美。

记忆检测

# 检测「记忆」而非「生成」：最近邻比对
import torch, torch.nn.functional as F

def memorization_check(gen_feats, train_feats, topk=1, threshold=0.95):
    '''若生成图与某张训练图特征余弦相似度 > 阈值，判定为记忆'''
    gen = F.normalize(gen_feats, dim=-1)
    train = F.normalize(train_feats, dim=-1)
    sims = gen @ train.T                      # (N_gen, N_train)
    max_sim, _ = sims.topk(topk, dim=-1)
    return (max_sim[:, 0] > threshold).float().mean().item()

# 判读：记忆率 > 5% 说明模型在复制训练数据，
#       这在版权与泛化上都是问题，FID 却可能很低
# 对策：去重训练集、降低模型容量、检查数据泄漏

人工评测的设计

维度问什么评分方式
整体质量这张图看起来真实吗？1~5 分
图文一致图是否符合提示词？1~5 分 / 二选一
结构合理人体/物体结构是否异常？是否 + 指出位置
A/B 偏好两张图更喜欢哪张？强制二选一，最可靠

二选一优于打分：让评测者给绝对分数时，个体尺度差异大（有人严格有人宽松），噪声高；两两比较只需要相对判断，一致性显著更好，统计上也更容易得出显著结论。

最小样本量：要检测出 5% 的偏好差异，通常需要几百到上千次比较。几十次比较的结果基本不可信——这是很多小团队评测的共同问题。

自检 Q&A

Q：FID 和 IS 该看哪个？

A：优先 FID。IS 有两个硬伤——① 它只看生成图，不比对真实分布，所以模型可以只生成少量高质量但单一的图来刷高 IS；② 它对模式崩塌不敏感。FID 直接比较生成分布与真实分布的距离，更全面。但 FID 也不衡量图文一致性，所以文生图任务必须再加 CLIP Score。标准组合是 FID + CLIP Score + 人工评测。

Q：FID 很低但图看起来很怪，为什么？

A：FID 衡量的是分布距离，不是单图质量。如果生成图在特征空间的统计特性上接近真实图（颜色分布、纹理频率等），FID 就低——哪怕每张图的具体内容很荒谬（六根手指、扭曲的人脸）。这类结构性问题需要专门检测：人体关键点、人脸属性、或用 VLM 做结构化问答（“图里有几只手？”）。

Q：怎么评测「文本渲染」能力？

A：自动指标都不可靠，必须用 OCR。流程是：① 生成一批包含指定文字的图（如「A coffee shop」）；② 用 OCR（PaddleOCR/TrOCR）识别图中文字；③ 计算字符准确率或完全匹配率。这是目前唯一可量化的办法。注意 OCR 本身有误差，所以要同时测「真实渲染图」作为对照组来校准。另外要测不同字数（1 个词 vs 长句），难度差异很大。

Q：多样性怎么量化？

A：两种互补方法——① 样本间距离：计算生成图两两的 LPIPS 或特征余弦距离，取均值；值低说明千篇一律。② 召回率（Recall）：衡量生成分布覆盖了真实分布的多少模式（与 precision 对应）。单独看多样性不够——随机噪声的多样性最高但毫无意义，所以必须同时看质量（precision/FID）与多样性（recall/LPIPS），两者共同构成完整评价。
