向量与矩阵：从点积到矩阵乘法

向量描述“在哪里”，矩阵描述“怎么变”。掌握内积、范数、矩阵乘法的两种视角，后面的行列式与特征值才有落脚点。

核心速览

内积 dot

a·b = Σ aᵢbᵢ = |a||b|cosθ，衡量方向与大小的共同匹配度

范数 norm

L1 绝对值之和、L2 欧氏长度、L∞ 最大分量；正则化就靠它

正交 orthogonal

内积为 0，两向量垂直；正交基让坐标计算变得极简

矩阵乘法

(m×k)·(k×n)→(m×n)，是「动作复合」而非逐格相乘

向量：一列有序的数字

长度为 n 的向量就是 ℝⁿ 中的一个元素。它有三种常见解读，切换视角是解几何与代数题的关键：

① 空间中的点

(3, 4) 是平面上横 3 纵 4 的那个位置。机器学习里一条样本的 n 个特征就是一个点。

② 带方向的箭头

从原点指向该点的位移，有长度和方向。物理里的力、速度，梯度下降里的「更新方向」都是箭头。

③ 一组权重 / 系数

把若干基向量按比例混合的配方，例如颜色 (R,G,B) 就是三种基色的配比。

④ 函数的离散采样

一段音频、一张图拉平后都是一个向量，「对函数做变换」就变成了「对向量做矩阵乘法」。

内积：衡量「同向程度」的万能尺子

内积 a·b = Σaᵢbᵢ 同时编码了长度与夹角。它在实际工程里的用法远比课本丰富：

用法含义典型场景
相似度值越大越「同向」推荐系统打分
余弦相似度a·b/(|a||b|) 去掉长度只看夹角embedding 检索、文本去重
投影长度a 在单位向量 u 上的投影 = a·uPCA、Gram-Schmidt 正交化
正交判定a·b = 0 ⟺ 垂直正交基、傅里叶基、注意力正交约束
卷积/相关滑动窗口逐位相乘再求和CNN、信号匹配
为什么检索时更常用余弦相似度而不是裸内积？因为裸内积会被「长度」主导：一篇很长的文档与任何查询的内积都偏大。归一化后只比方向，才真正比的是「语义是否接近」。

范数：长度的不同定义方式

L2 范数（欧氏）

√Σxᵢ²。最自然的「直线距离」，处处可导，优化友好；L2 正则（权重衰减）让参数整体变小。

L1 范数（曼哈顿）

Σ|xᵢ|。在零点不可导，但能逼出稀疏解——Lasso 用它做特征选择。

L∞ 范数

max|xᵢ|。只看最大分量，用于误差上界与对抗扰动约束。

Frobenius 范数

矩阵的「L2」：√Σaᵢⱼ²。衡量矩阵整体大小，用于正则化与重构误差。

一个形象的对比：在二维平面上画 |x|₁+|x|₂ = 1 是菱形，|x|₂ = 1 是圆。用 L1 做正则时，最优解更容易落在菱形的顶点（某个坐标为 0）上，这就是稀疏性的几何来源。

矩阵乘法的两种视角与代价

# 视角一：行 × 列 = 内积（最直观，适合手算）
C[i][j] = Σ_k A[i][k] * B[k][j]
for i in range(m):
    for j in range(n):
        for k in range(p):      # 三重循环，O(m·n·p)
            C[i][j] += A[i][k] * B[k][j]

# 视角二：外积累加（适合并行，BLAS 常用）
C = Σ_k A[:, k] ⊗ B[k, :]        # 每次把一个列向量与一个行向量撑成矩阵后相加

# 视角三：分块（cache 友好，Strassen 等快速算法的基础）
[[C11, C12],     [[A11, A12],   [[B11, B12],
 [C21, C22]]  =   [A21, A22]] ×  [B21, B22]]

朴素算法是 O(n³)；Strassen 把它降到约 O(n^2.81)，Coppersmith–Winograd 类算法理论上更低但常数巨大，实践中主流仍是高度优化的 BLAS（分块 + SIMD + 多核 + GPU）。关键优化点是访存而非浮点运算：让数据留在 cache 里（分块/重排循环顺序）往往比减少乘法次数收益更大。

形状组合乘法次数典型规模举例
(n×n)·(n×n)n³n=1000 → 10⁹ 次，GPU 毫秒级
(n×k)·(k×m)n·k·m全连接层：batch × in × out
(batch×d)·(d×1)batch·d一次前向推理
稀疏 × 稠密≈ nnz·m图神经网络、推荐

特殊矩阵：认识它们能省一半力气

类型定义好用的性质
单位矩阵 I对角线全 1AI = IA = A，乘法中的「1」
对角矩阵非对角全 0乘以它 = 各维度独立缩放，O(n) 而非 O(n³)
对称矩阵A = Aᵀ特征值全为实数、可正交对角化；协方差矩阵必对称
正交矩阵 QQᵀQ = I保长度保角度（旋转/反射），数值极稳定
正定矩阵xᵀAx > 0特征值全正，优化问题是凸的、有唯一最小值
转置 Aᵀ行列互换(AB)ᵀ = BᵀAᵀ（注意顺序反转）
记忆口诀：(AB)ᵀ = BᵀAᵀ、(AB)⁻¹ = B⁻¹A⁻¹——凡是「拆开」的运算，顺序都要反过来，就像先穿袜子再穿鞋，脱的时候得先脱鞋。

动手：用 NumPy 验证核心性质

import numpy as np
A = np.array([[1., 2.], [3., 4.]])
B = np.array([[0., 1.], [1., 0.]])
x = np.array([1., 1.])

print(A @ x)                       # 矩阵乘向量 → [3. 7.]
print(A @ B, B @ A)                # 不等！顺序不同结果不同
print((A @ B).T, B.T @ A.T)        # 相等：(AB)ᵀ = BᵀAᵀ
print(np.dot(x, x), np.linalg.norm(x)**2)   # 内积 = L2 范数平方
print(np.trace(A), np.linalg.det(A))        # 迹 = 5，行列式 = -2

# 余弦相似度（检索常用）
def cos(a, b): return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
print(cos(np.array([1., 2.]), np.array([2., 4.])))   # 1.0，同向

🎯 常见问法与答题要点

Q：内积为 0 说明什么？内积很大又说明什么？

A：内积为 0（且都不是零向量）说明两向量正交/垂直，在特征空间里意味着「这两个方向完全不相关」。内积很大可能是同向且都很长，也可能是夹角小——所以要区分裸内积与余弦相似度：裸内积受长度影响，余弦相似度只比方向。向量检索一般先用后者，或用归一化后的内积（二者等价）。

Q：L1 正则为什么能产生稀疏解？

A：从几何看：L1 的等值域是带尖角的菱形，L2 是光滑的圆。在约束优化中，最优解常出现在等值域与目标函数等高线首次相切的地方；菱形的尖角落在坐标轴上，那里恰好有某个分量为 0，于是解变稀疏。L2 的圆没有这种尖角，只会把参数整体压小而不会压成 0。

Q：矩阵乘法的时间复杂度一定是 O(n³) 吗？

A：朴素算法是 O(n³)（n×n 方阵），但理论上可以更低：Strassen 约 O(n^2.81)，Coppersmith–Winograd 系列更低但常数巨大，实际很少用。工程上更重要的是访存与并行：分块、循环重排、SIMD、GPU 张量核带来的加速往往远超算法层面的指数改进。稀疏矩阵则可降到约 O(nnz·n)。

Q：矩阵的转置和逆，先后顺序为什么要反过来？

A：因为这两个运算都是「反同态」：(AB)ᵀ = BᵀAᵀ、(AB)⁻¹ = B⁻¹A⁻¹。直觉是动作复合的顺序：AB 表示「先 B 后 A」，要撤销它就必须「先撤销 A 再撤销 B」，所以逆的顺序反过来；转置同理可用维度与定义直接验证。这是面试与作业里最常见的送分/送命题。

Q：正交矩阵为什么在数值计算里特别受欢迎？

A：因为正交变换保长度、保角度、条件数为 1，不会放大浮点误差。QR 分解把任意矩阵写成 A = QR（Q 正交、R 上三角），于是最小二乘、特征值迭代都能在「不放大误差」的前提下进行。相比之下直接用正规方程 (XᵀX)⁻¹Xᵀy 会把条件数平方，数值上明显更脆弱。

Q：向量组线性无关是什么意思？怎么判断？

A：线性无关 = 其中任何一个向量都不能由其余向量线性表示，等价于方程 c₁v₁+…+cₖvₖ=0 只有全零解。判断方法：把这些向量排成矩阵的列，求秩——秩等于向量个数就线性无关；方阵时也可看行列式是否非零。几何上，两个向量无关就是不共线，三个就是不共面。

向量与矩阵的核心运算与代价

矩阵-向量 Axm×1O(mn)
矩阵-矩阵 ABm×p（A: m×n, B: n×p）O(mnp)
转置 Aᵀn×mO(mn)

矩阵乘法的顺序会影响代价：三个矩阵 A(10×100) · B(100×5) · C(5×50)，(AB)C = 10×100×5 + 10×5×50 = 5000 + 2500 = 7500；A(BC) = 100×5×50 + 10×100×50 = 25000 + 50000 = 75000。差 10 倍。这就是「矩阵链乘法」这个经典 DP 问题的实际意义。

代码与手算

import numpy as np

# 1) 矩阵乘法的复杂度对比（顺序很重要）
import time
A = np.random.rand(10, 100); B = np.random.rand(100, 5); C = np.random.rand(5, 50)
t0 = time.time(); (A @ B) @ C; t1 = time.time()
A @ (B @ C); t2 = time.time()
print(f"(AB)C: {t1-t0:.6f}s   A(BC): {t2-t1:.6f}s")
# 浮点运算次数：(AB)C = 5000+2500 = 7500；A(BC) = 25000+50000 = 75000

# 2) 余弦相似度（向量检索的核心）
def cosine_sim_matrix(A, B):
    """A: (n,d) B: (m,d) -> (n,m) 余弦相似度矩阵"""
    A_norm = A / np.linalg.norm(A, axis=1, keepdims=True)
    B_norm = B / np.linalg.norm(B, axis=1, keepdims=True)
    return A_norm @ B_norm.T          # 归一化后点积 = 余弦
# 百万级向量检索就是靠这个矩阵乘，所以 GPU 上极快

# 3) 手算矩阵乘法
# A = [[1,2],[3,4]], B = [[5,6],[7,8]]
# AB[0][0] = 1*5 + 2*7 = 19
# AB[0][1] = 1*6 + 2*8 = 22
# AB[1][0] = 3*5 + 4*7 = 43
# AB[1][1] = 3*6 + 4*8 = 50
# 关键：AB ≠ BA（矩阵乘法<b>不满足交换律</b>）
# 4) 求解方程组：永远用 solve 而不是 inv
A = np.array([[3., 1.], [1., 2.]])
b = np.array([9., 8.])

x1 = np.linalg.solve(A, b)        # ✅ 快且数值稳定（LU 分解）
x2 = np.linalg.inv(A) @ b         # ❌ 慢约 2 倍，误差更大
print(x1, x2)                     # 结果相同但 x1 更可靠
print(np.allclose(x1, x2))        # True（本例矩阵良态）

# 5) 病态矩阵的识别（关键技能）
cond = np.linalg.cond(A)
print("条件数:", cond)             # 本例约 3.6，很健康
# 判据：cond > 1e10 时，解已经不可信（有效数字基本丢光）
# 病态的例子：希尔伯特矩阵
H = np.array([[1/(i+j+1) for j in range(8)] for i in range(8)])
print("希尔伯特矩阵 8x8 条件数:", np.linalg.cond(H))   # 约 1.5e10，已病态

# 6) 矩阵分解的选择
#   LU 分解：  解方程组           O(n^3)
#   QR 分解：  最小二乘           更稳定
#   SVD：      降维/伪逆/推荐     最稳定但最慢
#   Cholesky： 正定矩阵           比 LU 快 2 倍（对称正定时用）
