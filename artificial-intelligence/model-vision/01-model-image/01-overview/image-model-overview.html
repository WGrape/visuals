图像大模型全景：理解、生成、编辑三条主线

图像领域的大模型可以分成三条主线：看懂图片（理解）、画出图片（生成）、改图片（编辑）。本文先把这三条线的技术地图铺开，说明各自要解决什么问题、代表模型与范式差异，作为后续各章节的索引。

三条主线：看懂、画出、改图

把一张图片交给模型，能做的事不外乎三类，每类的输入输出和技术路线都不同：

主线输入输出代表任务主流技术范式
理解（看懂）图 → 标签/坐标/文字分类、检测、分割、OCRCNN → ViT；判别式监督训练
生成（画出）条件（文本/图）→ 图文生图、图生图、概念定制扩散模型为主，GAN 为辅；自回归/流匹配并行发展
编辑（改图）图 + 意图 → 图局部重绘、扩图、超分、风格迁移在生成模型上加条件约束与掩码控制
三条线并非彼此独立：现代图像模型大多是「先用理解模型把图文对齐（如 CLIP），再让生成模型在对齐空间里受控生成」，编辑则是加掩码/条件后的生成。

理解线：从 CNN 到 ViT

CNN 时代
卷积提供局部性与平移不变性，靠堆叠扩大感受野；代表 ResNet、EfficientNet
ViT 时代
把图切成 patch 当 token 送进 Transformer，全局建模更强、可规模化
多模态对齐
CLIP 用图文对比学习把两种模态拉进同一向量空间

理解任务的监督形式决定了输出形态：整图一个标签是分类；框出物体是检测；逐像素归属是分割；读出文字是OCR。

生成线：为什么是扩散模型赢了 GAN

GAN
生成器 + 判别器对抗。
优点：单步出图、速度快
缺点：训练不稳定、模式坍缩、多样性差
扩散模型 （当前主流）
先加噪再学去噪。
优点：训练稳定、多样性好、质量高
缺点：需多步迭代、推理慢
生成质量、可控性、训练稳定性三项综合下来，扩散模型成为文生图的事实标准；GAN 退居到需要极致速度或特定域的场景。

编辑线：生成模型 + 约束

  • 局部重绘 Inpainting：给掩码，只重画掩码区域并保证边缘连贯
  • 扩图 Outpainting：向外延展画面，保持风格与透视一致
  • 超分辨率：补全高频细节，常配合感知损失与对抗损失
  • 风格迁移：分离内容与风格表征后重组
编辑的本质：在生成过程中施加额外条件（掩码、参考图、深度图、边缘图），从而「炸掉一部分再重新生成」，而不是像素级涂抹。

面试速记卡

  • 三条主线：理解（图→语义）、生成（条件→图）、编辑（图+意图→图）。
  • 理解：CNN → ViT；CLIP 做图文对齐，是多模态的基石。
  • 生成：扩散模型取代 GAN 成为主流，胜在训练稳定与多样性，代价是多步迭代慢。
  • 编辑：本质是「带约束的生成」，掩码/条件图是核心控制手段。
  • 趋势：统一到 Transformer 架构 + 多模态对齐表示，三条线正在融合。

一图看懂视觉模型版图

视觉任务看似繁多，但可以按两个维度归位：判别式（输入图输出结果：分类/检测/分割/OCR）和生成式（输入条件输出图：GAN/扩散/编辑）。两者共用一套主干网络（CNN / ViT / U-Net / DiT）。理解这张地图，选型时就不会迷路。

判别式学习 P(y|x)，回答「这是什么、在哪」
生成式学习 P(x) 或 P(x|c)，回答「画一个这样的」
主干网络提取特征/去噪的骨架，任务头挂在其上
基础模型大规模预训练后可迁移：CLIP / SAM / DINOv2
可控生成ControlNet / LoRA / IP-Adapter 加条件
多模态视觉 + 语言：VLM、VQA、Grounding
任务 × 方法 × 主干：三层结构构成全部视觉模型

各任务的典型模型与选型

任务代表模型核心思路选型建议

目标检测YOLO 系列 / Faster R-CNN / DETR回归框 + 分类实时用 YOLO；精度优先用 DETR 系；两阶段适合小目标

图像编辑InstructPix2Pix / Inpainting条件扩散局部重绘局部修改用 inpainting；指令式用 Instruct 类

经验法则：先确认任务是「理解」还是「生成」，再选主干，最后挑任务头。90% 的选型错误来自第一步就选错范式。

落地路径与工程要点

① 优先复用预训练

  • 从零训练视觉模型几乎总是不划算，先用 ImageNet / CLIP 预训练。
  • 数据少于 1 万张：冻结主干，只训分类头。
  • 数据 1-10 万：全量微调，学习率主干取头部 1/10。

② 迁移学习的三种强度

  • Linear Probe：只训线性层，最快最稳。
  • Fine-tune：全网络微调，效果最好但需数据量。
  • LoRA / Adapter：只训少量参数，生成模型首选。

③ 数据决定上限

  • 标注质量 > 数量：100 条干净数据胜过 1000 条噪声。
  • 增强要贴合真实分布：医学图别做颜色抖动。
  • 长尾类别：重采样或重加权，否则模型只认大类。

④ 部署考量

  • 导出 ONNX → TensorRT / OpenVINO / CoreML。
  • 量化：FP16 基本无损，INT8 需校准集。
  • 扩散模型推理慢：用 LCM / Turbo 蒸馏或步数裁剪。
  • 批处理与动态 shape 要提前规划，否则上线返工。

深入自检

CNN 和 ViT 到底选哪个？

数据规模是分水岭：小数据（<10万）CNN 的归纳偏置（局部性、平移等变）更省数据，通常更稳；大数据或已有强预训练时，ViT 的上限更高、也更易扩展到多模态。工程上也可选 ConvNeXt 这类「用 CNN 结构吸收 ViT 设计」的折中方案。

为什么现在扩散模型基本取代了 GAN？

核心是三点：训练稳定性（GAN 需要精细调平衡、易模式崩溃）、多样性（扩散覆盖更好）、可控性（CFG、ControlNet 生态成熟）。GAN 仍在需要极低延迟（单步前向）的场景有优势，如实时风格迁移、人脸编辑。

SAM 能直接用于我的分割任务吗？

SAM 是「提示式」基础模型，给点/框/文本能零样本抠出物体，非常适合标注辅助与通用抠图。但若你的任务是固定类别的语义分割（如把路面/建筑/植被分开），SAM 不知道类别名，仍需训练专用分割头。

基础模型（DINOv2 / CLIP）怎么用最划算？

当作通用特征提取器：冻结主干提取 embedding，下游只训轻量头，常常能在极少标注下达到不错效果；也可以用它做数据清洗（异常检测、去重、聚类），提升标注效率。

生成模型上线延迟太高怎么办？

按性价比顺序：减少采样步数（20→8）、用蒸馏/一致性模型（LCM、Turbo）、切 FP16/INT8、降分辨率后超分放大、结果缓存。通常前两项就能把延迟降到可接受区间。

如何评估一个视觉模型是否真能用？

不要只看公开集分数。要构造贴合业务的验证集（含真实光照、角度、遮挡、长尾），看分场景指标与最差 10% 的表现，并做小流量灰度观察真实数据漂移。
