关系与函数

关系是「元素之间有没有联系」，函数是「每个输入恰好对应一个输出」。它们把集合连成结构，是数据库、哈希、排序的数学基础。

二元关系及其表示

在集合 A 上的二元关系 R 是笛卡尔积 A×A 的一个子集。若 (a,b)∈R，记作 aRb。同一关系有三种等价表示：

枚举

直接列出有序对，如 R={(1,1),(1,2),(2,3)}

关系矩阵

m[i][j]=1 表示 (i,j)∈R，否则为 0

关系图

顶点是元素，有向边 i→j 表示 (i,j)∈R

关系的性质与合成

关系可以「叠加」：若 R 含 (a,b)、S 含 (b,c)，则合成 R∘S 含 (a,c)。性质是关系的「性格」：

性质定义（对全集每对元素成立）
自反每个 a 都满足 (a,a)∈R
对称若 (a,b)∈R 则 (b,a)∈R
传递若 (a,b)∈R 且 (b,c)∈R，则 (a,c)∈R
同时满足「自反 + 对称 + 传递」的关系叫等价关系，它能把集合切成互不重叠的「等价类」，构成一种划分——这正是哈希桶、数据库分组背后的思想。

偏序与哈斯图

若关系「自反 + 反对称 + 传递」，则是偏序（如 ≤、整除）。哈斯图（Hasse diagram）把偏序画成「省略自环和传递边」的层次图，越往上越大。

上图表示「整除」偏序：1 整除 2 和 3，2 与 3 都整除 6。哈斯图只画「直接覆盖」的边，省略了 1|6 这种可由传递推出的边。

互动：判断关系性质

// 传递性判定（伪代码）
for i,j,k in {1,2,3}:
    if R[i][j] and R[j][k] and not R[i][k]:
        return "不满足传递"

函数：单射、满射、双射

函数是「每个输入恰好一个输出」的特殊关系。设 f: A→B：

单射

不同输入映射到不同输出（不「撞车」）。

满射

B 中每个元素都被某个输入映射到。

双射

既单又满，可一一配对，存在反函数。

双射让我们比较集合大小（基数）：若 A、B 之间存在双射，则 |A|=|B|。偶数集与自然数集一样「大」，因为它们能用 n↔2n 一一对应——这就是基数比较的核心。
