Python 是动态强类型

整数 int

任意精度，没有溢出的烦恼

Python 3 只有一种整数 int，底层按需要自动扩成多「机器字」，所以不存在 int32/int64 溢出的问题，大数运算直接写就行。

import sys
print(sys.maxsize)        # 与平台相关的"小整数"上限参考
a = 2 ** 1000        # 301 位大整数，照算不误
print(a.bit_length())    # 1001

# 小整数有缓存（[-5, 256]），身份相同；大整数每次新建
x = 256; y = 256; print(x is y)   # True
m = 257; n = 257; print(m is n)   # False（取决于实现）
相比 Go 必须选 int32/int64、网络协议里要固定位宽，Python 的 int 省心但代价是：不能精确控制内存占用，超大整数运算会吃 CPU 和内存，也不适合需要定长二进制的场景（那种用 struct / array 模块）。
浮点 float / 复数 complex

IEEE754 的精度坑照旧存在

float 是双精度（64 位），和 Go 的 float64 同一套标准；complex 是复数。金钱、计数别用浮点。

print(0.1 + 0.2)        # 0.30000000000000004 —— 经典精度误差
from decimal import Decimal
print(Decimal('0.1') + Decimal('0.2'))  # 0.3 精确

z = 3 + 4j
print(z.real, z.imag, abs(z))   # 3.0 4.0 5.0
⚠️ 比较浮点请用误差范围：abs(a-b) < 1e-9，或直接用 math.isclose(a, b)。别写 if a == b 判浮点相等。
布尔与 None

bool 是 int 的子类，None 是单例

True/False 实际就是 1/0 的别名（True + 1 == 2），但别在算术里滥用；None 是表示"空/无"的唯一单例，用 is None 判断。

print(True == 1, True + 1)   # True 2
print(True is 1)          # False（类型不同，不要混用）

x = None
if x is None: print("空")   # 用 is，不用 ==
print(bool(0), bool([]), bool(""), bool(None))  # 全是 False
「 falsy 」集合：None、False、0、0.0、空容器 "" [] {} set()、空 range(0)。写 if x: 即可，不用 if x is not None and len(x)>0。
字符串 str

不可变的 Unicode 码点序列

Python 的 str 是 Unicode 码点（不是字节！），中文和英文一样是一个字符；不可变，任何"修改"都生成新字符串。

s = "Python语言"
print(len(s))           # 8（码点数，不是字节数）
print(s[0], s[6])      # P 语
# s[0] = 'p'          # 报错：str 不可变
ns = s.replace("Python", "Py")  # 返回新串

# 编码到字节：str → bytes
b = s.encode("utf-8")
print(b, len(b))       # b'Python\xe8\xaf\xad\xe8\xa8\x80' 14（字节）
和 Go 的关键区别：Go 的 string 底层是 UTF-8 字节，要按字符数得用 utf8.RuneCountInString；Python 的 str 直接就是码点序列，len() 即字符数。需要字节时显式 .encode()。
字节 bytes / bytearray

不可变字节序列 vs 可变字节数组

bytes 类似 Go 的 []byte（不可变，字面量前缀 b"..."）；bytearray 是可变版本，适合流式拼接二进制。

raw = b"\x00\x01hello"
print(raw[0], raw[1])     # 0 1（每个元素是整数 0-255）
ba = bytearray(b"hi")
ba.append(33)              # 可变
print(ba)              # bytearray(b'hi!')
⚠️ str 与 bytes 不能混用：b"a" + "b" 直接 TypeError。网络/文件 IO 拿到的是 bytes，要处理文本先 .decode()；反之 .encode()。
可变性一览

牢记哪些能改、哪些不能

可变性是决定「能否当字典键」「函数里会不会被改」的核心。不可变对象可哈希，能作 dict/set 的键；可变不行。

类型可变性可作 dict 键
int / float / complex / bool不可变✅
str / bytes / tuple / frozenset不可变✅
None单例✅
list / dict / set / bytearray可变❌
