第 13 章 · 回溯

选择、探索、撤销

回溯在决策树上枚举候选解；剪枝让“不可能成功”的分支尽早停止。

把状态画成选择序列

当前路径记录已做的选择，候选集合给出下一步可选项，终止条件判定何时形成完整解。求 [1, 2, 3] 的全排列时，根节点有 3 个选择，下一层有 2 个，最后一层有 1 个，共 3! = 6 个叶子。

search(path, used):
    if len(path) == n:
        record(copy(path))
        return
    for i in range(n):
        if used[i]: continue
        used[i] = true; path.append(a[i])
        search(path, used)
        path.pop(); used[i] = false

递归返回后必须恢复 path 与 used，才能让其他分支看到相同的起始状态。保存结果时要复制当前路径，否则后续撤销会改变已经记录的答案。

剪枝必须有正确性理由

给定非负数，寻找和为目标值的组合。如果当前和已经超过目标，而且后续只能加非负数，这个分支不可能重新降到目标值，可以剪枝；如果允许负数，则该理由失效。

去重与剪枝不是一回事：含重复值的排列需要根据相同值的使用状态避免生成等价路径；含重复值的组合常先排序，再在同一层跳过相同的起点。

枚举 n 个不同元素的全排列有 n! 个结果，光输出就要 Ω(n·n!) 时间；剪枝能减少不合格分支，但不能让必须输出的结果数量消失。路径与访问标记占 O(n) 额外空间，不计输出。
