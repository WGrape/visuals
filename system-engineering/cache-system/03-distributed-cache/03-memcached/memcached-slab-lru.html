Slab 分配器

Memcached 按 item 大小分级预分配内存页（slab class），每类用固定 size 的 chunk 存储，避免频繁 malloc 与内存碎片。

LRU 淘汰

每个 slab class 内部用 LRU 管理 item；内存满时淘汰该类中最久未用的 item。不同 size 的 item 互不挤占。

调优

合理设置 -f（增长因子）与 -n（最小 chunk），让 slab 分级更贴合真实 value 分布，降低浪费。

🎯 面试问答

Q：Slab 解决什么问题？
A：减少内存碎片，按 size 分级管理。
Q：增长因子 -f 作用？
A：控制 chunk size 分级跨度，贴合 value 分布。
Q：MC 的 LRU 是全局还是分级？
A：每 slab class 独立 LRU。
