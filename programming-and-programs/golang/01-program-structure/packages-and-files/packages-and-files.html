包是 Go 的封装与编译单元

Go 代码以「包」为单位组织，每个目录通常只放一个包。包把相关的类型、函数聚到一起，并通过名字大小写控制对外暴露。

package 声明

每个文件第一句都是 package

同一目录下的所有 .go 文件必须用相同的 package 名开头；可执行程序入口包名固定为 main。

// 在 model/ 目录下所有文件
package model

// 可执行程序
package main
导入：四种写法

import 的标准形式与变体

标准库、第三方包、相对（已弃用）以及「别名 / 点导入 / 匿名导入」三种特殊形式各有所用。

import (
    "fmt"                       // 标准写法
    "github.com/gin-gonic/gin" // 第三方
    json "encoding/json"        // 别名
    . "math"                    // 点导入：直接用 Sin 而非 math.Sin
    _ "image/png"               // 匿名导入：仅触发 init，不暴露标识符
)
⚠️ 匿名导入 _ 常用于注册驱动（如数据库/图片解码器），利用 init 副作用把实现挂进全局表。点导入会污染命名空间，生产代码应慎用。
初始化顺序

init 函数的执行时机

每个包可有多个 init()，在包变量初始化后、main 之前自动执行；导入链上被依赖的包先完成初始化。

package main

var A = setupA()       // 1. 包级变量初始化

func init() { fmt.Println("init 1") }  // 2. init 按出现顺序
func init() { fmt.Println("init 2") }

func main() { fmt.Println("main") }     // 3. 最后执行
依赖顺序保证：若 main 导入 p，则 p 的变量与 init 全部先于 main 的 init 和 main 执行。可用此机制做配置加载、连接池预热等。
可见性与标识符

再看一次大小写规则

跨包访问只认首字母大写；同一个包内（即使不同文件）所有标识符互通，不存在「文件私有」。

情况可见范围
大写开头包外可见（导出）
小写开头仅本包可见
同包不同文件小写也能互相访问
文件组织约定

目录即包，别过度嵌套

Go 反对深层目录嵌套。一个功能一个目录一个包，目录名用简洁小写、不用下划线或驼峰（如 user、usermodel 而非 user_model）。
