计算机知识可视化

按学科脉络组织的知识可视化：从人工智能、系统工程、数据库系统、编程与程序，到计算机科学与技术，建立完整的计算机知识体系。

人工智能

模型基础

从神经网络地基（前向反向传播、优化器、损失函数、正则化、架构演进）到 Embedding 与 Transformer，建立理解大语言模型所必需的基础结构认知。

视觉模型

从图像到视频，学习视觉内容的表示、理解、生成与编辑，以及模型评测、安全和实时应用。

大语言模型

从发展历史和生成原理出发，依次学习 Token、上下文、提示与推理、结构化输出、工具调用、多模态能力，以及评测选型与安全风险。

语音与音频模型

从语音合成的模型链路与 SSML 输入控制，到语音识别的声学编码、对齐和解码；实时语音交互等专题仍待扩充。

模型训练与部署

从数据工程、预训练、微调与对齐，到蒸馏、分布式并行训练、量化、部署与推理加速，串联模型从训练到上线的完整链路。

系统工程

缓存系统

缓存技术的原理与工程实践：从本地缓存到分布式缓存，学习过期、淘汰、一致性、异常、多级部署与容量运维。

业务系统

从业务接入与身份校验，到内容、营销、交易和物联网设备的端到端系统设计。这里关注应用接口及具体业务流程。

AI 工程系统

从模型 API 接入、RAG、Agent 与工具协议，到记忆、评测和应用限流，构建可落地的 AI 应用。

大数据系统

本学科按五个环节组织：① 数据采集 → ② 数据存储 → ③ 数据处理与计算 → ④ 数据治理 → ⑤ 数据分析与应用。也可按计算模式观察批处理、流处理、交互式查询与图计算。

架构设计

分布式系统

理解分布式系统的核心理论与工程实践

云架构系统

理解云服务的网络、安全与架构组件

云原生系统

围绕容器、编排、微服务、声明式 API 与自动化交付，理解云原生应用如何在动态基础设施上运行，并结合服务网格与可观测性治理。

整体架构系统

讨论跨业务场景的架构风格、应用边界与设计决策。缓存的具体机制见缓存系统，端到端场景见业务系统。

高性能、高并发、高可用

先用指标评估体系量化吞吐、延迟、并发与服务质量，再以高并发架构、高可用保障和 CPU/内存/IO 优化改善这些结果。

数据库系统

向量数据库

算法层（相似度、ANN 索引、量化压缩、召回评测）、产品实践（Milvus、Qdrant、Weaviate、pgvector）与工程层（容量成本、压测、迁移、排障）。

关系型数据库

从关系模型与数据建模出发，学习 MySQL、PostgreSQL 的架构、索引、查询、锁、事务与高可用，并认识 SQLite 的实现与实践。

SQL 语言核心

跨数据库通用的查询基本功：JOIN、窗口函数、分页、分组聚合，以及执行顺序与计划诊断。

NoSQL 数据库

键值、文档、搜索、列族与图：按数据模型和主要工作负载区分数据库与检索引擎。

TSDB 时序型数据库

面向监控与 IoT 等时序负载，理解追加写入、压缩、时间范围聚合、降采样和数据保留策略。

OLAP 分析型数据库

从维度建模、列式存储、数据裁剪与预聚合理解分析型数据库，并按查询模式、并发和数据规模判断性能取舍。

NewSQL 分布式关系型数据库

以 TiDB、OceanBase 和 CockroachDB 为例，理解分布式 SQL、事务、分片和扩缩容；兼容范围、隔离语义与运维代价需按产品判断。

编程与程序

设计模式

从设计原则入门，用可点击的角色流程、生活场景和最小伪代码学会 23 个经典模式。

构建程序

从字节码到编译执行过程，理解程序如何从源代码变为运行结果。

运行时机制

从内存模型与分配、垃圾回收到事件循环及性能局部性，按不同运行时机制组织课程。

Golang 语言

从语言基础、并发运行时到工程实践与 Go 生态，建立完整的 Go 知识体系。

Python 语言

从语法特性、运行时与内存，到并发、异步与工程部署——6 个章节、15 个专题覆盖 Python 学习主干。

计算机科学与技术

计算机基础

从计算机发展史了解技术演进，以计算理论认识计算的能力与边界，再用离散数学、逻辑、线性代数、概率统计和数论打牢基础。

计算机网络

从链路、网络、传输到应用协议，理解数据如何跨主机传输；再用端到端链路、性能、安全与排障把协议知识连接到真实系统。

计算机组成原理

从数字电路与指令集出发，理解处理器、存储层次、设备 IO 和程序执行如何共同构成一台计算机。

计算机操作系统

以资源抽象、隔离和调度为主线，系统学习程序如何成为进程，内存、设备和文件又如何被内核组织为可用服务。

数据结构与算法

从算法技巧与复杂度开始，依次学习数据结构、搜索排序与算法设计。每章都有基础知识页，并可继续进入专题课程。
