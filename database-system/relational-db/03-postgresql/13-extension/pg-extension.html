扩展机制与常用扩展

CREATE EXTENSION 的生态：PostGIS、pg_stat_statements、pg_trgm、FDW 等。

扩展原理常用扩展FDW 外部表注意事项

① 扩展原理

PG 的核心哲学是“内核精简、能力靠扩展”。CREATE EXTENSION 把一组函数/类型/索引访问方法/操作符装进数据库，无需改内核。这是 PG 生态强大的根源。

CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS pg_stat_statements;

② 常用扩展

扩展能力
PostGIS地理空间类型与函数（GIST 索引）
pg_stat_statements聚合 SQL 执行统计（慢查询排查神器）
pg_trgmtrigram 模糊搜索 + GIN/GiST 索引
uuid-ossp / pgcryptoUUID / 加解密
hstore / citext键值对 / 不区分大小写文本
pgvector向量类型与 ANN 索引（AI embedding 检索）

③ FDW 外部表

postgres_fdw 等外部数据包装器让 PG 直接 SELECT 另一个数据库（甚至 MySQL/Redis）的表，像本地表一样查询，适合轻量数据联邦。

CREATE EXTENSION postgres_fdw;
CREATE SERVER srv FOREIGN DATA WRAPPER postgres_fdw OPTIONS (host 'other', dbname 'x');
CREATE FOREIGN TABLE remote_orders (...) SERVER srv OPTIONS (table_name 'orders');

④ 注意事项

版本与迁移：扩展有各自的版本，主备须一致；大版本升级时部分扩展需同步升级（ALTER EXTENSION ... UPDATE）。
