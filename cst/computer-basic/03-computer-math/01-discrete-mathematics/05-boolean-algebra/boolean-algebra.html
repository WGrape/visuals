布尔代数：只有 0 和 1 的代数系统

布尔代数是数字电路、位运算与逻辑表达式的数学基础。掌握它的运算律，就能化简条件、优化电路、写出高效的位技巧。

核心速览

基本运算

AND ∧、OR ∨、NOT ¬、XOR ⊕（异或）

运算律

交换/结合/分配/吸收/德摩根/幂等

完备性

{NAND} 或 {NOR} 单独即可表达任意布尔函数

位技巧

n & (n−1) 消最低位 1；n & −n 取最低位 1

什么是布尔代数

布尔代数是定义在 B = {0, 1} 上的代数系统 (B, ∧, ∨, ¬)，满足一组公理。它同时是命题逻辑、集合运算与数字电路的抽象模型——三者完全同构。

布尔代数命题逻辑集合论数字电路程序
a ∧ bp 且 qA ∩ BAND 门（串联）a & b
a ∨ bp 或 qA ∪ BOR 门（并联）a | b
¬a非 pAᶜNOT 门（反相器）~a
a ⊕ b异或A △ B（对称差）XOR 门a ^ b
1永真 T全集 U高电平全 1 掩码

这个同构极其实用：化简 SQL 的 WHERE 条件、化简代码里的 if 嵌套、化简电路门级数，用的是同一套恒等式。

运算律：化简的工具箱

律表达式化简用途
幂等律a∧a = a，a∨a = a去掉重复条件
交换/结合律a∧b = b∧a；(a∧b)∧c = a∧(b∧c)重排以便合并
分配律a∧(b∨c) = (a∧b)∨(a∧c)展开或提取公因式
吸收律a∧(a∨b) = a；a∨(a∧b) = a消除冗余条件
德摩根律¬(a∧b) = ¬a∨¬b；¬(a∨b) = ¬a∧¬b否定下推，便于短路
同一律/零律a∧1 = a，a∨0 = a；a∧0 = 0，a∨1 = 1常量折叠
互补律a∧¬a = 0，a∨¬a = 1检测矛盾/永真
消去律a∨(¬a∧b) = a∨b条件化简（共识定理）
# 化简实例
# 原表达式：if (a and (a or b)):        →   直接用吸收律：if a:
# 原表达式：if (not (x and y)):         →   德摩根：if (not x or not y):
# 原表达式：if (flag or (not flag and v)): → 消去律：if (flag or v):

# 用 Python 验证恒等式（穷举全部 2ⁿ 种输入）
def check_identity(f, g, n):
    for mask in range(1 << n):
        vals = [(mask >> i) & 1 for i in range(n)]
        if f(*vals) != g(*vals): return False, vals
    return True, None

print(check_identity(lambda a,b: a and (a or b), lambda a,b: a, 2))          # 吸收律
print(check_identity(lambda a,b: not (a and b), lambda a,b: (not a) or (not b), 2))  # 德摩根

功能完备性与电路实现

一组连接词若能表达任意布尔函数，称为功能完备集。n 个变量共有 2^(2ⁿ) 个不同的布尔函数（真值表 2ⁿ 行，每行可真可假）。

集合完备？说明
{¬, ∧, ∨}✅标准集
{¬, ∧}、{¬, ∨}✅德摩根律可互换
{¬, →}✅a∧b = ¬(a→¬b)
{NAND}、{NOR}✅单个门即完备
{∧, ∨}、{¬}❌无法表达否定 / 无法组合
{⊕, ∧}❌无法表达 ¬（全 0 输入必输出 0）
# 用 NAND 表达其他运算（证明其完备性）
def NOT(a):    return NAND(a, a)
def AND(a, b): return NAND(NAND(a, b), NAND(a, b))
def OR(a, b):  return NAND(NAND(a, a), NAND(b, b))    # 德摩根
# 有了 NOT 与 AND，任何 DNF 都能构造 ⟹ NAND 完备

# 多路选择器 MUX 是 FPGA 的基本单元
def MUX(s, a, b):        # s=0 选 a，s=1 选 b
    return (a & ~s) | (b & s)      # 或写成 (s & b) | (~s & a)
为什么工程上偏爱 NAND？在 CMOS 工艺中，NAND 门比 AND 门晶体管更少、速度更快（AND 实际是 NAND + 反相器）。所以标准单元库、NAND Flash 存储阵列都基于 NAND 结构——理论完备性与工程经济性在此一致。

位运算：布尔代数的并行实现

一个 w 位的机器字可以看作 w 个布尔变量，一次位运算相当于同时对 w 组数据做同样的逻辑操作（SIMD 思想的极致）。这带来了极致的常数优化。

技巧表达式作用
判断奇偶n & 1取最低位
消去最低位的 1n & (n - 1)统计 1 的个数（Brian Kernighan）
取最低位的 1n & -nlowbit，用于树状数组
判断 2 的幂n > 0 and (n & (n-1)) == 0只有一个 1
交换两数（不用临时变量）a ^= b; b ^= a; a ^= b利用 a^a=0、a^0=a
取模（除数为 2ᵏ）n & (2ᵏ - 1)哈希表寻址常用
集合运算并 |、交 &、差 & ~、对称差 ^状态压缩的基石
异或找唯一全部异或成对出现的数抵消，剩下单独那个
def popcount(n):                 # Brian Kernighan：循环次数 = 1 的个数
    c = 0
    while n:
        n &= n - 1               # 每次消掉最低位的 1
        c += 1
    return c

print(popcount(0b101101))        # 4

def lowbit(n): return n & -n     # 取最低位的 1（补码性质）
print(lowbit(0b101100))          # 4

# 异或的经典用法：找出只出现一次的数（其余都出现两次）
def single_number(nums):
    r = 0
    for x in nums: r ^= x        # a^a = 0，a^0 = a
    return r

print(single_number([4, 1, 2, 1, 2]))   # 4
为什么这些技巧有效？因为它们直接对应布尔恒等式：a^a = 0（自反）、a^0 = a（恒等）、a&(a−1) 消最低位 1（借位性质）、a&−a 取最低位 1（补码的「取反加一」使最低位 1 以下全变 0，与自身相与只剩那一位）。理解代数原理比死记更重要。

卡诺图与逻辑化简

卡诺图是两变量到四变量布尔函数手工化简的图形工具：把真值表按格雷码顺序排成网格，相邻的 1 圈成大小为 2 的幂的矩形，每个圈对应一个可合并的乘积项。

# 两变量卡诺图（f(a,b)）
#        b=0   b=1
#  a=0 |  0  |  1  |
#  a=1 |  1  |  1  |
# 圈住右侧一列（b=1）与下面一行（a=1）
# ⟹ f = a ∨ b

# 化简的本质就是反复应用：
#   吸收律：a∨(a∧b) = a
#   合并律：(a∧b)∨(a∧¬b) = a∧(b∨¬b) = a
# 即「只有一个变量不同」的两项可以合并，消去那个变量

# 多于 4 个变量时用 Quine-McCluskey 算法或 ESPRESSO（EDA 工具）
现代 EDA 工具用 ESPRESSO 启发式算法做两级逻辑最小化，而多级优化则结合时序分析与工艺库映射。手工卡诺图的意义在于建立「相邻可合并」的直觉。

常见陷阱

  • 位运算优先级低于比较运算符：n & 1 == 0 会被解析成 n & (1 == 0)！必须写 (n & 1) == 0。
  • 右移的符号位：算术右移（>>）对负数补符号位，逻辑右移（Java 的 >>>、Python 需手动掩码）补 0。
  • 不要依赖短路做副作用：a & f() 中 & 不短路，a and f() 才短路。
  • 异或不等于「或」：1⊕1 = 0 而 1∨1 = 1。XOR 是「不带进位加法」，OR 是「至少一个为真」。
  • 整数溢出与位宽：Python 整数无限宽，~n 会得到负数；要限制位宽需显式掩码 ~n & 0xFF。

🎯 常见问法与答题要点

Q：布尔代数和命题逻辑、集合运算是什么关系？

A：三者完全同构：∧ ↔ 且 ↔ 交集 ↔ AND 门 ↔ &；∨ ↔ 或 ↔ 并集 ↔ OR 门 ↔ |；¬ ↔ 非 ↔ 补集 ↔ NOT 门 ↔ ~；⊕ ↔ 异或 ↔ 对称差 ↔ XOR 门 ↔ ^。它们共享同一组运算律（交换、结合、分配、吸收、德摩根、幂等）。实用价值：在任一领域学到的化简技巧可以直接迁移到其他领域——化简 SQL 条件、化简代码 if 嵌套、化简电路门级数，用的是同一套恒等式。

Q：为什么 {NAND} 单独就功能完备？{∧, ∨} 为什么不完备？

A：NAND 完备：¬a = a NAND a；(a∧b) = (a NAND b) NAND (a NAND b)；有了 ¬ 与 ∧ 就能用德摩根律得到 ∨，进而构造任意 DNF，所以任意布尔函数都能只用 NAND 实现。{∧, ∨} 不完备：任何只含 ∧、∨ 的公式在全 0 输入下必输出 0（因为 0∧0 = 0∨0 = 0），无法表达 ¬（0 → 1）。同理 {⊕, ∧} 也不完备。工程意义：NAND 在 CMOS 中晶体管更少、更快，所以标准单元库与 NAND Flash 都基于它。

Q：德摩根律在位运算和代码里怎么用？

A：¬(a∧b) = ¬a∨¬b，¬(a∨b) = ¬a∧¬b——否定下推时运算翻转、各项取反。用法：① 代码可读性与短路：if (!(a && b)) → if (!a || !b)；② SQL 改写以命中索引：WHERE NOT (city='BJ' AND age<18) → OR 形式；③ 位运算：~(a & b) == (~a | ~b)，用于构造掩码；④ 集合论中同样成立：(A∩B)ᶜ = Aᶜ ∪ Bᶜ。它是「否定」操作的通用规律，跨领域一致。

Q：n & (n−1) 为什么能消去最低位的 1？

A：从二进制借位的角度看：n−1 会把 n 最低位的那个 1 变成 0，并把它右边所有的 0 变成 1，而更高位保持不变。于是 n & (n−1) 中：更高位相同（保留）、最低位那个 1 与 0 相与得 0（消去）、右侧各位与原 0 相与得 0（本来就是 0）。结果就是恰好消掉最低位的 1。应用：Brian Kernighan 算法数 1 的个数（循环次数 = 1 的个数，优于逐位扫描）、判断 2 的幂（n > 0 and n & (n−1) == 0）。

Q：n & −n（lowbit）为什么能取出最低位的 1？

A：依赖补码性质：−n = ~n + 1。设 n 最低位的 1 在第 k 位，则 n 的第 0..k−1 位全为 0；~n 使这些位全变 1、第 k 位变 0；加 1 后进位一路进到第 k 位，使第 k 位重新变 1、而 0..k−1 位回到 0。于是 −n 与 n 在第 k 位同为 1、更低位同为 0、更高位恰好相反，相与后只剩下第 k 位的那个 1。这正是树状数组（Fenwick Tree）中 i += lowbit(i)、i -= lowbit(i) 能正确跳转的原理。

Q：异或有哪些重要性质？为什么能用来找「只出现一次的数」？

A：核心性质：a⊕a = 0（自反）、a⊕0 = a（恒等）、交换律与结合律、a⊕b⊕b = a（自反性推论）。因此把数组中所有数异或，出现两次的数会成对抵消为 0，最后只剩下那个出现一次的数，且只需 O(n) 时间、O(1) 空间。其他应用：① 无临时变量交换两个数；② 判断两数符号是否相同（(a^b) >= 0）；③ 校验与错误检测（奇偶校验、RAID）；④ 密码学中一次一密的密钥流合成。

Q：卡诺图化简的原理是什么？变量多了怎么办？

A：原理是反复应用合并律与吸收律：(a∧b)∨(a∧¬b) = a∧(b∨¬b) = a——只有一个变量不同的两项可以合并，消去那个变量。卡诺图把真值表按格雷码顺序排列，使「只差一个变量」的格子在几何上相邻，于是圈出大小为 2 的幂的矩形就对应一次合并。变量超过 4~6 个时手工不再可行，改用 Quine-McCluskey 精确算法或工业界常用的 ESPRESSO 启发式两级最小化，并结合时序分析与工艺库映射做多级优化。

Q：位运算有哪些容易踩的坑？

A：① 优先级陷阱：n & 1 == 0 会被解析成 n & (1 == 0)，必须写 (n & 1) == 0——这是最高频的错误；② 右移符号位：算术右移对负数补符号位，需要逻辑右移时要先掩码或换用 >>>（Java）；③ 短路差异：&/| 是位运算不短路，and/or 才短路，依赖副作用时必须分清；④ 位宽：Python 整数无限宽，~n 得负数，要限制位宽需 ~n & 0xFF；⑤ 可读性：位技巧常数极小但可读性差，生产代码应加注释或优先用清晰的写法。
