特征值与特征向量：变换中“不动的方向”

大多数向量被矩阵改变方向，但总有若干特殊方向只被拉伸、不被扭转——这些方向就是特征向量，拉伸倍数就是特征值。

核心速览

定义

Av = λv：v 经 A 变换后方向不变，只被拉伸 λ 倍

特征多项式

det(A − λI) = 0，其根就是特征值

对角化

A = PΛP⁻¹，把变换拆成「换基—独立缩放—换回来」

谱定理

对称矩阵必可正交对角化，特征值全为实数

直觉：在旋转与拉伸中找到「不被扭转」的方向

想象把一个圆沿某个方向拉伸成椭圆。圆上绝大多数点的方向都变了，但拉伸轴与垂直于它的那条轴上的向量方向保持不变，只是长度乘以了不同的倍数——这两条轴就是特征向量，倍数就是特征值。

一句话：特征向量是变换中「方向不被改变」的那些轴，特征值就是沿该轴的伸缩倍率。λ > 1 拉长、0 < λ < 1 压缩、λ < 0 反向、λ = 0 直接被压没（该方向落在零空间里）。

怎么求：从特征方程到手算流程

由 Av = λv 且 v ≠ 0 可得 (A − λI)v = 0 有非零解，而这要求 A − λI 奇异，于是：

det(A − λI) = 0　← 特征方程，解出 λ；再代回 (A − λI)v = 0 解出 v
# 例：A = [[2, 1], [1, 2]]
# det(A − λI) = (2−λ)² − 1 = λ² − 4λ + 3 = (λ−1)(λ−3)
# → λ₁ = 3, λ₂ = 1
# λ₁ = 3: (A − 3I)v = [[−1,1],[1,−1]]v = 0 → v₁ = (1, 1)
# λ₂ = 1: (A − 1I)v = [[1,1],[1,1]]v = 0  → v₂ = (1, −1)

import numpy as np
A = np.array([[2., 1.], [1., 2.]])
w, V = np.linalg.eig(A)
print(w)                       # [3. 1.]
print(V)                       # 列向量即对应的特征向量
print(A @ V[:, 0], w[0] * V[:, 0])   # 两者相等，验证 Av = λv
print(np.trace(A), np.linalg.det(A)) # 5 = 3+1（迹），3 = 3×1（行列式）

两条快速校验：Σλᵢ = trace(A)、Πλᵢ = det(A)。手算完用这两个等式检查，能立刻发现错误。

对角化：为什么要费劲找特征向量

若 A 有 n 个线性无关的特征向量，把它们排成 P，对应特征值排成对角阵 Λ，则：

A = P Λ P⁻¹　→　Aᵏ = P Λᵏ P⁻¹

这个式子的威力在于：求 A 的 k 次幂（或矩阵指数、多项式）从 k 次矩阵乘法变成了一次对角阵的 k 次幂——对角阵求幂只是把每个对角元各自取 k 次方。

换句话说：换到「特征基」下看，这个变换只不过是在每个坐标轴方向各自独立地缩放而已——所有耦合都消失了。这正是解耦线性微分方程组、分析动态系统稳定性的核心技巧。

不是所有矩阵都能对角化（需要 n 个线性无关特征向量，重度亏缺的矩阵做不到，此时退而求其次用 Jordan 标准形 或 SVD）。但对称矩阵一定可以，而且能用正交矩阵对角化（谱定理），这让协方差矩阵、图拉普拉斯矩阵的分析变得非常干净。

幂迭代：工程上如何求「最大的那个」特征值

很多场景（PageRank、PCA 第一主成分）其实只需要最大的特征值及其特征向量。此时不用算全部谱，用幂迭代即可，每轮只是一次矩阵乘向量：

def power_iteration(A, k=100):
    """求按模最大的特征值（主特征值）与对应特征向量"""
    import random
    v = [random.random() for _ in A]          # 随机初始化
    for _ in range(k):
        w = [sum(A[i][j] * v[j] for j in range(len(v))) for i in range(len(A))]
        norm = sum(x * x for x in w) ** 0.5   # 归一化，防止溢出
        v = [x / norm for x in w]
    Av = [sum(A[i][j] * v[j] for j in range(len(v))) for i in range(len(A))]
    lam = sum(v[i] * Av[i] for i in range(len(v)))   # Rayleigh 商
    return lam, v

原理：反复乘 A 会把 v 中沿主特征方向的分量放大 λ₁ᵏ 倍，而其他方向只放大 |λ₂|ᵏ 倍，比值 (|λ₂|/|λ₁|)ᵏ → 0，于是 v 收敛到主特征向量。收敛速度取决于 λ₁ 与 λ₂ 的比值，越接近越慢。

经典应用场景

场景矩阵是谁特征值的含义
PageRank网页链接转移矩阵主特征向量 = 稳态排名；λ=1 是最大特征值
PCA 降维协方差矩阵（对称）特征值 = 该方向的方差；取最大的 k 个方向
谱聚类图拉普拉斯矩阵最小的几个特征值对应的向量给出聚类结构
动态系统稳定性状态转移矩阵所有 |λ| < 1 → 收敛；有 |λ| > 1 → 发散
马尔可夫链转移概率矩阵λ=1 对应的稳态分布
振动/结构分析刚度矩阵特征值 = 固有频率的平方

SVD 与特征值分解的关系：A 的奇异值是 AᵀA（或 AAᵀ）特征值的平方根。SVD 对任意矩阵都成立，比特征分解更通用，所以图像压缩、低秩近似、伪逆都更依赖 SVD。

常见误区与检查清单

  • 特征值可以为 0、负数或复数：λ=0 说明该方向被压没（矩阵奇异）；复特征值成对出现，对应「旋转 + 缩放」的复合动作。
  • 不同特征值的特征向量必线性无关，但同一特征值（重根）可能只给出不到 k 个无关向量——这就是无法对角化的根源。
  • 特征向量不唯一：任何非零倍数（乃至整个特征子空间里的向量）都可以，所以库返回的结果可能与手算差一个符号或比例。
  • 不要用手算特征多项式去求大规模矩阵：数值上极不稳定（多项式求根对系数误差极敏感），实际用的是 QR 算法、Lanczos、Arnoldi 等迭代方法。

🎯 常见问法与答题要点

Q：特征值与特征向量的直观含义是什么？

A：在变换 A 的作用下，大多数向量会改变方向，但某些特殊方向只被拉伸（或缩短、反向）而方向不变——这些方向就是特征向量 v，拉伸倍数就是特征值 λ，写成 Av = λv。几何上它们就是变换「主轴」：圆被变成椭圆时，椭圆的长轴和短轴就是两个特征方向。

Q：为什么 det(A − λI) = 0 能求出特征值？

A：由 Av = λv 移项得 (A − λI)v = 0。因为要求 v ≠ 0 的非零解，齐次线性方程组有非零解的条件是系数矩阵奇异，即 det(A − λI) = 0。这个关于 λ 的多项式叫特征多项式，它的根就是全部特征值。「非零解存在」⇔「矩阵奇异」⇔「行列式为 0」是这一推演的关键。

Q：对角化有什么用？

A：若 A = PΛP⁻¹，则 Aᵏ = PΛᵏP⁻¹，而 Λᵏ 只是把对角元各自取 k 次方。于是：① 快速算矩阵高次幂与矩阵指数（解线性微分方程组）；② 解耦——在特征基下各方向独立演化，动态系统稳定性只看 |λ| 是否小于 1；③ 数据压缩与主成分分析。本质是把耦合的系统拆成一堆独立的一维问题。

Q：所有矩阵都能对角化吗？

A：不能。需要 n 个线性无关的特征向量；当特征值重数与无关特征向量个数不匹配（几何重数 < 代数重数）时就会失败，典型如剪切矩阵 [[1,1],[0,1]]（λ=1 二重但只有一个特征方向）。此时可用 Jordan 标准形描述，或者改用 SVD——SVD 对任意矩阵都成立，是最通用的「对角化替代品」。

Q：对称矩阵的特征值有什么特殊性质？

A：谱定理给出：实对称矩阵的特征值全为实数，且存在一组正交的特征向量基，可写成 A = QΛQᵀ（Q 正交）。好处是：① 数值上极稳定（正交变换不放大误差）；② 特征值可直接解释为「各方向的方差/能量」；③ 保证 PCA、谱聚类等算法的解具有良好的几何意义。协方差矩阵天然对称，这是 PCA 成立的基础。

Q：幂迭代为什么能求出主特征值？收敛速度由什么决定？

A：把初始向量按特征基展开 v = Σcᵢvᵢ，乘 k 次 A 后为 Σcᵢλᵢᵏvᵢ，主特征值 λ₁ 的项增长最快并逐渐支配其他项，归一化后即收敛到 v₁。收敛速度取决于 |λ₂/λ₁|ᵏ——次大与最大特征值的模之比越接近 1，收敛越慢（这也是 PageRank 需要阻尼因子、以及要用 Lanczos/Arnoldi 加速的原因）。

Q：特征值和行列式、迹有什么关系？

A：det A = Πλᵢ（所有特征值之积），trace(A) = Σλᵢ（所有特征值之和）。这两条是相似变换下的不变量。直接推论：只要有一个特征值为 0，行列式就是 0，矩阵奇异；反之 det ≠ 0 则所有特征值非零、矩阵可逆。手算特征值后用这两条等式校验，能快速发现错误。

手算一遍：2×2 矩阵的完整过程

例题

A = [[4, 1],
     [2, 3]]

1) 特征多项式
   det(A - λI) = (4-λ)(3-λ) - 2·1
               = λ^2 - 7λ + 10
               = (λ - 5)(λ - 2)
   => λ1 = 5, λ2 = 2

2) 求 λ1 = 5 的特征向量
   (A - 5I)x = [[-1, 1], [2, -2]] x = 0
   => -x1 + x2 = 0  => x1 = x2
   => v1 = (1, 1)^T

3) 求 λ2 = 2 的特征向量
   (A - 2I)x = [[2, 1], [2, 1]] x = 0
   => 2x1 + x2 = 0
   => v2 = (1, -2)^T

4) 校验（一定要做）
   trace(A) = 4 + 3 = 7   = λ1 + λ2 = 5 + 2   ✓
   det(A)   = 12 - 2 = 10 = λ1 · λ2 = 5 · 2   ✓
性质结论用途
迹与行列式tr(A) = Σλ，det(A) = Πλ手算校验、快速判定
可对角化条件存在 n 个线性无关的特征向量；有 n 个互异特征值就一定可对角化判断能否写成 A = PΛP⁻¹
对称矩阵特征值全为实数，不同特征值的特征向量正交（谱定理）PCA、谱聚类的理论保证
幂迭代收敛速度取决于 |λ₂/λ₁|，越接近 1 越慢判断迭代要跑多少轮
相似不变量相似变换不改变特征值换基不改谱

特征值为 0 意味着什么：矩阵奇异（不可逆），存在非零 x 使 Ax = 0，即 A 把某个方向「压扁」了。这也是判断不可逆最快的办法之一。

数值计算：代码与踩坑

NumPy / SciPy 实战

import numpy as np

A = np.array([[4., 1.],
              [2., 3.]])

w, V = np.linalg.eig(A)        # 一般矩阵：w 特征值，V 的列是对应特征向量
print(w)                       # 顺序不保证，且可能有复数残留

# 对称 /  Hermitian 矩阵一定要用 eigh：更快、更稳、特征向量保证正交
S = (A + A.T) / 2
w2, V2 = np.linalg.eigh(S)     # 返回值已升序排列
print(w2)                      # 升序！不是降序

# 只想要最大的几个（大规模稀疏矩阵）
from scipy.sparse.linalg import eigs
# w3, V3 = eigs(sparse_A, k=5, which='LM')   # LM = largest magnitude

# --- 幂迭代（自己实现，理解收敛）---
def power_iter(A, iters=100, tol=1e-10):
    n = A.shape[0]
    v = np.ones(n) / np.sqrt(n)
    for i in range(iters):
        u = A @ v
        u = u / np.linalg.norm(u)
        if np.linalg.norm(u - v) < tol:
            break
        v = u
    lam = (v @ A @ v) / (v @ v)      # Rayleigh 商
    return lam, v, i

print(power_iter(A))
  • eig 的特征值顺序不保证，别直接取 w[0] 当最大值，要 np.argsort。
  • 一般矩阵即使数学上特征值是实数，数值上也可能返回带 1e-16j 的复数，取实部前先确认量级。
  • 对称矩阵务必用 eigh：它走的是专门算法，速度更快且保证正交特征向量。
  • 病态：|λmax/λmin| 很大时（条件数大），特征值对微小扰动极敏感。
  • 大规模稀疏矩阵别求全谱，用 eigs/svds 只要前 k 个。

Python 里 @ 是矩阵乘法，* 是逐元素乘法——这两个搞混是特征值计算最常见的低级错误。

矩阵不可对角化怎么办？

退化成 Jordan 标准形。判定：某个特征值的代数重数 > 几何重数。典型例子是剪切矩阵 [[1,1],[0,1]]：λ=1 二重但只有一个特征向量。

幂迭代什么时候会失败？

三种：主特征值不唯一（|λ₁|=|λ₂|）、初始向量与 λ₁ 的特征向量正交（概率为零但数值上可能接近）、|λ₂/λ₁| 接近 1 导致收敛极慢。

为什么对称矩阵这么重要？

实特征值 + 正交特征向量 + 可正交对角化，意味着没有 Jordan 块的麻烦，数值算法稳定，且 A = QΛQᵀ 里 Q⁻¹ = Qᵀ，求逆几乎免费。
