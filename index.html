计算机知识可视化

按学科脉络组织的交互式知识地图：从人工智能、系统工程，到数据库系统、编程语言与计算机科学基础，建立完整的计算机知识体系。

人工智能

模型基础

机器学习与深度学习的地基：损失函数、梯度下降与反向传播、过拟合与正则化、从 CNN/RNN 到注意力结构的演进；在学大模型之前，先把这些概念和数学直觉打牢。

模型生命周期

预训练、监督微调（SFT）、RLHF/DPO 对齐、LoRA 等高效微调，到量化压缩与推理部署的完整链路；理解每个阶段的数据与算力投入、能力变化，以及什么时候该微调、什么时候该用 RAG。

大语言模型

Prompt 与上下文工程、Token 与分词、注意力机制与 KV Cache、函数调用与工具使用、幻觉的成因与抑制；系统理解大模型的工作原理，以及它在工程中到底能做与不能做哪些事。

AI 工程

RAG 检索增强、Agent 与工具编排、MCP 协议、Skills 能力封装、长期记忆、评测与安全红队、推理服务与限流治理；并覆盖 AI 辅助编程实践——Harness 上下文工程、Claude Code 与 OpenClaw 的架构与记忆机制。重点是把大模型从演示变成可靠的生产系统：可观测、可评测、可回滚、可控制成本。

语音与音频智能

从音频信号与特征（MFCC）、语音识别 ASR、语音合成 TTS 到端到端实时语音对话；覆盖流式处理、延迟优化、打断与轮次控制，构建一条完整的语音 AI 技术链路。

系统工程

软件工程

从需求分析、领域建模、架构设计与接口约定，到代码规范、Code Review、单元与集成测试、CI/CD 与灰度发布；理解如何让一个系统在多人协作下长期可维护、可演进。

分布式系统

CAP 与 BASE、一致性模型与 Raft/Paxos 共识、分布式事务（2PC / TCC / Saga）、幂等与去重、服务发现与负载均衡、熔断降级；理解跨节点系统在部分失败下如何继续正确工作。

云原生与云架构

容器与镜像分层、Kubernetes 调度与自愈、Service Mesh 与服务治理、可观测性三件套（日志 / 指标 / 链路）、基础设施即代码与 GitOps；理解云时代应用如何构建、发布与弹性伸缩。

高性能、并发与高可用

从线程模型、协程与 CSP，到限流算法、熔断降级、隔离舱与兜底预案；结合缓存、异步化、连接池与压测数据，讲清如何构建高吞吐、低延迟，且在流量突增下不会雪崩的服务。

数据库系统

关系型数据库

以 MySQL / InnoDB 为主线：B+ 树索引与执行计划、事务隔离级别与 MVCC、行锁间隙锁与死锁排查、主从复制与读写分离；并横向对比 PostgreSQL、SQLite 等方案在功能与适用场景上的差异。

缓存与键值存储

Redis 的核心数据结构与底层编码、单线程模型与 IO 多路复用、RDB/AOF 持久化、主从与哨兵、Cluster 分片；同时讲清缓存穿透、击穿、雪崩与缓存一致性（延迟双删、订阅同步）的工程解法。

搜索与检索

倒排索引、分词与词权重、TF-IDF 与 BM25 相关性打分、索引段合并与近实时刷新；理解 Elasticsearch 如何支撑毫秒级全文检索，以及向量检索与传统检索如何组合成混合检索。

数据扩展

从读写分离、垂直拆分到分库分表的完整扩展路径：分片键选择与路由、全局唯一 ID、跨库 JOIN 与分布式事务、在线数据迁移与双写校验；理解每个阶段的收益、代价与回滚方案。

大数据系统

按数据采集、数据存储、数据处理与计算、数据治理、数据分析与应用五层划分的知识地图；覆盖 Kafka、HDFS、Hive、Spark、Flink 等核心组件的定位、协作方式与选型依据。

编程与程序

编译器与解释器

从类型体系讲起——静态类型与动态类型在检查时机、运行方式与工程取舍上的差异；再深入编译型、解释型与 JIT 三条执行路径：源码到 AST、字节码再到机器码，理解 V8 的隐藏类与即时优化、CPython 的解释循环与 GIL，以及启动速度与运行性能的权衡。

事件循环

从浏览器到 Node.js、Python asyncio 再到 Redis，讲清单线程如何靠事件驱动、任务队列与 IO 多路复用撑起高并发；覆盖宏任务与微任务、回调与协程的调度差异，以及阻塞操作为何会拖垮整个循环。

垃圾回收

引用计数、标记清除、三色标记、分代收集到并发与增量回收的完整演进；对比 Go、Java、Python 的 GC 实现与停顿来源，理解什么样的代码会触发频繁 GC，以及如何用逃逸分析与对象复用降低压力。

Go 语言

从语法基础、切片与 map 底层、接口与错误处理规范，到 goroutine 调度器 GMP 模型、channel 与 CSP 并发范式、逃逸分析与内存布局，再到 go-zero 等框架的 HTTP/RPC/中间件实践速查手册。

内存管理

栈与堆的分配策略、逃逸分析、对象头与内存对齐、内存池与对象复用；覆盖内存泄漏的定位思路、堆快照与 pprof 分析、OOM 与 GC 压力的排查路径，从运行时视角看一块内存的完整生命周期。

编程原理

局部性原理、缓存友好的数据布局、分支预测、伪共享与内存对齐、无锁与内存屏障；解释为什么同样的算法换个写法性能会差好几倍，并给出可落地的优化顺序：先量化、再定位热点、最后才动手。

Python

从语法基础、模块与包机制、装饰器与生成器，到引用计数与 GC、GIL 与多进程、协程与事件循环、FastAPI 工程化部署；一条可用于日常开发与面试复习的完整 Python 进阶路径。

计算机科学基础

数据结构与算法

线性表、栈与队列、树与堆、图、哈希表等核心结构的原理与实现；配合二分、双指针、滑动窗口、前缀和、位运算、动态规划、贪心与回溯等经典技巧，用可视化动画看清每一步操作、边界条件与时间空间复杂度的取舍。

编译原理

从词法分析、语法分析、语义分析到中间表示与代码生成，讲清编译器每个阶段的输入输出；结合语法树、符号表、类型检查与常见优化手段，理解源码是怎样一步步变成可执行程序的。

计算机组成原理

从晶体管、门电路、指令集，到流水线、乱序执行、分支预测与缓存层次，自底向上认识 CPU 如何取指、译码、执行一条指令；并覆盖存储金字塔、总线与 IO 设备，理解硬件为软件划定的性能边界。

计算机网络

自底向上拆解物理层、链路层、网络层、传输层到应用层：以太网与 ARP、IP 与路由转发、TCP 三次握手/拥塞控制/重传、DNS 与 HTTPS，配合抓包视角理解一次网页请求到底走了哪些路。

操作系统

进程与线程、上下文切换与调度算法、虚拟内存与页表、文件系统与设备 IO、中断与系统调用；理解操作系统如何把裸硬件抽象成统一接口，并为上层应用提供并发、隔离与资源复用。

计算机其他

尚未独立成学科的杂项主题归拢地：密码学与 Base64 编码实战、拓扑学的计算机科学视角，以及计算机领域 51 条名人名言——附中英原文、出处考证与流传最广的误传辟谣。
