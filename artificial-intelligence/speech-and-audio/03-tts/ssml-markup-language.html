SSML 标记语言：给 TTS 下"发音指令"

SSML（Speech Synthesis Markup Language，语音合成标记语言）是 W3C 语音接口框架的一部分。它让你不再只能把"纯文本"丢给语音合成引擎，而是用一套 XML 标签，精确控制读什么音、怎么停顿、按什么语义读、叠什么音效。本文基于火山引擎豆包语音的 Universal SSML 实现，把支持的标签、属性、示例和坑一次讲清楚。

SSML TTS 控制 phoneme say-as break 豆包语音

1. 一句话说清 SSML

SSML 是一份"给语音合成引擎看的排版说明书"。普通文本合成只能告诉 TTS"读这些字"；SSML 还能告诉它"这里用拼音读、那里停顿 2 秒、这个数字按金额读、整段加机器人音效"。

它从哪来 / 是什么

  • 标准归属：SSML 是 W3C 语音接口框架（Voice Browser）的一部分，本意是让不同厂商的 TTS 有一套通用的"标注方言"。
  • 在豆包语音里的实现叫 Universal SSML：它是 Flute 统一 TTS 前端（Universal FrontEnd，简称 UFE）采用的、与具体语种解耦的 SSML 框架——同一套标签能力能方便地复用到不同语种上。
  • 本质：一段合法的 XML，根元素必须是 <speak>；引擎先解析标签、再合成语音。
为什么会"与语种解耦"？前端（TextNorm / 音素预测）按语种走不同逻辑，但 SSML 标签这层抽象是统一的。所以你用 <say-as interpret-as="cardinal"> 这类标签时，不必关心底层是中前端还是英前端——这层标签就是"跨语种的统一控制面"。

2. 为什么需要 SSML

没有 SSML 时，TTS 只能按"默认规则"读文本，遇到下面几类情况就会读错或读得难听：

🔉

多音字读错

「茜茜公主」的"茜"应读 qiàn 还是 xī？纯文本合成靠猜测，容易翻车。

⏸️

停顿不对

长句一口气读完，没有呼吸感；或该停顿的地方没停，语义被切断。

🔢

同串不同读

"12:30" 可能是"十二点半"也可能是"十二比三十（比分）"，纯文本无法区分。

🎭

没有情绪/音效

想要机器人腔、心跳背景音、暴风雨氛围？纯文本无能为力。

图 1 · 同样一句话：纯文本"猜着读"，SSML"按指令读"

一句话总结：SSML 把"读得对不对、读得好不好听"的控制权，从 TTS 引擎的默认猜测，交还到你手里。

3. 使用前的必读约束

豆包语音的 SSML 有若干硬约束，踩中任何一个都会报错或产生 badcase。调用前先把这几条刻进脑子：

① 传参必须选 text_type=ssml
接口请求里要显式声明 text_type=ssml，否则引擎不会按 SSML 解析。
② 所有文本必须包在 <speak> 内
没有 <speak> 根元素，输入文本不会被当作 SSML。
③ 合成字符 ≤ 150（含标签）
包含标签本体在内不要超过 150 字符，否则出现 badcase 概率大增。
④ 双向流式 API 不支持 SSML
流式双向场景目前用不了 SSML，需要用非流式/普通合成接口。

还有几个"不支持"要记牢

限制项说明
语种当前仅支持中文普通话音色的 SSML 调用；方言及小语种后续支持。
标签可用性不同语种模型可使用的标签不同，必须严格按官方支持表请求，否则系统报错。
2.0 音色"豆包语音合成模型 2.0"中 _saturn_bigtts 结尾的音色（如 zh_male_dayi_saturn_bigtts）不支持 SSML；<phoneme> / <say-as interpret-as="name"> 也不适用于 saturn_ 前缀音色。
soundEvent<soundEvent> 不适用于 2.0 音色、也不适用于"豆包声音复刻模型 2.0（icl 2.0）"音色。
中英混音色提示：用中英混音色时，较短的英文句子可能被语种识别为中文，导致部分标签在中英文场景下表现不同（例如中文场景下 Verbatim 内的文本若是有效单词，不会按字母读）。

4. SSML 文档结构

一个 SSML 文档就是一棵以 <speak> 为根的 XML 树。根元素里可以放豆包特有的全局属性（背景音乐 / 音量 / 音效），里面再嵌套各个控制标签。

图 2 · SSML 文档结构：根 + 全局属性 + 五个控制标签（可混排纯文本）
标签核心属性一句话作用
<speak>bgm / backgroundMusicVolume / effect必选根元素 + 全局音效/背景乐
<phoneme>alphabet / ph手指定某字词的发音（音素/拼音）
<say-as>interpret-as指定文本的语义类型，决定怎么读
<sub>alias把内部文本替换成另一段文本再读
<break>time在文本间插入可控时长的停顿
<soundEvent>src在任意位置插入提示音

5. <speak> 根元素与全局属性

<speak> 是根元素，所有内容都包在里面；它本身还能携带三个豆包特有的全局属性，用来给整段合成加背景音乐和音效。

三个全局属性

属性类型 / 取值作用
bgmString（线上可调用的背景音乐名，或自定义 TOS URL）为合成语音叠加指定背景音乐。
backgroundMusicVolume[0,100] 整数，默认 50控制背景音乐音量；>50 增大，<50 减小。
effecttrue_robot / heartbeat_intimacy / ethereal_spirit / …让合成语音产生特定音效。一个 SSML 只支持一种音效，且会增大首包延时约 110~150ms。

bgm 示例（自定义背景音）

<speak backgroundMusicVolume="50"
      bgm="https://xxx-test.tos-cn-guangzhou
            .volces.com/SSML-bgm-24k-3s.wav">
    今天天气真不错
</speak>

自定义 BGM 须放火山 TOS（cn-beijing / cn-shanghai / cn-guangzhou 公共读），24kHz 单声道 WAV、≤2MB；合成时长超出时循环播放。

effect 示例

<speak effect="true_robot">
    你喜欢机器人瓦力吗？
</speak>

可选音效（节选）：

true_robot heartbeat_intimacy ethereal_spirit office_ambiance storm_scene cafe_ambiance dreamcore tavern_live school_announcement …
根元素铁律：根元素包含其余全部内容；不应有与之并列或嵌套的其他根元素，且只应出现一次。
错误示范（多次出现 / 并列 / 缺失）：<speak>hello <speak>world</speak></speak>、<speak>hello</speak> <speak>world</speak>、或直接写 hello world（不被当作 SSML）。

6. <phoneme> 指定发音（音素）

<phoneme> 用来手动指定部分字词的发音，最常见的用途是纠正 TTS 多音字的错误读音。通过 alphabet 选音标格式，ph 写具体音素。

alphabet适用ph 写法
py中文前端空格分隔拼音，不区分大小写；声母可选；音调 1 阴平 / 2 阳平 / 3 上声 / 4 去声 / 5 轻声 / 6 连上变调。子元素须为纯文本汉字、无标点。
cmu英文前端空格分隔 CMU 音素，不区分大小写；元音可带重音标号（如 IY1）。子元素须为纯文本英文单词、无标点。
ipa英文前端柯林斯美音音标，连续书写不加分隔符，只能用美式音标。子元素须为纯文本英文单词、无标点。

中文 py 示例

<speak>《<phoneme alphabet="py"
      ph="xi1 xi1">茜茜</phoneme>公主》是
    奥地利拍摄的历史题材电影。</speak>
<speak>要一起去<phoneme alphabet="py"
      ph="chi1">吃</phoneme>饭吗</speak>

英文 cmu / ipa 示例

<speak><phoneme alphabet="cmu"
   ph="w uw1 ch IY1 l Uw n">Wu Qilong</phoneme>
    and Wu Qilong</speak>
<speak><phoneme alphabet="ipa"
   ph="wutʃilun">Wu Qilong</phoneme>
    and Wu Qilong</speak>
易错点：① 子元素里不能出现标点符号，否则报错（如 Wu, Qilong 会报 "should align with the word groups"）；② 不适用于 saturn_ 前缀的 2.0 音色。

7. <say-as> 语义读法

同一串文本可以有不同读法，<say-as> 用 interpret-as 告诉引擎"按什么语义解读"。比如 20 可读作 "twenty"（基数）、"twentieth"（序数）或逐位 "two zero"（数字序列）。

看一眼就懂的对比：12:30 用 interpret-as="score" 读作"十二比三十"，用 interpret-as="time" 读作"十二点半"；20 分别用 ordinal / digit 得到"第二十 / 二 零"。

常用 interpret-as 取值（中英对照）

语义中文写法英文写法示例 / 读法
基数Cardinalcardinal20 → 二十
序数Ordinalordinal20 → 第二十
数字序列Spell / Spell-Yaodigit / letters20 → 二 零（Yao：幺 零）
小数Decimaldecimal12.30 → 十二点三零
时间Timetime12:30 → 十二点半
时间段Time-Duration—时长类读法
日期Date-Y / Date-M / Date-D / Date-YMD …date按年/月/日/年月日组合读
百分数Percent—50% → 百分之五十
分数Fractionfraction几分之几
比分Scorescore12:30 → 十二比三十
金钱Currencymoney按金额读

示例

<speak>12:30 and
  <say-as interpret-as="score">12:30</say-as>
</speak>

<speak>hello and
  <say-as interpret-as="verbatim">hello</say-as>
</speak>

<speak>她的曾用名是
  <say-as interpret-as="name">曾小凡</say-as>
</speak>

注意事项

  • 子元素必须是纯文本，大小写不敏感。
  • name 仅作用于中文多音字的姓；若要全名生效，直接用 <phoneme>。
  • 纯英文场景建议请求参数指定 explicit_language=en，否则可能默认识别为中文。
  • 不能嵌套其它标签，否则报 "can only contain plain text"。
错误示范：<say-as interpret-as="digit">12 <break time="100ms"/> 34</say-as> —— 内部出现了 <break>，会解析失败。

8. <sub> / <break> / <soundEvent>

① <sub> 文本替换

把标签内部文本替换成 alias 里的文本再读。常用于缩略语、专有名词的口语化。

<speak><sub alias="语音合成标记语言">SSML</sub></speak>
→ 实际读作"语音合成标记语言"

② <break> 插入停顿

在文本间插入可控时长的停顿，time 属性支持 [数字]s（1~10）或 [数字]ms（1~10000）。空属性默认停顿 1 秒。

<speak>测试<break time="1s"/>停顿</speak>
<speak>测试<break time="10ms"/>停顿</speak>
<speak>测试<break/>停顿</speak>  <!-- 默认1s -->
坑：① 连续多个 <break> 时长累加，总时长超过 10s 只生成 10s；② <break> 必须闭合——<break>（无斜杠）或 <break time="1s">…</break> 都是错误写法。

③ <soundEvent> 提示音

在合成过程的任意位置插入一段提示音（空标签，不含子标签）。src 指向音频 URL，音频要求与 bgm 一致（TOS 公共读、24kHz 单声道 WAV、≤2MB）。

<speak>一匹马受了惊吓
  <soundEvent src="https://xxx.tos-cn-guangzhou
        .volces.com/SSML-sound-event-1.wav"/>
  人们四散躲避</speak>
注意：<soundEvent> 是空标签，不可包含任何标签；且不适用于 2.0 音色与 icl 2.0 复刻音色。

9. 综合示例与调用

把前面几个标签拼起来，就能产出一段"控制得很细"的语音。下面是一个综合示例：纠正多音字 + 按时间读 + 加停顿 + 叠机器人音效。

<speak effect="true_robot">
  各位乘客请注意，
  <say-as interpret-as="time">12:30</say-as>的
  <phoneme alphabet="py" ph="chi1">吃</phoneme>饭航班
  <break time="500ms"/>
  即将开始登机。
</speak>

调用要点速记

步骤要点
1. 选接口用非流式合成接口（双向流式不支持 SSML）。
2. 设参数请求里设置 text_type=ssml。
3. 包根整段文本包进 <speak>…</speak>，且只出现一次。
4. 控长度含标签在内 ≤ 150 字符，避免 badcase。
5. 选音色用中文普通话音色；避开 _saturn_bigtts / saturn_ 前缀的 2.0 音色。

一句话收尾：SSML 不神秘——它就是把"读什么音、怎么停、按啥语义读、叠什么效果"这四件事，用一套 XML 标签交给你在调 TTS 时精确指定。豆包语音的 Universal SSML 在 <speak> 上额外提供了 BGM 与音效两个实用旋钮，是做"有氛围感"语音内容的好帮手。
