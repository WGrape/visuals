第 10 章 · 搜索

怎样缩小候选范围

搜索不只是查一个值：核心是用输入性质排除不可能的候选，直到答案落在可验证的范围。

从顺序扫描到二分

无额外结构的无序数组需要逐项比较，最坏 O(n)；有序数组可以利用单调顺序，每次丢弃一半候选。二分的前提是判定条件沿搜索范围单调变化，不一定必须是“查找某个恰好相等的元素”。

求第一个不小于 target 的位置（lower bound）时，可维护半开区间 [lo, hi)：答案始终在区间内；若 a[mid] < target，令 lo = mid + 1，否则令 hi = mid。当 lo = hi 时，这个位置就是插入点，即使 target 不存在也定义明确。

lo, hi = 0, len(a)
while lo < hi:
    mid = lo + (hi - lo) // 2
    if a[mid] < target: lo = mid + 1
    else: hi = mid
return lo  # 可能等于 len(a)
a = [1, 3, 3, 8]，target = 3，结果为 1；target = 5，结果为 3；target = 9，结果为 4（数组末尾）。

搜索对象不同，算法也不同

问题可利用的性质常见做法
有序值或单调答案可排除半边二分，O(log n) 次判定
无权图的最少边数路径层层扩展BFS，O(|V|+|E|)
文本中匹配模式串已匹配的前后缀KMP，O(文本长+模式长)

二分答案的整体复杂度还要乘以“一次可行性判定”的成本。边界写错会死循环、漏答案或越界；先写区间不变量再写循环条件。
