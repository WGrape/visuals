📦 Memcached 数据模型

Key、Value、过期与 CAS

基本模型

🔑

Key

字符串，最大 250 字节，建议保持短小。

📄

Value

任意二进制，最大 1MB。

🏷️

Flags

32 位整数，客户端用来标记数据类型（如 JSON/压缩）。

⏱️

Expire

过期时间：相对秒（≤30天）或 Unix 时间戳。

命令与 CAS

基础命令：get / set / add / replace / delete / incr / decr。

cas（Check-And-Set）提供轻量乐观锁：读取时拿到一个唯一的 64 位 cas token，写入时带上它；若期间被别人改过，cas 失败，可重试——适合计数器、库存等并发场景。

  • 过期是『惰性 + 主动』：访问时检查；LRU 爬扫时顺带清理；不会精确准时删除。
  • 没有范围查询、没有二级索引——它就是一张巨型哈希表。
💡 Memcached 的『小』正是它的『快』：协议简单、无额外元数据结构，单实例可轻松扛十万级 QPS。
