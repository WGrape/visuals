文生图扩散架构与条件控制

从图像生成路线进入 Stable Diffusion 的潜空间架构，再看文本、姿态、深度等条件怎样控制出图，以及 DiT 和采样加速的取舍。

加噪、去噪和 DDPM 训练目标由扩散模型原理专题讲解；本页集中在文生图系统的组件和条件控制。

01生成模型谱系

GAN

生成器/判别器对抗，出图快但训练不稳、模式易崩塌。

VAE

把图编码到潜空间再解码，可生成但偏模糊。

自回归 (AR)

像 LLM 一样逐像素/分块生成，质量高但慢。

Diffusion ✅

逐步去噪，训练稳、质量高，是当前主流（SD / DALL·E 3 / 即梦）。

02Stable Diffusion：潜空间扩散

直接在像素上 diffusion 太贵。Stable Diffusion 的巧思是先在潜空间（latent）里扩散：

  • VAE 把 512×512 像素压到 64×64 的潜变量，去噪在 1/8 分辨率上做，算力骤降。
  • UNet 是去噪主力，带噪声预测 + 文本交叉注意力。
  • Classifier-Free Guidance (CFG)：同时算「带提示」与「空提示」的预测，拉开差距以强化文本贴合度。guidance scale 越大越听话、但越易过饱和。

03条件控制：不只是文字

Text / Image

文生图、图生图（img2img：先加噪再重建）。

ControlNet

冻结原 UNet，外接可训练分支，用边缘/姿态/深度图精确控构图。

LoRA（图像）

用小权重注入特定画风/角色，和 LLM 的 LoRA 思想一致。

04DiT 与加速采样

DiT（Diffusion Transformer）

用 Transformer 替换 UNet 做去噪骨干，Sora、SD3、即梦均基于此，可规模化、质量高。

采样加速

原生 DDPM 要上千步；DDIM、DPM-Solver 等确定性/常微分方程采样器把步数压到 20–50 步，速度数量级提升。

05文生图架构复习要点

潜空间先行

先压缩图像表示，再在潜空间去噪，降低生成成本。

SD 快在潜空间

VAE 压缩 + UNet 在 latent 去噪 + CLIP 文本条件。

CFG

带/不带提示双预测拉开差距，控制「听话程度」。

DiT

用 Transformer 替 UNet，是新一代文生图/视频底座。

Visuals · 文生图扩散架构与条件控制

用「擦除噪声」的直觉理解扩散

文生图最常见的路线不是「凭空画」，而是从一团纯噪声开始，一步步把它擦成一张图。模型学的就是「给定一个看上去乱七八糟的画面，判断里面哪些是噪声、该擦掉多少」。

前向加噪是确定的，反向去噪是学出来的

训练目标惊人地简单：随机挑一个时间步 t，往图上加对应强度的噪声，让网络去预测「加进去的这个噪声是什么」，然后跟真实噪声算均方误差。它不需要判别器，也不需要做图像块的重构损失。

三个关键设计

① 潜空间扩散

直接在像素上跑这个流程，一张 1024×1024 的图每次迭代要处理几百万个数值，非常贵。

聪明的做法是先用自编码器（VAE）把图压到一个小得多的潜表示（例如边长缩小 8 倍），噪声化和去噪都在这个压缩空间里进行，最后再由解码器还原成像素。这一步让计算量下降一个数量级，是 Stable Diffusion 这类模型能跑在消费级显卡上的关键。

② 文本条件怎么注入

文字不能直接塞进卷积层，于是走交叉注意力：先用文本编码器（常用 CLIP、T5 一类）把提示词变成一串向量，再让去噪网络在每一层都可以「回头查询」这些向量。

这解释了两个常见现象：提示词里的词有顺序权重差异（靠前的更容易被注意到），以及提示词过长时中间部分会被稀释。

③ 无分类器引导 CFG

去噪时同时算两个方向的结果 —— 「带文本条件」和「不带条件」，然后朝两者的差值方向放大：

pred = uncond + guidance_scale × (cond − uncond) guidance_scale = 1 → 基本不听文本 = 7 → 常见默认，兼顾贴合与画质 ≥ 15 → 过度锐化、色彩过饱和、结构崩坏

采样器与步数

去噪要走多少步、每步怎么走，由采样器决定。它不影响模型能画出什么，只影响「多快走到那里、稳不稳」。

采样器类型特点适用
DDPM（原始）随机性强，需要很多步作为基线理解用
DDIM 系确定性更强，可大幅减少步数需要结果可复现的场景
DPM-Solver 系高阶求解器，20 步左右就能接近效果日常大部分出图的默认选择
祖先 / a 后缀（如 Euler a）带随机扰动，变化更多希望同 prompt 多版本时
步数 15~30速度与质量的常用区间再多收益递减，太少结构未成形

种子（seed）的作用：初始噪声分布完全由随机种子决定。固定种子 + 固定其它所有参数，就能复现同一张图。这也解释了「改一个字整张图都变了」—— 去噪是全局的，任何条件变化都会沿着所有层传播开。

常见翻车点与实践提示

  • 手、手指、复杂肢体：这是当前最强的公开痛点。原因是训练数据里这类结构的统计一致性弱、且潜空间分辨率有限。缓解办法是构图规避（手部不在画面里、遮挡、远景），或事后补救。
  • 属性绑定错乱：「一只红猫和一只蓝狗」可能变成「红狗蓝猫」。多对象多属性时，拆成多次生成再合成通常比硬凑一条提示词更靠谱。
  • 文字渲染：生成器不知道字形结构，画出来的字常常是「看起来像字」。需要真正文时不建议用文生图，应当后合成。
  • 角色一致性：每次生成是独立的，同一个人物的身份不会自动保持。需要固定角色时要依赖专门的训练/适配器，或锁 seed 加微调。
  • 负面提示（negative prompt）：本质是给「不带条件」那一路提供具体的负向锚点，与 CFG 配合生效；它不是万能过滤器，堆太多会互相干扰。

深入自检

为什么叫「扩散」，它和物理上的扩散有关吗？

有关系但不完全一样。最初的灵感确实来自非平衡热力学：前向过程逐步加噪，等价于让原始图像的信息逐渐扩散丢失；反向过程就是逆转这个随机过程。不过现在主流的训练目标（预测噪声的均方误差）已经非常工程化了，物理直觉更多是用来建立第一印象。

能不能只加一点点噪声、只去噪几次，一步生成？

这就是「少步/单步扩散」以及一致性模型研究的方向：通过特定的训练方式让模型学会跨大步去噪。它们能做到几步出图，代价通常是细节丰富度与多样性的下降。日常建议仍是 20~30 步的常规采样器作为质量基准。

加噪声为什么按「越来越强」而不是均匀？

因为不同噪声强度下要学的事情不同：噪声很小时要把细节修得很准，噪声很大时要把握大结构与构图的走向。按不同强度安排不同的学习比重，整体收敛更好，这也是后来提出的各种噪声调度着重优化的地方。

prompt 里用「越多修饰词越好」吗？

不完全。过度堆叠形容词会稀释每个词的权重、引入冲突倾向，还容易触发数据集中高频的模板搭配（导致风格雷同）。更有效的做法是：主体与关键属性用具体名词表达、风格用明确的参考 Artists/媒介用语、把不重要 的东西交给反向提示与后期处理。
