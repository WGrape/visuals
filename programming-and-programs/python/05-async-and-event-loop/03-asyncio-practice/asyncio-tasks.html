asyncio 任务与并发

协程本身不会「并发跑」，它只是个能暂停的函数。asyncio 把它包装成 Task 交给事件循环调度，才能真正「同时等待多个 I/O」。gather / TaskGroup / wait_for 是并发编排的三件套。

运行与循环

asyncio.run 启动事件循环

asyncio.run(coro()) 创建事件循环、运行协程直到完成、再关闭循环。这是 3.7+ 的标准入口。事件循环负责在「await 点」切换协程。

import asyncio

async def main():
    print("start")
    await asyncio.sleep(1)   # 挂起，把控制权交还循环
    print("done")

asyncio.run(main())

「单线程、协作式多任务」是核心：协程只在 await 处让出控制权，没有「被强制打断」，所以不需要锁。事件循环怎么运转见事件循环图解、事件循环 Demo；await 原理见async/await 入门。

Task 是什么

协程 + 循环 = Task

直接 await coro() 是「串行」的（等它跑完才下一步）。用 asyncio.create_task(coro()) 把协程包成 Task 并立即排进循环，它就开始「并发」跑了——之后你再 await 它拿结果。

async def job(n):
    await asyncio.sleep(n)
    return n

async def main():
    t1 = asyncio.create_task(job(1))  # 立即入队，开始跑
    t2 = asyncio.create_task(job(2))
    r1 = await t1                      # 这里才等结果
    r2 = await t2
    return r1, r2                     # 总耗时≈2s 而非 3s
记住：create_task 之后两个任务已在并发推进，你「先 create 再 await」的顺序决定了并发度。若写成 r1 = await job(1) 再 create_task(job(2))，就退化成串行了。
gather 并发

一次性并发多个协程

asyncio.gather(*aws) 把多个协程/任务并发调度，等全部完成返回结果列表。爬虫并发请求 N 个 URL 的典型写法。

import asyncio, time

async def fetch(url):
    await asyncio.sleep(0.5)     # 模拟网络 I/O
    return url

async def main():
    t0 = time.time()
    results = await asyncio.gather(
        fetch("a"), fetch("b"), fetch("c"))
    print(results, time.time()-t0)  # ['a','b','c'] ≈0.5s

asyncio.run(main())
⚠️ gather 有个坑：其中一个任务抛异常，其它任务不会被取消，且异常会包装抛出。若要「一出错就全部停」，用下面 3.11+ 的 TaskGroup。
TaskGroup

3.11+ 推荐：结构化并发

async with asyncio.TaskGroup() as g: 创建一组任务，任一任务失败会自动取消其余任务，异常汇总成 ExceptionGroup。这是「结构化并发」的标准做法。

async def main():
    async with asyncio.TaskGroup() as tg:
        t1 = tg.create_task(job(1))
        t2 = tg.create_task(job(2))
    # 退出 with 块 = 等所有任务完成（或全取消）
    print(t1.result(), t2.result())
TaskGroup 替代了 gather 的「异常不取消兄弟任务」缺陷，也替代了手搓 try/finally: task.cancel()。新代码优先用 TaskGroup（Python 3.11+）。
超时与取消

给等待加时限，超时就取消

asyncio.wait_for(aw, timeout) 给协程设超时，到点自动取消；task.cancel() 主动取消。协程要在 await 处响应取消（捕获 CancelledError 做清理）。

async def slow():
    await asyncio.sleep(10)

async def main():
    try:
        await asyncio.wait_for(slow(), timeout=2)
    except asyncio.TimeoutError:
        print("超时取消")

    # Python 3.11+ 还能用上下文管理器写法
    async with asyncio.timeout(2):
        await slow()

并发原语讲完，但「怎么在协程里安全地调用同步阻塞代码」「常见坑」在异步模式里接着说。它和线程的锁是不同思路：协程靠「不抢占」天然避开竞态，而非靠锁。
