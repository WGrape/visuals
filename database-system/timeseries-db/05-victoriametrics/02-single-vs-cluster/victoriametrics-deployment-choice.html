03单机版 vs 集群版怎么选

考量单机版集群版
运维复杂度低，一个进程高，三类组件 + 分片 + 副本
扩容方式垂直扩容（加 CPU / 内存 / 磁盘）水平扩容
多副本 / HA靠外部手段（双写、存储层冗余）原生支持，vmstorage 可配副本数
适用规模百万级活跃时间线以内通常够用超出单机能力、或需要 HA 时
建议默认起点确需时再迁，不要一上来就上集群
「先上集群」是常见的过度设计。单机版能撑的规模往往远超预期，而集群版带来的组件数量、分片规划和故障排查复杂度是实打实的成本。先单机，监控住资源水位，撑不住了再迁。
