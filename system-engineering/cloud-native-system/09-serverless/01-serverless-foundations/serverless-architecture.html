Serverless 无服务器架构

把服务器运维彻底交给云厂商，只写函数/托管服务，按真实调用付费。

Serverless 两层含义 FaaS + BaaS

从下到上：开发者只关心『函数逻辑』与『事件绑定』

Serverless = <b>FaaS</b>（函数即服务，如 AWS Lambda）＋ <b>BaaS</b>（后端即服务，如托管数据库）。开发者不再管『机器』，只管『触发→函数→结果』。

适合的与不适合的

面试高频问答

Q：Serverless 是不是真的没有服务器？
A：有，只是『你不用管』。运维、扩缩容、容灾由云厂商负责，你按调用次数/时长付费，闲时不花钱。
Q：冷启动是什么，怎么缓解？
A：函数长时间无调用后首次拉起需初始化运行时，带来额外延迟。可预留实例(Provisioned)、减小包体积、用轻量运行时、保持温调用缓解。
