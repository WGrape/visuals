为什么可变默认参数是坑

因为默认参数在函数定义时只求值一次，所有调用共享同一个对象。如果它是可变的，一次调用的修改会留给下一次。正确做法是用不可变的哨兵值，在函数内部再创建新的容器。

并发模型怎么选

判断任务是等待为主还是计算为主：等待为主（网络、磁盘）用多线程或异步，两者都能有效利用等待时间；计算为主只能用多进程，因为锁阻止了多线程的并行计算。

高频问题

Python 到底是值传递还是引用传递？

都不是标准意义上的任何一种，更准确的描述是传对象的引用值：函数拿到的是同一个对象的引用副本。所以重新绑定名字不会影响调用方，但原地修改对象会影响。是否「被改到」取决于你做的是重新绑定还是原地修改。

为什么推荐用上下文管理器管资源？

因为它保证退出时一定执行清理，即使中途出错也一样。这比手动关闭可靠得多，尤其是在有异常路径的代码里。文件、锁、连接、事务都适合用它。

生成器相比返回列表好在哪？

好在惰性与省内存：它逐个产出，不需要先把全部结果放在内存里，还能中途停止。代价是只能遍历一次，需要反复使用时要先转成容器。

为什么多线程在 CPU 密集任务上无效？

因为同一时刻只允许一个线程执行字节码。计算密集型任务会一直占用执行权，多线程只是交替执行，还多出切换开销。这类任务要用多进程，或借助能在底层释放锁的计算库。

入口守卫为什么必须写？

因为导入模块会执行它的顶层代码。不加守卫，别人导入你的模块时就会触发启动逻辑；在多进程场景甚至会递归创建子进程。原则很简单：只有直接运行该文件时才该做的事，全部放进守卫里。
