ASR 识别错误：WER、CER 与诊断

识别准确率要和文本切分方式、业务词汇及延迟一起解释。

核心机制

词错误率 WER = (替换 S + 删除 D + 插入 I) / 参考文本词数 N。它用最小编辑距离对齐参考与输出；当 N 很小时，插入较多会使 WER 超过 100%。

中文可用字错误率 CER，但字对了不代表实体、数字格式和标点可用。评估前要固定大小写、标点、数字与分词的归一化规则，否则两次分数不可比。

用一个例子看过程

参考：请订 明天 的 机票
识别：请订 今天 的 机票
替换 1，删除 0，插入 0，N=4，WER=25%。

固定评测口径

确定参考文本、分词器和数字/标点归一化规则，并保存版本。

做编辑对齐

逐条统计 S、D、I；同时按噪声、口音、设备与领域词分桶。

回放失败样本

确认是前端音频、端点、声学识别还是后处理造成的错误。

观察、原因与处理

观察原因或含义处理与验证
漏整句端点或语音活动检测失败对照音频时间线与送入模型的片段
专名错训练分布或词汇偏移单列实体准确率并检查热词机制
格式错数字、日期后处理不一致统一评测和产品展示规则

编辑距离怎样得到错误数

评测前先统一大小写、数字、标点和分词规则，再用最小编辑距离对齐参考与输出。把“请 / 订 / 明天 / 的 / 机票”识别为“请 / 订 / 今天 / 的 / 机票”时，五个参考词里只有一次替换，WER 为 1/5，即 20%。若把“请订”合成一个词，分母会变成四，得分变为 25%；这不是模型突然变差，而是计量单位改变。因此报告中必须保存分词器、归一化规则和测试集版本。

中文 CER 使用字粒度，便于减少分词歧义，但可能无法体现专名、金额和地址的业务含义。一个药名只错一个字，CER 影响不大，对业务却可能非常严重。可同时记录 CER、WER、实体完全正确率和关键字段错误案例。

语料汇总的算术陷阱

整份测试集的 WER 应先汇总所有句子的替换、删除、插入和参考词数，再做一次除法。例：句 A 有 2 个词，错 1 个，WER=50%；句 B 有 98 个词，错 1 个，WER 约 1.02%。整份语料共错 2 个、参考 100 个，整体 WER 为 2%，而两句 WER 的算术平均约 25.51%。前者按词加权，后者按句加权，不能混用来比较模型版本。

分桶诊断比一个总分更有用：按噪声、口音、设备、语速、说话人数、时长和领域词分组。模型升级后总 WER 降低，却在专有名词上退化，应单独回放那些样本并检查训练域、热词支持和后处理。整个过程中还要保存音频原件、时间戳和送入模型的切片，便于分辨识别错误与端点漏切。

错误类型到实验的对应

现象实验预期判别
整句消失对照 VAD 前后波形音频是否进入模型

练习：设计一个手机号码评测集，分别说明何时使用字符错误率、整串完全正确率和最终结果延迟。

边界与误区

总体 WER 下降不保证关键业务字段更准。手机号、药名等应另算字段级正确率，并同时观察最终结果延迟。

让评测集能解释产品风险

评测集应拆成开发集、固定回归集与最近线上失败样本。开发集可用于调参，固定集用于比较版本，线上失败集用于发现新分布；若持续对固定集调规则，分数会过拟合，不能再代表未见样本。保存原始音频、参考转写、录音设备、场景标签和审核记录，人工参考也可能错，尤其是同音字、方言和多人对话。抽样复核参考答案是评测的一部分。

当 WER 改善时，还要检查删除和插入是否同时变化。例如模型更保守，少插入幻听词，却漏掉更多弱音；总 WER 可能相近，用户感受到的故障却不同。若产品涉及实时交互，还应比较最终结果延迟和被端点切断的比例。一个指标无法同时表达准确性、速度和安全性，发布判断应基于关键任务的组合门槛。

从分数走向成本

相同一次替换，在普通聊天和医疗药名中代价不同。可先保持标准 WER/CER 作为可比基线，再单独设业务加权指标：关键实体完全正确、数字串完全正确、危险误识别次数和人工纠错时长。加权指标必须透明，不能随版本调整权重来制造进步。比较两个模型时，同一测试集逐样本并排观察退化案例，尤其是少数高风险类别。若线上分布明显变化，应新增代表性样本，但保留旧的固定回归集，以便分辨模型提升与语料更换。

进一步验证

发布前可在相同样本上做配对比较：列出新模型改善与退化的每个句子，按关键实体、噪声和设备分组查看。只看两个总体数字，可能看不见模型把易样本变得更好、难样本变得更差。对参考文本存在争议的样本先人工复核，避免把标注噪声当成模型错误。

自检

为什么两套分词器算出的中文 WER 不能直接比较？

词边界改变了参考词数和编辑操作数；必须先统一分词与归一化规则。
