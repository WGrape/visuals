1三条能力迁移路线

当你想让小模型获得大模型的能力时，主流有三条路：知识蒸馏（用教师模型输出做监督）、监督微调 SFT（用人工/高质量标注训练）、继续预训练（在更多领域语料上接着预训练）。三者目标不同，选错路线会既烧钱又没效果。

本文只比路线选择，不展开量化/剪枝（别处已覆盖）。

2三路对比

路线数据适用成本
蒸馏教师生成的软标签/轨迹已有强教师、想降本中（需跑教师）
SFT人工/专家标注教新技能、对齐格式高（标注贵）
继续预训练领域无标注语料注入领域知识高（算力大）

3蒸馏训练片段

import torch, torch.nn.functional as F

def distill_loss(student_logits, teacher_logits, labels, T=4.0, alpha=0.7):
    soft = F.kl_div(
        F.log_softmax(student_logits/T, -1),
        F.softmax(teacher_logits/T, -1),
        reduction="batchmean") * (T*T)
    hard = F.cross_entropy(student_logits, labels)
    return alpha*soft + (1-alpha)*hard

# 教师冻结，只训学生
with torch.no_grad():
    t_logits = teacher(batch)
loss = distill_loss(student(batch), t_logits, batch["labels"])

温度 T 软化分布，让学生学到"非正确类的相对概率"这一暗知识；alpha 平衡软硬损失。

4路线选择决策

图：三条路线的选择逻辑

第一层 · 概念与判定

路线选择判定：

  • 已有可调用的大教师 + 目标只是"降本/提速" → 蒸馏；
  • 要教模型原本不会的技能或固定输出格式 → SFT；
  • 模型在垂直领域术语/知识匮乏 → 继续预训练；
  • 三者可组合：先继续预训练补知识，再 SFT 对齐，最后蒸馏压缩。

第二层 · 参数·命令·量化

关键参数：

项经验
蒸馏温度 T2–6，软化分布
alpha（软/硬）0.5–0.9 偏软
SFT 数据量千～万级高质量即可见效
继续预训练领域语料占比与学习率需退火

第三层 · 排障与边界

边界与坑：

  • 蒸馏天花板：学生容量不够，软标签也救不回；
  • 教师错误传播：教师错的样本学生照学，需过滤；
  • SFT 过拟合：小数据强训会遗忘通用能力；
  • 继续预训练灾难性遗忘：需保留通用语料混合。

第四层 · 原理与取舍

原理取舍：

  • 蒸馏用"教师分布"换数据效率，但受限于教师上限；
  • SFT 灵活但依赖昂贵标注且易过拟合；
  • 继续预训练改底层表征，最贵但能补知识；
  • 结论：按"是否有教师 / 是否缺知识 / 是否教新技能"三维选路，常组合而非单选。
