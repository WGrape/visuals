OceanBase 租户资源与隔离边界

明确租户、资源池和共享基础设施的关系。

OceanBase

01多租户资源隔离

OceanBase 原生支持在一个物理集群内创建多个逻辑租户， 每个租户有独立的 CPU、内存、IOPS 配额，硬隔离互不抢占。

🏢 租户 Tenant

相当于一个逻辑数据库实例，有自己的用户、库表、资源规格。 租户之间数据完全隔离，看不到对方。

📐 资源规格 Unit

定义 CPU 核数、内存大小、IOPS。租户通过 Unit 分布在多个 OBServer 上， 实现资源弹性伸缩。

💰 价值

一套集群替代多个独立 MySQL 实例， 资源利用率大幅提升，运维收敛到一套系统——这是它在大型企业受欢迎的原因。

-- 创建资源规格
CREATE RESOURCE UNIT unit_1c2g
  MAX_CPU = 1, MEMORY_SIZE = '2G', MAX_IOPS = 2000;

-- 创建资源池
CREATE RESOURCE POOL pool_app
  UNIT = 'unit_1c2g', UNIT_NUM = 3, ZONE_LIST = ('z1','z2','z3');

-- 创建租户（MySQL 兼容模式）
CREATE TENANT tenant_app
  RESOURCE_POOL_LIST = ('pool_app'),
  PRIMARY_ZONE = 'z1',
  CHARSET = 'utf8mb4',
  OB_COMPATIBILITY_MODE = 'mysql';
