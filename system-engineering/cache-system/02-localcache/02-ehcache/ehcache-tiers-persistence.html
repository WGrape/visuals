🗄️ Ehcache 三级分层与持久化

Heap / OffHeap / Disk 分层、JCache 标准与本地持久化恢复

💾

Heap 堆内

最快 / 受 GC

🧊

OffHeap 堆外

不受 GC / 需序列化

💽

Disk 磁盘

持久 / 大容量

🪪

JCache

标准 API

分层与数据流向

热数据驻留 Heap，访问最快但受 GC 影响；OffHeap 在 JVM 堆外，不受 GC 停顿但需序列化；Disk 容量大可持久化。Ehcache 按 Tiering 自动在层间搬运数据。

持久化与恢复

开启 disk 持久层后，重启时可从磁盘恢复缓存，减少冷启动回源压力。符合 JCache（JSR-107）标准，可替换实现。

与 Caffeine 取舍

Caffeine 只有堆内、性能极致；Ehcache 支持堆外 / 磁盘分层与持久化，适合单机大容量本地缓存。

🎯 面试问答

Q：堆外缓存为什么要序列化？
A：堆外内存在 JVM 堆之外，对象需转为字节存储。
Q：Ehcache 持久化有什么用？
A：重启后恢复缓存，缓解冷启动。
Q：何时选 Ehcache 而非 Caffeine？
A：需要大容量、堆外、磁盘或持久化时。
