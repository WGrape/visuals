统计推断：从样本反推总体

手里只有样本，却要对总体下结论——估计给出数值与区间，假设检验给出「证据够不够」的判断标准。

核心速览

点估计

用一个数值估计参数，如 X̄ 估 μ；关注无偏、有效、一致

区间估计

给出置信区间 [L,U]，同时表达精度与不确定性

假设检验

设 H₀ 与 H₁，算 p 值，与显著性水平 α 比较

两类错误

Ⅰ型（假阳性）概率 α；Ⅱ型（假阴性）概率 β；功效 = 1−β

推断的两大任务

点估计：好估计量的三个标准

标准含义数学表达
无偏性估计的期望等于真值，没有系统性偏差E[θ̂] = θ
有效性在无偏估计中方差最小，最「稳」Var(θ̂) 尽可能小
一致性样本量趋于无穷时收敛到真值θ̂ →ᵖ θ（n → ∞）

常用估计量：样本均值 X̄ 估 μ（无偏且一致）；样本方差用 1/(n−1) 而非 1/n——这就是贝塞尔校正，除以 n 会低估方差（因为 X̄ 本身是用数据算出来的，已经「贴近」样本）。

import statistics as st
data = [2.3, 1.9, 2.7, 2.1, 2.5, 1.8, 2.4, 2.0]
n = len(data)
mean = sum(data)/n
var_biased   = sum((x-mean)**2 for x in data)/n        # 有偏（低估）
var_unbiased = sum((x-mean)**2 for x in data)/(n-1)    # 无偏，贝塞尔校正
print(round(mean, 4), round(var_biased, 4), round(var_unbiased, 4))
print(round(st.stdev(data), 4))      # 标准差（无偏版）
为什么除以 n−1？直观解释：用 X̄ 代替未知的真值 μ，消耗掉了 1 个自由度，剩下的「独立信息」只有 n−1 份。当 n 很小时两者差别显著（n=2 时差一倍），n 大时可忽略。

置信区间：给估计配上误差棒

样本均值 X̄ 的 95% 置信区间（σ 已知或 n 大时用 z；σ 未知且 n 小时用 t）：

X̄ ± z_(α/2) · σ/√n　（σ 已知）　　或　　X̄ ± t_(α/2, n−1) · s/√n　（σ 未知）
置信水平z 值（双尾）含义
90%1.64510 次里约 1 次不覆盖
95%1.960最常用
99%2.576要求更高，区间更宽
def ci_mean(data, conf=0.95):
    """样本均值的置信区间（σ 未知，用 t 分布）"""
    import math
    n = len(data)
    m = sum(data)/n
    s = (sum((x-m)**2 for x in data)/(n-1)) ** 0.5
    se = s / math.sqrt(n)               # 标准误
    z = {0.90: 1.645, 0.95: 1.96, 0.99: 2.576}[conf]
    return m - z*se, m + z*se

print([round(v, 3) for v in ci_mean([2.3,1.9,2.7,2.1,2.5,1.8,2.4,2.0])])
正确读法：「用此方法重复抽样 100 次，约 95 个区间会覆盖真值 μ」。错误读法：「μ 有 95% 概率落在 [L,U] 内」——频率学派里 μ 是固定常数，随机的是区间本身。后者是贝叶斯可信区间的说法。

假设检验的完整流程

  1. 提出假设：原假设 H₀（如「新旧版本转化率相同」）与备择假设 H₁；
  2. 选择检验统计量：z 检验（大样本/σ 已知）、t 检验（小样本）、卡方检验（分类数据）、比例检验；
  3. 确定显著性水平 α：通常 0.05，即容忍 5% 的假阳性；
  4. 计算检验统计量与 p 值：p = 在 H₀ 为真时观察到当前或更极端结果的概率；
  5. 下结论：p < α 则拒绝 H₀，否则「不拒绝」；
  6. 报告效应量与置信区间：不只说「显著」，还要说「大多少」。
def two_sample_z(x1, n1, x2, n2):
    """两组比例差异的 z 检验（A/B 实验常用）"""
    import math
    p1, p2 = x1/n1, x2/n2
    p_pool = (x1 + x2) / (n1 + n2)
    se = math.sqrt(p_pool*(1-p_pool)*(1/n1 + 1/n2))
    z = (p2 - p1) / se
    # 双尾 p 值（正态近似）
    p = 2 * (1 - 0.5*(1 + math.erf(abs(z)/math.sqrt(2))))
    return z, p

# 对照组 1000 人转化 100，实验组 1000 人转化 125
z, p = two_sample_z(100, 1000, 125, 1000)
print(round(z, 3), round(p, 4))     # z ≈ 1.79，p ≈ 0.073 → 在 α=0.05 下不显著
H₀ 实际为真H₀ 实际为假
拒绝 H₀❌ Ⅰ型错误（假阳性），概率 α✅ 正确（功效 1−β）
不拒绝 H₀✅ 正确❌ Ⅱ型错误（假阴性），概率 β
α 与 β 此消彼长：把 α 调小（更严格）会让 β 变大（更容易漏检）。唯一的双赢手段是增大样本量——这就是为什么 A/B 实验要做功效分析（power analysis）来提前计算所需样本量。

样本量怎么定：功效分析

要在显著性水平 α 下，以至少 1−β 的功效检出大小为 δ 的效应，每组所需样本量约为：

n ≈ 2 · (z_(α/2) + z_β)² · σ² / δ²　　（两独立样本均值比较）
def sample_size_per_group(delta, sigma, alpha=0.05, power=0.8):
    """每组所需样本量：delta=想检出的最小差异，sigma=标准差"""
    import math
    z_a = {0.05: 1.96, 0.01: 2.576}[alpha]
    z_b = {0.80: 0.84, 0.90: 1.28}[power]
    return math.ceil(2 * (z_a + z_b)**2 * sigma**2 / delta**2)

# 例：想检出转化率从 10% 提升到 11%（δ=0.01，σ≈√(0.1*0.9)≈0.3）
print(sample_size_per_group(0.01, 0.3))     # 每组约 14100 人
这条公式揭示了一个常被低估的事实：样本量与效应量的平方成反比。想检出的差异缩小一半，样本量要翻四倍。这就是为什么「微小改进」的 A/B 实验需要海量流量——也是为什么小流量产品做 A/B 实验常常得不出结论。

A/B 实验的实践陷阱

  • 偷看（peeking）：实验中途反复看结果并提前停止，会把假阳性率抬高到远超 5%。要用序贯检验（如 SPRT、贝叶斯方法）或固定样本量。
  • 多重比较：同时看 20 个指标，即使都是噪声也平均会有 1 个「显著」。要做 Bonferroni（α/m）或 FDR 校正。
  • 辛普森悖论：分组后整体趋势与子组趋势相反（如按设备拆分后结论翻转）。要预先分层并检查子组一致性。
  • 新奇效应：用户对新界面的短期好奇会夸大效果，需观察足够长时间。
  • 只看 p 值不看效应量：大样本下 0.1% 的提升也能「显著」，但业务上毫无意义。必须同时报告置信区间与业务含义。
  • 指标选择：护栏指标（guardrail）与成功指标要分开，防止「提升点击率却破坏留存」。

最大似然估计 MLE：通用估计框架

MLE 的思路非常朴素：选择让「已观测到的数据」出现概率最大的那个参数。

θ̂ = argmax_θ L(θ) = argmax_θ Π P(xᵢ | θ)　　（取对数后变成求和，更好优化）
# 例：抛硬币 10 次 7 次正面，估计正面概率 p
# 似然 L(p) = p⁷(1−p)³，取对数：7ln p + 3ln(1−p)
# 求导令其为 0：7/p − 3/(1−p) = 0  ⟹  p̂ = 7/10 = 0.7
# 结论：对二项分布，p 的 MLE 就是「正面次数 / 总次数」

# 正态分布的 MLE：μ̂ = 样本均值，σ̂² = (1/n)Σ(xᵢ−μ̂)²（注意是有偏版本）
# 逻辑回归的 MLE：最大化对数似然 ⇔ 最小化交叉熵损失
# → 这就是为什么「训练神经网络 = 最小化 loss」本质上就是 MLE（或 MAP）
MLE 与 MAP 的关系：MAP = MLE + 先验项。正则化就是先验：L2 正则（权重衰减）等价于给参数加高斯先验，L1 正则等价于拉普拉斯先验。这个视角把「机器学习」与「贝叶斯统计」统一了起来。

🎯 常见问法与答题要点

Q：点估计和区间估计有什么区别？为什么更推荐区间估计？

A：点估计只给一个数字（如「转化率是 12.3%」），完全不表达不确定性——读者无法判断这个数字有多可靠。区间估计额外给出一个范围与置信水平（如「12.3% ± 1.1%，95% 置信」），同时传达了估计值与精度。样本量越大区间越窄；区间宽度本身就是「样本够不够」的直接信号，因此科研与工业报告普遍要求同时给出点估计与置信区间。

Q：为什么要除以 n−1 而不是 n 来算样本方差？

A：这就是贝塞尔校正。因为计算离差时用的是样本均值 X̄ 而非真实 μ，而 X̄ 是从同一批数据算出来的，它「天然贴近」这组数据，导致 Σ(xᵢ−X̄)² 系统性偏小。可以证明 E[Σ(xᵢ−X̄)²] = (n−1)σ²，所以要除以 n−1 才是无偏估计。直觉：X̄ 消耗了 1 个自由度，剩下 n−1 份独立信息。除以 n 会低估方差，n 小时偏差尤其明显。

Q：95% 置信区间到底怎么解释才对？

A：正确解释：如果重复抽样并用同样方法构造 100 个区间，大约 95 个会覆盖真实参数 μ。注意随机的是区间（因为区间由样本决定），而不是参数。常见误解「μ 有 95% 的概率落在这个区间内」是贝叶斯可信区间的表述——频率学派认为 μ 是固定常数，不能谈它的概率。两种框架各有道理，但不能混用。

Q：p 值到底是什么？p < 0.05 能说明什么、不能说明什么？

A：p 值 = 在 H₀ 为真的前提下，观察到当前结果乃至更极端结果的概率。能说明：数据与 H₀ 不太相容，可以提供拒绝 H₀ 的证据。不能说明：① 不是「H₀ 为真的概率」；② 不表示效应有多大（大样本下微小差异也显著）；③ p > 0.05 不等于「H₀ 成立」，只是证据不足；④ 不说明结果可复现。正确做法：p 值必须与效应量、置信区间一起报告。

Q：Ⅰ型错误和Ⅱ型错误是什么？怎么权衡？

A：Ⅰ型（假阳性）：H₀ 真却拒绝了，概率 = α（通常 0.05）；Ⅱ型（假阴性）：H₀ 假却没拒绝，概率 = β，功效 = 1−β（通常要求 ≥ 0.8）。两者此消彼长：把 α 调严（如 0.01）会让 β 上升；反之亦然。唯一的双赢手段是增大样本量。选择取决于代价：新药审批严控假阳性（α 小）；疾病筛查严控假阴性（β 小，功效高）。

Q：为什么 A/B 实验不能中途偷看结果？

A：因为每看一次就等于做了一次检验，反复检验会大幅抬高总体假阳性率——原本 5% 的错误率在偷看 10 次后可能升到 20% 以上。更严重的是，人们往往在恰好出现显著差异时停止，这是一种选择性偏差。正确做法：① 事先固定样本量，到量再看；② 或采用专门的序贯检验方法（SPRT、贝叶斯 Bandit、always-valid p 值），它们在数学上允许连续监测且仍控制错误率。

Q：多重比较问题怎么处理？

A：同时检验 m 个假设时，即使全是噪声，期望也有 m·α 个「显著」。处理方法：① Bonferroni：把阈值改成 α/m（简单保守，漏检多）；② Holm–Bonferroni：逐步法，比 Bonferroni 更有功效；③ Benjamini–Hochberg（FDR）：控制错误发现率而非族错误率，更适合探索性分析（如同时看几十个指标）。在 A/B 实验里，最实际的做法是预先指定一个主指标，其余作为次要/护栏指标。

Q：MLE 和机器学习里的损失函数是什么关系？

A：极大似然估计等价于最小化负对数似然，而常见的损失函数正是各种分布下的负对数似然：① 均方误差 MSE ⇔ 高斯分布假设下的 MLE；② 交叉熵/对数损失 ⇔ 分类（伯努利/多项）分布的 MLE；③ 加上正则化后就是 MAP（最大后验）——L2 正则 = 高斯先验，L1 正则 = 拉普拉斯先验。所以「训练模型 = 最小化 loss」本质上就是在做统计推断，这把机器学习与统计学统一在同一个框架下。

Q：辛普森悖论是什么？为什么要警惕？

A：指分组看时每个子组都是同一趋势，合并后整体趋势却相反的现象（或反之）。成因是存在一个同时影响分组与结果的混杂变量（如不同设备类型的用户比例在两组间不同）。经典案例：某药在男性和女性子组中都更有效，合并后却显示更差——因为用药组中重症比例更高。在 A/B 实验中的防范：随机分流保证组间可比、预先分层分析、检查关键子组结论是否一致。
