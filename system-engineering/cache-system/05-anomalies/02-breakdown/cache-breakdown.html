🔥 缓存击穿

热点 key 过期瞬间，浊涌并发全部打向数据库

🔥

定义

热点 key 过期瞬间

🔒

互斥锁

单线程重建

⏱️

逻辑过期

异步重建

📍

热点不过期

后台刷新

现象

某个极端热点 key 突然过期，浊涌并发同时发现缓存没了 → 瞬间全部打 DB。

对策

  • 互斥锁：只一个线程重建，其余等待
  • 逻辑过期：值里存过期时间，发现过期由单线程异步重建，读仍返旧值
  • 热点永不过期：+后台定期刷新

🎯 面试问答

Q：击穿和雪崩区别？
A：击穿是单点热点过期；雪崩是大批 key 同时过期。
Q：互斥锁实现注意？
A：用 Redis SET NX 加锁，重建后释放；设超时防死锁。
Q：逻辑过期是什么？
A：不真删，值里带过期时间，发现过期由单线程异步重建，读仍返旧值。
