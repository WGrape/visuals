单例要保证『全局唯一』且『并发安全』。Go 首选 sync.Once，Python 用模块级对象或改写 __new__。

1Go 双重检查锁（不推荐但常见）

type singleton struct{}
var (
    instance *singleton
    mu       sync.Mutex
)
func Get() *singleton {
    if instance == nil {        // 第一次检查
        mu.Lock()
        defer mu.Unlock()
        if instance == nil {    // 锁内第二次检查
            instance = &singleton{}
        }
    }
    return instance
}

2Go sync.Once（推荐）

type singleton struct{}
var (
    instance *singleton
    once     sync.Once
)
func Get() *singleton {
    once.Do(func() { instance = &singleton{} })
    return instance
}
要点：sync.Once 内部已处理内存可见性与只执行一次，比手写双重检查更安全。

3Python 实现

class Singleton:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

# 更 Pythonic：模块级对象天然单例
# db.py
db = Database()  # import 多次也只执行一次

5何时不要用单例

  • 其实是『配置容器』→ 用依赖注入，便于测试与替换。
  • 需要多个实例或不同环境的实例 → 单例会锁死可测试性。
  • 隐藏的全局状态会让并发测试和推理变难。
