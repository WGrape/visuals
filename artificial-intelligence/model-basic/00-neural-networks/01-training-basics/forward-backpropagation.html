前向传播与反向传播：神经网络是怎么"学会"的

前向传播负责"算出一个答案"，反向传播负责"算出每个参数该背多少锅"。整个深度学习的训练过程，就是这两步反复循环。本文用计算图和链式法则把它彻底讲透。

一句话概括

前向传播：输入从第一层流到最后一层，得到预测值 y_hat，途中把每层的中间结果缓存下来。

反向传播：用损失函数算出的误差，从最后一层倒着往回传，靠链式法则算出每一个参数对误差的"贡献度"（梯度），然后让参数沿着减小误差的方向挪一小步。

记住这个循环：前向算预测 → 算损失 → 反向算梯度 → 更新参数。大模型预训练做的就是这件事，只不过规模是千亿参数、万亿 token。

前向传播：从输入到预测

一个最简单的全连接层做的事只有两步：加权求和，再过一个非线性激活。

z = W·x + b   →   a = f(z)
  • x：上一层送来的输入向量
  • W：这一层的权重矩阵（模型真正要学的参数）
  • b：偏置
  • f：激活函数（ReLU / GELU / SwiGLU 等），没有它，多层线性变换叠加后仍然等价于一层线性变换，网络就白堆了
大模型里的 "层" 不是全连接层，而是 注意力层 + FFN 层，但本质完全一样：都是 z = W·x + b 再过激活，只是 W 换成了 Q/K/V 投影矩阵和前馈矩阵。

损失：先知道"差多少"，才知道"往哪改"

损失函数把"预测值和真实答案的差距"压成一个标量数字。有了这个数字，训练才有目标。

回归
MSE = (y - ŷ)²
预测连续数值
分类
CE = -Σ y·log(ŷ)

大语言模型的预训练目标就是交叉熵：让正确下一个 token 的概率尽量接近 1。所谓"模型变强"，就是这个词表上的交叉熵一路下降。

反向传播：链式法则的工程实现

我们想知道：损失 L 对某个靠前的权重 W₁ 的梯度 ∂L/∂W₁。W₁ 离 L 隔着好几层，直接求很难；但链式法则允许我们拆成一串局部梯度的乘积：

∂L/∂W₁ = (∂L/∂a₃) · (∂a₃/∂z₃) · (∂z₃/∂a₂) · (∂a₂/∂z₂) · (∂z₂/∂W₁)

关键在于：每一项的局部梯度都只需要本层的缓存值，而前向传播时已经把 z、a 全存下来了。所以反向传播不需要重新算前向，只是倒着做一串小乘法。

为什么"反向"比"逐个参数数值微分"快得多

数值微分（朴素做法）
每个参数扰动一次、重跑一遍前向。
千亿参数 = 千亿次前向，不可行。
反向传播
一次前向 + 一次反向，同时拿到所有参数梯度。
复杂度与前向同阶（约 2~3 倍）。
代价是显存：前向的中间激活必须缓存到反向用完为止。这就是为什么训练比推理吃显存得多，也是梯度检查点（用时间换显存，只存部分激活、反向时重算）存在的原因。

用一个极简例子走一遍

设 z = w·x，a = f(z)，L = (a - y)²，求 ∂L/∂w：

∂L/∂w = (∂L/∂a) · (∂a/∂z) · (∂z/∂w) = 2(a-y) · f'(z) · x

注意最后乘的是 x：输入越大，这个参数拿到的梯度越大。这就是为什么输入要归一化——否则某些特征维度会持续产生巨大梯度，训练不稳定。

然后按梯度下降更新（lr 是学习率）：

w ← w - lr · ∂L/∂w

常见坑：梯度消失与梯度爆炸

反向传播是一串梯度连乘。层数一多，这串乘积就会出问题：

现象成因表现主流解法
梯度消失激活函数导数长期 < 1（如 sigmoid 两端），连乘后趋近 0浅层参数几乎不更新，模型学不动ReLU 类激活、残差连接（ResNet/Transformer 的 x + F(x)）、LayerNorm
梯度爆炸导数长期 > 1，连乘后指数增长loss 突然 NaN、参数变成 inf梯度裁剪（clip by norm）、残差连接、合理初始化
Transformer 能堆到上百层，核心就是靠 残差连接 + Pre-LN 归一化 给梯度修了一条"高速公路"，让它不至于在连乘中衰减掉。

面试速记卡

  • 前向 vs 反向：前向算预测并缓存中间激活；反向用链式法则从损失倒推每个参数的梯度。
  • 为什么要缓存激活：反向要用本层的输入和中间值算局部梯度，代价是显存。
  • 复杂度：反向传播一次拿到全部梯度，约等于 2~3 倍前向计算量，远优于逐参数数值微分。
  • 梯度消失/爆炸：本质是深层梯度连乘；解法是 ReLU + 残差 + 归一化 + 梯度裁剪。
  • 与大模型的关系：预训练 = 在万亿 token 上反复执行"前向 → 交叉熵损失 → 反向 → 更新"这个循环。
