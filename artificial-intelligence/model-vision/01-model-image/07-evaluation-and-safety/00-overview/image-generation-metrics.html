评测与安全

图像生成评测与安全：FID、CLIP Score、水印与鉴伪

生成的图好不好看很难量化。本文梳理生成质量的客观指标（FID / IS / CLIP Score）与人类评测各自的含义与局限，并讲清水印、溯源与深度伪造治理这条产业必答题。

为什么图像生成难评测

文本有 BLEU/ROUGE 这类参考答案对比，图像却没有唯一正确答案：同一个提示词，两种完全不同的画面都可能很好。

所以图像评测天然是「分布层面」和「主观层面」的混合：既要衡量生成分布与真实分布接不接近，也要人来看好不好。

客观指标三件套

指标在测什么局限
IS（Inception Score）生成图是否清晰可辨、类别分布是否多样只看生成图，不与真实图比较，容易被"记住训练集"刷高
FID生成分布与真实分布在特征空间的距离（越低越好）依赖特征提取网络与样本数量，不同实现不可直接横比
CLIP Score生成图与提示词的语义匹配度对"图文不符"敏感，但对画质本身不敏感
实践结论：FID 看真实感/分布，CLIP Score 看图文一致性，两者必须配套看；再叠加人类偏好评测（两两对比 / Elo）才接近体感。

人类评测怎么做得靠谱

  • 两两对比胜率比绝对打分更稳定，可聚合为 Elo 排名
  • 明确评分维度：画质、图文一致性、无明显畸变分开打，避免单一总分掩盖问题
  • 随机化左右顺序，防止位置偏差
  • 保留自己的业务评测集并做回归，不要只信公开榜单
务必单独检查手部、文字、人脸、多物体数量这类高频翻车点——平均分往往掩盖这些致命局部错误。

水印、溯源与鉴伪

数字水印
生成时在像素/频域嵌入不可见标识；也可做主动标识（可见水印/元数据）
溯源
记录生成来源与模型信息，配合元数据标准（如 C2PA 类思路）
鉴伪检测
训练二分类器识别生成痕迹；但会随生成技术进步而持续失效，属于跟跑
合规治理
敏感内容过滤、人物肖像与版权审查、日志留存与可追溯
现实策略是多层组合：主动标识（能防住大多数误用）+ 检测兜底 + 平台级审核与追溯，而不是指望单一检测手段。

面试速记卡

  • 难评原因：图像没有唯一正确答案，必须结合分布指标与主观评测。
  • IS：只看自信度与多样性，不比真实分布；FID：分布距离，实现不可横比；CLIP Score：图文一致性，不看画质。
  • 人类评测：两两对比 + Elo、分维度打分、随机顺序、自建回归集。
  • 必查局部：手、文字、人脸、物体数量——平均分常掩盖翻车点。
  • 安全：水印/溯源/检测/审核多层组合，单一检测必然会被绕过。

先问「我要回答什么问题」，再选指标

没有「最好的生成指标」，只有「对应某个问题的指标」。一张图可以真实但不相关、相关但不真实、两者都好但千篇一律——这三种失败需要三个不同指标才能区分。所以评测的第一步永远是明确问题，而不是挑一个数去刷。

FID生成集与真实集在 Inception 特征空间的分布距离，越小越真实
IS单图分类置信度与类别多样性，越大越「清晰且多样」
CLIP Score图与文本的 CLIP 相似度，衡量语义对齐
LPIPS两张图的感知相似度，越小越像（需参考图）
PSNR / SSIM像素级/结构级相似，只在有参考图时有意义
Precision / Recall分别衡量「真实性」与「覆盖多样性」，拆开了看更清楚
决策树：问题不同，指标就不同；单指标必然误判

指标全景对比

指标需要参考图需要参考集数值方向衡量什么主要局限
FID否是（真实图集）越小越好整体分布真实度对特征模型敏感；样本少(<10k)偏差大；不同实现不可比
KID否是越小越好同 FID，但无偏估计计算慢，报告较少
IS否否越大越好清晰度 + 类别多样性不看真实度；易被模式崩溃刷高；对 ImageNet 类目才准
CLIP Score否否越大越好图文语义对齐对数量、方位、颜色等细节不敏感
LPIPS是否越小越好感知相似度必须有成对参考图；不适用于无条件生成
PSNR / SSIM是否越大越好像素/结构保真与人类感知相关性弱；PSNR 高不等于好看
Precision / Recall否是越大越好真实性与覆盖度分解实现细节影响大，需固定设置
人工偏好 / Elo否否胜率综合体验与审美成本高、需规范流程否则噪声大

最常见误用：把 PSNR/SSIM 用在无条件生成上（没有参考图，指标无定义），或者只看 IS 就宣称模型更好（IS 完全不衡量真实性）。

搭一套可信的评测

① 固定三件事

  • 样本量：FID 至少 10k 张（常用 30k/50k），低于 5k 数值不可信。
  • 特征实现：明确 PyTorch InceptionV3 权重版本，不同实现差好几个点。
  • 预处理：resize 到 299、是否抗锯齿，都会影响结果。

② 主辅结合

  • 主指标：FID（真实度）+ CLIP Score（对齐）。
  • 辅指标：Precision/Recall 看是否模式崩溃；多样性可看特征方差或去重率。
  • 再做 200-500 组人工二选一，覆盖主指标无法判断的审美。

③ 分场景评测

  • 不要只报一个总分，要按类别拆分：人像 / 场景 / 文字 / 抽象。
  • 按 prompt 难度分层：简单主体 vs 复杂多主体关系。
  • 关注最差 10% 的样本，往往比均值更能说明上线风险。

④ 报告规范

  • 写清：样本数、分辨率、采样步数、CFG、种子策略、特征实现。
  • 同时给出均值与方差（多种子）。
  • 横向对比必须在同一评测脚本下重跑对手模型，别直接抄论文数字。
10k+FID 可信样本下限
30k/50k论文常用
CFG影响 FID 巨大，必须固定
步数采样步数需报告
多主体最难，单独分层

深入自检

FID 是不是越低越好？

在真实度维度是的，但要警惕「用多样性换 FID」：模型只生成最容易的几种图像时 FID 会下降，但 Recall 暴跌。所以必须同时看 Precision/Recall 或多样性指标，否则会选出「很真实但很无聊」的模型。

为什么我复现的 FID 和论文差这么多？

最常见的四个原因：样本量不同、Inception 权重/预处理不同、生成分辨率不同、采样步数与 CFG 不同。这四项任一不一致，差 10-30% 都很正常。务必在同一脚本下重跑基线。

CLIP Score 能替代人工评测吗？

不能。CLIP 擅长判断「大致主题对不对」，但对数量（三只猫 vs 两只猫）、空间关系（左边/右边）、属性绑定（红色的球、蓝色的盒子）几乎不敏感。这些恰恰是用户最常抱怨的点。

有参考图时该用哪个？

要判断「像不像」用 LPIPS（感知层，最贴合人眼）；PSNR/SSIM 只在需要像素级保真（如压缩、超分复原）时参考，因为它们经常给出与观感相反的结论。超分任务尤其要警惕 PSNR 高但画面过度平滑。

如何检测模式崩溃？

三种方法：① 看 Recall 是否明显低于 Precision；② 随机抽 1000 张算两两 LPIPS，平均距离过小说明高度重复；③ 直接肉眼扫 100 张，人眼对重复极其敏感。

评测集应该多大才够？

FID 至少 10k 张生成图 + 同规模真实参考集；人工评测 200-500 组二选一可获得较稳定排序；如果只做内部迭代（不对外发数字），5k 张 + 100 组人工也能支撑相对比较，但别把绝对值写进报告。
