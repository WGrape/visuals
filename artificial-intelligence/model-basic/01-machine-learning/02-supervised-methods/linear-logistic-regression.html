线性与逻辑回归：从分数到预测

给定输入与标签，先用最简单的线性模型建立基线：连续值用线性回归，二分类常用逻辑回归。两者都从特征的加权组合出发，却回答不同问题。

从学习任务进入第一个可训练模型：先把输入变成分数，再决定预测的是数值还是概率。

三个关键机制

线性回归

预测连续数值，如销量或耗时；常以均方误差衡量偏差，需检查异常值影响。

逻辑回归

将线性分数经 Sigmoid 映射到 0～1 的概率，常配合交叉熵训练二分类模型。

正则化与特征

L1/L2 约束参数，特征缩放与编码影响优化；相关性不等于因果解释。

对照与边界

任务输出关注指标
预测单量连续数值MAE / RMSE
是否违约正类概率与分类阈值精确率 / 召回率
是否多类别按实现选多类策略类别分布与混淆
带入一个具体问题假设模型给出“订单会取消”的概率 0.72：它不代表已经发生，也不意味着阈值一定是 0.5。拦截成本很高时，要在验证集上选择阈值并检查校准。

选一个场景，试着做判断

点击切换场景，比较为什么同一方法不能直接套用到所有问题。

目标是明天销售额连续值回归更自然，先用线性回归设基线，再对照非线性方法。

记住这个边界

“逻辑回归”名字里有回归，常用于分类；Sigmoid 输出是概率估计，并非因果效应。
