NP 完全性归约：从 3-SAT 到顶点覆盖

亲手构造变量边与子句三角形，理解“答案保持”如何证明一个问题至少一样难。

证明 NP 完全需要两件事

顶点覆盖问题问：给定图 G 与整数 k，是否能选至多 k 个顶点，使每条边至少有一个端点被选中。要说明它是 NP 完全，一方面给出候选顶点集合后可在多项式时间检查所有边，因此问题属于 NP；另一方面把已知 NP 完全的 3-SAT 多项式归约到它，说明顶点覆盖至少与 3-SAT 一样难。只证明“能快速验证”并不能推出 NP 完全，方向写反也不能传递困难性。

3-SAT 输入是若干子句的合取，每个子句有三个文字，文字是变量或其否定。归约需要把任意公式变成图和 k，并保持“公式可满足，当且仅当图有不超过 k 个顶点的覆盖”。构造本身不能先知道公式是否可满足，否则就把困难问题藏进了构造步骤。

逐步推演

转换变量

每个变量建正反文字两个顶点与一条边。

转换子句

每个三文字子句建三角形，连接到对应变量文字。

设定预算

令 k=n+2m，使局部最低选择数用满预算。

证明等价

分别从满足赋值构造覆盖、从覆盖还原满足赋值。

变量边、子句三角形和连接边

对每个变量 x_i 建两个顶点 x_i 与 ¬x_i，并用一条边连接，迫使覆盖至少选其中一个。对每个三文字子句建三个代表其文字出现的顶点，互相连接成三角形，迫使覆盖至少选两个。再把每个子句文字顶点连接到对应的变量文字顶点。若有 n 个变量、m 个子句，设置 k=n+2m。图规模随公式线性增长，构造可以在多项式时间内完成。

构件顶点覆盖最低需求逻辑含义
变量边 x_i—¬x_i至少选 1 个为变量作真假选择
子句三角形至少选 2 个留下一个文字顶点不选
文字连接边不选的子句顶点须由变量端覆盖留下的文字必须为真
预算 k=n+2m恰好达到所有局部下界不能额外随意补救矛盾

为什么答案双向保持

若公式有满足赋值，在每条变量边选择代表真文字的顶点；每个子句至少有一个真文字，留下其中一个对应的子句顶点不选，其余两个选中。变量边和子句三角形都被覆盖；未选子句顶点到变量端的连接边，由那个为真的变量文字顶点覆盖。总数正好 n+2m。

反过来，若图存在大小至多 n+2m 的覆盖，每条变量边至少需一个、每个子句三角形至少需两个，这已经用满预算。因此每条变量边恰好选一个、每个三角形恰好留下一个。把选中的变量文字解释为真；每个未选的子句文字顶点与相应变量文字顶点之间有边，为覆盖该边，对应变量文字顶点必须被选中，所以每个子句至少有一个真文字。两方向都证明后，归约才完整。

用小公式检查构造

考虑一个子句 (x∨¬y∨z)，有三个变量、一个子句，所以预算 k=3+2=5。赋值 x=true、y=false、z=false 可满足公式。变量边选 x、¬y、¬z，子句三角形留 x 的顶点不选，选另两个，共五个顶点。若换成不可满足公式，想让所有子句各留一个真文字就会失败；不能靠第六个顶点补救，因为预算固定为 n+2m。

  1. 先画变量边和一个子句三角形，数清必须选择的最少顶点。
  2. 检查连接边连向的是同一个文字，而不是它的否定；连错会使证明方向改变。
  3. 证明构造复杂度、属于 NP、正向与反向，而不是只给一个满足赋值例子。

练习：若仅证明“公式可满足 ⇒ 有顶点覆盖”，还缺哪一半？为什么不能据此宣称两个问题等价？

把构造当成一次预算审计

变量部分至少要 n 个顶点，子句部分至少要 2m 个，两个下界加起来恰好是 k。这个“预算刚好用满”是反向证明的核心：如果某变量边选了两个端点，就必须有另一处少选一个，但子句三角形和其余变量边都达不到更低，所以不可能。于是每个变量边都恰好选一个，才能把选择解释成一致的真假赋值。

顶点覆盖与独立集还有一个简单关系：在同一图中，S 是顶点覆盖，当且仅当剩余顶点 V∖S 没有内部边，即形成独立集。它帮助检查手算结果，却不能取代 3-SAT 归约的多项式构造和双向证明。NP 完全性是最坏情况复杂度结论，不表示每个小图都难；实际求解器、剪枝和近似算法在许多实例上仍很有用。

构造规模检查

若原公式有 n 个变量、m 个子句，变量部分有 2n 个顶点，子句部分有 3m 个顶点，外加变量边、三角形边和文字连接边，总规模随输入线性增长。写归约时明确规模，才能证明构造是多项式时间，而不只是逻辑上可想象。

归约构造的三块组件

组件构造数量作用
变量 gadget每个变量 x 建一条边，两端是文字 x 与 ¬xn 条边迫使覆盖至少选一个文字（对应赋真值）
子句 gadget每个子句建一个三角形（3 个顶点两两相连）3m 个顶点、3m 条边覆盖一个三角形至少要 2 个点
连接边子句里的文字顶点与变量 gadget 中同名文字顶点连边3m 条边让「选变量赋值」能顺带覆盖子句的边
参数 kk = n + 2m—n 个变量各选 1 个 + m 个三角形各选 2 个

构造规模：顶点数 2n + 3m、边数 n + 6m，均为输入规模的多项式（线性），因此是合法的多项式归约。

手算示例：2 变量 2 子句

实例：(x₁ ∨ ¬x₂) ∧ (¬x₁ ∨ x₂ ∨ x₂)，即 n=2、m=2。

项取值说明
变量 gadget边 (x₁, ¬x₁)、边 (x₂, ¬x₂)2 条边
子句 1 三角形顶点 (x₁)₁、(¬x₂)₁、(aux)₁3 个顶点、3 条边
子句 2 三角形顶点 (¬x₁)₂、(x₂)₂、(x₂)₂'3 个顶点、3 条边（重复文字用独立顶点）
连接边每个子句顶点连到变量 gadget 的同名端点6 条边
kn + 2m = 2 + 4 = 6要求找出 6 个点的覆盖
  • Yes 方向：若公式可满足，取每个变量为真的那个文字（共 n 个），每个子句至少有一个真文字，再从该子句三角形里补 2 个点覆盖剩余两条边（共 2m 个），总计 n+2m = k，构成合法覆盖。
  • No 方向：若存在大小 k 的覆盖，变量 gadget 的 n 条 disjoint 边各需至少 1 点（用掉 n 个），剩下 2m 个点要覆盖 m 个三角形，每个三角形恰好用 2 个点；未被选中的那条边必须由「连接边」那侧的顶点覆盖，从而导出一个满足赋值。
  • 关键校验点：变量 gadget 的边两两不相交，所以「至少 n 个点」是硬下界——这正是 k 取 n+2m 的原因。

可执行的构造与校验

构造

def sat3_to_vertex_cover(clauses, n_vars):
    """clauses: [[literal, ...], ...]，literal 为带符号整数（+1 表示 x1，-1 表示 ¬x1）"""
    verts, edges = set(), []
    # 1) 变量 gadget：每个变量一条边，两端为 x 与 ¬x
    for i in range(1, n_vars + 1):
        verts.add(("v", i, True)); verts.add(("v", i, False))
        edges.append((("v", i, True), ("v", i, False)))
    # 2) 子句 gadget：三角形
    for ci, cl in enumerate(clauses):
        tri = []
        for li, lit in enumerate(cl):
            v = ("c", ci, li, abs(lit), lit > 0)
            verts.add(v); tri.append(v)
        for a in range(len(tri)):
            for b in range(a + 1, len(tri)):
                edges.append((tri[a], tri[b]))      # 三角形内部 3 条边
        # 3) 连接边：子句顶点 <-> 变量 gadget 的同名端点
        for v in tri:
            edges.append((v, ("v", abs(v[3]), v[4])))
    k = n_vars + 2 * len(clauses)                    # 关键：k = n + 2m
    return list(verts), edges, k

def is_cover(edges, chosen):
    chosen = set(chosen)
    return all((u in chosen or v in chosen) for u, v in edges)

常见错误与排障清单

症状原因处理
k 取错（如只写 m 或 2m）忘了变量 gadget 的硬下界 nk 必须等于 n + 2m
No 方向证不过没用「三角形至少要 2 个点」推出剩余点数明确 n 条不相交边各需 1 点，剩余 2m 分给 m 个三角形
把重复文字合并成一个顶点子句里有重复文字时三角形退化重复文字用独立顶点（如本例的 x₂ 出现两次）
忘记连接边子句覆盖与变量赋值脱钩每个子句顶点必须连到同名变量端点
归约方向写反从 Vertex Cover 归约到 3SAT要证 VC 是 NP-hard，方向必须是 3SAT ≤p VC
只证了 Yes 方向缺少 No→No（或逆否）两个方向都要写完整

深入自检

为什么变量 gadget 要做成一条边？

因为覆盖一条边至少要选一个端点，这恰好对应「变量必须取一个真值」；而且各变量的边两两不相交，n 条边就需要至少 n 个点，构成 k 中不可压缩的下界。

k 为什么恰好是 n + 2m？

n 来自 n 条不相交的变量边各需 1 点；2m 来自 m 个三角形各需 2 点（三角形 3 条边，选 2 点可全覆盖，选 1 点只能覆盖 2 条）。合计 n+2m，正好让「可满足」与「存在 k 覆盖」等价。

子句里重复出现同一个文字怎么办？

要建多个独立顶点（每个出现位置一个），否则三角形会退化成两点一条边，「至少要 2 个点」的论证就失效。本例中 x₂ 出现两次，对应两个独立顶点。

这个归约说明什么？

说明 Vertex Cover 至少和 3SAT 一样难，即 Vertex Cover 是 NP-hard；再加上「给定点集可在多项式时间验证是否为覆盖」，它就是 NP-complete。注意方向：是 3SAT 归约到 VC，不是反过来。

如何从覆盖反推出赋值？

看变量 gadget 上哪个端点被选中：选中 x 的端点则令 x 为真，选中 ¬x 则为假。由于覆盖大小恰好为 k，被选中的子句顶点会强制对应的文字端点也在覆盖里，从而保证每个子句至少有一个真文字。

自检

预算为什么设为 n+2m？

变量边各需至少一个，子句三角形各需至少两个，预算刚好等于这些局部下界之和。

3-SAT 到顶点覆盖的归约能推出哪个问题至少一样难？

顶点覆盖至少与 3-SAT 一样难；若顶点覆盖有多项式算法，就能用它解 3-SAT。
