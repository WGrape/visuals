数据血缘

血缘记录“数据从哪来、经过什么加工、到哪去”。当指标异常时，可顺藤摸瓜定位根因；字段下线前也能评估影响面。

治理平台

Apache Atlas 等平台把 Hive/Kafka 的元数据与血缘统一管理，配合标签（tag）、分类与权限，构成数据治理的基础。

🎯 面试问答

Q：血缘是自动采集还是手填？
A：优先自动解析 SQL/任务依赖采集，减少人工维护；关键业务口径再人工补充。
Q：没有血缘会怎样？
A：数据出问题难定位、影响评估靠喊人、合规审计无法举证。
