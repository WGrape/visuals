01查询语言：InfluxQL 与 Flux

语言风格状态示例
InfluxQL类 SQL，易上手1.x 主力，2.x 仍支持 SELECT mean(usage) FROM cpu WHERE host='web1' AND time > now()-1h GROUP BY time(1m)
Flux函数式管道，能力强2.x 主推 from(bucket:"m") |> range(start:-1h) |> filter(fn:(r)=>r.host=="web1") |> aggregateWindow(every:1m, fn:mean)

Flux 在 2.x 提供函数式数据处理，InfluxQL 采用类 SQL 风格；可用语法与兼容方式需按实例版本核对。3.x 不应沿用本页的 Flux 查询示例。

-- InfluxQL 常用模式
-- 1. 时间窗口聚合（降采样的核心）
SELECT mean("usage_user") FROM "cpu"
WHERE time > now() - 6h
GROUP BY time(5m), "host"          -- 按 5 分钟窗口、按 host 分组

-- 2. 填充缺失值（避免图表断点）
GROUP BY time(1m) fill(previous)

-- 3. 保留策略查询
SELECT * FROM "autogen"."cpu"       -- 指定 RP
