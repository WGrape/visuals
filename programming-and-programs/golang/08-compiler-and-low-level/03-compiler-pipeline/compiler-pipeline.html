词法分析（scanner）

字符流切成 token

扫描器跳过空白注释，把关键字、标识符、运算符、字面量识别成 token 流，供解析器消费。

// 源码: x := 1 + 2
// token 流: IDENT(x) DEFINE(:=) INT(1) ADD(+) INT(2)
语法分析（parser）

token 组成 AST

解析器按语法规则把 token 流构造成抽象语法树（AST），表达式、语句、声明都成了树节点。

// x := 1 + 2 的 AST 片段
AssignStmt {
  Name: Ident("x")
  Value: BinaryExpr {
    Op: ADD
    L: BasicLit(1)  R: BasicLit(2)
  }
}
类型检查

语义校验 + 类型推导

遍历 AST 检查类型是否匹配、标识符是否声明、隐式转换（如无类型常量）如何处理，并把推导出的类型写回 AST 节点。

Go 是强类型，类型检查能在编译期拦下大量错误；同时它还处理「无类型常量」的延迟定型（如 1 在浮点上下文变 float）。
前端的产出

交给中端后端

经过类型检查的 AST 被转换成更规整的中间表示（SSA 前身），进入中端优化与后端机器码生成（见下一篇）。

调试入口
