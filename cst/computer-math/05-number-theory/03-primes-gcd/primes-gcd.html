素数与欧几里得算法

整数的原子，以及求最大公约数的千年高效算法。

素数：整数的原子

素数是大于 1、且只能被 1 和自身整除的正整数（2,3,5,7,11…）。算术基本定理告诉我们：每个大于 1 的整数都能唯一分解成素数乘积——素数就是整数的"原子"。

如何判定素数

  • 试除法：只需试到 √n。若都没有因子，则 n 是素数。简单但慢。
  • 埃拉托斯特尼筛法：从 2 开始，划掉每个素数的倍数，剩下的就是素数。适合批量求小范围内的素数。
为什么素数对密码学重要？两个大素数相乘很容易，但要把乘积反推回这两个素数却极难——这就是 RSA 的安全基石。

最大公约数 gcd

gcd(a,b)是能同时整除 a、b 的最大正整数。例如 gcd(12,18)=6。求 gcd 在约分、调度周期、以及求模逆元时都是关键步骤。

欧几里得算法：辗转相除

核心原理：gcd(a,b) = gcd(b, a mod b)。不断用余数替换较大的数，直到余数为 0，此时的非零数就是 gcd。两千年前的算法，至今无可替代地高效（步数不超过较小数位数的 5 倍）。

def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

扩展欧几里得：顺手求模逆元

不仅能求 gcd，还能找到整数 x、y 使 a·x + b·y = gcd(a,b)。当 gcd(a,n)=1 时，x mod n 就是 a 在模 n 下的逆元——RSA 解密离不开它。

def egcd(a, b):
    if b == 0: return (a, 1, 0)
    g, x1, y1 = egcd(b, a % b)
    return (g, y1, x1 - (a//b)*y1)

应用：密钥交换前奏与任务调度

密钥交换

Diffie-Hellman 依赖在模素数下"离散对数难"；其前置正是 gcd 与逆元计算。

任务调度

两个周期任务分别每 a、b 单位触发，最小公倍 lcm(a,b)=a·b/gcd(a,b) 给出重合周期。
