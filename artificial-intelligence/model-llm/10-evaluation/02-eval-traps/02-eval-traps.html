评测的陷阱：基准污染、数据泄漏与指标自欺

基准分数上升不等于变好，警惕污染、泄漏与指标自欺。

1评测不是跑分

基准分数上升 ≠ 模型变好。工业界反复踩的坑是：分数被"刷"上去，但真实任务没改善。问题出在评测本身的污染、泄漏与指标自欺。理解这些陷阱，比多跑几个 benchmark 更重要。

危险信号：新模型在某基准暴涨，但你的业务样本没变；或"改进"恰好落在公开测试集的分布上。

2三大陷阱

陷阱机制后果
基准污染训练数据含测试题/近似题分数虚高，泛化被高估
数据泄漏评测集混入训练/微调分布无法区分记忆与能力
指标自欺选有利指标、平均掩盖长尾整体好、长尾崩

3用 n-gram 重叠粗筛污染

def overlap(a, b, n=5):
    def grams(s): return set(tuple(s[i:i+n]) for i in range(len(s)-n+1))
    A, B = grams(a), grams(b)
    return len(A & B) / max(1, len(A))

# 若评测题与训练语料高度重叠，则可能被污染
for q in eval_questions:
    score = max(overlap(q, doc) for doc in training_corpus_sample)
    if score > 0.6:
        print("疑似污染:", q[:40], score)

这是粗筛；正式防污染还需去重、时间切分（用晚于训练截止的题）与私有保留集。

4分数与真实能力的裂缝

图：刷榜使基准分数与真实能力背离

第一层 · 概念与判定

判定评测是否可信：

  • 评测集是否早于训练数据截止日（时间切分）；
  • 是否存在与训练集的 n-gram/语义重叠；
  • 指标是否掩盖了关键子群体的失败；
  • 是否有独立、不可被"针对性调参"碰到的保留集。

第二层 · 参数·命令·量化

量化做法：

手段操作
去重训练与评测做 MinHash/SimHash 去重，阈值如 Jaccard<0.8
时间窗评测题发布时间晚于训练截止
分层抽样按难度/领域分层报分，不只给 macro 平均
# 分层抽样报分，暴露长尾
for group in groups:
    print(group, acc(results[group]))

第三层 · 排障与边界

排障：

  • 发现污染：删除重叠样本重测，或用污染检测工具（如 Min-K%）；
  • 指标自欺：补充难例集、对抗集，避免只报简单平均；
  • 刷榜式过拟合：保留集在调参全程不可见；
  • 人类偏好失真：A/B 用小样本易噪声，需足够样本与显著性。

第四层 · 原理与取舍

原理取舍：

  • 公开基准利于比较，却天然吸引针对优化（ Goodhart 定律）；
  • 越细的指标越真实，但标注与维护成本越高；
  • 自动化指标（BLEU/准确率）与真实效用常不一致；
  • 结论：把评测当"假设检验"而非"分数竞赛"，保留集与污染检测是底线。
