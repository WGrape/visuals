朴素 LFU 问题

只累加访问次数：早期高频项频率长期最高，即使已不再热，新热点也难以挤入；且计数无上限会溢出。

频率衰减与对数递增

用对数递增（如 counter = log 增长）避免数值暴涨；定期衰减（频率减半），让历史热度随时间淡去，新热点有机会上位。

Redis LFU

Redis 用 8bit 计数器 + 衰减因子 lfu-decay-time，访问概率性 +1，随时间衰减，兼顾抗扫描与时效性。

🎯 面试问答

Q：LFU 为什么需要衰减？
A：避免历史高频项长期占优，影响新热点。
Q：对数递增有什么用？
A：让计数平滑增长，避免迅速触顶。
Q：Redis LFU 计数几位？
A：8 bit，配合衰减与概率递增。
