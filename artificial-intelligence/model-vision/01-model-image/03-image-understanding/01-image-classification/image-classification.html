图像分类：从特征到类别决策

一张图如何得到类别分数，哪些置信度和数据陷阱不能忽视。

学完能解释什么

  • 分清特征编码、分类头与类别分数
  • 区分单标签 softmax 和多标签 sigmoid
  • 用混淆矩阵与分层评估定位偏差，而不只看总体准确率

逐步看机制

统一输入与标签规则

尺寸、色彩空间与归一化必须与训练时一致；训练/验证集按来源隔离，避免同一物体的近重复图跨集合泄漏。

“图里有什么”是整图问题

分类器回答整张输入图像属于什么类别，不给物体的框或逐像素范围。设特征编码器输出向量 h，线性分类头给每类一个 logit：z = Wh + b。分数高说明模型更偏向这一类，不表示它找到了物体位置。

猫和狗互斥时可以使用 softmax 与交叉熵；一张图同时有“汽车”和“夜景”时是多标签任务，各标签独立用 sigmoid，不能强迫概率和为 1。

为什么高准确率可能骗人

若 95% 的图都是“正常”，模型永远猜“正常”也有 95% 准确率，却不能发现异常。至少按类别查看精确率、召回率及混淆情况；部署场景还要按光照、拍摄设备、遮挡和地域切片。训练集与测试集共用同一视频的相邻帧会造成泄漏，评估应按视频或主体隔离。

Top-1 是最高分类别是否正确；Top-5 允许正确类落在前五名，更适合类别很多的任务，但不能代替风险业务的误报/漏报分析。

判定前先问三个问题

  • 标签互斥吗？如果不是，改成多标签建模和逐类阈值。
  • 模型是否依赖背景？遮住主体或换背景，比较预测是否剧变。
  • 分数要拿来做自动决策吗？先做校准和人工复核阈值评估。

当业务需要“在哪里”而不是“是否存在”，下一步应学目标检测或分割，不要用分类模型的热力图冒充可靠边界。

自检

一张图片同时有猫和狗，为什么不宜直接用互斥 softmax？

softmax 让类别概率竞争、总和为 1；多标签图像需要各类别独立预测，通常使用 sigmoid 和逐类阈值。

训练图像分类的实用技巧

迁移学习（最实用）

不要从零训练。做法：加载在 ImageNet 上预训练的权重 → 替换最后的分类头 → 用较小的学习率（如 1e-4）在自己的数据上微调。小数据集（几千张）也往往能取得很好的效果。

数据增强

随机裁剪、水平翻转、色彩抖动、随机擦除（Random Erasing）、MixUp、CutMix。本质是人为扩大数据分布，让模型见过更多变化，减少过拟合。

学习率策略

常用 warmup + 余弦退火：先用小学习率预热几轮，再逐步升到峰值，最后按余弦曲线降到接近 0。比固定学习率通常能高 1~2 个点。

处理类别不平衡

用加权交叉熵（少数类权重大）、过采样/欠采样、或 Focal Loss（降低易分样本的权重，让模型专注难样本）。评估时别只看整体准确率，要看每类的召回。

指标怎么读

Top-1 准确率预测概率最高的那个类别是否正确——最严格
Top-5 准确率正确类别是否出现在前 5 个预测里——ImageNet 常用
混淆矩阵看清「哪两类容易搞混」，比单一数字有用得多
每类 PR找出薄弱类别，指导补数据
校准度 ECE预测概率与真实正确率是否一致，影响阈值设定

深入自检

为什么深层网络曾经更难训练，残差连接怎么解决的？

理论上网络越深表达力越强，但实践中深层网络的训练误差反而更高（不是过拟合，是退化问题）——深层梯度在反向传播中逐层衰减，前面的层几乎学不到东西。残差连接加了一条恒等映射的捷径：输出 = F(x) + x，梯度可以沿这条捷径无损回传。更妙的是，如果某层学不到有用的东西，F(x) 会趋向 0，输出退化为输入 x，至少不会比不加深更差。这把「加深」从风险变成了收益。

只有几百张图片，还能做图像分类吗？

能，用迁移学习。加载 ImageNet 预训练权重，替换最后的分类头，冻结大部分层（或全部层只训练分类头），用较小的学习率微调。预训练模型已经学会了边缘、纹理、形状等通用视觉特征，这些在小数据集上依然有效。经验：几千张图微调能达到从零训练几十万张的效果。数据少于几百张时可以只训练分类头。

准确率高但线上效果差，可能是什么原因？

常见四类：①数据分布不一致——训练集是网上爬的清晰图，线上是手机拍的模糊/暗光图（domain shift）；②类别不平衡——整体准确率被多数类拉高，关键少数类召回很低；③预处理不一致——训练时做了归一化/Resize，线上忘了做或参数不同；④评估集有泄露——训练集和测试集有重复图片。排查方式是拿真实线上数据做一个小测试集，按场景拆分看准确率。

CNN 和 ViT 该怎么选？

看数据量。CNN（ResNet、EfficientNet）有内置的局部性和平移不变性先验，中小数据（几万张以内）上通常更优，且推理快、生态成熟。ViT 缺少这些先验，需要大数据预训练（几百万到几十亿张）才能发挥优势；一旦预训练充分，它的上限更高、迁移性更好，而且与多模态模型（CLIP 等）天然统一。实践建议：数据少用 CNN 或预训练 ViT；数据充足且要接多模态，用 ViT。

Top-1 和 Top-5 准确率差很多说明什么？

说明模型「知道大概是什么，但不够确定」——正确类别常常排在 2~5 位。典型原因：类别定义过细（如 1000 个犬种）、类间相似度高、或训练数据不足。如果业务允许「给出几个候选让人选」，Top-5 高就够用；如果必须唯一确定，就要针对易混类别补充数据或调整类别体系（合并相近类）。

import torch, torchvision
from torch import nn

# 微调（迁移学习）
model = torchvision.models.resnet50(weights="IMAGENET1K_V2")
model.fc = nn.Linear(2048, num_classes)

# 分层学习率（backbone 小、头大）
opt = torch.optim.SGD([
    {"params": model.fc.parameters(), "lr": 1e-2},
    {"params": model.layer4.parameters(), "lr": 1e-3},
    {"params": model.parameters(), "lr": 1e-4},     # 其余（含 layer1~3）
], momentum=0.9, weight_decay=1e-4)

# 混合精度（省显存约 40%，快 1.5~3 倍）
scaler = torch.cuda.amp.GradScaler()
for x, y in loader:
    with torch.autocast("cuda"):
        out = model(x); loss = criterion(out, y)
    scaler.scale(loss).backward()
    scaler.step(opt); scaler.update(); opt.zero_grad()

# 标签平滑
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
# 推理优化（上线必做）
model.eval()
# 1) torch.compile（PyTorch 2.0+，一行 1.3~2x）
model = torch.compile(model)
# 2) 半精度
model = model.half()

    out = model(x)

排障清单

症状原因处理
用了预训练但准确率极低归一化没用 ImageNet 统计量必须用相同的 mean/std；检查输入是否在 [0,1]
训练 loss 不降学习率太大/太小；或梯度消失先用 1e-3 的 1/10 试；加 warmup；检查数据标签
验证集准确率远高于测试集数据泄漏 / 验证集来自训练集检查切分；按时间或主体切分而不是随机
类别不平衡长尾类差头部类主导加权采样；focal loss；两阶段（先全量后重采样微调）
推理延迟不达标模型大 / 没开 batch / 没量化换小模型；开 batch；FP16/INT8
相似类别混淆类间差异小（如车型）加细粒度特征（更高分辨率）；用注意力；加难例挖掘
部署后效果与训练时不一致前后处理不一致把预处理固化进模型（或用同一份代码）；检查 resize 插值方式

最常见的部署坑：训练用 bicubic 插值、部署用 bilinear，或者训练时做了 /255 而部署忘了。这类不一致能造成 2~5 个点的精度损失。解决办法是把预处理写进模型导出图里。
