线性代数：把“很多个数”当成一个对象

向量、矩阵、变换、分解——线性代数给计算机提供了批量处理数值的语言，也是图形学、机器学习和数值计算的底座。

核心速览

向量 vector

一串有序数字，既是空间中的点，也是一条带方向的箭头

矩阵 matrix

数字的矩形阵列，本质是「一个线性变换」的操作说明书

线性变换

保持加法与数乘的映射：直线仍变直线、原点不动

分解 decomposition

把复杂矩阵拆成简单因子（LU/QR/SVD/EVD），换来可解性与洞察

为什么计算机科学离不开线性代数

如果说微积分研究「连续变化的量」，那么线性代数研究的是成批出现的量以及它们之间的线性关系。一个 1920×1080 的彩色图片就是 1920×1080×3 个数字；一个批次的 128 条样本、每条 768 维的 embedding 就是一个 128×768 的矩阵。逐个写循环处理不但慢，而且难以表达；线性代数让我们一次写出「对整个批次做同一件事」的公式，再交给 BLAS / GPU 高效执行。

一句话记住主线：向量是「东西」，矩阵是「动作」，矩阵乘向量就是「让动作发生在东西上」。后面所有的行列式、特征值、分解，都是在问：这个动作有什么性质？

四条必须掌握的基本运算

运算写法形状规则直觉
加减A ± B形状必须相同，逐元素算两张表逐格相加
数乘cA形状不变整体缩放
矩阵×向量A x(m×n)·(n×1) → (m×1)结果是 A 各列的线性组合，权重来自 x
矩阵×矩阵A B(m×k)·(k×n) → (m×n)「先做 B 再做 A」两个动作的复合

最容易踩的坑是矩阵乘法不满足交换律：AB ≠ BA。原因是「先旋转 90° 再水平拉伸」和「先水平拉伸再旋转 90°」结果完全不同——动作的顺序会改变结局。但结合律 (AB)C = A(BC) 成立，这正是矩阵乘法可以重排计算顺序来提速（如矩阵链乘法动态规划）的理论依据。

# 矩阵乘向量的两种等价视角（以 2×2 为例）
A = [[a, b],        x = [x1]
     [c, d]]            [x2]

# 视角一：点积视角（逐行）——每一行与 x 做内积
Ax = [a*x1 + b*x2]
     [c*x1 + d*x2]

# 视角二：列组合视角——结果是 A 的列向量按 x 加权求和
Ax = x1 * [a]  +  x2 * [b]
          [c]          [d]

第二种视角更「高级」：Ax 的所有可能结果，就是 A 的列向量张成的空间（列空间）。判断 Ax = b 是否有解，等价于判断 b 是否落在 A 的列空间里——这比解方程本身更本质。

四大子空间：解方程的几何图

对任意 m×n 矩阵 A，有四个天然的子空间，它们的维数由一个数字秩 rank串起来：

列空间 Col(A)

A 的各列张成的空间，位于 ℝᵐ；维数 = r。Ax=b 有解 ⇔ b ∈ Col(A)

零空间 Null(A)

满足 Ax=0 的所有 x，位于 ℝⁿ；维数 = n−r。解不唯一时，零空间就是「自由度高多少」

行空间 Row(A)

A 的各行张成的空间，位于 ℝⁿ；维数也是 r（行秩 = 列秩，这是个非平凡的定理）

左零空间

满足 Aᵀy=0 的 y，位于 ℝᵐ；维数 = m−r。与「相容性约束」有关

由此得到秩-零化度定理：rank(A) + dim Null(A) = n。解线性方程组 Ax=b 的完整结构一目了然：

  • r = m = n（满秩方阵）：唯一解，x = A⁻¹b；
  • r = n < m（列满秩，方程多于未知数）：要么无解，要么唯一解（最小二乘的经典场景）；
  • r = m < n（行满秩，未知数多于方程）：一定有无穷多解；
  • r < min(m,n)：要么无解，要么无穷多解。

场景矩阵是谁在算什么

实践提醒：真正写代码时不要手写三重循环，也不要轻易去求逆矩阵。数值稳定的做法是调用成熟的分解（LU / QR / SVD），让库去处理主元选择、条件数与浮点误差。

常见误区

  • 「矩阵就是一堆数」——更准确的说法是「矩阵是一个线性变换在一组基下的表示」。换一组基，同一个变换的矩阵就变了，但行列式、特征值、秩这些不随基改变的量才真正刻画变换本身。
  • 「求逆就能解所有方程」——求逆代价高（O(n³)）且数值不稳定；更要命的是很多矩阵根本不可逆（秩亏），此时要用伪逆 / 正则化（岭回归就是在 XᵀX 上加 λI 让它可逆）。
  • 「AᵀA 一定可逆」——只有 A 列满秩时才成立；样本数少于特征数时 XᵀX 必然奇异，这也是高维小样本必须正则化的原因。

🎯 常见问法与答题要点

Q：向量和矩阵的本质区别是什么？

A：向量是空间中的一个对象（点或箭头），矩阵是对空间施加的一个动作（线性变换）。矩阵乘向量 = 把动作作用在对象上得到新对象。之所以容易混淆，是因为矩阵本身也可以被看成「一堆列向量」，而矩阵乘矩阵就是两个动作的复合（先右后左）。

Q：什么是线性变换？为什么要求「线性」？

A：满足 T(u+v)=T(u)+T(v) 且 T(cu)=cT(u) 的映射。线性带来两个巨大好处：① 整个变换由它在基向量上的行为完全决定，于是有限个数字（矩阵）就能描述无限多个点的变换；② 线性保证叠加原理成立，可以把复杂输入拆成简单部分分别处理后相加——这是傅里叶分析、卷积、特征值分解的共同前提。

Q：矩阵乘法为什么不满足交换律？

A：因为矩阵乘法是动作复合，而动作的顺序会改变结果。例如「先旋转 90° 再沿 x 轴拉伸」与「先沿 x 轴拉伸再旋转 90°」得到的形状不同。但结合律成立（复合动作天然满足结合律），所以 A(BC)=(AB)C，这让我们可以自由调整计算顺序以最小化代价（矩阵链乘法）。

Q：秩 rank 到底在衡量什么？

A：秩 = 矩阵真正「有效」的独立方向个数，也就是列空间的维数。秩越小，说明各行/各列之间存在越多线性依赖，信息被压缩得越厉害。工程上的直接用途：判断方程是否有解/唯一解、判断特征是否冗余（多重共线性）、做低秩近似压缩（SVD 截断后只保留前 k 个奇异值）。

Q：为什么数值计算里总说「不要直接求逆」？

A：三个原因：① 慢——求逆与解一个方程同为 O(n³) 但常数更大；② 不稳——当矩阵接近奇异（条件数很大）时，求逆会把浮点误差放大几个数量级；③ 没必要——要解 Ax=b 用 LU/QR 分解直接解，要最小二乘用 QR/SVD，都比显式构造 A⁻¹ 更精确。

Q：线性代数在机器学习里最核心的用处有哪些？

A：① 批量表达：一次矩阵乘法处理整个 batch；② 表示学习：embedding 本质是高维向量，相似度是内积；③ 降维与压缩：PCA / SVD 保留主要方向；④ 求解：线性回归闭式解、最小二乘；⑤ 图谱与稳态：PageRank、马尔可夫链稳态即主特征向量；⑥ 注意力机制：Q·Kᵀ 算相似度矩阵，softmax 后乘 V，全是矩阵运算。

NumPy 速查

import numpy as np

A = np.array([[2.0, 1.0], [1.0, 3.0]])

np.linalg.det(A)                     # 行列式 = 5.0
np.linalg.matrix_rank(A)             # 秩
w, V = np.linalg.eig(A)              # 特征值 / 特征向量
np.allclose(A @ V, V * w)            # 验证 Av = λv
np.trace(A), np.prod(w)              # 迹 == 特征值之和；det == 特征值之积

U, S, Vt = np.linalg.svd(A)          # SVD
np.allclose(A, U @ np.diag(S) @ Vt)  # 还原
S[0] / S[-1]                         # 条件数（2-范数）
np.linalg.cond(A)                    # 同上，库函数

# 解方程组：永远用 solve，不要 inv(A) @ b
x = np.linalg.solve(A, b)            # 快且稳
# x = np.linalg.inv(A) @ b           # 慢约 2~3 倍，误差也更大

一条贯穿全篇的实践原则：永远不要显式求逆矩阵。inv(A) @ b 比 solve(A, b) 慢且精度差（多了不必要的矩阵乘法与舍入）。同理，判断可逆不要用 det != 0（浮点下行列式可能被缩放成极小值），要用条件数或 matrix_rank。

特征值和奇异值什么关系？

奇异值是任意矩阵都有的（AᵀA 的特征值开根号），特征值只有方阵才有。关系：奇异值 σᵢ = √(λᵢ(AᵀA))；当 A 是对称半正定矩阵时，奇异值 == 特征值。实践中 SVD 更常用，因为它对方阵/非方阵都成立且数值稳定。

为什么 PCA 要用 SVD 而不是直接算协方差矩阵的特征分解？

两个原因：① 精度——显式算 XᵀX 会平方条件数，数据尺度差异大时丢精度；② 效率——样本数远小于维度时（如 100 个样本、10000 维），直接对 X 做 SVD 比对 10000×10000 的协方差矩阵做特征分解快得多。sklearn 的 PCA 默认就是走 SVD。

条件数大怎么办？

三条路：① 换算法——用 SVD/QR 而不是正规方程；② 加正则化——岭回归 (AᵀA + λI)⁻¹Aᵀb，λ 让最小奇异值不至于接近 0，这是「用少量偏差换大幅降低方差」；③ 预处理——对列做归一化/标准化，让各列量级接近。
