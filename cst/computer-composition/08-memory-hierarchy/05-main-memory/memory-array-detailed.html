内存的基本单位
内存的最小可寻址单位是 字节（Byte），1 Byte = 8 bit。 也就是说，内存中的每个格子（每个地址）存储 1 个字节，包含 8 个二进制位（0 或 1）。

📦 存储单位换算

1 Byte = 8 bit
1 KB = 1024 Bytes
1 MB = 1024 KB
1 GB = 1024 MB
1 TB = 1024 GB

🎯 地址是什么？

地址就是每个格子的"门牌号"。
32位系统最多有 2³² = 4,294,967,296 个地址
= 4GB 内存空间
每个地址对应 1 Byte

🔢 一个字节能存什么？

• 一个 ASCII 字符（如 'A'）
• 一个 0-255 的整数
• 8 个布尔值（true/false）
• 指令的一部分（如 MOV 操作码）

🔧 机器指令（代码段）

MOV ADD SUB JMP 等
这些是 CPU 能直接执行的二进制指令。
比如 MOV EAX, EBX 会被编译成若干字节。
程序运行时，CPU 从内存取出这些指令并执行。

📊 数据（变量、常量）

0x3F 1024 0xA5 等
程序中的变量值、数组元素、结构体字段。
比如 int x = 100; 会把 100 存入某地址。
数据可以被读取、修改、传递。

🏷️ 标识符/符号（调试信息）

R0 R1 FLG PTR 等
这些是程序员/调试器用的符号名。
实际运行时内存里存的是二进制值，
但可视化时我们用这些标签帮助理解。

地址是怎么算出来的？
内存地址从 0 开始递增。在 8×8 的阵列中，地址 = 行号 × 8 + 列号。 实际计算机中，地址计算更复杂，涉及 Bank、Row、Column 等多级解码。
📝 核心要点总结

1. 基本单位：内存最小可寻址单位是 1 Byte（字节） = 8 bit
2. 地址含义：每个地址对应一个 Byte，地址从 0 开始连续编号
3. 存储内容：内存是通用的，可以存指令、数据、指针、字符串等任何二进制信息
4. 多字节数据：int（4字节）、float（4字节）、double（8字节）等需要占用连续多个地址
5. 类型是概念：内存本身不知道类型，类型是程序/CPU解释数据的方式

一个 DRAM 单元有多简陋

DRAM 的每一个比特，只由一个晶体管 + 一个电容构成（1T1C）。电容里有电荷表示 1，没有表示 0。这就是它密度极高、成本极低的原因 —— 也是它麻烦一堆的原因。

1T1C 单元的三个麻烦：破坏性读出、漏电、信号微弱

对照 SRAM：CPU 里那几 MB 缓存用的 SRAM 是 6 个晶体管构成一个比特（6T），不需要刷新、读写快、结构稳定，代价是面积是 DRAM 的几倍、成本高得多。这就是为什么缓存那么小而内存那么大。

从一维到三维：bank/chip/rank/channel

内存条并不是一个扁平的字节数组，而是一个层层打包的结构：

channel 内存通道：CPU 到内存的一条独立总线（双通道 = 两条） └── DIMM 插在主板上的那根内存条 └── rank 条子上能被同时选中的一组芯片（常见 1~2 个 rank） └── chip 一颗物理 DRAM 芯片 └── bank 芯片内部的独立阵列（常见 16~32 个） └── row / column 行列组成的二维阵列 读一次数据的完整寻址： channel → rank → bank → row → column
层级作用为什么要这样
多 channel并行传输，直接乘带宽双通道/四通道几乎是「免费的带宽翻倍」
多 rank交替工作，隐藏刷新与预充电延迟同一时间只有一个 rank 能用数据总线
多 bank不同 bank 可并行激活不同行交替访问能大幅减少行冲突
row buffer一次把整行读出来暂存同行后续访问几乎免费

一条很重要的推论：如果你的访问模式能让读写分散在不同的 bank / rank / channel 上，实际吞吐会明显高于「集中在一个 bank 里反复换行」的访问。跨过了 mandates NAND 层次，就慢，这是物理结构决定的。

刷新：DRAM 逃不开的税

因为电容会漏电，控制器必须定期把每个单元读出来再写回去 —— 这就是刷新。行业标准通常是 在 64 毫秒内把所有行刷新一遍。

刷新命令控制器按行周期性地发出 refresh 命令。
占用时间每次会占住一小段时间，期间不能正常读写。
占比整体开销通常在个位数百分比量级，但对延迟敏感的场景不可忽略。
自刷新系统休眠时 DRAM 自己维持刷新以保数据，功耗很低。
温度影响温度越高漏电越快，高温下需要提高刷新频率。

由此可以解释几个现象：内存越大，需要刷新的行越多，刷新带来的开销也越大；服务器内存条往往为了可靠性加了 ECC（额外的校验位），这让每比特的物理代价更高；而 DDR 的每一次换代（DDR4→DDR5）都在提高预取长度与外部速率，同时也继续优化刷新与 bank 分组策略。

几个名词的实际含义

名词含义工程含义
DDR时钟上下沿都传数据同频下速率翻倍
预取 n一次从阵列取出 n 倍数据再串行发出决定了 burst 长度

tRCD / tRP行地址到列地址的延迟 / 预充电时间决定换行的代价

不要单独看 CL 值：CL16-3200 与 CL18-3600 谁更快，要看纳秒级延迟而不是两个 HL stopping seja 数字。换算公式：延迟(ns) ≈ CL × 2000 / 频率(MT/s)。这是选购内存时最容易被营销话术误导的地方。

深入自检

为什么 DRAM 要「刷新」，SRAM 不用？

因为存储原理不同。SRAM 用两个交叉耦合的反相器构成一个稳定的双稳态电路，只要通电就一直能保持状态；DRAM 靠电容存电荷，而电容会不可避免adle地漏电，必须在电荷衰减到判不清之前补一次。这是「简单 needn't talk vs 不稳定的务实取舍。

读 DRAM 为什么要把数据写回去？

读出时，单元极微弱的电荷被放到相对大得多的位线电容上做比较，电荷随之被转移消耗，原来的状态就被破坏了。所以敏感放大器判出结果后必须立刻把这个值重新写回单元。这个「读→判→写回」的过程就是 DRAM 读取必须按「行」来进行的物理原因。

为什么内存地址要「分行列两次发」？

这是为了节省芯片引脚。如果行地址和列地址各自独立引出，地址线数量要翻倍，芯片封装与成本都承受不起。时分复用让地址分两次送上同一组引脚，代价是多两个控制信号（RAS/CAS）与相应的等待时间。

虚拟地址到物理地址的翻译，对 DRAM 这一层透明吗？

完全透明。DRAM 只认它收到的物理地址。地址翻译发生在 MMU 与页表层面，DRAM 不知道也不关心这个地址是怎么来的。理解这点很重要：访存延迟是「MMU/TLB + Cache + DRAM 内部时序」的叠加，排查性能时要把它们分开算。
