GAN：生成器与判别器的对抗学习

理解对抗目标、交替训练、模式坍塌与适用边界。

学完能解释什么

  • 画出生成器与判别器的数据流并分清两者目标
  • 解释模式坍塌和训练不稳定的成因
  • 与扩散模型比较采样速度和训练机制

逐步看机制

建立判别器的参照

从真实数据集中取图像，并采样随机向量 z；数据覆盖不足会限制生成结果，不能靠对抗训练“创造”缺失类别。

两张网络不是轮流“作画”

生成器 G 将噪声或条件映射为图像，判别器 D 接受真实样本与生成样本并尝试区分。训练中 D 的梯度告诉 G 哪些特征还不像真实分布；推理时通常只使用 G。原始 GAN 用一个最小最大目标描述博弈，实际训练常改用更稳定的非饱和损失、Wasserstein 距离思路或梯度惩罚。不能把 D 输出直接当客观的“美学分”。

模式坍塌为何危险

G 可能只生成少数能骗过 D 的样式，却漏掉真实数据中的其它模式。例如训练集有多种颜色的鸟，生成结果都变成一种颜色。单看几张高质量样本会误判模型成功；要同时检查覆盖、多样性和条件遵循。训练不稳定还可能表现为 G 与 D 相互追逐、梯度消失或结果忽好忽坏。

缓解方法取决于问题：调整更新比例与正则、增加数据覆盖、检查判别器容量并用更稳定目标。没有一种技巧对所有数据集保证收敛。

GAN 与扩散模型的工程取舍

典型 GAN 推理只需一次生成器前向传播，适合要求低延迟的图像转换等任务；扩散模型通常要逐步去噪，采样步数较多，但训练过程和多样性在许多现代生成场景中更易控制。采样加速技术会改变这项比较，不能笼统说一种永远更快或质量永远更好。

对生成图像的评估需结合任务：分布指标、下游识别性能、人工质量检查及错误案例。合成影像的来源标识和授权也属于部署边界。

三个经典问题与对策

① 模式崩塌 Mode Collapse

生成器发现「生成某一种特别逼真的图」就能骗过判别器，于是所有输入都生成同一个样本，多样性归零。对策：WGAN / WGAN-GP、Unrolled GAN、Mini-batch Discrimination、多生成器。

② 训练不稳定

生成器与判别器的能力必须势均力敌：判别器太强 → 生成器梯度消失学不动；生成器太强 → 判别器失去指导意义。对策：谱归一化、TTUR（不同学习率）、判别器不要训太多次。

③ 梯度消失

当判别器能完美区分真假时，它给生成器的梯度趋近 0。原始 GAN 用 JS 散度时这个问题尤其严重。WGAN 改用 Wasserstein 距离，即使两个分布不重叠也有连续梯度，这是它成功的核心。

④ 评估困难

GAN 没有显式似然，难以用损失判断好坏。常用 FID（Frechet Inception Distance，越低越好）和 IS（Inception Score，越高越好），但都要结合人眼判断。

深入自检

GAN 的核心思想是什么？用一句话说清。

造假者与鉴定师的对抗：生成器（造假者）把随机噪声变成图像，努力骗过判别器；判别器（鉴定师）努力分辨真伪。两者在对抗中共同进步，直到判别器再也分不出真假——此时生成器产出的数据分布就逼近了真实分布。这个「用可学习的损失函数（判别器）代替人工设计的损失」的思路，是 GAN 最重要的贡献。

什么是模式崩塌？为什么会发生？

模式崩塌指生成器只输出极少数几种样本，甚至所有输入都生成同一张图，完全丧失多样性。原因：生成器发现「与其冒险生成多样但可能有破绽的图，不如反复生成那几张判别器判别不了的图」——只要判别器被这几张骗过，生成器的损失就降了。数学上，原始 GAN 优化的 JS 散度在两个分布不重叠时是常数，导致梯度消失，无法引导生成器探索新模式。对策是 WGAN 系列（改用 Wasserstein 距离，梯度连续）以及各种鼓励多样性的正则。

WGAN 为什么能改善训练？

两个关键改动：①换损失函数——用 Wasserstein 距离（EM 距离）替代 JS 散度。即使真实分布与生成分布完全不重叠，Wasserstein 距离仍然给出连续且有意义的梯度，不会像 JS 散度那样变成常数导致梯度消失；②换约束方式——为了满足 Lipschitz 条件，原始 WGAN 用权重裁剪（有问题），WGAN-GP 改成梯度惩罚（gradient penalty），效果好得多。结果：训练更稳定、几乎不模式崩塌，而且损失值本身有意义（越小表示生成质量越好），可以用来监控训练。

现在（扩散模型时代）GAN 还有价值吗？

有，而且不小。GAN 的一次前向出图的速度优势是扩散模型短期内追不上的，所以在这些地方仍然是主力：①实时/视频生成——需要每秒几十帧；②超分辨率与图像修复——实时性要求高（如视频超分、直播画质增强）；③风格迁移（CycleGAN 类）——轻量快速；④数据增强——需要快速生成大量样本；⑤扩散模型的加速——很多一步生成方法本质是用 GAN 的对抗损失去蒸馏扩散模型。所以定位是：追求最高质量用扩散，追求最快速度用 GAN。

怎么判断 GAN 训练得好不好？

不能只看损失（GAN 的损失不收敛也不代表坏）。常用：①FID（Frechet Inception Distance）——比较生成样本与真实样本在 Inception 特征空间的高斯分布距离，越低越好，目前最主流的指标；②IS（Inception Score）——衡量生成图的清晰度与多样性，越高越好（但容易被模式崩塌欺骗）；③人眼检查多样性——生成一批样本看是否有重复；④损失曲线（仅 WGAN 有意义）。实践上 FID + 抽样目视是标配。

GAN 的核心机制与训练目标

GAN 由生成器 G（造假币的）和判别器 D（警察）构成，二者零和博弈：G 想让假图骗过 D，D 想分辨真假。纳什均衡时，G 生成的数据分布 = 真实数据分布。

概念公式 / 含义说明
原始 minimax 损失min_G max_D E[log D(x)] + E[log(1 − D(G(z)))]理论形式，但早期梯度消失
Non-saturating（实际用）G 改为最大化 log D(G(z))实际训练都用这个
最优判别器D*(x) = p_data(x) / (p_data(x) + p_g(x))给定 G 时 D 的最优解
此时 G 的目标等价于最小化 JS 散度原始 GAN = 最小化 JS（这正是问题所在）

为什么原始 GAN 难训：当真实分布与生成分布几乎不重叠（高维空间中几乎必然如此）时，JS 散度恒为 log 2 的常数，梯度为 0——生成器收不到任何信号。这就是最经典的“梯度消失”问题，也是 WGAN 出现的直接动因。

WGAN / WGAN-GP：用什么替代 JS 散度

方案距离度量关键约束效果
原始 GANJS 散度无梯度易消失，训练不稳
WGAN（2017）Wasserstein（EM）距离权重裁剪到 [−0.01, 0.01]梯度稳定，但权重裁剪会削弱能力
WGAN-GPWasserstein 距离梯度惩罚（λ = 10）实用标准做法
SNGAN—谱归一化约束 Lipschitz实现简单，StyleGAN 采用

WGAN-GP 实现

# WGAN-GP 的梯度惩罚项（核心 10 行）
def gradient_penalty(D, real, fake, device):
    b = real.size(0)
    # ① 在真实样本和生成样本之间随机插值
    alpha = torch.rand(b, 1, 1, 1).to(device)
    interpolates = (alpha * real + (1 - alpha) * fake).requires_grad_(True)
    d_inter = D(interpolates)
    # ② 求判别器对插值样本的梯度
    grads = torch.autograd.grad(
        outputs=d_inter, inputs=interpolates,
        grad_outputs=torch.ones_like(d_inter),
        create_graph=True, retain_graph=True)[0]
    # ③ 惩罚"梯度范数偏离 1"的程度（Lipschitz 约束 = 梯度范数 <= 1）
    grads = grads.view(b, -1)
    gp = ((grads.norm(2, dim=1) - 1) ** 2).mean()
    return gp

# 训练循环
lambda_gp = 10                      # 论文推荐值，基本不用调
for real in loader:
    z = torch.randn(batch, nz, 1, 1)
    fake = G(z)
    # 判别器损失：Wasserstein 距离 + 梯度惩罚
    loss_d = D(fake).mean() - D(real).mean() + lambda_gp * gradient_penalty(D, real, fake)
    opt_d.zero_grad(); loss_d.backward(); opt_d.step()
    # 生成器：每训 n_critic 次 D 才训一次 G（关键！）
    if step % n_critic == 0:        # n_critic 通常取 5
        loss_g = -D(G(z)).mean()
        opt_g.zero_grad(); loss_g.backward(); opt_g.step()

# 关键超参：
#   n_critic = 5     : D 要比 G 强，但不能太强（否则 G 学不到）
#   lambda_gp = 10   : 论文固定值
#   优化器用 Adam 且 beta1 = 0（WGAN 原论文要求，用 RMSProp 也行）

模式崩溃：GAN 最著名的失败模式

现象原因检测缓解手段
模式崩溃 Mode CollapseG 发现只生成少数几种样本就能骗过 D生成样本多样性骤降minibatch discrimination、Unrolled GAN
模式丢弃 Mode DroppingG 完全忽略某些类别某些类别从不出现加大 batch、用 VEEGAN
判别器过强D 太准，G 拿不到有效梯度D(real)→1, D(fake)→0减小 D 容量、加噪声、标签平滑
震荡不收敛两者能力此消彼长loss 持续震荡降低学习率、用 TTUR（不同 lr）

直观理解：把 G 想象成一个学生，D 是考官。如果学生发现“只背三道题就能及格”，他就不会去学全部知识——这就是模式崩溃。解法本质是让考官能看到整体的多样性（minibatch discrimination：让 D 一次看一批样本并比较它们的差异），而不是逐个独立判断。

判别器输出的判读（最实用的调试指标）：D(real) ≈ 0.5 且 D(fake) ≈ 0.5 → 理想状态（D 已无法分辨）；D(real) ≈ 1, D(fake) ≈ 0 → D 太强，G 学不到东西，需要削弱 D。训练中盯这两个数，比盯 loss 有用得多。

指标含义方向参考值

深入自检

GAN 和扩散模型该怎么选？

2024 年后的现实：新项目优先扩散模型。扩散模型的优势：训练稳定（没有博弈、没有模式崩溃）、多样性好、可扩展性强（文生图效果远超 GAN）。GAN 的剩余优势：推理快（一次前向，而扩散要迭代 20 – 50 步）、单步生成质量高（适合实时/移动端）、隐空间结构清晰（StyleGAN 的 W+ 空间可做精细的语义编辑）。所以：要效果和可控性 → 扩散；要速度和编辑性 → GAN。另外 GAN 的对抗损失仍被广泛用作辅助（如超分里的 ESRGAN）。

为什么 GAN 训练要“D 比 G 强一点”？

因为D 提供梯度信号——G 的所有学习都来自 D 的判别结果。如果 D 太弱（什么都判为真），G 得不到改进方向；如果 D 太强（D(real)=1, D(fake)=0 且梯度为 0），G 同样学不到东西（梯度消失）。实践做法：① n_critic = 5（D 训 5 次、G 训 1 次）；② 给 D 的输入加噪声或做标签平滑（把真标签从 1 改成 0.9）；③ D 的学习率通常比 G 小。目标是把 D(real) 维持在 0.7 – 0.9 之间。

StyleGAN 相比普通 GAN 做对了什么？

三个关键设计：① 风格向量注入（AdaIN）——把隐变量 z 先映射成 w，再在每个分辨率层注入，实现了分层控制（粗层管姿态脸型、中层管五官、细层管肤色发丝）；② 常数输入——生成器输入不是随机噪声而是可学习的常数，风格完全由 AdaIN 注入，消除了“输入噪声导致伪影”的问题；③ 噪声注入 + 正则——在每个层加逐像素随机噪声生成头发、肤质等随机细节，配合 R1 正则稳定训练。这三点让 StyleGAN 在人脸生成上统治了数年。

GAN 的隐空间能做语义编辑吗？

能，这是 GAN 相对扩散的一大优势。StyleGAN 的 W+ 空间（18 层 × 512 维）有很好的解耦性——找到某个语义方向（如“微笑”、“年龄”、“光照”），沿着它加减就能编辑。两种找方向的方法：① 监督式——用预训练的属性分类器（如年龄、性别）的梯度方向；② 无监督式（SeFa、GANSpace）——对映射矩阵的权重做 PCA，主成分天然对应“主要的语义变化”。SeFa 尤其优雅：不需要任何标注数据，纯线性代数就能找出可解释的编辑方向。
