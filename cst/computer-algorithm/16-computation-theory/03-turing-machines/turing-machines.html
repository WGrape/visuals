图灵机与可计算性

一台极简的抽象机器，却能精确刻画「什么叫做一个可被算法解决的问题」。它是现代计算机的理论原型。

一、图灵机长什么样

图灵机（Turing Machine）由四部分构成：一条向两端无限延伸的纸带（分成一个个格子，每格写一个符号）；一个能在纸带上左右移动的读写头；一个记录当前情况的状态；以及一张转移函数——它根据「当前状态 + 读写头看到的符号」决定「写什么、头往哪移、下一个状态」。

部件类比今天的计算机
纸带无限存储（内存/磁盘的抽象）
读写头CPU 访问存储的指针
状态 + 转移函数程序计数器与指令集

关键洞见：图灵机虽简单，却被公认为「能模拟任何真实计算机的计算能力」——这就是丘奇-图灵论题。

二、什么是「可计算」

如果一个问题存在一台图灵机，对每一个输入都能在有限步内停机并给出正确答案，就说它是可计算的（可判定的）。否则便是不可判定——无论多强的计算机都不存在能解决它的通用算法。

停机问题（Halting Problem）：不存在一台「万能程序」能判断「任意给定程序在任意输入上是否会停机」。直觉证明用归约：假设存在这样的判定器 H，我们就能构造一个「若 H 说我停机我就无限循环，若 H 说我循环我就停机」的矛盾程序，从而推翻 H 的存在。

三、交互演示：二进制加 1 的图灵机

下面这台图灵机读取纸带上的二进制数，把它加 1。规则：先把读写头移到最右端，再向左回退并「处理进位」——遇到 1 改成 0 继续进位，遇到 0 改成 1 即停；若一直进位到最左还要补一个 1。

点击「下一步」开始：状态 R（向右扫描找末尾）。
转移函数（状态, 读入）→ (写入, 移动, 下一状态）
  R, 0/1 → (原样, 右移, R)        # 向右找末尾
  R, _   → (原样, 左移, A)        # 到了末尾，回头处理进位
  A, 1   → (0,    左移, A)        # 进位：1 变 0，继续向左
  A, 0   → (1,    右移, H)        # 进位终止：0 变 1，停机
  A, _   → (1,    右移, H)        # 一直进位到最左，补 1，停机

四、意义

图灵机告诉我们计算的「通用上限」：能写的程序、能模拟的机器，最终都等价于它。同时它也划出了边界——可计算 ≠ 一切都能算。理解这一点，就不会再幻想存在「自动证明所有程序正确」的银弹。
