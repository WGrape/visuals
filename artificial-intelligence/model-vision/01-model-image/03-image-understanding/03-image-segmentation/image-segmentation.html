图像分割：从边界框到像素掩码

语义、实例与全景分割的标签粒度、结构和评估方式。

学完能解释什么

  • 区分语义分割、实例分割和全景分割
  • 解释像素分类与解码上采样为何需要空间信息
  • 按类别与边界检查 IoU/Dice，而不只看整图得分

逐步看机制

确定像素的含义

语义分割为每像素给类别；实例分割还要分开同类不同对象；全景分割统一标注可数的 thing 和不可数的 stuff。

“两个人”是分割边界测试

语义分割可把两个人的像素都标为“人”，但未必区分谁是谁；实例分割要输出两张独立的“人”掩码。全景分割同时处理“人”等可数实体（thing）与“道路、天空”等背景区域（stuff），并保证像素有一致归属。把实例检测框直接当掩码会丢失形状细节。

模型如何兼顾语义与空间

编码器逐层扩大感受野，理解区域所属类别；解码器上采样回原图分辨率。单靠最低分辨率特征容易抹平细边界，因此常加入浅层高分辨率特征、跳跃连接或专门的边界细化。把预测 mask 与原图对齐时，插值、裁剪和坐标映射同样重要。

指标与错误分析

单类 IoU = 交集 / 并集；Dice = 2 × 交集 / 两个掩码面积之和。背景占比很大时，像素准确率高也可能完全漏掉小病灶。需注明是否包含背景类、空类别如何处理，再按类报告 mIoU 等结果。实例和全景任务还需分别评估对象识别、匹配及区域质量，不能直接把语义 mIoU 解释成实例质量。

要审查错误是否集中在细结构、遮挡、透明表面或模糊标注，必要时明确标注规范而不是一味加深网络。

两个人在同一张图上，语义分割输出两个独立实例吗？

不一定。它通常只把两人像素标成相同类别；要分别识别对象需要实例分割或全景分割的实例 ID。

编码器-解码器为什么这样设计

矛盾在哪

分割需要两件矛盾的事：高层语义（知道这是"人"）和精细空间（知道边界在哪一层像素）。下采样能提语义但丢空间，不下采样则感受野太小、算力爆炸。

怎么解决

编码器逐步下采样提取语义，解码器逐步上采样恢复分辨率，中间用跳跃连接把编码器各层的细节特征直接拼到解码器对应层——这就是 U-Net 的形状由来。

损失怎么选

逐像素交叉熵最常用；类别极不平衡时用 Dice Loss 或 Focal Loss（前景像素往往远少于背景）；边界要求高时加 边界感知损失。实践中常组合使用。

后处理

常用 CRF（条件随机场） 做边界精修，让分割边缘贴合图像边缘；也可用形态学操作（开闭运算）去掉小空洞。

评估指标

mIoU各类别 IoU 的平均——分割最核心的指标
Pixel Accuracy逐像素准确率；背景占多数时会被虚高，慎用
Dice 系数2×交集/(并集)，医学影像常用，对小目标更敏感
AP（实例分割）按掩膜 IoU 阈值判命中，与检测的 AP 类似
边界 F1只看轮廓是否贴合，适合边缘质量要求高的任务

深入自检

语义分割和实例分割的本质区别是什么？

语义分割只回答「这个像素属于哪个类别」，不区分同类个体——图里两个人都是同一种颜色，无法区分是两个人还是一个。实例分割还要回答「这个像素属于哪个个体」，每个人一个独立 ID。所以语义分割是纯像素分类问题，实例分割是检测 + 分割的组合问题（先找到每个实例，再在框内做掩膜）。全景分割则把两者统一：不可数的背景（天空、道路）做语义分割，可数的前景（人、车）做实例分割。

为什么 U-Net 在医学影像上这么流行？

三个契合点：①医学影像通常数据量小（几百张），U-Net 结构简单、参数少、不易过拟合；②医学分割要求边界极其精确（肿瘤轮廓），U-Net 的跳跃连接把编码器的高分辨率细节直接传给解码器，边界保真度好；③病灶往往极小，Dice Loss 配合 U-Net 对小目标敏感。加上弹性形变等针对性数据增强，U-Net 及其变体（U-Net++、nnU-Net）至今仍是医学分割的强基线。

分割的掩膜为什么常常边缘锯齿、不贴合？

根本原因是下采样丢失空间细节：编码器输出的特征图分辨率往往只有原图的 1/16 或 1/32，上采样回来时边界信息已经模糊。缓解办法：①用跳跃连接补细节（U-Net）；②用空洞卷积保持分辨率（DeepLab）；③上采样时用双线性 + 卷积而非转置卷积（减少棋盘格伪影）；④后处理用 CRF 精修边缘；⑤训练时加边界感知损失。

SAM 这类「分割一切」的模型能替代传统分割吗？

不能简单替代，定位不同。SAM 是提示式（promptable）零样本分割：给个点/框/文本就给出掩膜，不需要针对特定类别训练，适合标注工具、交互编辑、开放场景。但它不输出类别（只说「这是个东西」，不说「这是狗」），且在某些专业领域（医学、遥感）精度不如专用模型。传统分割模型则输出固定类别、可端到端批量推理、在特定域上精度更高。实践中常组合：用 SAM 辅助标注，再用数据训练专用模型。

分割任务标注成本很高，怎么降低？

几条路：①弱监督——只用框标注或点标注训练分割（BoxSup、点监督）；②半自动标注——用 SAM 或已有模型预打标，人工只做修正，通常能省 60%~80% 时间；③合成数据——用渲染引擎生成带精确掩膜的数据（自动驾驶行业常用）；④主动学习——优先标注模型最不确定的样本，用更少标注达到同等效果；⑤迁移学习——在大规模分割数据集上预训练再微调。

深入自检

语义分割、实例分割、全景分割的区别是什么？

语义分割只给每个像素一个类别，不区分同类个体；实例分割要区分每个个体并给出 mask（通常只针对可数目标 thing）；全景分割把两者统一——可数目标按实例输出，背景类（stuff，如天空、道路）按语义输出，并保证不重叠。

mIoU 和像素准确率该看哪个？

看 mIoU。像素准确率（aAcc）会被大面积类别（背景、道路）主导，即使小类全错也可能显示 90%+；mIoU 对每类同等加权，能反映长尾类别的真实表现。报告时应同时给出 mIoU 与逐类 IoU。

PQ 是什么，为什么是乘法形式？

PQ（Panoptic Quality）= SQ × RQ，其中 RQ（Recognition Quality）类似 F1 衡量「有没有找对、有没有漏」；SQ（Segmentation Quality）是匹配上的实例的平均 IoU 衡量「mask 准不准」。乘法的含义是识别与分割任何一项差，总分都会直接被拉低。

SAM 这类提示式模型能替代语义分割吗？

不能完全替代。SAM 输出的是「候选 mask」而非语义类别（不知道这块是猫还是狗），且边界与稳定性需要后处理。它的价值是零样本、可交互、可作为标注工具或与其它模型组合（用 SAM 出 mask、用分类器打标签）。

标注成本很高时怎么办？

四类手段：① 用 SAM 之类模型做预标注再人工修；② 弱监督（框/点/涂鸦级标注训练）；③ 半监督与自训练（用高置信伪标签）；④ 数据增强与合成数据（Copy-Paste 增强对实例分割尤其有效）。
