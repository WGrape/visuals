SQLite 索引

自动主键索引、CREATE INDEX、表达式/部分索引，以及索引膨胀与 Analyze。

自动索引创建索引表达式/部分维护

① 主键与 ROWID

SQLite 表默认有隐式 ROWID（64 位整数行号）。INTEGER PRIMARY KEY 会直接成为 ROWID 的别名，免索引、最快定位；其它类型主键会额外建唯一索引。这就是“整数主键最快”的原因。

② 创建索引

CREATE INDEX idx_name ON users(name);
CREATE UNIQUE INDEX idx_email ON users(email);

索引加速等值/范围/排序/LIKE 'prefix%' 查询。但 LIKE '%后缀' 和函数包裹列（lower(name)）用不上普通索引。

③ 表达式与部分索引

SQLite 同样支持表达式索引与部分索引（语法接近 PG）：

CREATE INDEX idx_lower ON users(lower(name));
CREATE INDEX idx_active ON orders(user_id) WHERE status='active';

④ 维护与 Analyze

索引会随删改产生碎片；REINDEX 重建，VACUUM 整理整个库文件。删大量数据后跑 ANALYZE 让查询规划器获得统计：

REINDEX idx_name;
VACUUM;
ANALYZE;
