原理

查询 DB 返回空时，也把“空”结果缓存起来（如 value=null，TTL 较短）。后续相同 key 直接命中空值，不再打 DB。

与布隆配合

布隆过滤器拦掉明显非法的 key；漏进来的（误判）由空值缓存兜底，二者互补。

坑：穿透变种

若攻击者用大量不同的非法 key，空值缓存也会占用内存。需加参数校验、限流，并控制空值 TTL 与总量。

🎯 面试问答

Q：空值缓存 TTL 为什么短？
A：防止后来真有了却一直返回空。
Q：只靠空值缓存够吗？
A：不够，海量非法 key 会占内存，需布隆+限流。
Q：空值缓存和正常缓存区别？
A：value 为空且 TTL 更短。
