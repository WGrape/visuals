晶体管：换掉「灯泡」的固体开关

1947 年 12 月，贝尔实验室。一只比米粒还小的器件，终结了真空管的统治。

🔬 历史时刻

巴丁、布拉顿、肖克利在贝尔实验室做出第一只点接触晶体管。它基于半导体（锗/硅）的物理特性：掺入杂质形成 N 型、P 型区，用电场控制电子能否流过——不需要加热灯丝、不需要真空、没有会烧断的零件。

三人因这一发明同获 1956 年诺贝尔物理学奖。从此「开关」从厘米级的灯泡，变成微米级、纳米级的固体。

🏆 为什么是革命性的

  • 体积：灯泡大 → 米粒大 → 纳米级
  • 速度：每秒开关数十亿次（GHz）
  • 功耗：不用加热，微瓦级控制
  • 寿命：纯固态，没有会烧断的灯丝
  • 量产：光刻工艺批量「印刷」，成本暴跌
硬件载体进化：真空管 → 晶体管 → 集成电路
对比项真空管晶体管

🔁 关键认知：换的是「零件」，不是「思想」

二进制、存储程序思想从 1945 年诞生后沿用至今，一字未改。晶体管解决的只是工程问题：做出极小、超快、廉价、可海量复制的 0-1 开关。图灵机的规则、冯·诺依曼的架构、晶体管的开关——三者各司其职，共同构成现代计算机。

第二层 · 从晶体管到集成电路的关键数字

时间事件意义规模变化
1947贝尔实验室做出点接触晶体管替代真空管的可靠器件出现体积、功耗大幅下降
1954第一台晶体管计算机证明可规模使用可靠性显著提升
1958~1959集成电路被发明多个器件做在同一块硅片上集成度成为新维度
1965摩尔定律被提出集成度约每两年翻倍给出可预期的增长曲线
1971第一款商用微处理器计算机的核心缩小到一块芯片成本下降几个数量级
1970s~1990s个人计算机普及计算机从机构走向个人装机量指数增长
# 摩尔定律到底在说什么：用数字感受一下
def transistors(year, start=1971, start_n=2300, doubling_years=2):
    # 示意：1971 年约 2300 个晶体管，约每两年翻一倍
    return start_n * 2 ** ((year - start) / doubling_years)

for y in (1971, 1980, 1990, 2000, 2010, 2020):
    n = transistors(y)
    print(f'{y}: 约 {n/1e6:.2f} 百万 → {n:.3e} 个晶体管')
# 注意：这是「趋势示意」，真实曲线在近几年已经明显放缓
#   物理限制（制程、功耗、成本）让翻倍周期变长

# 制程节点的量级（纳米是栅极尺度的标称值，不等于物理尺寸）
for node in ('10um', '1um', '180nm', '65nm', '28nm', '7nm', '3nm'):
    print(node, end='  ')
print()

晶体管相对真空管的三个决定性优势：① 不需要灯丝加热（功耗与预热问题消失）；② 固态器件寿命长得多（可靠性问题解决）；③ 可以越做越小并集成（打开了集成度这条路）。

第三层 · 五个常见误解

  • 误解：摩尔定律是物理定律：它是产业观察与预期，后来变成了行业的自我实现目标，近年已明显放缓。
  • 误解：制程数字就是晶体管尺寸：节点名称（如 7nm、3nm）是商业命名，不等于任何具体物理尺寸。
  • 误解：集成电路是一个人发明的：基尔比与诺伊斯分别独立做出，专利与产业化路径不同。
  • 误解：晶体管一出现计算机就便宜了：早期晶体管成本很高，直到集成电路与量产工艺成熟后才真正便宜。
  • 误解：性能提升全靠制程：架构（流水线、缓存、多核、专用加速）贡献同样巨大，甚至更大。

记忆锚点：第二代 = 晶体管，第三代 = 集成电路；分界标准是「器件形态」与「是否集成」，不是年代。

第四层 · 这段历史对今天的意义

摩尔定律放缓意味着什么？

意味着靠换工艺就能免费变快的时代结束了。性能增长越来越依赖架构创新、专用加速、软件优化，以及「少做无用功」。

为什么晶体管能一直变小？

靠光刻、材料与结构创新（如 FinFET、GAA）一次次突破；但每一次突破的成本都在上升，这就是放缓的根本原因。

集成度提高带来了什么新问题？

功耗密度与散热变成主约束（暗硅、功耗墙），还有制造良率与成本。今天的芯片设计常常是「先受限于功耗，再谈性能」。
