计算机知识可视化

按学科脉络组织的交互式知识地图：从人工智能、系统工程、数据库系统、计算机科学基础，到编程与程序，建立完整的计算机知识体系。

人工智能

模型基础

机器学习与深度学习的地基：损失函数、梯度下降与反向传播、过拟合与正则化、从 CNN/RNN 到注意力结构的演进；在学大模型之前，先把这些概念和数学直觉打牢。

模型运维

预训练、监督微调（SFT）、RLHF/DPO 对齐、LoRA 等高效微调，到量化压缩与推理部署的完整链路；理解每个阶段的数据与算力投入、能力变化，以及什么时候该微调、什么时候该用 RAG。

大语言模型

Prompt 与上下文工程、Token 与分词、注意力机制与 KV Cache、函数调用与工具使用、幻觉的成因与抑制；系统理解大模型的工作原理，以及它在工程中到底能做与不能做哪些事。

图像大模型

图像全景与表示基础、理解四任务（分类 / 检测 / 分割 / OCR）、扩散模型原理、局部重绘编辑、视觉问答 VQA、生成评测与水印鉴伪；部分专题仍在建设中。

音频大模型

从音频信号与特征（MFCC）、语音识别 ASR、语音合成 TTS 到端到端实时语音对话；覆盖流式处理、延迟优化、打断与轮次控制，构建一条完整的语音 AI 技术链路。

视频大模型

视频全景与帧时序基础、视频理解与检索、文生视频与时序一致性、插帧与超分编辑、流媒体协议与实时链路、FVD 评测与深度伪造治理；部分专题仍在建设中。

系统工程

缓存系统

从本地进程内缓存到分布式缓存：原理、淘汰策略、一致性、穿透/击穿/雪崩与多级/ CDN 实践。专题建设中。

分布式系统

CAP 与 BASE、一致性模型与 Raft/Paxos 共识、分布式事务（2PC / TCC / Saga）、幂等与去重、服务发现与负载均衡、熔断降级；理解跨节点系统在部分失败下如何继续正确工作。

大数据系统

按数据采集、数据存储、数据处理与计算、数据治理、数据分析与应用五层划分的知识地图；覆盖 Kafka、HDFS、Hive、Spark、Flink 等核心组件的定位、协作方式与选型依据。

AI 工程系统

RAG 检索增强、Agent 与工具编排、MCP 协议、Skills 能力封装、长期记忆、评测与安全红队、推理服务与限流治理；并覆盖 AI 辅助编程实践——Harness 上下文工程、Claude Code 与 OpenClaw 的架构与记忆机制。重点是把大模型从演示变成可靠的生产系统：可观测、可评测、可回滚、可控制成本。

云原生系统

专为云计算模型设计的技术体系：CNCF 四大支柱——容器、微服务、DevOps、声明式 API。容器化打包与 Kubernetes 编排（架构 / Pod / Service）、微服务与单体取舍、CI/CD 与 GitOps 拉模式、声明式 API 与基础设施即代码；并以服务网格接管东西向流量、可观测性三件套（指标 / 日志 / 链路）作支撑能力。

云架构系统

云上的基础设施与流量架构：上云与自建的取舍、IT 基础设施全景、云网络（VPC / 专线 / 带宽 / CDN / 负载均衡）、Web 服务（API / Nginx / 应用服务器）、边缘计算；以及通用软件架构——架构风格（分层 / SOA / 事件驱动）、经典模式（MVC / CQRS / 六边形 / 整洁）、分布式模式（网关 / 熔断 / 限流 / Saga / 幂等）与云架构设计（高可用 / 读写分离 / 分库分表 / 缓存 / 弹性伸缩）。

高性能、高并发、高可用

从线程模型、协程与 CSP，到限流算法、熔断降级、隔离舱与兜底预案；结合缓存、异步化、连接池与压测数据，讲清如何构建高吞吐、低延迟，且在流量突增下不会雪崩的服务。

数据库系统

关系型数据库

OLTP 主战场。以 MySQL / InnoDB 为主线：B+ 树索引与执行计划、事务隔离级别与 MVCC、行锁间隙锁与死锁排查、主从复制与读写分离；并横向对比 PostgreSQL、SQLite 等方案在功能与适用场景上的差异。

NoSQL 数据库

键值（Redis）、文档（Elasticsearch）、列族与图四类 NoSQL：Redis 核心数据结构、单线程模型与持久化、Cluster 分片；ES 倒排索引、分片副本与写入/查询流程；以及它们与关系型数据库的边界与选型。

向量数据库

面向 Embedding 检索的向量数据库：ANN 近似最近邻、向量索引（IVF / HNSW）选型、相似度度量、混合检索与检索延迟；以 Milvus 为主线讲清向量检索的工程实践。

OLAP 分析型数据库

列式存储与向量化执行为何能快一个数量级：行存 vs 列存、字典/RLE/Delta 压缩、SIMD 与延迟物化；ClickHouse 的 MergeTree 与稀疏索引、Doris/StarRocks 的 MPP 与三种 JOIN，以及按时效、模型、并发的选型决策树；并讲清它与 OLTP 的负载边界——为什么 MySQL 撑不住全表聚合。

NewSQL 分布式关系型数据库

单机到顶后怎么办：分库分表中间件的硬伤 vs 原生分布式；TiDB 的存算分离与 Percolator 事务、OceanBase 的 LSM 与三地五中心、CockroachDB 的 HLC 与 Serializable，覆盖自动分片、Raft/Paxos、2PC 与 HTAP。

TSDB 时序型数据库

监控与 IoT 数据为什么不能存 MySQL：Series 时间线模型、Delta-of-Delta 与 XOR 压缩、高基数陷阱、降采样与保留策略；InfluxDB 的 TSM 引擎与行协议、TDengine 的「一设备一表」与超级表。

SQL 语言核心

跨数据库通用的查询基本功：JOIN 的七种语义与 Nested Loop/Hash/Merge 三种算法、窗口函数的排名与累计聚合、GROUP BY 与聚合函数的 NULL 陷阱、以及书写顺序与执行顺序的错位如何决定别名可见性。

计算机科学基础

计算机发展史

分开学习计算机与硬件演进、Web 平台变迁和人物思想的出处考证。

计算机数学基础

以拓扑基础及计算应用为起点，按数学知识边界组织课程。

计算机组成原理

从晶体管、门电路、指令集，到流水线、乱序执行、分支预测与缓存层次，自底向上认识 CPU 如何取指、译码、执行一条指令；并覆盖存储金字塔、总线与 IO 设备，理解硬件为软件划定的性能边界。

数据结构与算法

线性表、栈与队列、树与堆、图、哈希表等核心结构的原理与实现；配合二分、双指针、滑动窗口、前缀和、位运算、动态规划、贪心与回溯等经典技巧，用可视化动画看清每一步操作、边界条件与时间空间复杂度的取舍。

计算机操作系统

进程与线程、上下文切换与调度算法、虚拟内存与页表、文件系统与设备 IO、中断与系统调用；理解操作系统如何把裸硬件抽象成统一接口，并为上层应用提供并发、隔离与资源复用。

计算机网络

自底向上拆解物理层、链路层、网络层、传输层到应用层：以太网与 ARP、IP 与路由转发、TCP 三次握手/拥塞控制/重传、DNS 与 HTTPS，配合抓包视角理解一次网页请求到底走了哪些路。

编程与程序

构建程序

从类型体系讲起——静态类型与动态类型在检查时机、运行方式与工程取舍上的差异；再深入编译型、解释型与 JIT 三条执行路径：源码到 AST、字节码再到机器码，理解 V8 的隐藏类与即时优化、CPython 的解释循环与 GIL，以及启动速度与运行性能的权衡。

软件设计

从设计模式、接口契约与数据序列化，到认证授权与业务系统建模；理解如何写出可维护、可演进的代码与模块。

运行时机制

按内存模型、分配、垃圾回收、事件驱动执行和局部性组织运行时知识。

Golang 语言

从语法基础、切片与 map 底层、接口与错误处理规范，到 goroutine 调度器 GMP 模型、channel 与 CSP 并发范式、逃逸分析与内存布局，再到 go-zero 等框架的 HTTP/RPC/中间件实践速查手册。

Python 语言

从语法基础、模块与包机制、装饰器与生成器，到引用计数与 GC、GIL 与多进程、协程与事件循环、FastAPI 工程化部署；一条可用于日常开发与面试复习的完整 Python 进阶路径。

性能排查与优化

从 CPU、内存、网络 IO 到文件 IO 的优化思路，再到一套可落地的排查方法论——覆盖「性能优化的第一步」与「CPU 高 / 内存持续上涨怎么查」。
