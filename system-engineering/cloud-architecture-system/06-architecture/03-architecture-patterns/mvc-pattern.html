架构 · 架构模式

MVC 模式

把交互系统切为模型、视图、控制器三件套，分离数据与展示。

MVC 三角色 Model-View-Controller

用户操作经 Controller，Controller 改 Model，Model 变更通知 View 重绘

<b>Model</b>：业务数据与规则；<b>View</b>：用户界面；<b>Controller</b>：接收输入、调用 Model、选 View。三者各司其职，便于并行开发与测试。

与 MVP / MVVM

  • MVC：View 可直接读 Model（耦合略高）。
  • MVP：Presenter 隔离 View 与 Model，View 被动。
  • MVVM：ViewModel 经数据绑定自动同步 View（前端/移动端常见）。

面试高频问答

Q：MVC 里 View 能不能直接访问 Model？
A：传统 MVC 允许 View 订阅 Model 自动刷新（如桌面控件）；Web MVC 中通常 View 由 Controller 注入数据、不直接读库，以降低耦合。看具体变形。
Q：MVC 属于架构还是设计模式？
A：它介于两者之间，是『架构模式』（组织整个应用的结构），比 GoF 的『设计模式』粒度更大。
