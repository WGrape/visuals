一阶逻辑

当“真 / 假”不够用：引入个体、性质与量词，描述“所有”与“存在”。

谓词与量词

命题逻辑把整句话当作不可分割的真值块。一阶逻辑更进一步：用谓词 P(x) 表示“x 具有性质 P”，x 是论域中的个体。再用量词统御个体：

∀ 全称量词

∀x P(x)：“对所有 x，P(x) 成立”。如“所有素数都大于 1”。

∃ 存在量词

∃x P(x)：“存在某个 x 使 P(x) 成立”。如“存在一个偶素数”。

与命题逻辑的区别：命题逻辑只谈“这句话真不真”，一阶逻辑能谈“某个具体对象是否满足某性质”，表达力更强。

量词的作用域与否定

量词有作用域：它只管自己后面的公式。否定会“翻转”量词，这是最容易出错、也最有用的一条规则：

¬(∀x P(x))  ≡  ∃x ¬P(x)     “并非所有都” = “有的不”
¬(∃x P(x))  ≡  ∀x ¬P(x)     “不存在” = “所有都不”
直觉：要反驳“所有人都会飞”，你只需找出“一个不会飞的人”；要反驳“存在会飞的猪”，你必须证明“所有猪都不会飞”。否定时，∀ 与 ∃ 互换，命题取反。

前束范式：把所有量词都挪到公式最前面（后接一个无量词的母式），如 ∀x ∃y P(x,y)。它让量词的层级一目了然，便于自动推理。

应用：SQL 查询与程序规约

一阶逻辑不是纯理论，它藏在日常工具里：

SQL 的谓词本质

SELECT * FROM 用户 WHERE 年龄 > 18 就是 ∃/∀ 思想的实例化：选出满足谓词 P(年龄) 的个体。

程序规约

前置条件 {P}、后置条件 {Q} 用谓词描述：“对所有输入，若 P 成立则运行后 Q 必成立”。

{ n ≥ 0 }          // 前置：对所有调用，n 非负
x := 0; i := 0;
while i < n do ( x := x + i; i := i + 1 )
{ x = n(n−1)/2 }   // 后置：对所有路径，结论成立

这里的“对所有”正是 ∀ 的精神：规约保证的是任意合法输入下都成立，而非某个测试用例。

交互：量词否定规则练习

集合里有若干形状，谓词 P = “是圆形”。点击按钮验证：¬(∀x P(x)) 是否为真，等价于 ∃x ¬P(x)。只要出现一个非圆形，全称命题即被推翻。
