命题逻辑

命题是「非真即假」的陈述句。把命题用联结词拼起来，就得到可以计算真假的「逻辑公式」——这正是数字电路的语言。

命题与联结词

命题（proposition）是一个能判断真假的陈述句，真值记为 T（真）或 F（假）。「今天下雨」是命题；「请关门」不是命题（它是祈使句）。

联结词记号读法真值规则
非¬p非 pp 为真时结果为假，反之
与p ∧ qp 且 q两者皆真才真
或p ∨ qp 或 q至少一个真则真
蕴含p → q若 p 则 q仅当 p 真且 q 假时为假
双条件p ↔ qp 当且仅当 q两者同真同假时为真
「蕴含 p → q」是最容易误解的：只有「p 真而 q 假」这一种情况是假的。日常里「如果太阳从西边出来，我就给你钱」——因为前提为假，整句话在逻辑上算「真」。

真值表与逻辑等价

真值表把公式中每个命题的所有可能取值都列出来，逐行算出公式结果。如果两个公式对所有取值结果相同，它们逻辑等价。

重要等价式

德摩根律

¬(p ∧ q) ≡ ¬p ∨ ¬q
¬(p ∨ q) ≡ ¬p ∧ ¬q

分配律

p ∧ (q ∨ r) ≡ (p∧q) ∨ (p∧r)
p ∨ (q ∧ r) ≡ (p∨q) ∧ (p∨r)

蕴含等价

p → q ≡ ¬p ∨ q

还有主析取范式（由「小项」用 ∨ 拼成）和主合取范式（由「大项」用 ∧ 拼成），它们是把任意逻辑公式写成标准化形式的方法，对电路化简很关键。

互动：生成真值表

选择一个含 p、q 的公式，下面会实时生成它的四行真值表。

// 真值表的本质：枚举输入的 2ⁿ 种组合，对每种算一遍公式
rows = [(T,T),(T,F),(F,T),(F,F)]
for (p,q) in rows:
    print(p, q, formula(p,q))
