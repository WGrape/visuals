集合论基础

集合是计算机科学的「名词」。几乎一切数据结构——数组、字典、数据库表——都能翻译成集合与映射。

什么是集合

集合就是「一堆确定的、互不相同的对象」的整体。一个对象要么属于集合，要么不属于，没有「半个属于」。

列举法

把元素一个个写出来：A = {1, 2, 3}

描述法

用性质定义：B = {x | x 是偶数且 x < 10}

直觉：集合像是一个「去重后的清单」。重复写同一个元素没有意义，{1,1,2} = {1,2}。

幂集、笛卡尔积与子集

子集：若 A 的每个元素都在 B 中，则 A ⊆ B；若还满足 A ≠ B，则 A 是 B 的真子集 A ⊂ B。

幂集 P(A)：A 的所有子集构成的集合。若 |A| = n，则 |P(A)| = 2ⁿ。例如 A={a,b}，其幂集为 {∅, {a}, {b}, {a,b}}，共 4 个。

笛卡尔积 A × B = {(a,b) | a∈A, b∈B}。它是「有序对」的集合——这正是关系型数据库里「一行记录」的数学原型。

// 笛卡尔积示例
A = {1, 2}
B = {x, y}
A × B = {(1,x),(1,y),(2,x),(2,y)}   // 共 2 × 2 = 4 个有序对

基数与可数性

「集合有多大？」对有限集就是元素个数；对无限集，我们用「能否与自然数一一对应」来比较。

可数无限

自然数 N、整数 Z、有理数 Q 都能排成一列，与 N 一一对应。

不可数

实数 R 无法排成一列——它「更密」。

康托对角线法（直觉）

假设能列出所有 0~1 之间的实数（写成二进制小数）。我们构造一个新数：第 i 位与第 i 个数的第 i 位「取反」。这个构造出的新数一定不在原列表中——因为它和列表里每个数都至少差一位。矛盾！所以实数不可数。

为什么重要：它告诉我们「无限」也有大小之分。计算机能表示的浮点数只是可数集，而连续数学面对的实数是不可数的——这是离散与连续的又一道分水岭。
