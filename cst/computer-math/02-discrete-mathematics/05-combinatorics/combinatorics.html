组合数学

组合数学回答一个朴素的问题：「有多少种可能的安排？」从密码强度到算法复杂度，它无处不在。

计数两大原理

加法原理

分类完成：若 A 类有 m 种、B 类有 n 种，且两类互斥，则共有 m+n 种。

乘法原理

分步完成：第一步 m 种、第二步 n 种，则共 m×n 种。

类比：点套餐（主食选 1 + 饮料选 1）用乘法；只从「主食或饮料」里挑一样用加法。先想清是「分步」还是「分类」，计数就不会乱。

排列与组合

排列：从 n 个里取 k 个排顺序。不可重复：P(n,k)=n!/(n−k)!；可重复：nᵏ。

组合：从 n 个里取 k 个不排序。C(n,k)=n!/(k!(n−k)!)。因为 k 个元素的排列有 k! 种，所以 C(n,k)=P(n,k)/k!。

情形公式例子（n=5,k=3）
排列（不可重复）P(5,3)60
组合（不可重复）C(5,3)10
可重复排列5³125

二项式定理与容斥

二项式系数 C(n,k) 正是 (a+b)ⁿ 展开中 aⁿ⁻ᵏbᵏ 的系数：

(a+b)ⁿ = Σ C(n,k)·aⁿ⁻ᵏ·bᵏ     (k 从 0 到 n)
例：(a+b)³ = a³ + 3a²b + 3ab² + b³

容斥原理（两集合）

要数「在 A 或 B 中」的元素个数，不能直接相加（重叠部分会被算两次）：

|A ∪ B| = |A| + |B| − |A ∩ B|

例如 100 人里，60 人会 Python、50 人会 C++、两者都会的 30 人。会至少一门的 = 60+50−30 = 80 人。

鸽巢原理与递推

鸽巢原理：把 n+1 只鸽子放进 n 个巢，必有某个巢里至少 2 只鸽子。推论：367 个人中必有至少两人生日相同（一年最多 366 天）。

递推关系用「前几项」定义后面：

斐波那契

F(n)=F(n−1)+F(n−2)，F(0)=0,F(1)=1

汉诺塔

T(n)=2T(n−1)+1，解得 T(n)=2ⁿ−1

汉诺塔说明：多一层盘子，步数翻一倍还多一步——这是指数增长的典型信号，也是算法最坏复杂度的来源之一。

互动：组合数计算器

输入 n 和 k（0 ≤ k ≤ n，n 建议 ≤ 30），计算 C(n,k) 并展示公式。

// 用乘法避免直接算大阶乘（防溢出）
C(n,k) = (n/1)·((n-1)/2)·...·((n-k+1)/k)
例：C(10,3) = 10·9·8 / (3·2·1) = 120
