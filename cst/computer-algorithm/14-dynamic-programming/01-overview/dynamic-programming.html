第 14 章 · 动态规划

把重复的子问题只算一次

动态规划的关键不是写二维数组，而是定义状态、证明转移覆盖所有选择，并安排合法的计算顺序。

识别重叠子问题

朴素递归计算 Fibonacci(n) = Fibonacci(n−1) + Fibonacci(n−2) 时，会重复求同一个 Fibonacci(k)。记忆化在首次求值后缓存结果；自底向上的表格则按 0、1、2 … n 的顺序计算，时间降为 O(n)。只需前两项时空间可从 O(n) 降为 O(1)。

设 F(0)=0、F(1)=1，则 F(2)=1、F(3)=2、F(4)=3、F(5)=5。计算 F(5) 时，F(3) 不必分别由 F(4) 与 F(3) 的递归支路重复求值。

用 0/1 背包练习状态设计

令 dp[i][c] 表示只考虑前 i 件物品、容量不超过 c 的最大价值。第 i 件物品重 w、价值 v：不选时继承 dp[i-1][c]；若 c ≥ w，选择时为 dp[i-1][c-w] + v；取两者较大。边界 dp[0][c] = 0。

dp[i][c] = dp[i-1][c]                  if c < w
           max(dp[i-1][c], dp[i-1][c-w] + v) otherwise

n 件物品、容量 C 的表格有 O(nC) 个状态，每个状态 O(1) 转移，时间 O(nC)、空间 O(nC)。这是关于数值 C 的伪多项式时间，不能只根据输入位数称为普通多项式时间。用一维数组压缩时，0/1 背包的容量必须从大到小更新，避免同一件物品被使用多次。

和贪心的分界

DP 保留多个中间状态来比较未来选择；贪心只保留当前局部最优选择，必须单独证明这种选择可扩展为全局最优。若无法证明，不能仅凭样例正确就丢弃其他状态。

写转移前先说清状态的精确定义与无后效性；“dp[i] 是答案”不足以决定前一状态包含哪些信息。
