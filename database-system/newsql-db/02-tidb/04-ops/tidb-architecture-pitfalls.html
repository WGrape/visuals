Q：TiDB 完全兼容 MySQL 吗？
A：高度兼容但不是 100%。常用 SQL、协议、客户端驱动都兼容，但仍有差异： 不支持 Serializable 隔离级别、存储过程/触发器/外键支持有限、 自增 ID 行为不同（不保证连续）、部分函数与语法有差异。 迁移前务必用官方工具做兼容性评估。
Q：TiDB 和 MySQL 分库分表怎么选？
A：如果业务已经能很好地按分片键拆、跨片查询很少、团队有中间件运维经验—— 分库分表成本更低、延迟也更低。如果需要全局一致性、弹性扩缩容、不想改业务代码—— 选 TiDB。核心判断是业务的分布式复杂度能否被分片键约束住。
