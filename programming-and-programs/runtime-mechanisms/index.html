栈和堆的本质区别

栈随着函数调用自动分配与释放，速度快、无需回收，但生命周期受作用域限制；堆可以存活到任意时刻，但需要分配器与回收机制，成本更高。所以「能不能放栈上」直接影响性能。

为什么事件循环怕阻塞

因为它只有一个执行线程：所有任务轮流使用。任何一个任务做了阻塞等待，后面所有任务都要排队等着。所以事件驱动模型要求所有等待都必须是非阻塞的，这是它高效的前提，也是它的约束。

高频问题

逃逸分析有什么用？

它判断一个对象会不会被作用域之外使用。如果不会，就可以分配在栈上，甚至把对象拆散成若干个局部变量，从而减少堆分配与回收压力。这是很多「看起来在堆上、实际被优化掉」现象的原因。

内存泄漏和内存溢出有什么区别？

泄漏是指对象不再使用却仍被引用，无法回收，表现为内存缓慢上涨；溢出是指需要的内存超过了可用上限，表现为直接失败。长期泄漏最终会导致溢出，但两者不是一回事。

引用计数为什么还要配追踪式回收？

因为引用计数处理不了循环引用：两个对象互相指向，计数永远不为零。所以需要额外的可达性分析来清理这类环。反过来，引用计数的优点是对象能及时释放、停顿更短。

为什么分代收集有效？

因为它利用了「大多数对象很快就不用了」这一经验规律。把对象按存活时间分代，对年轻代频繁回收、成本低，对老年代少回收，总体开销就降下来了。代价是需要处理跨代引用。

伪共享为什么会让程序变慢？

因为 CPU 按缓存行整块管理，不同核心写同一行里的不同变量，也会导致缓存行来回失效。明明是两个无关变量，却像在抢同一把锁。解决办法是让热点变量各自独占一行，或者按核心分片统计。
