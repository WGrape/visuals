过拟合与正则化：为什么模型"背下了答案"却考不好

训练集上 99 分、测试集上 60 分，就是过拟合。本文讲清怎么从 loss 曲线判断过拟合/欠拟合、偏差-方差怎么权衡，以及 L1/L2、Dropout、数据增强、早停等正则化手段各自的作用原理，最后说明大模型时代的特殊之处。

一句话区分

欠拟合 Underfitting
训练集和测试集都很差。
模型太弱 / 训练不够 / 特征不行。
过拟合 Overfitting
训练集很好、测试集明显差。
模型把训练集的噪声和特例也背下来了。
判断的唯一依据：训练指标与验证指标之间的差距（泛化 gap），而不是训练集分数本身。

从 loss 曲线一眼看出来

看到验证 loss 触底反弹就该停了（早停）。继续训练只会让训练集分数更好看，但真实能力在下降。

为什么会过拟合：偏差-方差权衡

偏差 Bias（欠拟合）方差 Variance（过拟合）
含义模型假设太简单，连训练集规律都没学会模型对训练集的具体样本过于敏感
典型原因参数太少、特征太弱、训练轮数不够参数远多于数据量、数据噪声多、训太久
解法方向加大模型、加特征、训更久、降正则加数据、加正则、减模型、早停
总误差 ≈ 偏差² + 方差 + 不可约噪声。正则化的本质是：主动牺牲一点训练集拟合度，换取方差下降、泛化提升。

正则化手段一览

1. L2 / L1 正则（weight decay）

在损失里额外惩罚"过大的参数"：

L' = L + λ·Σθ² （L2）   |   L' = L + λ·Σ|θ| （L1）
L2：让参数整体变小、更平滑，是最常用的默认选项，也叫 weight decay
L1：会把不重要的参数直接压到精确的 0，天然做特征选择，产生稀疏解

2. Dropout

训练时按概率 p 随机把一部分神经元输出置 0。

为什么有效：强制网络不能依赖任何少数几个神经元的组合（防止"共适应"），等价于在训练大量不同的子网络并做集成。测试时不随机，而是按 1-p 缩放（或直接训练时用 inverted dropout，推理不用改）。

3. 数据增强

图像：翻转/裁剪/色彩抖动；文本：回译/同义替换；语音：加噪/变速。本质是用"免费制造更多样的样本"来直接降低方差，通常是最有效的手段。

4. 早停 Early Stopping

验证 loss 连续若干轮不再下降就停止训练。简单但几乎总是有效。

5. 其它

BatchNorm / LayerNorm（附带正则效果）
噪声注入
集成 / 模型平均
标签平滑
减小模型容量

大模型时代：过拟合这件事变了

传统小模型场景
  • 数据量有限、参数相对过剩
  • 要跑很多 epoch
  • 靠正则化压住过拟合
大模型预训练
  • 数据以万亿 token 计，基本只跑 1 个 epoch
  • 模型没机会反复"背"同一批数据
  • 主要威胁不是过拟合，而是数据质量与重复
但微调阶段过拟合非常常见：SFT 数据量小（几千到几万条）、模型巨大，跑 2~3 个 epoch 就可能把答案背下来。典型症状是"训练集 loss 掉得很快，但回答变死板、泛化变差"。此时要用小学习率、少 epoch、加 weight decay，并优先扩充高质量数据。
一句话总结：预训练靠数据量避免过拟合，微调靠正则化和早停避免过拟合。

面试速记卡

  • 判断依据：过拟合 = 训练好、验证差；欠拟合 = 两边都差。看 gap 不看绝对值。
  • 偏差-方差：正则化是牺牲一点偏差换方差下降。
  • L2 vs L1：L2 平滑缩小（weight decay，默认）；L1 产生稀疏、可做特征选择。
  • Dropout：训练随机置零防共适应，等价于子网络集成；测试时不随机。
  • 大模型：预训练基本不过拟合（1 epoch + 海量数据）；微调极易过拟合，小 lr + 少 epoch + 数据质量为先。

一、怎么判断过拟合

现象说明对策
训练误差远低于验证误差典型过拟合正则化 / 加数据 / 减容量
两者都高欠拟合（模型能力不足或特征不好）加大模型 / 加特征 / 训练更久
训练误差一直降，验证误差先降后升找到了最佳停止点早停：取验证误差最低的那一步
验证误差震荡但不上升可能是学习率偏大降学习率或加调度

二、正则化手段一览

手段做法直觉适用
L2 权重衰减损失里加 λ·Σw²惩罚大权重，让模型更平滑默认首选，几乎所有模型
L1 正则损失里加 λ·Σ|w|把不重要的权重压到 0，产生稀疏做特征选择时
Dropout训练时随机丢弃一部分神经元强迫网络不依赖任何单个特征全连接层、Transformer
数据增强对输入做保持标签的变换直接扩大数据多样性图像、语音、文本（最有效）
早停验证误差不再降就停在分岔点前收手所有场景，几乎零成本
BatchNorm对每层输入归一化附带轻微正则化效果已普遍默认使用
标签平滑把 hard label 换成软标签防止模型对预测过度自信分类任务
权重共享 / 参数量少从结构上限制容量容量小自然不容易背答案小数据集

三、L1 与 L2 到底差在哪

# 损失函数 loss = task_loss + l1_lambda * sum(abs(w)) + l2_lambda * sum(w**2) # L2（权重衰减）：惩罚与 w 的平方成正比 # 大权重被压得更狠，但不会到 0 -> 所有特征都保留一点 # 梯度：d/dw = 2 * l2 * w -> 每次更新都按比例缩小 w # 所以实现上常写成 w = w * (1 - lr*l2) - lr*grad # L1：惩罚与 |w| 成正比 # 梯度是常数 ±l1，会把小权重一路推到 0 -> 稀疏 # 用于特征选择：留下来的权重就是重要特征 # 直觉比喻： # L2 像「所有学生都减分」，但没人被淘汰 # L1 像「末位淘汰」，弱者直接归零
为什么 L2 也叫权重衰减

因为它的梯度正比于 w，更新时等价于每步先把 w 乘一个略小于 1 的系数，再减去任务梯度。这就是「衰减」的字面含义。注意 Adam 等自适应优化器里，L2 惩罚会被自适应学习率缩放，行为与 SGD 下不完全一致——这也是 Weight Decay 与 AdamW 分离的原因。

四、Dropout 为什么有效

两种解释，都很有说服力：

集成解释每次丢弃相当于训练一个不同的子网络，推理时相当于平均了指数多个子网络
鲁棒性解释强迫网络不能依赖任何单一神经元，必须学到冗余的、分散的表示
实现注意推理时不丢弃，但要按保留概率缩放输出（或训练时做 inverted dropout 预缩放）

五、深入自检

正则化越强越好吗？

不是。正则化太强会走向欠拟合——模型连基本规律都学不到。正确做法是从 0（或很小的默认值）开始，观察验证误差，逐步加大直到验证误差不再改善。

为什么加数据是最有效的手段？

因为过拟合的本质是「数据不足以约束模型」。加数据直接从根源上解决问题，而正则化只是在信息不足时做的妥协。这也是数据增强如此重要的原因。

大模型参数远超数据量却不严重过拟合，为什么？

这就是「双下降」与隐式正则化的现象：过参数化模型的优化过程本身倾向于找到平滑解；再加上大量数据、早停、正则化共同作用。但这也意味着「参数量 > 数据量」不再是判断过拟合的简单标准。

早停要用验证集，那验证集不就被污染了吗？

确实会有一点。标准做法是分三部分：训练集训练、验证集调参与早停、测试集只在最后评估一次。如果数据很少，用交叉验证取平均。

Dropout 在现代 LLM 里还用吗？

用得少了。大规模预训练本身数据量极大，过拟合风险低；而且 Transformer 普遍用 Pre-LN + 大 batch，Dropout 的收益不明显。但在微调小数据集时仍然常用。

正则化和归一化会互相干扰吗？

会。BatchNorm 之后再加 Dropout 有时会导致方差偏移（尤其在高丢弃率下）。实践中的顺序通常是 Conv/Linear -> BatchNorm -> 激活 -> Dropout，并且用较小的丢弃率。

首选手段L2 + 数据增强 + 早停
L1 vs L2L1 稀疏，L2 平滑
最强解药加数据 / 数据增强
