🐘 HBase 概览

构建在 HDFS 之上的列式 NoSQL 数据库

核心定位

📊

列式存储

按列族物理聚簇，适合海量稀疏宽表与按列扫描。

🚀

海量写入

基于 LSM 树，写吞吐极高，PB 级数据常见。

🔑

强一致行级

单行操作原子，无多行事务（2.x+ 有限多行事务）。

🧱

依赖 HDFS

数据落在 HDFS，借其副本保障可靠性。

与关系型 / MongoDB 区别

HBase 是『稀疏、分布式、多维有序映射表』：(rowkey, column-family:qualifier, timestamp) → value。没有 SQL、没有二级索引（需另建）、适合按 rowkey 点查与范围扫描，而非任意条件检索。

💡 HBase 适用：时序、日志、消息、画像等『写多读少、按 key 查』的海量场景；不适合多维度即席查询（那交给 ES / OLAP）。
