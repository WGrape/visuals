Bitmap

用位存储布尔状态，极省空间。典型：用户每日签到 SETBIT sign:2026-01-01 uid 1，BITCOUNT 统计。

HyperLogLog

用极少量内存（约 12KB）估算基数（去重计数），误差 ~0.81%。适合 UV、独立访客统计，不支持取明细。

GEO / Stream

GEO 基于 ZSet 存经纬度，支持半径查询（附近的人）；Stream 是追加日志式消息流，支持消费组，可作轻量 MQ。

🎯 面试问答

Q：HyperLogLog 能取出具体用户吗？
A：不能，只能估算基数。
Q：Bitmap 适合什么？
A：海量布尔标记（签到、在线状态）。
Q：Stream 和 List 做队列区别？
A：Stream 支持消费组、消息确认与回溯。
