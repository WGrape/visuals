🧭 MongoDB 副本集与分片

高可用与水平扩展

副本集（Replica Set）

一组维护相同数据集的 mongod：1 个 Primary 负责写，多个 Secondary 异步复制 oplog 并提供读。Primary 故障时自动选举新主，实现高可用。

分片（Sharding）

  • Shard：每个分片是一个副本集，存部分数据。
  • Mongos：查询路由，把请求分发到对应分片并汇总。
  • Config Server：存集群元数据与 chunk 映射。
  • Shard Key：决定数据如何分片，选错会导致热点 / 无法分散——务必高基数且写分散。
💡 分片是『重量级操作』：一旦启用很难更改 shard key。上线前务必根据访问模式慎重选择。
