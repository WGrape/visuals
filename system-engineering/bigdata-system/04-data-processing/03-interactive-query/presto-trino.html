MPP 架构

Coordinator 负责解析、规划与调度；Worker 并行执行。数据在内存中流水线式流转，避免落盘，因此延迟远低于 MR。

联邦查询

通过不同 Connector（Hive、MySQL、Kafka、ES……）可以把多个异构数据源当成一个库来 Join，非常适合交互式 BI 与跨源探查。

🎯 面试问答

Q：Presto 内存爆了怎么办？
A：内存密集查询需控制并发、加资源，或把大表预处理下沉到列式存储再查。
Q：Presto 和 Spark SQL 怎么选？
A：交互式即席查询选 Presto；需要复杂 ETL、多阶段、落盘容错选 Spark SQL。
