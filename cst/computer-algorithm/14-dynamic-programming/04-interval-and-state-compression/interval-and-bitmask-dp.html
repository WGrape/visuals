第 14 章 · 动态规划

按长度枚举区间，用位掩码表示集合

区间 DP 必须按长度从小到大枚举并常以「最后一个操作」划分区间；状态压缩 DP 用二进制整数表示集合，适用 n ≤ 20 的顺序决策问题。

区间 DP：按长度从小到大算

dp[i][j] 表示区间 [i, j] 上的最优值。它的特点是：大区间的答案由更小的子区间组合而来，所以必须按区间长度从小到大枚举，保证算 dp[i][j] 时它依赖的短区间已经算完。

for length in range(2, n + 1):          # 区间长度
    for i in range(n - length + 1):
        j = i + length - 1
        for k in range(i, j):          # 枚举分割点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j))

复杂度 O(n³)（长度 × 起点 × 分割点），空间 O(n²)。n 一般在几百以内。

石子合并：n 堆石子排成一排，每次合并相邻两堆，代价是两堆总重量，求最小总代价。cost(i,j) 就是区间和（可用前缀和 O(1) 得到）。

最常见的错误是按起点 i 从 0 到 n 枚举——那样算 dp[i][j] 时 dp[i][k] 或 dp[k+1][j] 可能还没算。长度必须是最外层循环。

典型区间 DP 问题

问题状态转移要点
石子合并dp[i][j]：合并区间的最小代价枚举分割点 + 区间和
括号匹配 / 最长合法括号串dp[i][j]：区间内最长合法长度若 s[i] 与 s[j] 配对则 dp[i][j] = dp[i+1][j−1] + 2
矩阵连乘最优括号化dp[i][j]：最少乘法次数枚举最后一次相乘的位置
戳气球dp[i][j]：开区间内戳完的最大得分枚举最后被戳的那个，而不是第一个
回文子串最少切割dp[i]：前缀最少切割 + 预处理回文表实质是一维版区间 DP

区间 DP 的一个通用技巧：枚举「最后一个操作」而不是「第一个操作」。因为最后一个操作能把区间干净地切成两半，第一个操作则不好定义。

状态压缩 DP：用一个整数表示集合

当 n 很小（通常 ≤ 20）而「哪些元素已用过」会影响决策时，把集合压缩成一个二进制整数 mask：第 i 位为 1 表示元素 i 已使用。

# TSP：从 0 出发，访问所有城市后回到 0 的最短路
# dp[mask][i] = 已访问集合为 mask、当前在 i 的最短距离
def tsp(dist):
    n = len(dist); full = (1 << n) - 1
    dp = [[float("inf")] * n for _ in range(1 << n)]
    dp[1][0] = 0
    for mask in range(1 << n):
        for i in range(n):
            if not (mask >> i) & 1 or dp[mask][i] == float("inf"): continue
            for j in range(n):
                if (mask >> j) & 1: continue
                dp[mask | (1 << j)][j] = min(
                    dp[mask | (1 << j)][j], dp[mask][i] + dist[i][j])
    return min(dp[full][i] + dist[i][0] for i in range(1, n))

复杂度 O(2n · n²)。常见位运算：

  • 判断第 i 位：(mask >> i) & 1
  • 置位：mask | (1 << i)；清位：mask & ~(1 << i)
  • 枚举子集：for sub in range(mask, 0, (sub - 1) & mask)（倒着来）

区间 DP 的遍历顺序是核心：必须按区间长度从小到大枚举，因为 dp[i][j] 依赖比它短的区间。写成 for i: for j: 而不按长度枚举，是区间 DP 最常见的错误。

模板代码

# 模板 1：区间 DP —— 石子合并（最小代价）
def merge_stones(stones):
    n = len(stones)
    pre = [0] * (n + 1)
    for i, s in enumerate(stones):
        pre[i + 1] = pre[i] + s            # 前缀和，O(1) 求区间和

    INF = float('inf')
    dp = [[0] * n for _ in range(n)]
    for length in range(2, n + 1):               # 关键：按长度从小到大
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = INF
            for k in range(i, j):                 # 枚举分割点
                dp[i][j] = min(dp[i][j],
                               dp[i][k] + dp[k + 1][j] + pre[j + 1] - pre[i])
    return dp[0][n - 1]
# 复杂度：O(n^3) 时间，O(n^2) 空间
# 模板 2：状态压缩 DP —— TSP
def tsp(dist):
    n = len(dist)
    INF = float('inf')
    size = 1 << n
    dp = [[INF] * n for _ in range(size)]
    dp[1][0] = 0                       # 从城市 0 出发，已访问 {0}

    for mask in range(size):
        for i in range(n):
            if dp[mask][i] == INF: continue
            for j in range(n):
                if mask & (1 << j): continue          # 已访问
                nmask = mask | (1 << j)
                dp[nmask][j] = min(dp[nmask][j], dp[mask][i] + dist[i][j])

    full = size - 1
    return min(dp[full][i] + dist[i][0] for i in range(n))
# 复杂度：O(n^2 * 2^n)；n=20 时约 4 亿次操作，勉强

# 位运算技巧（必须熟）
#   mask | (1<<j)        置位
#   mask & ~(1<<j)       清位
#   mask & (1<<j)        判断
#   mask & (mask-1)      去掉最低位的 1
#   mask & -mask         取最低位的 1
#   bin(mask).count('1') 或 mask.bit_count()   数 1 的个数

# 子集枚举（O(3^n)）
for mask in range(1 << n):
    sub = mask
    while sub:
        # 处理 sub 这个子集
        sub = (sub - 1) & mask

区间 DP 的识别特征：问题涉及「合并/消除相邻元素」且代价与合并顺序有关。石game 状态是 dp[i][j]，转移是枚举分割点 k，复杂度通常是 O(n³)。n 超过 500 时 O(n³) 不可行，需要优化。

区间按长度枚举、集合用位掩码表示，是这两类 DP 的入场信号。
