数据库（database/sql）

database/sql 的接口设计、驱动注册、查询、预处理与事务。一篇讲清 Go 操作关系型数据库的标准姿势。

概述

接口而非实现

database/sql 定义通用 SQL 接口，具体能力由驱动（如 go-sql-driver/mysql）提供；通过匿名导入注册驱动。

database/sql 内置连接池：SetMaxOpenConns / SetMaxIdleConns / SetConnMaxLifetime 控制池行为。
打开与驱动

匿名导入注册

sql.Open 仅校验参数不建连；真正建连延迟到首次使用；驱动通过 import _ 触发 init 注册到 sql.Register。

import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)
db, err := sql.Open("mysql", "user:pwd@/dbname")
db.SetMaxOpenConns(20)
err = db.Ping()  // 真正建立连接
查询

Scan 到变量

Query/QueryRow 取多行/单行；用 Scan 把列填进变量；注意 NULL 用 sql.NullString 等可空类型接。

var name string
err := db.QueryRow("SELECT name FROM u WHERE id=?", 1).Scan(&name)

rows, _ := db.Query("SELECT id,name FROM u")
for rows.Next() {
    var id int; var n string
    rows.Scan(&id, &n)
}
写入

Exec 改数据

INSERT/UPDATE/DELETE 用 Exec；LastInsertId、RowsAffected 取结果；参数占位符用 ?（具体看驱动）。

res, _ := db.Exec("INSERT INTO u(name) VALUES(?)", "Li")
id, _ := res.LastInsertId()
事务

Begin/Commit/Rollback

db.Begin 开事务，tx 上的操作在同一连接；成功 Commit，出错 Rollback；用 defer tx.Rollback() 兜底。

tx, _ := db.Begin()
defer tx.Rollback()
tx.Exec("UPDATE a SET ...")
tx.Exec("UPDATE b SET ...")
tx.Commit()
