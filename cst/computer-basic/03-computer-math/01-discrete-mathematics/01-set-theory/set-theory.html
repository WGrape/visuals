集合论：数学的词汇表

集合是无序、无重复的对象汇集。并交差补、幂集、笛卡尔积——这些运算直接对应数据库的 JOIN、位运算与子集枚举。

核心速览

基本运算

并 ∪、交 ∩、差 −、补 ᶜ、对称差 △

幂集 P(A)

所有子集构成的集合，大小 2^|A|

笛卡尔积

A × B 是所有有序对，对应 SQL 的 CROSS JOIN

基数

有限集的元素个数；无限集用「能否一一对应」比较

什么是集合

集合是确定的、互不相同的对象的整体。三个关键词：

确定性

任一对象要么属于、要么不属于，不含糊。「高个子的人」不构成集合（标准模糊）。

互异性

元素不重复：{1, 1, 2} 就是 {1, 2}。这与「多重集 multiset」不同。

无序性

{1, 2} 与 {2, 1} 是同一个集合；需要顺序时要用序列/元组。

表示法

列举法 {1,2,3}；描述法 {x | x 是偶数且 x < 10}

特殊集合：∅（空集，|∅| = 0）、U（全集）、N/Z/Q/R（自然数/整数/有理数/实数）。注意 ∅ 与 {∅} 不同——后者是一个「含有空集作为元素」的集合，基数为 1。

基本运算与文氏图

# 集合运算的位掩码实现（全集不超过机器字长时最高效）
A, B = 0b101101, 0b011010        # 两个子集
union        = A | B             # 并集
inter        = A & B             # 交集
diff         = A & ~B            # 差集
sym_diff     = A ^ B             # 对称差（异或！）
print(bin(union), bin(inter), bin(diff), bin(sym_diff))

运算律（与布尔代数完全同构）

律表达式
交换律A∪B = B∪A，A∩B = B∩A
结合律(A∪B)∪C = A∪(B∪C)
分配律A∩(B∪C) = (A∩B)∪(A∩C)
德摩根律(A∪B)ᶜ = Aᶜ∩Bᶜ，(A∩B)ᶜ = Aᶜ∪Bᶜ
吸收律A∪(A∩B) = A，A∩(A∪B) = A
幂等律A∪A = A，A∩A = A
补集律A∪Aᶜ = U，A∩Aᶜ = ∅
这张表与布尔代数、命题逻辑的运算律完全同构：∪ ↔ ∨ ↔ OR，∩ ↔ ∧ ↔ AND，ᶜ ↔ ¬ ↔ NOT。理解了这个同构，就能在「集合运算」「逻辑表达式」「位运算」「SQL 条件」之间自由迁移。

幂集：为什么是 2ⁿ

幂集 P(A) 是 A 的所有子集构成的集合。构造一个子集时，每个元素独立地有「选 / 不选」两种可能，由乘法原理得 2ⁿ。

from itertools import combinations, chain

def powerset(items):
    """用位掩码枚举全部子集：O(n·2ⁿ)"""
    n = len(items)
    for mask in range(1 << n):
        yield [items[i] for i in range(n) if mask >> i & 1]

print(list(powerset(['a', 'b', 'c'])))
# [[], ['a'], ['b'], ['a','b'], ['c'], ['a','c'], ['b','c'], ['a','b','c']]

# 性质：|P(A)| = 2^|A|；P(A) 的幂集是 2^(2^|A|)
# 恒等式：C(n,0) + C(n,1) + … + C(n,n) = 2ⁿ（子集按大小分类计数）
2ⁿ 的爆炸速度：n = 20 → 约 100 万；n = 30 → 约 10 亿；n = 60 → 约 10¹⁸（超过一秒内可枚举的量级）。这解释了为什么子集型问题（0/1 背包、TSP、集合覆盖）是 NP 困难的，也解释了为什么「状态压缩 DP」通常只能处理 n ≤ 20~25。

笛卡尔积与关系

A × B = {(a, b) | a ∈ A, b ∈ B}，元素个数 |A|·|B|。注意有序：(a,b) ≠ (b,a)（当 a≠b），所以 A×B ≠ B×A。

概念数学程序 / 数据库
笛卡尔积A × B，所有有序对CROSS JOIN、嵌套循环
二元关系R ⊆ A × B邻接矩阵、外键表
n 元关系R ⊆ A₁ × … × Aₙ关系数据库的一张表
函数特殊的 R（每个 x 至多一个 y）映射、字典
# 关系数据库的数学基础就是集合论
# 一张表 = 一个 n 元关系（行的集合，集合天然去重）
# SELECT ... WHERE     ⟹ 选择（σ，筛选行）
# SELECT a, b FROM     ⟹ 投影（π，筛选列）
# JOIN                 ⟹ 笛卡尔积 + 选择
# UNION / INTERSECT    ⟹ 集合并 / 交
# DISTINCT             ⟹ 去重（把多重集变回集合）

# 因此 SQL 的很多等价改写就是集合恒等式
# 例：A JOIN B ON ... ⟹ σ(A × B)

基数：怎么比较无限集的大小

有限集的基数是元素个数；无限集比较大小靠能否建立双射（一一对应）——这是康托尔的革命性思想。

集合基数说明
自然数 Nℵ₀（可数无限）最小的无限
整数 Zℵ₀与 N 一样多！（可一一对应）
有理数 Qℵ₀与 N 一样多（康托尔配对）
实数 R2^(ℵ₀) > ℵ₀不可数，对角线论证
P(N) 幂集2^(ℵ₀)康托尔定理：|P(A)| > |A| 恒成立
康托尔对角线论证：假设能把 [0,1) 内所有实数排成序列 r₁, r₂, …，构造一个新数 d，使它的第 i 位与 rᵢ 的第 i 位不同。于是 d 与每个 rᵢ 都至少一位不同，不在序列中——矛盾，故实数不可数。这个技巧与「停机问题不可判定」「不存在万能程序」的对角化证明是同一个套路。

常见误区

  • ∅ 与 {∅}：前者没有元素，后者有 1 个元素（那个元素是空集）。
  • ∈ 与 ⊆：a ∈ A 是「a 是 A 的元素」；A ⊆ B 是「A 的每个元素都在 B 中」。层次不同。
  • 集合天然去重：{1,1,2} = {1,2}；数据库表里允许重复行，严格说是多重集，需要 DISTINCT 才回到集合语义。
  • 无限集可以与真子集等势：偶数集与整数集元素「一样多」（n ↔ 2n 是双射）——这是无限集区别于有限集的本质特征。

🎯 常见问法与答题要点

Q：集合的三个特性是什么？为什么「高个子的人」不是集合？

A：集合要求 ① 确定性（任一对象要么属于要么不属于）、② 互异性（元素不重复）、③ 无序性。「高个子的人」违反确定性——「高」没有明确阈值，边界模糊，无法判断某人是否属于它。对应到工程：给集合下定义时必须给出可判定的成员条件（如「身高 > 180cm」），否则既无法存储也无法判断——这与「模糊集合 fuzzy set」和「谓词必须可判定」直接相关。

Q：为什么 A − B 不等于 B − A？

A：因为差集不交换：A − B 保留「属于 A 但不属于 B」的元素，方向相反自然结果不同。例：A = {1,2,3}、B = {2,3,4}，则 A − B = {1}，B − A = {4}。若需要「只在其中一边」的对称概念，要用对称差 A △ B = (A−B) ∪ (B−A)，它是交换的，在位运算中正好对应异或 XOR。常见错误是在 SQL 里把 NOT IN 的方向写反。

Q：幂集为什么有 2ⁿ 个元素？

A：构造子集时，每个元素都独立地有「选」或「不选」两种选择，由乘法原理，n 个元素共 2×2×…×2 = 2ⁿ 种组合。等价视角：子集与长度为 n 的 0/1 串一一对应（第 i 位表示第 i 个元素是否入选），而 0/1 串有 2ⁿ 个——这正是位掩码枚举的数学依据。工程含义：2ⁿ 是指数爆炸的原型，n = 30 就达 10⁹，因此子集枚举类问题必须靠 DP、剪枝或近似算法。

Q：德摩根律在集合论里怎么说？有什么用？

A：(A∪B)ᶜ = Aᶜ∩Bᶜ，(A∩B)ᶜ = Aᶜ∪Bᶜ——补集穿过运算时翻转运算并分别取补。用途：① 化简复杂的集合表达式；② SQL 中把 NOT (A AND B) 改写为 (NOT A) OR (NOT B) 以命中索引；③ 逻辑电路化简（NAND/NOR 互换）；④ 与量词的对偶律 ¬∀x = ∃x¬ 形式一致，是同一结构的不同表现。它是「否定」这一操作的通用规律。

Q：无限集怎么比较大小？整数和偶数一样多吗？

A：靠能否建立双射（一一对应）：能一一对应就等势。整数与偶数确实「一样多」——映射 n ↔ 2n 是双射，尽管偶数集是整数集的真子集（这正是无限集区别于有限集的本质：无限集可与真子集等势）。同理有理数 Q 也与 N 等势（可用康托尔配对函数枚举）。但实数 R 严格多于 N——康托尔对角线论证证明不可数，基数 2^(ℵ₀) > ℵ₀。

Q：康托尔对角线论证的思路是什么？它和停机问题有什么关系？

A：思路：假设 [0,1) 的所有实数可排成序列 r₁, r₂, …，构造数 d 使其第 i 位与 rᵢ 的第 i 位不同，则 d 与序列中每个数都至少一位不同，d 不在序列中——矛盾，故不可数。与停机问题的关系：两者用的是同一个对角化套路——假设存在「完备列表」（所有实数 / 所有可判定程序），然后构造一个与列表中每一项都故意不同的新对象，从而推翻完备性。哥德尔不完备定理、Rice 定理也都是这一思想的变体。

Q：集合论和关系数据库有什么关系？

A：关系数据库的数学基础就是集合论与关系代数：① 一张表 = 一个 n 元关系（笛卡尔积的子集，即元组的集合）；② WHERE = 选择 σ（筛选行）；③ SELECT 列 = 投影 π（筛选列）；④ JOIN = 笛卡尔积 + 选择；⑤ UNION/INTERSECT/EXCEPT = 集合的并/交/差；⑥ DISTINCT = 把多重集去重回集合。理解了这层对应，SQL 的等价改写与优化就成了集合恒等式的应用。

Q：康托尔定理 |P(A)| > |A| 说明了什么？

A：它说明幂集运算总能产生严格更大的无穷，因此不存在「最大的无穷」——ℵ₀ < 2^ℵ₀ < 2^(2^ℵ₀) < …，无穷有无穷多层。证明同样是对角化：假设存在双射 f: A → P(A)，构造集合 D = {x ∈ A | x ∉ f(x)}，则 D 不可能是任何 f(a)（代入 a 即得矛盾）。CS 中的回响：这个结构与「不存在能判定所有程序性质的算法」（Rice 定理）、「停机问题不可判定」完全同构——自我指涉 + 对角化是计算理论的核心武器。
