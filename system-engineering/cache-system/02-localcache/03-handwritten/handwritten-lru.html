LinkedHashMap 实现

重写 removeEldestEntry，开启 accessOrder=true，访问即把节点移到链表尾（或头，依实现）；超容量时自动淘汰最久未用。

双向链表 + HashMap

HashMap 存 key→节点，双向链表维护访问顺序。get 命中后把节点移到头；put 超容时删尾节点。两者配合实现 O(1) 读写与淘汰。

为什么是 O(1)

HashMap 提供 O(1) 查找，链表移动是局部指针操作，互不依赖，故整体 O(1)。

🎯 面试问答

Q：为什么不用数组？
A：数组删中间元素要搬移，O(n)。
Q：LinkedHashMap 的 accessOrder？
A：true 时访问顺序即 LRU 顺序。
Q：并发 LRU 怎么做？
A：加锁或用 ConcurrentLinkedHashMap 思路（Caffeine 前身）。
