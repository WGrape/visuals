前向传播与反向传播：神经网络是怎么"学会"的

前向传播负责"算出一个答案"，反向传播负责"算出每个参数该背多少锅"。整个深度学习的训练过程，就是这两步反复循环。本文用计算图和链式法则把它彻底讲透。

一句话概括

前向传播：输入从第一层流到最后一层，得到预测值 y_hat，途中把每层的中间结果缓存下来。

反向传播：用损失函数算出的误差，从最后一层倒着往回传，靠链式法则算出每一个参数对误差的"贡献度"（梯度），然后让参数沿着减小误差的方向挪一小步。

记住这个循环：前向算预测 → 算损失 → 反向算梯度 → 更新参数。大模型预训练做的就是这件事，只不过规模是千亿参数、万亿 token。

前向传播：从输入到预测

一个最简单的全连接层做的事只有两步：加权求和，再过一个非线性激活。

z = W·x + b   →   a = f(z)
  • x：上一层送来的输入向量
  • W：这一层的权重矩阵（模型真正要学的参数）
  • b：偏置
  • f：激活函数（ReLU / GELU / SwiGLU 等），没有它，多层线性变换叠加后仍然等价于一层线性变换，网络就白堆了
大模型里的 "层" 不是全连接层，而是 注意力层 + FFN 层，但本质完全一样：都是 z = W·x + b 再过激活，只是 W 换成了 Q/K/V 投影矩阵和前馈矩阵。

损失：先知道"差多少"，才知道"往哪改"

损失函数把"预测值和真实答案的差距"压成一个标量数字。有了这个数字，训练才有目标。

回归
MSE = (y - ŷ)²
预测连续数值
分类
CE = -Σ y·log(ŷ)
大模型下一个 token 预测就用它

大语言模型的预训练目标就是交叉熵：让正确下一个 token 的概率尽量接近 1。所谓"模型变强"，就是这个词表上的交叉熵一路下降。

反向传播：链式法则的工程实现

我们想知道：损失 L 对某个靠前的权重 W₁ 的梯度 ∂L/∂W₁。W₁ 离 L 隔着好几层，直接求很难；但链式法则允许我们拆成一串局部梯度的乘积：

∂L/∂W₁ = (∂L/∂a₃) · (∂a₃/∂z₃) · (∂z₃/∂a₂) · (∂a₂/∂z₂) · (∂z₂/∂W₁)

关键在于：每一项的局部梯度都只需要本层的缓存值，而前向传播时已经把 z、a 全存下来了。所以反向传播不需要重新算前向，只是倒着做一串小乘法。

为什么"反向"比"逐个参数数值微分"快得多

数值微分（朴素做法）
每个参数扰动一次、重跑一遍前向。
千亿参数 = 千亿次前向，不可行。
反向传播
一次前向 + 一次反向，同时拿到所有参数梯度。
复杂度与前向同阶（约 2~3 倍）。
代价是显存：前向的中间激活必须缓存到反向用完为止。这就是为什么训练比推理吃显存得多，也是梯度检查点（用时间换显存，只存部分激活、反向时重算）存在的原因。

用一个极简例子走一遍

设 z = w·x，a = f(z)，L = (a - y)²，求 ∂L/∂w：

∂L/∂w = (∂L/∂a) · (∂a/∂z) · (∂z/∂w) = 2(a-y) · f'(z) · x

注意最后乘的是 x：输入越大，这个参数拿到的梯度越大。这就是为什么输入要归一化——否则某些特征维度会持续产生巨大梯度，训练不稳定。

然后按梯度下降更新（lr 是学习率）：

w ← w - lr · ∂L/∂w

常见坑：梯度消失与梯度爆炸

反向传播是一串梯度连乘。层数一多，这串乘积就会出问题：

现象成因表现主流解法
梯度消失激活函数导数长期 < 1（如 sigmoid 两端），连乘后趋近 0浅层参数几乎不更新，模型学不动ReLU 类激活、残差连接（ResNet/Transformer 的 x + F(x)）、LayerNorm
梯度爆炸导数长期 > 1，连乘后指数增长loss 突然 NaN、参数变成 inf梯度裁剪（clip by norm）、残差连接、合理初始化
Transformer 能堆到上百层，核心就是靠 残差连接 + Pre-LN 归一化 给梯度修了一条"高速公路"，让它不至于在连乘中衰减掉。

面试速记卡

  • 前向 vs 反向：前向算预测并缓存中间激活；反向用链式法则从损失倒推每个参数的梯度。
  • 为什么要缓存激活：反向要用本层的输入和中间值算局部梯度，代价是显存。
  • 复杂度：反向传播一次拿到全部梯度，约等于 2~3 倍前向计算量，远优于逐参数数值微分。
  • 梯度消失/爆炸：本质是深层梯度连乘；解法是 ReLU + 残差 + 归一化 + 梯度裁剪。
  • 与大模型的关系：预训练 = 在万亿 token 上反复执行"前向 → 交叉熵损失 → 反向 → 更新"这个循环。

前向与反向传播的计算量

量关系说明
前向计算量1 倍每层的矩阵乘 + 激活
反向计算量约 2 倍要算输入的梯度（1 次）和权重的梯度（1 次）
总训练计算量约 3 倍前向所以常说的「FLOPs」通常指前向，训练要乘 3
激活值显存O(batch × 各层输出)反向要用，所以前向的激活必须全部保留
权重显存参数量 × 精度字节7B 模型 FP16 = 14 GB
梯度显存与权重同大小再加 14 GB
优化器状态（Adam）2 倍参数（m 和 v）再加 28 GB
混合精度训练的 master weightsFP32 副本再加 28 GB

训练 7B 模型的显存账本（FP16 + Adam + 混合精度）：权重 14GB + 梯度 14GB + Adam 状态 28GB + FP32 主权重 28GB = 84 GB，加上激活值，单卡 80GB 都装不下。这就是为什么需要 ZeRO/DeepSpeed 来做优化器状态分片——ZeRO-3 把这三部分都分片到多卡，显存降到 1/N。

手算与代码

# 两层网络的手算（理解反向传播）
import numpy as np

# 前向
x = np.array([1.0, 2.0])              # 输入 (2,)
W1 = np.array([[0.1, 0.2], [0.3, 0.4]])   # (2,2)
b1 = np.array([0.1, 0.1])
z1 = W1 @ x + b1                       # (2,) = [0.1+0.6+0.1, 0.2+0.8+0.1] = [0.8, 1.1]
a1 = np.maximum(0, z1)                 # ReLU -> [0.8, 1.1]

W2 = np.array([[0.5, 0.6]])            # (1,2)
z2 = W2 @ a1                           # = 0.5*0.8 + 0.6*1.1 = 1.06
y_pred = 1 / (1 + np.exp(-z2))         # sigmoid -> 0.743
loss = 0.5 * (y_pred - 1.0) ** 2       # MSE，真实标签=1.0

# 反向（链式法则，从后往前）
dL_dy  = y_pred - 1.0                          # = -0.257
dy_dz2 = y_pred * (1 - y_pred)                 # sigmoid 导数 = 0.191
dL_dz2 = dL_dy * dy_dz2                        # = -0.0491

dL_dW2 = dL_dz2 * a1                           # (2,) 外积关系
dL_da1 = W2.T * dL_dz2                         # (2,) 传回上一层
dL_dz1 = dL_da1 * (z1 > 0)                     # ReLU 导数：>0 为 1，否则 0
dL_dW1 = np.outer(dL_dz1, x)                   # (2,2)

# 关键：每一层的梯度 = (上游梯度) × (本层局部导数)
# 这就是为什么 autograd 只需要记录计算图就能自动求导
# 用 PyTorch 验证手算
import torch
x = torch.tensor([1.0, 2.0])
W1 = torch.tensor([[0.1, 0.2], [0.3, 0.4]], requires_grad=True)
W2 = torch.tensor([[0.5, 0.6]], requires_grad=True)

a1 = torch.relu(W1 @ x + 0.1)
y  = torch.sigmoid(W2 @ a1)
loss = 0.5 * (y - 1.0) ** 2
loss.backward()
print(W1.grad, W2.grad)      # 与手算一致

# 梯度检查（ numerical gradient check，调试必备）
def gradcheck(f, x, eps=1e-5):
    """用 (f(x+e)-f(x-e))/(2e) 验证解析梯度"""
    analytic = x.grad.clone()
    numeric = torch.zeros_like(x)
    for i in range(x.numel()):
        old = x.flat[i].item()
        x.flat[i] = old + eps; f1 = f().item()
        x.flat[i] = old - eps; f2 = f().item()
        x.flat[i] = old
        numeric.flat[i] = (f1 - f2) / (2 * eps)
    return torch.allclose(analytic, numeric, atol=1e-4)
# 写自定义层时<b>必须</b>做梯度检查，否则可能有隐性 bug

排障清单

症状原因处理
loss 不降学习率太大/太小；梯度消失试 1e-3 → 1e-5；检查梯度范数是否为 0
梯度爆炸（nan）学习率太大 / 没做梯度裁剪clip_grad_norm_(1.0)；降学习率
梯度消失深层网络 + sigmoid/tanh换 ReLU/GELU；加残差连接；用 LayerNorm
显存 OOM激活值占大头（batch 太大）降 batch；用梯度检查点（时间换空间，显存降到 1/√n）
训练慢前向+反向 3 倍计算混合精度（FP16/BF16，快 2~3 倍）；加大 batch 提高 GPU 利用率
自定义层结果不对反向传播写错了做数值梯度检查
推理时结果不对忘了 model.eval()Dropout/BatchNorm 在训练与推理行为不同

梯度检查点（gradient checkpointing）：训练时不保存所有层的激活，只在需要时重新计算。显存从 O(n) 降到 O(√n)，代价是多一次前向计算（约慢 30%）。这是显存不够时最有效的手段。
