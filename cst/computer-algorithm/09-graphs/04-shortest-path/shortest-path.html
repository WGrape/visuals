最短路径

从一张城市的路网里，找到从起点到所有终点「走得最近」的路线。这背后是计算机最常被使用的算法家族之一。

一、问题：什么是「单源最短路」

给定一个带权图（边上有数值，表示距离/时间/成本）和一个起点 s，单源最短路径要求算出 s 到每个节点的最少代价。最短路不一定边数最少，而是权值之和最小。

类比：把图想成地铁线网，边权是站间耗时，最短路径就是「从我家出发，换乘最少时间到达任意目的地」的最优方案。

示例带权图（无向，下文 Dijkstra 演示按无向处理）。从 A 出发，最终距离为 A0, B4, C2, D9, E9, F12。

二、Dijkstra：贪心 + 优先队列

Dijkstra 是处理非负权最短路的经典算法。它维护一个「已确定最短距离」的集合，每一步从「还未确定」的节点里挑当前估计距离最小的那一个，把它确定下来，再用它去「松弛（relax）」邻居——如果「经过我到你」比「你原来的估计」更短，就更新。

为什么要求非负权？因为一旦出现负权，刚被「确定」的节点可能被后面更短的负路径推翻，贪心保证就失效了。
def dijkstra(graph, s):
    dist = {u: inf for u in graph}; dist[s] = 0
    pq = [(0, s)]                       # 优先队列：最小代价优先
    while pq:
        d, u = heappop(pq)
        if d > dist[u]: continue        # 过期条目，跳过
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:    # 松弛
                dist[v] = dist[u] + w
                heappush(pq, (dist[v], v))
    return dist

三、Bellman-Ford 与 Floyd-Warshall

Bellman-Ford

允许负权边，反复对所有边「松弛」V−1 轮。第 V 轮若还能更新，说明存在负权环，此时最短路无定义。

Floyd-Warshall

求全源最短路（任意两点间）。动态规划思想：枚举中转点 k，尝试 dist[i][j] = min(dist[i][j], dist[i][k]+dist[k][j])。复杂度 O(V³)。

四、三种算法怎么选

算法适用条件时间复杂度典型用途
Dijkstra非负权、单源O((V+E)logV)导航、网络路由
Bellman-Ford可负权、单源、可查负环O(VE)汇率套利检测
Floyd-Warshall全源、可负权(无负环)O(V³)所有点对距离矩阵
一句话记忆：非负权挑 Dijkstra，要处理负权或找负环用 Bellman-Ford，要算「任意两点」用 Floyd-Warshall。
