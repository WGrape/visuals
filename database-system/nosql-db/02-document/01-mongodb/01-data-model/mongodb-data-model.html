🧬 MongoDB 数据模型

BSON、文档、集合与 _id

核心概念

📦

Document

一条 BSON 记录，键值对集合，支持嵌套文档与数组。

📚

Collection

文档的容器，相当于『表』，但无强制统一结构。

🆔

_id

每个文档默认的主键，ObjectId（含时间戳），索引唯一。

🔢

BSON

二进制 JSON，支持 Date、BinData、ObjectId、Decimal128 等类型。

建模思路

  • 嵌入式（反范式）：一对少 / 一对多且常一起读，直接嵌套子文档/数组，减少查询次数。
  • 引用（范式）：一对多且体量巨大、或需要复用的数据，用 $ref 般的字段引用，按需 $lookup。
  • 用 dot notation（如 addr.city）精确查询嵌套字段。
💡 经验法则：先按『访问模式』设计，而不是先画 ER 图。读多写少、整体读取的场景优先嵌入式。
