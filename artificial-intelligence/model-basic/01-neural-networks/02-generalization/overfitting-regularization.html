过拟合与正则化：为什么模型"背下了答案"却考不好

训练集上 99 分、测试集上 60 分，就是过拟合。本文讲清怎么从 loss 曲线判断过拟合/欠拟合、偏差-方差怎么权衡，以及 L1/L2、Dropout、数据增强、早停等正则化手段各自的作用原理，最后说明大模型时代的特殊之处。

一句话区分

欠拟合 Underfitting
训练集和测试集都很差。
模型太弱 / 训练不够 / 特征不行。
过拟合 Overfitting
训练集很好、测试集明显差。
模型把训练集的噪声和特例也背下来了。
判断的唯一依据：训练指标与验证指标之间的差距（泛化 gap），而不是训练集分数本身。

从 loss 曲线一眼看出来

看到验证 loss 触底反弹就该停了（早停）。继续训练只会让训练集分数更好看，但真实能力在下降。

为什么会过拟合：偏差-方差权衡

偏差 Bias（欠拟合）方差 Variance（过拟合）
含义模型假设太简单，连训练集规律都没学会模型对训练集的具体样本过于敏感
典型原因参数太少、特征太弱、训练轮数不够参数远多于数据量、数据噪声多、训太久
解法方向加大模型、加特征、训更久、降正则加数据、加正则、减模型、早停
总误差 ≈ 偏差² + 方差 + 不可约噪声。正则化的本质是：主动牺牲一点训练集拟合度，换取方差下降、泛化提升。

正则化手段一览

1. L2 / L1 正则（weight decay）

在损失里额外惩罚"过大的参数"：

L' = L + λ·Σθ² （L2）   |   L' = L + λ·Σ|θ| （L1）
L2：让参数整体变小、更平滑，是最常用的默认选项，也叫 weight decay
L1：会把不重要的参数直接压到精确的 0，天然做特征选择，产生稀疏解

2. Dropout

训练时按概率 p 随机把一部分神经元输出置 0。

为什么有效：强制网络不能依赖任何少数几个神经元的组合（防止"共适应"），等价于在训练大量不同的子网络并做集成。测试时不随机，而是按 1-p 缩放（或直接训练时用 inverted dropout，推理不用改）。

3. 数据增强

图像：翻转/裁剪/色彩抖动；文本：回译/同义替换；语音：加噪/变速。本质是用"免费制造更多样的样本"来直接降低方差，通常是最有效的手段。

4. 早停 Early Stopping

验证 loss 连续若干轮不再下降就停止训练。简单但几乎总是有效。

5. 其它

BatchNorm / LayerNorm（附带正则效果）
噪声注入
集成 / 模型平均
标签平滑
减小模型容量

大模型时代：过拟合这件事变了

传统小模型场景
  • 数据量有限、参数相对过剩
  • 要跑很多 epoch
  • 靠正则化压住过拟合
大模型预训练
  • 数据以万亿 token 计，基本只跑 1 个 epoch
  • 模型没机会反复"背"同一批数据
  • 主要威胁不是过拟合，而是数据质量与重复
但微调阶段过拟合非常常见：SFT 数据量小（几千到几万条）、模型巨大，跑 2~3 个 epoch 就可能把答案背下来。典型症状是"训练集 loss 掉得很快，但回答变死板、泛化变差"。此时要用小学习率、少 epoch、加 weight decay，并优先扩充高质量数据。
一句话总结：预训练靠数据量避免过拟合，微调靠正则化和早停避免过拟合。

面试速记卡

  • 判断依据：过拟合 = 训练好、验证差；欠拟合 = 两边都差。看 gap 不看绝对值。
  • 偏差-方差：正则化是牺牲一点偏差换方差下降。
  • L2 vs L1：L2 平滑缩小（weight decay，默认）；L1 产生稀疏、可做特征选择。
  • Dropout：训练随机置零防共适应，等价于子网络集成；测试时不随机。
  • 大模型：预训练基本不过拟合（1 epoch + 海量数据）；微调极易过拟合，小 lr + 少 epoch + 数据质量为先。
