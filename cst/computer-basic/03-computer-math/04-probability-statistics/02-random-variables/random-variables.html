随机变量与常见分布：给随机性建模

随机变量把随机结果变成数字，分布描述数字出现的规律；期望与方差刻画中心与离散程度。

核心速览

离散型

取有限或可列个值，用 PMF 描述：伯努利、二项、泊松、几何

连续型

取值连续，用 PDF 与积分描述：均匀、指数、正态

期望 E[X]

长期平均；线性，不要求独立

方差 Var

离散程度；独立时方差可加

随机变量：把结果数字化

随机变量 X 是从样本空间到实数的函数。有了它，「掷两次骰子的点数和」就能写成一个可运算的量，而不是一段文字描述。

离散型分布速查

分布记号期望方差典型场景
伯努利Bern(p)pp(1−p)单次成功/失败
二项B(n,p)npnp(1−p)n 次独立试验的成功次数
几何Geom(p)1/p(1−p)/p²首次成功所需试验次数
泊松Pois(λ)λλ单位时间/空间内的稀有事件数
超几何Hyper(N,K,n)nK/N—不放回抽样（抽奖、质检）
负二项NB(r,p)r/pr(1−p)/p²第 r 次成功所需试验数
# 二项分布：n 次独立伯努利试验的成功次数
from math import comb
def binom_pmf(k, n, p):
    return comb(n, k) * p**k * (1-p)**(n-k)

print(round(binom_pmf(7, 10, 0.5), 4))    # 0.1172

# 泊松分布：λ 是单位时间内的平均事件数
from math import exp, factorial
def poisson_pmf(k, lam):
    return exp(-lam) * lam**k / factorial(k)

print(round(poisson_pmf(3, 2), 4))        # 0.1804

# 泊松近似二项：n 大、p 小时 B(n,p) ≈ Pois(np)
print(round(binom_pmf(3, 1000, 0.002), 4), round(poisson_pmf(3, 2), 4))  # 几乎相等
泊松分布的工程价值极高：它描述「单位时间内随机到达的事件数」，是排队论、容量规划、限流设计的标准模型。例如某接口平均每秒 100 次请求，那么「一秒内到达超过 130 次」的概率可用 Pois(100) 精确算出，据此设置限流阈值与缓冲队列长度。

连续型分布速查

分布记号期望方差典型场景
均匀U(a,b)(a+b)/2(b−a)²/12随机采样、无信息先验
指数Exp(λ)1/λ1/λ²事件间隔时间；无记忆性
正态N(μ,σ²)μσ²误差、测量、CLT 极限分布
对数正态LogNormale^(μ+σ²/2)—延迟、文件大小等长尾量
帕累托Pareto(α)α/(α−1)（α>1）∞（α≤2）长尾：财富、请求大小
卡方 / t / Fχ², t, F——假设检验的抽样分布
指数分布的无记忆性是它最独特的性质：P(X > s+t | X > s) = P(X > t)——已经等了 s 秒，再多等 t 秒的概率与从零开始等 t 秒完全一样。这意味着「已经等了很久」不会让事件更可能发生（与直觉相反）。它也是唯一具有无记忆性的连续分布，因此成为建模「随机到达间隔」的标准选择（泊松过程的间隔时间恰好服从指数分布）。

期望与方差的运算律

性质公式是否需要独立
期望线性E[aX + bY + c] = aE[X] + bE[Y] + c❌ 不需要
乘积期望E[XY] = E[X]E[Y]✅ 需要独立
方差平移Var(X + c) = Var(X)❌
方差缩放Var(aX) = a²Var(X)❌
方差可加Var(X + Y) = Var(X) + Var(Y)✅ 需要独立（或不相关）
方差定义式Var(X) = E[X²] − (E[X])²—
# 协方差与相关系数：衡量两个变量的共同波动
# Cov(X,Y) = E[XY] − E[X]E[Y]
# ρ = Cov(X,Y) / (σ_X σ_Y)，取值 [−1, 1]，0 表示无线性相关

import statistics as st
X = [1, 2, 3, 4, 5]
Y = [2, 4, 5, 4, 6]
mx, my = st.mean(X), st.mean(Y)
cov = sum((x-mx)*(y-my) for x, y in zip(X, Y)) / len(X)
rho = cov / (st.pstdev(X) * st.pstdev(Y))
print(round(cov, 3), round(rho, 3))     # 2.0  0.894 → 强正相关
相关系数只衡量线性关系：ρ = 0 不代表独立（如 Y = X² 且 X 对称分布时 ρ = 0，但二者完全相关）。另外相关 ≠ 因果——冰淇淋销量与溺水人数高度正相关，共同原因是「气温」。

分布之间的关系（记忆地图）

关系说明
伯努利 → 二项n 个独立伯努利之和 = 二项分布 B(n,p)
二项 → 泊松n 大、p 小、np = λ 适中时，B(n,p) ≈ Pois(λ)
二项 → 正态n 大且 np(1−p) 不太小时，B(n,p) ≈ N(np, np(1−p))
泊松 → 指数泊松过程的到达间隔服从指数分布
任意 → 正态中心极限定理：独立同分布求和标准化后 → N(0,1)
正态 → 卡方k 个独立标准正态的平方和 = χ²(k)
指数 → 伽马k 个独立指数之和 = Gamma(k, λ)（爱尔朗分布）
# 中心极限定理的数值演示：均匀分布求均值后趋向正态
import random
def sample_mean(n, trials=5000):
    return [sum(random.random() for _ in range(n))/n for _ in range(trials)]

for n in (1, 2, 10, 30):
    s = sample_mean(n)
    m = sum(s)/len(s)
    var = sum((x-m)**2 for x in s)/len(s)
    print(f"n={n:3d}  均值={m:.4f}  标准差={var**0.5:.4f}  理论 σ/√n = {((1/12)**0.5)/n**0.5:.4f}")
# 标准差严格按 1/√n 收缩，形状逐渐变钟形

常见误区

  • 「期望就是最可能的值」——期望是长期平均，未必是任何一次的可能取值（如掷骰子期望 3.5，但骰子没有 3.5 点）。
  • 「方差可加无条件成立」——只有独立（或至少不相关）时才成立，一般公式是 Var(X+Y) = Var(X)+Var(Y)+2Cov(X,Y)。
  • 「ρ = 0 即独立」——只能说明无线性相关，非线性依赖依然存在。
  • 「大样本就一定正态」——CLT 要求方差有限；帕累托分布 α ≤ 2 时方差无穷，样本均值不收敛到正态，这正是长尾系统的麻烦所在。
  • 「用均值描述延迟」——延迟近似对数正态/帕累托，长尾极厚，必须看 P99/P999。

🎯 常见问法与答题要点

Q：随机变量和普通变量有什么区别？

A：随机变量是「函数」而非「未知数」：它是从样本空间 Ω 到实数的映射 X(ω)。之所以叫「变量」，是因为它的取值随随机试验结果而变；之所以是「函数」，是因为每个结果 ω 都唯一对应一个数值。这个视角转变很重要：有了它就能对随机现象做代数运算（求期望、方差、做变换），而不只是定性描述。

Q：离散型和连续型随机变量的核心区别是什么？

A：离散型取有限或可列个值，用 PMF（概率质量函数）描述，P(X=k) 直接是概率，求期望用求和；连续型取值不可列，用 PDF（概率密度）描述，单点概率恒为 0（P(X=x)=0），只能谈区间概率 P(a<X<b) = ∫f，求期望用积分。关键直觉：连续型的 f(x) 是「密度」不是「概率」，可以大于 1。

Q：期望和方差分别刻画什么？为什么方差要平方？

A：期望 E[X] 是「长期平均」，刻画分布的中心位置；方差 Var = E[(X−μ)²] 刻画离散程度。用平方的原因：① 若直接用 E[X−μ] 恒等于 0（正负抵消），无法度量波动；② 用绝对值 |X−μ| 数学性质差（不可导）；③ 平方保留了良好的代数性质（可展开、可加），且标准差 σ = √Var 与原变量同量纲，便于解释。

Q：泊松分布适合建模什么？和二项分布什么关系？

A：泊松分布建模「单位时间/空间内稀有事件发生的次数」：每秒请求数、每天故障数、每页印刷错误数。它只有一个参数 λ（既是期望也是方差——这个「期望=方差」的特征是判断数据是否泊松的快速检验）。与二项的关系：当 n 很大、p 很小、np = λ 适中时，B(n,p) ≈ Pois(λ)。工程上常用这个近似把「n 次独立尝试」简化成「强度为 λ 的到达流」。

Q：指数分布的无记忆性是什么意思？有什么实际影响？

A：P(X > s+t | X > s) = P(X > t)：已经等了 s 秒，再多等 t 秒的概率与从头等 t 秒完全一样——「等待历史」不影响未来。它是唯一具无记忆性的连续分布。实际影响：① 建模随机到达间隔的标准选择（泊松过程的间隔恰是指数分布）；② 反直觉之处：已等待很久不会让事件「更该发生」，所以对无记忆过程做「超时重试」并不会提高成功率；③ 若实测数据有明显「老化」特征，就不该用指数分布。

Q：为什么独立时方差可加，而标准差不能直接相加？

A：因为方差是二阶量，可加性来自交叉项消失：Var(X+Y) = Var(X)+Var(Y)+2Cov(X,Y)，独立时 Cov = 0。而标准差 σ = √Var 是平方根，√a + √b ≠ √(a+b)。正确算法是 σ_(X+Y) = √(σ_X² + σ_Y²)（独立时），也叫「误差的平方合成」。直觉：两个独立噪声叠加，总噪声按勾股定理合成，而不是简单相加。

Q：中心极限定理有什么用？有什么前提？

A：用途：无论总体分布形状如何，样本均值 X̄ₙ 近似服从 N(μ, σ²/n)，于是可以构造置信区间、做假设检验、估算所需样本量。前提：① 样本独立同分布；② 总体方差有限（关键！帕累托 α≤2 时方差无穷，CLT 失效）；③ n 足够大（经验上 n ≥ 30，但偏态越重需要越大）。它是「用样本推断总体」这一整套统计方法的理论许可证。

Q：实际系统里，为什么延迟分布不能用正态建模？

A：因为延迟是非负且长尾的：正态允许负值、尾部衰减太快（e^(−x²)），严重低估 P99。实测延迟更接近对数正态（多个独立因素相乘，如队列等待 × 处理时间 × GC 停顿）或帕累托/重尾（少数请求因锁竞争、GC、网络重传而极慢）。后果：用均值和正态假设算出的 SLO 会被真实长尾打穿，所以必须用分位数（P99/P999）度量与告警。
