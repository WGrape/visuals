网络层 · 跨层设备地图

数据包经过哪些网络设备？

家里的光猫、路由器，办公室的交换机，网站前面的防火墙……它们到底是盒子，还是软件？先看家里的接线图，再跟着数据走一遍。术语不用先背。

先认家里的设备跟着数据走逐个认设备一眼区分常见问题
01 / START AT HOME

先别管术语：你家里可能这样接线

你打开一个网站，数据不是一下就“飞到服务器”。先看看网线和设备摆在哪儿。下图是一种常见接法，不要求每家都有四个独立盒子。

  1. 〰运营商的光纤一根送来网络信号的线
  2. ONT光猫（ONT）常见的小白盒：光纤进，网线出
  3. ↗家用路由器帮你找外网、共享连接；常带 Wi-Fi
  4. PC手机 / 电脑用 Wi-Fi 或网线接入

箭头表示设备怎样接在一起，不代表数据只能往一个方向走；打开网站时，请求通常从你的手机或电脑向外出发。

网线口不够？加交换机。

接在路由器后面，像“会认收件人”的多网口扩展盒，让几台有线设备互通。

Wi-Fi 覆盖不够？加 AP。

接上网线，给手机再开一个无线入口；家用路由器通常已经内置 AP。

最容易搞混的是光猫和路由器：光猫负责接入运营商的光纤；路由器负责决定数据下一步去哪儿，并常把全家的设备接到同一条外网连接上。运营商给的“一体机”可以同时做两件事，所以你家可能只看到一个盒子。

IP 地址 ≈ 要去的地方例如网站服务器在哪个网络。路由器主要看它。
MAC 地址 ≈ 这一小段路交给谁只管相邻链路；交换机主要看它。
端口号 ≈ 交给哪项服务同一台机器上，网站服务和别的程序靠端口区分。

03 / DEVICE ATLAS

它到底是个什么东西？

先看“你能在哪里见到它”和“它会怎样处理数据”。盒子名称不等于唯一功能：家用无线路由器常把路由、交换机、AP、NAT 和防火墙装在一起；企业或云上，这些功能又可能各自运行在软件里。每张卡片都可以展开技术细节。

光猫 ONT / 调制解调器 接入运营商

它是啥？运营商上门装的小盒子，常见的“光猫”一端插入户光纤，另一端有网线口。光猫通常指光网络终端 ONT；老式电话线或有线电视线路上的 modem（调制解调器）是另一类接入设备，叫法相近，技术并不一样。

光纤细头 → 【光猫 ONT】 → 网线口 → 路由器

它干啥？把运营商线路上的传输变成家里设备能使用的网络连接。好比在两种接头之间翻译，而不是给每个网站挑路线。

你在哪见？入户弱电箱、电视柜旁；光猫上常有 PON、LOS、LAN 指示灯。有些运营商设备还自带 Wi-Fi 和路由功能。

看数据时更准确地说

ONT 终结光纤接入链路（如 PON），处理相应信号与链路封装；单纯桥接时通常不改 IP 源/目的。如果设为路由模式，还会执行路由、NAT 等功能。普通 modem 则按它使用的 DSL / 有线电视等接入技术处理信号。

路由器 / 三层交换机 找下一段路

它是啥？家里的“无线路由器”通常是有 WAN/LAN 网口、可能带天线的盒子；机房里的路由器也可能是一台大型设备。三层交换机也可以承担路由功能。

它干啥？看数据要去哪个网络，再选一条路送出去。每经过一个路由节点，就重新写“这一小段路交给谁”。

你在哪见？光猫后面；公司出口，或不同部门网络之间。

看数据时更准确地说

按目标 IP 查路由表，选出口/下一跳；TTL 减 1，重新封装链路帧，IPv4 头校验和更新。普通路由不改 IP 两端地址；TTL 到期通常丢弃并回 ICMP 差错。

网桥 / 二层交换机 找正确网口

它是啥？看起来像一个有很多网线插孔的盒子。网桥是类似连接功能的名称；现代局域网里通常用交换机。

它干啥？记住“哪台设备在哪个网口”，把数据送向正确的网口，而不是每个口都发。还不认识目的地时，才可能在同一局域网范围内向其他网口转发。

你在哪见？办公室的网线汇聚处；家里网口不够时。

看数据时更准确地说

从源 MAC 学习端口，按目的 MAC 与 VLAN 转发；未知单播在所属 VLAN 内泛洪。可能增删 VLAN 标签并重算帧校验，但普通二层交换不改 IP 地址或 TTL。

无线 AP 给手机一个无线入口

它是啥？让手机连上 Wi-Fi 的无线接入点。可以是天花板上的小圆盘，也可以是家用无线路由器自带的功能。

它干啥？把手机的无线通信接入有线局域网，相当于给不能插网线的手机开一扇无线门；它本身不一定负责选去外网的路线。

你在哪见？办公室天花板、商场、家用路由器内部。

看数据时更准确地说

桥接模式下在 Wi-Fi（802.11）与以太网帧之间转接，通常不改 IP 源/目的；家用一体机的路由能力来自它的其他功能。

NAT 网关 换出门地址

它是啥？通常不是必须单独购买的盒子，而是家用路由器、公司出口网关或云网络中的一项功能。

它干啥？全家电脑都有各自的内网地址，但上网时常共用一个公网地址。它记住谁从哪个地址和端口出门，回来的数据才知道还给谁。

你在哪见？家用路由器、企业或云的网络出口。

看数据时更准确地说

常见出站 NAPT 修改源 IP 和源端口，保存映射并在回包时反向还原；相关校验和也要更新。它通常与路由一起工作，但 NAT 本身不是路由表。

防火墙 决定让不让过

它是啥？网络门禁，可以是一台专用设备，也可以是路由器或服务器里的一组软件规则。

它干啥？符合规则的连接放行，不符合的阻止。比如允许访问网站，却不允许陌生人直接连内网电脑。

你在哪见？家用路由器的安全设置、公司网络边界、服务器上。

看数据时更准确地说

按协议、IP、端口、连接状态等匹配规则，放行、拒绝或丢弃。透明模式可不改 IP；应用层检查可能需要解密，不能假设它能直接读懂加密网页。

负载均衡器 替网站挑服务器

它是啥？网站入口的一台设备，或者一项软件/云服务；它的后面有多台提供同一服务的机器。

它干啥？新连接来了，选一台健康的后端机器接待；一台坏了，就不再选它。像多个服务窗口前的分流员。

你在哪见？企业机房或云服务中；不是家庭上网的必需设备。

看数据时更准确地说

L4 依据连接字段选后端，可用 DNAT / SNAT 或封装转发；L7 可按可读取的 HTTP 域名、路径等选后端。实现方式不同，有的还会终止前端连接再代理。

反向代理 / API 网关 替网站接待请求

它是啥？一般是服务器上的软件，不一定有专用硬件盒子。客户端先连它，再由它联系真正处理业务的应用。

它干啥？读懂“我要看哪个网页”这样的请求，检查、转交或缓存，再把结果回给你。它像前台接待，不只是让原数据包穿过去。

你在哪见？网站和 API 的入口；家庭普通上网不需要自己部署。

看数据时更准确地说

可终止 TLS、读取 HTTP 请求并按域名/路径路由，向后端建立或复用独立连接；可修改请求头/内容，原 TCP/IP 包不会原封不动到后端。

中继器 / 集线器 老式“全口都发”

它是啥？旧式网络中用来延长信号距离或连接多根网线的设备。集线器也有很多网口，却没有交换机的“认门牌”能力。

它干啥？收到信号就送向其他端口，不按接收人的地址选一个出口；现代以太网局域网基本用交换机取代集线器。

你在哪见？教材和老设备里较多，日常组网很少需要。

看数据时更准确地说

物理层处理比特信号，不查 MAC 或 IP，也不会主动修改 IP 包；中继器负责再生信号，集线器向其他端口重复发送。

05 / CHECK YOUR MODEL

还是容易混？从这几个问题想起

光猫和路由器是一回事吗？为什么我家只有一个盒子？

不是同一种功能。光猫 ONT 把运营商光纤接到家庭网络；路由器负责跨网络选路，常兼做 NAT 和防火墙。有些运营商的一体机两种功能都做；也有人让光猫只负责接入，再连接自己的路由器。

交换机和路由器都在“转发”，到底差在哪？

普通二层交换机按目的 MAC 在同一 VLAN 找出口；路由器按目的 IP 在不同网络间选下一跳，TTL 递减并重新封装链路帧。三层交换机也能做路由，所以关键是当前执行的功能，不是机箱名称。

从电脑到网站，源 IP 和目的 IP 一直都不变吗？

普通路由转发通常保持两端 IP 不变；遇到 NAT、DNAT 或代理则可能改变。MAC 只在本跳有效，路由器转发时会更换链路层源/目的。L7 代理更进一步：原连接在代理处终止，后面是新连接。

防火墙、负载均衡、反向代理会同时出现吗？

可能，但不是必需，也可能合并部署。防火墙决定能否通过，负载均衡决定交给哪个后端，反向代理处理应用层请求；一台设备可以同时承担多种职责。
