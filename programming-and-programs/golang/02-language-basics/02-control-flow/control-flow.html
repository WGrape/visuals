控制流：if / for / switch / range

Go 只有少量控制结构，但每个都设计得简洁：if 可带初始化、for 是唯一循环、range 遍历一切、switch 默认不穿透。

if：带初始化的条件

最常见的「逗号 ok」模式

if 可在条件前加分号写初始化，作用域仅限于 if 块，非常适合「先取值再判断」。

if v, err := do(); err != nil {
    return err
}
// 等价经典写法
v, err := do()
if err != nil {
    return err
}
for：三种形态

Go 的全部循环都是 for

经典三段式、单条件、无限循环，再加上 range 变体，覆盖所有需求。

for i := 0; i < 10; i++ { }     // 三段式
for cond { }                 // while 等价
for { }                      // 无限循环（break 退出）
for i := range 5 {}           // Go 1.22+ 可直接遍历整数
range：遍历一切

数组/切片/映射/字符串/通道

range 返回（索引, 值）或（键, 值）。对字符串它会按 UTF-8 解码出 rune，是最安全的遍历方式。

for i, v := range slice { }       // i 下标, v 元素副本
for k, v := range m { }         // 映射键值（顺序随机）
for i, r := range "Go" { }      // r 是 rune，自动解码
for v := range ch { }           // 从通道接收，直到关闭
// 只要下标
for i := range slice { }
// 只要值
for _, v := range slice { }
switch：不穿透更安全

默认每个 case 自带 break

Go 的 switch 不穿透，匹配即停；case 可以是任意表达式，甚至省略表达式当 if-else 链用。

switch x {
case 1, 2:        // 可多值
    fmt.Println("small")
default:
    fmt.Println("other")
}

// 省略表达式 = 多条件分支
switch {
case x < 0:
    fmt.Println("neg")
case x == 0:
    fmt.Println("zero")
}
实战技巧

让控制流更 Go

用 continue/break + 标签跳出多层循环；用 range + 空标识符忽略不需要的值；用 switch 替代长串 if-else 提升可读性。

标签控制

命名循环 + break/continue label 可一次性跳出外层循环，比在多层里设 flag 更干净。

Go 只有三种控制结构

Go 刻意保持控制结构的精简：if、for、switch（外加并发场景的 select）。没有 while、没有 do-while、没有三元运算符。

没有 while用 for condition 代替。
没有三元老老实实写 if-else。
if 带 init把变量作用域限制在 if 内。
switch 更灵活可以没有表达式，case 可写条件。
// ① if 带初始化语句（Go 的特色写法） if err := doSomething(); err != nil { return err // err 的作用域只在这个 if 块 } // 这里访问不到 err // ② for 的三种形式 for i := 0; i < 10; i++ { } // 经典三段 for n > 0 { n-- } // 相当于 while for { break } // 无限循环 // ③ range 遍历 for i, v := range slice { } // 索引 + 值（值是副本） for k, v := range m { } // map（顺序随机） for v := range ch { } // channel，直到关闭 for i := range 10 { } // Go 1.22+ 可直接遍历整数

switch：比其它语言更灵活

// ① 常规 switch（自带 break，不会贯穿） switch day { case "Mon", "Tue": fmt.Println("工作日") case "Sat", "Sun": fmt.Println("周末") default: fmt.Println("其它") } // ② 无表达式 switch（替代长串 if-else） switch { case score >= 90: grade = "A" case score >= 60: grade = "B" default: grade = "C" } // ③ 带初始化语句 switch v := getValue(); v { case 1: ... } // ④ fallthrough：显式贯穿（很少用） switch n { case 1: fmt.Println("one") fallthrough // 强制执行下一个 case 的体 case 2: fmt.Println("two") } // ⑤ 类型 switch（配合接口使用） switch v := x.(type) { case string: fmt.Println(v) case int: fmt.Println(v) }

与 C/Java 的关键区别：Go 的 case 默认不贯穿，不需要写 break。需要贯穿时必须显式 fallthrough。这消除了大量因忘记 break 导致的 bug。

break / continue / label / goto

label 跳出多层

内层循环里想跳出外层，用 label。

outer: for _, row := range rows { for _, cell := range row { if cell == target { found = true break outer // 直接跳出外层 } } } // continue outer 同理：继续外层的下一次迭代

没有 label 的话只能靠标志变量，代码更脏。

goto 何时用

Go 保留了 goto，但限制很多：不能跨变量声明跳转。

  • 几乎总能用循环与函数替代
  • 偶尔用于集中清理的错误处理
  • 日常业务代码不建议使用
  • 跳过的变量声明会导致编译错误

range 的坑

  • range 的第二个值是副本，修改它不影响原切片
  • 要修改用下标：s[i] = v
  • range 大结构体时会逐个拷贝，可只取下标
  • range map 顺序随机，不能依赖
  • range 时增删 map 有未定义行为
// ❌ 无效：v 是副本 for _, u := range users { u.Age = 18 // 改的是副本 } // ✅ 用下标 for i := range users { users[i].Age = 18 } // ✅ 或用指针切片 for _, u := range userPtrs { u.Age = 18 }

深入自检

Go 为什么没有三元运算符？

官方的解释是：三元运算符常被用来写出难以阅读的嵌套表达式，Go 宁可多写几行 if-else 换取清晰。这是 Go 一贯的取舍——宁可啰嗦，也要让代码路径一目了然。

switch 的 case 为什么不贯穿？

C 语言里忘记写 break 是经典 bug 来源。Go 颠倒默认值：不贯穿，需要时显式 fallthrough。这样即使忘了写也不会出错。

range 拿到的是副本吗？

是的。range 的第二个变量是元素的拷贝（string、int 这类小类型无所谓）。修改它不会影响原集合；要修改必须用下标，或者集合本身存的是指针。

什么时候需要 label？

当你需要在嵌套循环里「一次跳出多层」或「直接继续外层下一轮」时。没有 label 就得用布尔标志在外层再判断一次，可读性反而更差。

Go 1.22 的循环变量改动有什么影响？

Go 1.22 起每次循环迭代的变量都是新变量，闭包捕获各自的值，经典的「goroutine 里打印同一个值」问题基本消失。同时 range 支持直接遍历整数。旧代码行为可能变化，需确认构建工具链版本。

switch x := f(); {无表达式 switch等价于 switch true {}，可替代长 if-else
type switchswitch v := i.(type)只能用于 interface{}；v 在每个 case 中是对应具体类型
goto存在但受限不能跳过变量声明；几乎只在错误处理与状态机中使用
defer后进先出参数在 defer 语句处就求值，不是执行时

最经典的坑：for _, v := range s { defer fmt.Println(v) }——在 Go 1.21 及以前，循环变量 v 被复用，所有 defer 打印的都是最后一个值。Go 1.22 起循环变量每次迭代独立，行为已修正。跨版本代码要显式 v := v。

代码对照

// defer 的参数在声明时求值 —— 经典陷阱
func f() (r int) {
    defer func() { r++ }()   // 闭包，读到的是返回后的 r → 返回 1
    return 0
}
func g() (r int) {
    defer fmt.Println(r)     // 参数 r 此刻已求值为 0 → 打印 0
    r = 5
    return                   // 返回 5，但 defer 打印 0
}

// range 取值副本：改 v 无效，改 s[i] 有效
s := []int{1, 2, 3}
for i, v := range s {
    v *= 10      // ❌ 无效
    s[i] *= 10   // ✅ 有效
}
// 遍历指针 slice 时 v 是指针副本，v.Field = x 有效（指向同一对象）
// switch 的高级用法
switch {                        // 无表达式 = switch true
case score >= 90:
    return "A"
case score >= 60:
    return "pass"
default:
    return "fail"
}

// type switch
switch v := any(x).(type) {
case int:
    fmt.Println("int", v+1)     // 此分支 v 是 int
case string:
    fmt.Println("len", len(v))  // 此分支 v 是 string
case nil:
    fmt.Println("nil")
default:
    fmt.Printf("other %T\n", v)
}

// 带标签的 break/continue：跳出外层循环
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if j == 1 { continue outer }  // 跳过 i 这一轮的剩余部分
        if i*j > 2 { break outer }    // 直接跳出双层
    }
}
