01一张图看清操作系统谱系

图：主流操作系统的血缘关系。Unix 分出 System V 与 BSD 两支，Linux 独立但沿用 Unix 接口，Windows NT 自成体系。
看懂谱系不是为了背历史，而是为了理解接口为什么是这样：POSIX 来自 Unix，socket 来自 BSD，systemd 的争议来自 System V 与 BSD init 的分歧。

02Unix 的两大分支：System V 与 BSD

Unix 在 1970 年代被 AT&T 贝尔实验室发明后，代码以授权方式流向高校，最终分裂为两条主线：

分支代表系统留下的遗产
System VSolaris、AIX、HP-UXinit/rc 启动脚本、SysV IPC（共享内存/消息队列/信号量）、termios
BSDFreeBSD、OpenBSD、macOSTCP/IP 与 socket、虚拟内存、csh、vi、cron

Linux 两者都吸收：接口上遵循 POSIX（主要是 System V 风格），但网络栈和虚拟内存设计大量借鉴 BSD。这就是为什么 shmget（SysV IPC）和 mmap（BSD 风格）在 Linux 上同时存在。

一个容易混的点

POSIX 不是某个实现，而是一份 API 标准。Linux 不是 Unix，但实现了 POSIX 接口，所以叫「类 Unix」（Unix-like）。macOS 通过了 UNIX 认证，可以合法自称 Unix。

03Linux 到底是什么：内核 ≠ 发行版

日常说的「装个 Linux」其实装的是发行版，而 Linux 严格说只是内核。两者的边界必须分清：

组成属于内核？举例
进程调度、内存管理、VFS、网络栈、驱动是sched/、mm/、fs/、net/
系统调用接口是sys_call_table
C 库（glibc/musl）否提供 printf/malloc 并封装 syscall
shell、coreutils、包管理器否bash、ls、apt/dnf
init 系统否systemd / openrc

所以「Alpine 比 Ubuntu 小」不是内核小，而是用户态用了 musl + BusyBox，去掉了大量 GNU 工具。

排查时最常踩的坑：容器里 uname -r 显示的是宿主机内核版本，因为容器共享宿主内核，不是「容器自己的 Linux 版本」。

04Windows NT：从微内核理想走向混合内核

Windows NT（1993）最初按微内核思路设计，把图形、文件系统等做成用户态子系统。但性能代价太大，最终演化为混合内核：

内核态核心
Executive + 微内核（调度、中断、同步）+ HAL（硬件抽象层）
用户态
子系统：Win32 / POSIX / WSL；以及 csrss、lsass 等
关键差异
图形子系统（win32k）跑在内核态，这是 Windows 与 Linux 图形栈最大的架构分歧
驱动模型
WDM / KMDF / UMDF，用户态驱动框架降低崩溃面
对比记忆：Linux 图形走用户态（X11/Wayland + DRM），Windows 图形核心在内核。前者更安全、崩溃可恢复；后者路径更短、延迟更低。

05macOS 与 XNU：Mach + BSD 的混血

macOS/iOS 的内核叫 XNU（X is Not Unix），由三部分拼成：

Mach 微内核层

任务/线程、虚拟内存、IPC（mach port）、调度。提供微内核的抽象。

BSD 层

POSIX 系统调用、文件系统、网络栈、权限。让 macOS 能跑 Unix 程序。

I/O Kit

面向对象的驱动框架，支持用户态驱动（DriverKit）。

它不是纯微内核：BSD 层与 Mach 同处内核态，属于混合内核。真正的微内核代表作是 QNX 和经过形式化验证的 seL4。

06实时操作系统：正确性由截止时间定义

RTOS 的目标不是「快」，而是可预测地在截止时间内完成。分两类：

类型要求代表典型场景
硬实时错过截止时间 = 系统失败FreeRTOS、VxWorks、QNX汽车刹车、飞控、起搏器
软实时偶尔超时只降质量Linux PREEMPT_RT、Android音视频、交互界面

RTOS 的关键机制：抢占式优先级调度、优先级继承防优先级反转、确定性中断延迟（微秒级抖动）。普通 Linux 的调度延迟抖动在毫秒级，不满足硬实时。

PREEMPT_RT 补丁已于 2024 年合入 Linux 6.12 主线，把大部分自旋锁改为可抢占的 rtmutex，让 Linux 具备软/准硬实时能力——这是近年内核最重要的变化之一。

08速记卡

Unix 两支

System V → SysV IPC/init；BSD → socket/虚存。Linux 两者都吸收。

内核 ≠ 发行版

Linux 是内核；Debian/Alpine 是内核 + 用户态 + 包管理。

Windows 的特殊性

win32k 图形子系统在内核态，这是与 Linux 最大的架构分歧。

XNU = Mach + BSD

混合内核；纯微内核看 QNX / seL4。

RTOS 要的是确定性

不是快，是可预测；PREEMPT_RT 已进 Linux 主线。
