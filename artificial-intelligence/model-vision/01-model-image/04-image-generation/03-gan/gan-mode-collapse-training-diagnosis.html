GAN 模式坍塌：为什么生成器只会画一种猫

从两类真实样本的玩具分布出发，解释生成器、判别器的博弈、覆盖率与训练诊断。

看起来真实与覆盖真实分布是两件事

假设训练集一半是黑猫、一半是白猫。生成器只会画很逼真的黑猫，随机抽一张看很不错，但白猫模式完全消失，这就是模式坍塌的一种直观例子。GAN 的生成器试图产生让判别器难以区分真假的样本；判别器学习识别真实样本与生成样本。两者交替更新，目标是让生成分布接近真实分布，而不是让少数几张图好看。一个只会重复样本的生成器可能暂时得到不错的单张观感，却不能满足多样化生成的要求。

训练数据本身也可能不均衡：若真实白猫只有 1%，生成器忽略白猫的含义与 50% 白猫时不同。评估前应确认训练数据和业务期望的目标分布，而不是凭某一张失败图命名“模式坍塌”。

博弈为什么容易不稳定

判别器太强时，生成器早期产生的图很容易被识别，部分目标形式下可得到的有效梯度变弱；判别器太弱时，生成器又缺少有用方向。经典极小极大写法常用其他生成器损失形式改善训练信号，但换损失不等于自动避免坍塌。模型容量、学习率、批量、归一化、数据增强和两个网络更新步数都会影响动态。GAN 不是一个静态损失函数训练到底：生成器每更新一次，判别器面对的数据分布就变了。

在黑白猫例子里，判别器学会识别黑猫伪影后，生成器可能突然跳到白猫模式；下一轮又跳回来。只记录单个最终 checkpoint，可能误以为某配置稳定。保存训练时间线和固定随机种子的样本网格，能看到模式是否反复切换。

怎样观察“只画一种猫”

固定一组潜变量 z，在不同训练步生成同位置的样本，观察是否每个 z 都逐渐变成几乎同一只猫。再随机抽大量 z，比对颜色、姿态、背景与身份多样性；如果视觉变化极少，说明潜变量没有有效控制输出。但纯视觉判断可能被背景噪声误导：模型可以在背景上变化很多，却总只生成一种主体。应按关键语义属性做覆盖统计，并与真实集比例比较。

FID 等分布指标可提供整体差异线索，但单个数无法告诉你漏掉哪类样本，也不宜在不同特征提取器、样本量或预处理下直接比较。可结合生成样本的 precision/recall 风格指标：质量高但覆盖低，正是模式坍塌的典型组合之一。

现象可能解释应检查
图都逼真但相似模式覆盖不足固定 z 网格与属性比例
图质量差且多样生成器尚未拟合训练动态、预处理与样本质量
类别来回切换训练振荡多检查点样本和梯度
判别器 50%平衡或无力学习质量、覆盖和独立验证

一次训练日志复盘

训练 20 万步后，判别器训练准确率长期接近 100%，生成图几乎都是黑猫。先检查数据加载器是否真的送入白猫、标签和预处理是否正确；若训练输入本就错了，调 GAN 损失无济于事。接着检查固定 z 样本、判别器损失与梯度、每步更新次数及学习率变化。若判别器一开始就过强，可考虑调整容量或更新比例、采用稳定训练技巧并重新跑对照实验，而不是直接把准确率强行压到 50%。

判别器准确率 50% 也未必证明成功：它可能只是没学会，或正好在复杂非平衡博弈中输出不确定。必须与图像质量、覆盖、多样性和训练稳定性共同看。

可试的缓解方向

数据增强可让判别器在样本有限时更稳健；谱归一化、梯度惩罚等约束可缓解某些训练不稳定；调整生成器与判别器的学习率或更新步数可避免某一方长期压制另一方。不同 GAN 家族的损失和正则化细节并不通用，不能把某篇论文的超参数原样套到所有分辨率和数据集。每次改动只变少数因素，在相同随机种子组、样本预算和评估协议下比较。

如果任务是高保真但不需覆盖整个数据分布，例如固定角色风格，部分模式集中未必是问题；若任务是合成训练数据，漏掉少数类会让下游模型更偏。工程目标决定“多样性”要如何测量。

与扩散模型怎样比较

扩散模型通常按逐步去噪训练和采样，训练目标与 GAN 的双网络博弈不同，在许多图像生成任务上更易获得覆盖与稳定性的某些优势，但采样步骤、算力与延迟也有代价。不能简单说“扩散永远没有模式坍塌”：数据偏差、条件不足和采样策略仍可能让输出缺少某些模式。比较时应固定分辨率、数据集、采样预算和安全过滤条件，再看质量、多样性与推理成本。

GAN 仍可能适用于要求极低延迟的特定生成或图像变换场景。技术选型应由业务分布和验收指标驱动，而非按模型发布时间排序。

验收一套可复现实验

给黑白猫各 500 张训练图，固定若干随机种子和训练步检查点。每步保存 100 张固定 z 的网格，另外随机生成足够样本，统计黑白比例、身份或姿态多样性和人评质量。对照改变判别器更新频率前后，观察是否只是从“全黑猫”变成“全白猫”，而非真正覆盖两类。最后在未见过的验证集上计算分布指标，并展示原图与生成图的混排盲评。

写结论时明确是“质量差”“覆盖差”“训练振荡”中的哪一种，不要用一个 GAN loss 曲线解释所有失败。

GAN 训练的诊断信号与阈值

信号健康范围异常含义
判别器准确率 D(x)训练中 50%~80%> 95% = D 太强，G 的梯度消失；≈50% 且生成质量差 = mode collapse
loss_D抖动但趋势平稳趋近 0 = D 完美区分，G 学不动了
loss_G有波动单调下降到 0 = D 崩了；持续上升 = G 崩了
梯度范数（G）不为 0接近 0 = 梯度消失，D 太强
生成样本的多样性类内差异明显所有样本几乎一样 = mode collapse
FID（有条件生成）越小越好训练中突然变差 = 崩了，回退 checkpoint
D 的参数量 / G通常 D 略小或相当D 太强会压制 G
学习率（Adam）1e-4 ~ 2e-4GAN 对 LR 极敏感，β₁=0.5 是常用设置

理论最优：纳什均衡时 D 无法区分真假，准确率 = 50%，此时 loss_D = log 4 ≈ 1.386、loss_G = -log 4。实际训练中达不到，但 loss_D 长期远离 1.386 说明训练失衡。

稳定训练的具体手段与代码

# 1) 标签平滑：把真样本标签从 1.0 改成 0.9，防 D 过于自信
real_labels = torch.full((b,), 0.9, device=device)     # 不再是 1.0
fake_labels = torch.full((b,), 0.0, device=device)

# 2) 单边标签平滑（更常用）：只平滑真的，不平滑假的
# 3) 给 D 的输入加噪声，且噪声随训练衰减
noise = torch.randn_like(real) * max(0.0, 0.1 * (1 - epoch / n_epochs))
d_real = netD(real + noise)

# 4) WGAN-GP：用梯度惩罚代替 weight clipping（最有效的稳定手段之一）
def gradient_penalty(D, real, fake):
    alpha = torch.rand(real.size(0), 1, 1, 1, device=real.device)
    interp = (alpha * real + (1 - alpha) * fake).requires_grad_(True)
    d = D(interp)
    grad = torch.autograd.grad(outputs=d, inputs=interp,
                               grad_outputs=torch.ones_like(d),
                               create_graph=True, retain_graph=True)[0]
    return ((grad.norm(2, dim=1) - 1) ** 2).mean()     # 让梯度范数趋近 1
loss_D = -(d_real.mean() - d_fake.mean()) + 10.0 * gp  # lambda=10

# 5) 谱归一化（SNGAN）：约束 D 的 Lipschitz 常数，一行生效
netD = torch.nn.utils.spectral_norm(netD)
# 监测 mode collapse：统计生成样本的两两距离
@torch.no_grad()
def diversity_score(G, n=500, batch=50):
    imgs = []
    for _ in range(n // batch):
        z = torch.randn(batch, nz, 1, 1, device=device)
        imgs.append(G(z).flatten(1))
    imgs = torch.cat(imgs)
    d = torch.cdist(imgs, imgs)                 # 两两 L2 距离
    return d.mean().item()                      # 崩塌时会显著下降

# 训练中每 N 个 epoch 记录：
#   - diversity_score（下降 = 正在崩塌）
#   - D(real).mean(), D(fake).mean()（差距持续变大 = D 太强）
#   - FID（上升 = 崩了，回退到上一次的 checkpoint）

# 常用超参（DCGAN 基线）
# lr = 2e-4, betas = (0.5, 0.999)   <- β₁=0.5 是 GAN 的特殊设置，减少动量震荡
# D 每步更新 1 次，G 每步更新 1 次；D 太强时才 k=2~5 次 D / 1 次 G

训练问题排查

症状原因处理
loss_D 很快到 0D 太强，梯度消失减小 D 容量 / 加噪声 / 标签平滑 / 改用 WGAN-GP
loss_G 一直上升G 学不动，D 太强同上；或降低 D 的学习率、减少 D 的更新次数
生成样本全一样mode collapse用 minibatch discrimination / unrolled GAN / WGAN；增加 G 的多样性约束
生成图有棋盘状伪影转置卷积的「不均匀重叠」改用 上采样 + 卷积；或 kernel 能被 stride 整除（如 4/2）
训练中期突然崩了学习率过大 / D 与 G 失衡保存 checkpoint 定期回退；加梯度裁剪；降低 LR
FID 先降后升过拟合或训练不稳定早停；或用 FID 最好的那个 checkpoint 而不是最后一个
显存不够D 和 G 同时在显存减小 batch；用梯度累积；del 中间变量 + torch.cuda.empty_cache()

关于 β₁=0.5：Adam 默认 β₁=0.9，但 GAN 训练中动量会造成震荡，DCGAN 论文把 β₁ 降到 0.5 后稳定性明显改善。这是 GAN 特有的经验设置。

自检

判别器准确率恰好 50%，就一定说明 GAN 已经学到真实分布吗？

不一定。判别器也可能没有学会；还需检查生成质量、模式覆盖和训练时间线。
