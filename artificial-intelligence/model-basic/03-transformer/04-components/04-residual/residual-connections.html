04 · 组件拆解

残差连接：让 100 层网络还能训得动的那条加号

一个 x + F(x) 的加号，解决了深层网络梯度消失，也解释了为什么 Transformer 可以整齐堆 32 层、80 层甚至更多。它还是理解 Pre-LN / DeepNorm / LayerScale 的入口。

一句话定位：主干是流，子层是读写

Transformer 不是「一层算完交给下一层」，而是一条宽度固定为 d 的残差流贯穿始终；注意力和 FFN 各自从流里读一份、算出一份增量、再写回流里。这条流本身不做任何变换，所以可以堆任意多层。

结构x_{l+1} = x_l + F_l(Norm(x_l))
关键性质恒等路径：即使 F 全为 0，信息也能原样传到最后一层
梯度∂x_L/∂x_l = 1 + ∂F/∂x，那个 1 保证梯度不会指数级消失
副产物残差流维度恒定，所以所有子层输入输出必须同维（o_proj / down 的存在理由）
Pre-LN block：主干是残差流，子层是带 Norm 的旁路

公式与数值：为什么 1 这么重要

∂x_L / ∂x_l = ∏(1 + ∂F_k/∂x)　—— 展开后含大量「全为 1」的项，梯度可以不经任何缩放直达浅层

如果没有这个 1，梯度是一个 ∏ ∂F_k/∂x 的连乘：每项奇异值小于 1 就指数衰减（梯度消失），大于 1 就指数爆炸。有了残差，最坏情况梯度也只是「1 + 小扰动」，深度从瓶颈变成不是问题。

Pre-LN / Post-LN / DeepNorm 的取舍

方案写法优点代价现状
Post-LN（原版）x = LN(x + F(x))同参数量下效果略好残差路径被归一化缩放，深了必须精细 warmup基本弃用
Pre-LNx = x + F(LN(x))残差恒等直通，训练稳，warmup 可大幅缩短深层残差范数会逐层增大，末层需 final norm所有现代 LLM 默认
DeepNormx = LN(α·x + F(x))，α>1可训 1000 层α 需按深度调，破坏恒等性极深网络研究
LayerScalex = x + γ·F(x)，γ 初始 1e-4~1e-6训练初期几乎恒等，后期自动放开多一组参数ViT / 部分视觉模型
Pre-LN 必须配 final norm

Pre-LN 下残差流的 RMS 会逐层增长（LLaMA 系实测末层可到首层的数倍），如果最后不接一个 RMSNorm 就直接算 logits，数值会随深度漂移，logits 幅度不可控。

实现细节：三个容易写错的点

  1. 精度：残差累加建议在 fp32 做（或 bf16 存、fp32 累加）。bf16 的有效位数只有 8 位，几十次累加后小量级增量会被吞掉。
  2. 顺序：x = x + dropout(sublayer(norm(x)))。dropout 放在残差相加之前，不是在相加之后。
  3. 初始化：残差分支的最后一层（o_proj / down_proj）常用较小的初始化（GPT-2 按 1/√(2L) 缩放），让训练初期每个 block 近似恒等，避免一开始就把残差流冲乱。
# Pre-LN block（现代写法） h = x + self.attn(self.norm1(x)) # norm 在子层输入侧 h = h + self.ffn(self.norm2(h)) # 模型最后 h = self.final_norm(h) # 必须有 logits = self.lm_head(h)

原理与取舍：残差到底在解决什么

它同时解决三件事：梯度（恒等路径）、优化（每层只需学增量，任务从「拟合映射」变成「拟合残差」）、集成（展开后有 2^L 条路径，等价于对 2^L 个不同深度子网络的隐式集成）。第三条解释了为什么 Transformer 删掉几层还能跑、为什么 layer pruning 有容忍度。

为什么 Pre-LN 效果略差于 Post-LN？

Post-LN 的归一化在残差之后，等价于每层输出都被重新标准化，深层表达更「锐利」；Pre-LN 的残差流范数逐层增长，深层子层的输入分布偏大，等效于对深层用了更小的有效学习率。差距在小模型上明显、大模型上被规模抹平。

残差一定要加在 Norm 之前吗？

不一定。Sandwich Norm 在子层前后各放一个 Norm，效果更稳但多一次归一化开销；QK-Norm 只对注意力里的 Q、K 归一化，是另一类防爆手段。

残差流范数增长有危害吗？

有。它会让深层的注意力 logits 变大、softmax 饱和，也会让量化时的离群值更严重。LLaMA 系的做法是靠 final norm 收口；更激进的做法（如 Gemma-2）在每个子层输出上加缩放。

第一层 · 概念与判定：残差解决什么问题

一句话：残差连接给梯度开了一条「直达高速公路」，让深层网络不会因为连乘而梯度消失。

问题无残差有残差
梯度传播需穿过所有层的变换，连乘后趋近 0+1 项保证梯度至少能原样回传
深层训练层数一多就训不动可训到上百层
信息保留每层都要重新学恒等映射是默认选项，学「增量」即可
损失曲面陡峭、难优化更平滑

公式：y = x + F(x)，反向时 ∂y/∂x = 1 + ∂F/∂x——那个 1 就是关键，它保证即使 ∂F/∂x 很小，梯度也不会消失。

  • 信号一：网络加深后训练反而变差 → 缺残差（或归一化位置不对）。
  • 信号二：Transformer 每个子层（Attention、FFN）后都有残差。
  • 信号三：残差流（residual stream）视角——信息沿着残差主干流动，各层只往里「读写」。

关键区分：残差解决「能不能训深」，归一化解决「训得稳不稳」。深层 Transformer 两者缺一不可。

第二层 · 参数·命令·量化：Pre-LN vs Post-LN

形式公式特点用在哪
Post-LN（原始）y = LN(x + F(x))效果略好但训练不稳定，需 warmup原始 Transformer
Pre-LNy = x + F(LN(x))训练稳定，warmup 要求低现代 LLM 全部采用

Pre-LN / Post-LN / RMSNorm

import torch
import torch.nn as nn

# Pre-LN（现代主流）
class PreLNBlock(nn.Module):
    def __init__(self, dim, fn):
        super().__init__()
        self.norm = nn.LayerNorm(dim)   # 或 RMSNorm
        self.fn = fn
    def forward(self, x):
        return x + self.fn(self.norm(x))    # 先归一化，再变换，最后加残差

# Post-LN（原始 Transformer）
class PostLNBlock(nn.Module):
    def __init__(self, dim, fn):
        super().__init__()
        self.norm = nn.LayerNorm(dim)
        self.fn = fn
    def forward(self, x):
        return self.norm(x + self.fn(x))    # 先加残差，再归一化

# RMSNorm（LLaMA / Qwen 用，比 LayerNorm 少减均值、更快）
class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(dim))
        self.eps = eps
    def forward(self, x):
        rms = x.pow(2).mean(-1, keepdim=True).add(self.eps).rsqrt()
        return x * rms * self.weight
参数常见值说明
eps（归一化）1e-5 / 1e-6防除零
dropout（残差上）0.1（原始）/ 0（现代 LLM）作用在子层输出、残差相加前
学习率 warmupPost-LN 必需；Pre-LN 可短Pre-LN 更稳定
层数12（BERT-base）→ 80+（大模型）残差让深层可训

量化参考：Pre-LN 几乎是现代 LLM 的标配。原因是它在深层下梯度更稳定——Post-LN 在层数多时容易出现训练初期 loss 尖刺甚至发散，必须靠精细的 warmup 缓解。

第三层 · 排障与边界：残差的坑

坑后果正确做法
残差分支维度不匹配直接报错用线性投影把 F(x) 的维度对齐 x
Pre-LN / Post-LN 混用训练不稳定全模型统一
残差上又加了 LayerNorm 又加 dropout顺序混乱、训练变慢遵循标准实现
以为残差能替代归一化深层仍然发散两者都要
初始化没考虑残差累积深层激活值爆炸残差分支用小初始化；依赖 Pre-LN
  • 排查顺序：先确认维度对齐 → 再确认 LN 位置全模型统一 → 再看初始化 → 最后确认 dropout 位置。
  • 边界一：残差要求 x 与 F(x) 维度完全一致，否则相加报错（需 1×1 卷积或线性层投影）。
  • 边界二：残差流的数值会随层数累积，所以每个残差块前必须有归一化（Pre-LN 正是为此）。
  • 边界三：残差让网络「默认恒等」，所以加深不总是变好——增加层数可能只带来微小收益，要权衡计算成本。

第四层 · 原理与取舍：为什么「恒等映射是好的默认」

残差的核心思想：让每层默认「什么都不做」，只学「需要改动的增量」。这样优化目标从「学一个完整变换」变成「学一个接近零的修正」——后者容易得多，因为初始时网络就接近恒等映射，不会比浅网络更差。

视角解释含义
梯度高速路∂y/∂x = 1 + ∂F/∂x梯度至少能原样回传
恒等默认F(x)≈0 时 y≈x加层不会变差
残差流信息沿主干流动，各层读写可解释性研究的重要视角
集成视角相当于多条不同深度路径的集成解释了为什么深层也有效
残差连接和跳跃连接是一回事吗？

基本是。残差连接（ResNet）是跳跃连接的一种，特指 y = x + F(x) 这种「恒等 + 变换」形式。U-Net 里的拼接式跳跃连接（concat）是另一种。

为什么现代 LLM 都用 Pre-LN？

因为训练稳定性。Post-LN 的梯度要穿过每层的归一化，深层时梯度范数会失衡，需要精心调 warmup；Pre-LN 的残差路径是「干净」的（不经过任何归一化），梯度回传更顺畅，大模型训练几乎都选它。

残差会让模型「学不动」吗？

不会。残差只是提供了「恒等」这个默认选项，如果确实需要变换，F(x) 照样能学出来。它解决的是「深层难以优化」，不是「限制表达能力」。
