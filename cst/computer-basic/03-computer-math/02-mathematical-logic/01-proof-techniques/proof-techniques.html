证明方法：六种套路覆盖九成定理

直接证明、反证法、数学归纳、构造法、反例法、鸽巢原理——掌握它们的适用场景，就能把「不知道怎么下手」变成「按图索骥」。

核心速览

直接证明

从定义与已知定理出发，一步步推到结论

反证法

假设结论不成立，推出矛盾；利用逆否等值 p→q = ¬q→¬p

数学归纳

证明 P(1) 与 P(k)→P(k+1)，适用于与自然数相关的命题

构造法 vs 反例

证「存在」给一个例子；证「不普遍」给一个反例

怎么选方法：看命题的形式

① 直接证明：最朴素也最常用

从定义与已知结论出发，通过一连串合法推理直达目标。适用对象是 ∀x (P(x) → Q(x)) 形式的命题。

命题：若 n 是奇数，则 n² 也是奇数。
证明：由定义，n 为奇数 ⟹ n = 2k + 1（k 为整数）。
      n² = (2k+1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1
      令 m = 2k² + 2k（整数），则 n² = 2m + 1，符合奇数定义。∎

要点：先写清「任取…假设…」（unrolling 全称与蕴含），再展开代数推导。绝大多数初学者卡壳，是因为没有把「任意 x，假设 P(x)」这半句写下来。

② 反证法：假设结论不成立

依据是逆否等值 p → q = ¬q → ¬p：要证 p→q，可假设 p 且 ¬q，推出矛盾（与已知事实、定义或假设本身冲突）。

命题：√2 是无理数。
证明：假设 √2 是有理数，即 √2 = a/b，其中 a、b 互素（既约分数）。
      两边平方：2 = a²/b²  ⟹  a² = 2b²
      ⟹ a² 是偶数 ⟹ a 是偶数，设 a = 2k
      代入：4k² = 2b²  ⟹  b² = 2k² ⟹ b² 是偶数 ⟹ b 是偶数
      于是 a、b 都是偶数，与「互素」矛盾。
      ⟹ 假设不成立，√2 是无理数。∎

命题：素数有无穷多个。
证明：假设只有有限个素数 p₁, p₂, …, pₖ。
      令 N = p₁p₂…pₖ + 1。
      N 除以任何 pᵢ 都余 1，故 N 不被任何已知素数整除；
      于是 N 本身是素数，或含有不在列表中的新素因子 —— 矛盾。∎
何时用反证法？三个信号：① 结论是否定形式（「不存在」「不相等」「无理」）；② 结论说唯一性；③ 直接推导走不通但「若不然」立刻引发矛盾。另一个典型场景是停机问题不可判定的证明——假设存在判定器 H，构造出让它自相矛盾的程序。

③ 数学归纳法：多米诺骨牌

要证对所有 n ≥ n₀，P(n) 成立，只需两步：

奠基 Base Case

证明 P(n₀) 成立（通常是 n = 0 或 1）。

归纳步骤 Inductive Step

假设 P(k) 成立（归纳假设），推出 P(k+1) 成立。

为什么有效

奠基推倒第一块牌，归纳步骤保证「倒一块必倒下一块」→ 全部倒下。

强归纳

假设 P(n₀)…P(k) 全部成立来推 P(k+1)，适用于递推依赖多个前项的情形。

命题：1 + 2 + … + n = n(n+1)/2
证明：奠基 n = 1：左 = 1，右 = 1×2/2 = 1 ✓
      归纳：假设对 k 成立，即 1+2+…+k = k(k+1)/2
           则 1+…+k+(k+1) = k(k+1)/2 + (k+1)
                          = (k+1)(k/2 + 1) = (k+1)(k+2)/2 ✓
      故对所有 n ≥ 1 成立。∎

命题：用 2×1 骨牌铺满 2ⁿ × 2ⁿ 缺一格的棋盘（n ≥ 1）
证明：奠基 n = 1：2×2 缺一格，正好放一块 L 形骨牌 ✓
      归纳：假设 2ᵏ×2ᵏ 可铺。对 2ᵏ⁺¹×2ᵏ⁺¹ 棋盘，
           先切成四个 2ᵏ×2ᵏ 象限，缺口所在象限直接递归；
           在中心放一块 L 形骨牌「制造」另外三个象限的缺口，
           于是三个象限都化归为已知可解的子问题 ✓
归纳法与递归算法是同一件事的两面：归纳证明 = 递归算法的正确性证明；归纳假设就是「递归调用能正确返回」。这也是为什么「分治算法的正确性」几乎总用归纳法证明（归并排序、快速排序、线段树、DP 都如此）。

④ 构造法与反例法

构造法（证「存在」）

要证 ∃x P(x)，直接把 x 造出来并验证它满足 P。例如证「存在两个无理数 a、b 使 aᵇ 为有理数」：取 a = √2^√2、b = √2，分情况讨论即可。

反例法（证「并非全体」）

要推翻 ∀x P(x)，只需一个反例。例如「所有素数都是奇数」的反例是 2；「n²+n+41 恒为素数」的反例是 n = 40。

计数/鸽巢（证「必存在」）

把 n+1 个物体放入 n 个盒子，必有一个盒子 ≥ 2 个。用于证明「必然存在」而不必指出是哪一个。

双重计数

用两种方式数同一个集合，令结果相等，从而得到恒等式。如「握手定理」：Σdeg(v) = 2|E|。

# 鸽巢原理的经典应用
# ① 367 人中必有 2 人生日相同（365 个盒子）
# ② 任意 6 人中必有 3 人互相认识或 3 人互相不认识（拉姆齐 R(3,3)=6）
# ③ 哈希表：n+1 个 key 放入 n 个桶，必有碰撞
# ④ 任意长度为 n²+1 的实数序列，必含长度 n+1 的单调子序列（Erdős–Szekeres）
# ⑤ 抽屉原理推广：把 m 个物体放入 n 个盒子，必有一盒含 ≥ ⌈m/n⌉ 个

⑤ 反证与归谬的区别，以及常见逻辑谬误

谬误形式为何错
肯定后件p→q，q ⟹ p下雨地湿，但地湿可能是洒水
否定前件p→q，¬p ⟹ ¬q不下雨地也可能湿
循环论证用结论证明前提「《圣经》是真的，因为上帝不会说谎」
以偏概全几个例子 ⟹ 全体需要穷举或演绎，举例只能证「存在」
等价混淆把「必要」当「充分」n 是素数需 n>1，但 n>1 不保证是素数
循环论证在归纳法里也有对应陷阱：归纳步骤中若把「要证的 P(k+1)」偷偷当作已知使用，就变成了循环。检查方法：把归纳假设写清楚，确认只用了 P(k)（或更强归纳中的更小项）。

⑥ 算法正确性证明的实用模板

三种主流技术，对应不同的算法结构：

技术做法适用
循环不变式证明「初始成立、每轮保持、结束时给出结论」三件事迭代算法（插入排序、二分查找、Dijkstra）
数学归纳对递归深度或问题规模归纳递归/分治（归并排序、快速幂、DP）
交换论证把任意最优解逐步「改造」成算法输出而不变差贪心算法（活动选择、Huffman、分数背包）
def binary_search(a, x):
    """循环不变式：若 x 在 a 中，则必在 [lo, hi] 区间内"""
    lo, hi = 0, len(a) - 1
    while lo <= hi:                    # 不变式在每轮入口保持
        mid = (lo + hi) // 2
        if a[mid] == x: return mid
        elif a[mid] < x: lo = mid + 1  # 排除左半，x 若存在必在右半
        else:           hi = mid - 1   # 排除右半，x 若存在必在左半
    return -1                          # 区间为空 ⟹ x 不存在

# 不变式三要素：
# 初始化：lo=0, hi=n-1，全数组就是搜索范围 ✓
# 保持：每次排除的一半中不可能含 x（因为数组有序）✓
# 终止：区间为空 ⟹ 若 x 存在就会与不变式矛盾 ⟹ x 不存在 ✓

🎯 常见问法与答题要点

Q：什么情况下应该优先考虑反证法？

A：三个信号：① 结论是否定形式——「不存在…」「不是…」「无理数」；② 结论涉及唯一性——假设有两个，推出它们相等；③ 直接推导无从下手，但假设反面会立刻引发矛盾。经典例子：√2 无理、素数无穷、停机问题不可判定、不存在比较排序快于 O(n log n)。逻辑依据是逆否等值 p→q ≡ ¬q→¬p，所以「假设 p 且 ¬q 推出矛盾」即证明了 p→q。

Q：数学归纳法为什么是有效的证明方法？

A：依据自然数的良序性（或皮亚诺公理中的归纳公理）。直观理解是多米诺骨牌：奠基推倒第一块（P(n₀) 真），归纳步骤保证「第 k 块倒下必然带倒第 k+1 块」（P(k)→P(k+1)），于是全部倒下。反证视角：若存在不成立的 n，取最小的那个 m，则 m > n₀ 且 P(m−1) 成立，由归纳步骤 P(m) 也应成立——矛盾。关键：归纳步骤必须对「任意 k」成立，不能只对特例验证。

Q：普通归纳和强归纳有什么区别？什么时候必须用强归纳？

A：普通归纳只用 P(k) 推 P(k+1)；强归纳假设 P(n₀)…P(k)全部成立来推 P(k+1)。当 P(k+1) 依赖多个更小规模的子问题时必须用强归纳：如任意整数的素因子分解存在性（n 可分解为 a×b，a、b 都比 n 小但不等于 n−1）、归并排序复杂度（T(n) = 2T(n/2) + O(n)）、斐波那契相关性质。两者逻辑等价（可互相归约），只是书写便利。

Q：构造法和反例法分别用来证什么？

A：构造法证明存在性命题 ∃x P(x)——把那个 x 明确造出来并验证它满足 P（如「存在偶素数」构造出 2）。反例法否定全称命题 ∀x P(x)——只需找出一个反例即可推翻（如「所有素数都是奇数」的反例是 2）。注意二者的不对称性：证「存在」只需一个例子，证「对所有」却必须给出一般性论证，举再多例子也不构成证明（n²+n+41 在 n=0..39 都是素数，但 n=40 时不是）。

Q：鸽巢原理能证明什么？为什么它只证存在不给方法？

A：鸽巢原理（抽屉原理）：n+1 个物体放入 n 个盒子，必有一盒含至少 2 个；推广为 m 个物体放 n 个盒子，必有一盒含 ≥ ⌈m/n⌉ 个。它能证明的命题形如「必然存在某种配置」：367 人必有同生日、n+1 个 key 放入 n 个桶必有哈希碰撞、任意 6 人中必有 3 人互相认识或互不认识（R(3,3)=6）。它是非构造性的——只保证存在，不指出是哪一个、也不给寻找算法，这正是它与构造法的区别。

Q：循环不变式证明的三步是什么？

A：① 初始化：循环开始前不变式为真；② 保持：若某轮迭代开始前不变式为真，则该轮结束后它仍为真；③ 终止：循环结束时，不变式 + 终止条件共同推出期望的正确性结论。它与数学归纳法本质相同（初始化=奠基，保持=归纳步骤），是证明迭代算法（插入排序、二分查找、Dijkstra、KMP）正确性的标准工具。常见错误是只验证「保持」而忘记「终止」——那只能说明不变式一直成立，却没说明算法做对了什么。

Q：为什么「举很多例子」不能代替证明？

A：因为全称命题 ∀x P(x) 覆盖无限多个对象，有限个正例无论多少都无法排除反例的存在。经典反例：多项式 n² + n + 41 在 n = 0 到 39 时都给出素数，看似「恒为素数」，但 n = 40 时 40²+40+41 = 41² = 1681 不是素数。例子只能用于证「存在」（构造法）或否定「全称」（反例法），不能证「全称」。证明必须依赖定义与演绎推理，覆盖所有可能情形。

Q：贪心算法为什么常用「交换论证」来证明？

A：因为贪心算法缺少递归结构，归纳法不好直接套用。交换论证的思路：取任意一个最优解 OPT，逐步把它「改造」成贪心解 GREEDY，每一步修改都不降低解的优劣，且改造步数有限，于是最终得到「存在不劣于 OPT 的贪心解」，即贪心最优。典型应用：活动选择（每次选最早结束）、分数背包、Huffman 编码、最小生成树的 Kruskal/Prim（配合切割性质）。关键技巧是找到「第一个与贪心选择不同的位置」并证明可以安全替换。
