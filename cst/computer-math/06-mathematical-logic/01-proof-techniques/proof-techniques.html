证明方法

五种把“猜想”变成“定理”的武器：从正面推导到以退为进。

五种核心方法

直接证明

由前提 P 出发，经一连串逻辑推导直达 Q。最自然、最常用的方式。

反证法

假设结论不成立，推出矛盾，从而反证结论成立。

数学归纳法

证 base case，再证“若对 n 成立则对 n+1 成立”，从而对所有 n 成立。

构造性证明

不止说“存在”，还直接造出一个例子来。

举反例

要证“并非总是成立”，只需给出一个不成立的具体情形。

反证法的经典范例

√2 是无理数：假设 √2 = p/q（既约分数）。则 p² = 2q²，故 p 为偶数，设 p=2k，得 4k²=2q² → q²=2k²，q 也为偶数，与“既约”矛盾。

素数有无穷多个：假设只有有限个 p₁…pₙ，取 N = p₁p₂…pₙ + 1，它不被任一 pᵢ 整除，故要么本身是新素数，要么含新素因子——矛盾。

反证法像“先假装对手赢了，再证明这会导致规则崩溃”，于是对手必输。在算法里常用来证“不存在更优解”。

数学归纳法详解

归纳法分两步：基础步（n=1 成立）与归纳步（假设 n=k 成立，推出 n=k+1 成立）。第二归纳法还允许假设“所有小于 n 的都成立”。

例：前 n 个奇数之和 = n²。即 1 + 3 + … + (2n−1) = n²。

基础步 n=1: 左边=1，右边=1²=1，成立。
归纳步: 假设对 n=k 成立，即 1+…+(2k−1)=k²。
则对 n=k+1: 左边加上第 k+1 个奇数 (2k+1)，
得到 k² + (2k+1) = (k+1)²。证毕。

交互：逐步展开归纳证明

点击按钮，依次展示“前 n 个奇数和 = n²”的归纳结构，看清每一步在做什么。

待证命题：对任意正整数 n，1 + 3 + … + (2n−1) = n²。
基础步 (n=1)：左边 = 1，右边 = 1² = 1。1 = 1，命题在起点成立。这像多米诺的第一张骨牌被推倒。
归纳假设：假设对某个 k ≥ 1，命题成立，即 1 + 3 + … + (2k−1) = k²。
归纳步：考虑 n = k+1，在其和式末尾加上第 (k+1) 个奇数 (2k+1)：
1 + 3 + … + (2k−1) + (2k+1) = k² + (2k+1) = (k+1)²。
结论：基础步已立，归纳步把“k 成立”推到“k+1 成立”，故对所有正整数 n 成立。整排多米诺全部倒下。
