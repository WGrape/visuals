定位

IR 是什么，为什么必须有它

IR（Intermediate Representation，中间表示）是源代码与目标机器码之间的一种程序表示形式。前端把它生产出来，中端在它上面做优化，后端把它翻译成机器指令。

🌉
解耦
前端不必关心目标机器，后端不必关心源语言
♻️
复用
优化只写一次，所有语言与平台共享
🔬
易分析
结构比源码规整，便于数据流与控制流分析
好的 IR 有三个标准：① 表达力强，能承载各种语言特性；② 结构规整，便于分析变换；③ 与目标机器保持适当距离，不能太贴近某一种架构。

重点

SSA：为什么它这么重要

SSA（Static Single Assignment，静态单赋值）要求：每个变量在程序中只被赋值一次，每次使用都能唯一追溯到它的定义。

// 普通形式：x 被赋值两次，用到 x 时不确定是哪一次
x = 1;
if (cond) { x = 2; }
y = x + 1;      // x 是 1 还是 2？取决于运行时

// SSA 形式：每次赋值生成新版本
x1 = 1;
if (cond) { x2 = 2; }
x3 = φ(x1, x2);   // φ 函数按分支来源选择版本
y1 = x3 + 1;
φ（phi）函数是 SSA 的关键：当控制流合并（如 if 的两个分支汇合）时，用 φ 函数「挑选」来自不同路径的变量版本，从而保持单赋值约束。

面试问答

高频问题

Q1：什么是 IR，为什么编译器要用它？
IR 是源码与机器码之间的中间程序表示。用它解耦前端与后端，使「N 语言 × M 机器」变为「N + M」，并让优化只需实现一次即可被所有语言/平台复用。
Q2：AST 和 IR 是一回事吗？
不是。AST 是树形、贴近源语言语法、便于类型检查；IR 通常更线性、更接近机器模型，便于数据流分析与优化。前端先建 AST，再 lowering 成 IR。
Q3：什么是三地址码？
一种线性 IR，每条指令形如 x = y op z，最多包含三个地址（两个源、一个目的）。结构规整、便于分析，是中端优化的经典形式。
Q4：SSA 是什么？带来什么好处？
静态单赋值：每个变量只赋值一次，控制流汇合处用 φ 函数选择版本。好处是定义-使用关系唯一，常量传播、死代码消除、寄存器分配等优化算法大幅简化且更高效。
Q5：φ 函数的作用是什么？
在控制流合并点（如 if 两分支汇合）根据执行路径选择对应的变量版本，保证 SSA 的「单赋值」属性不被破坏。
Q6：Java 字节码是 SSA 吗？
不是。JVM 字节码是栈式指令（操作数栈），不是 SSA。SSA 通常出现在 JIT 编译器（如 HotSpot C2）或 LLVM 这类中端优化 IR 中。
